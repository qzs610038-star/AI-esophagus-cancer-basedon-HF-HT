# 部署方案目录索引

> 管理模式：仅本索引纳入 Git。  
> 复核日期：2026-08-09。  
> 同步范围：`main` 与所有新建工作树仅获得本文件；部署方案正文不参与服务器同步。

## 当前定位

本目录保存服务器部署、模型集成、数据预处理、离线加载、训练操作和历史排障等本机参考材料。它们用于人工查阅与本机维护，不是工作树的默认输入，也不应被整体复制到服务器。

## 当前权威边界

- 服务器路径的机器事实源是 `configs/server_paths.yaml`。
- 服务器与本地的日常代码、状态和小型结果交换仅使用 Gitee Git remote。
- 训练、服务器操作、结果导入和证据接纳仍受 `project_state/`、显式批准和 W### 工作树边界约束。

## 使用方式

1. 新工作树仅同步本索引，不同步部署方案正文。
2. 需要某项部署知识时，在受管方案或诊断记录中引用其标题与本机相对路径；不得把整份文档作为工作树依赖。
3. 可复用的部署规则、脚本或配置必须经过审核后迁入 `deploy/`、`configs/`、`project_state/` 或 active 治理文档。

## 写入边界

- 禁止提交部署方案正文、远程访问资料、历史排障记录、文献附件或导出文件。
- 本索引只记录目录用途、权威边界和同步规则；不承载具体服务器凭据、绝对路径快照或训练结论。
- 新增部署材料默认仅保存在本目录；如需成为当前规范，须先完成文档生命周期审核。
