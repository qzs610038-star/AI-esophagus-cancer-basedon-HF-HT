# 空间转录组评价指标与论文对比建议

> 日期：2026-08-23  
> 范围：PFMval Phase 2，H&E 图像预测 30 个空间 ssGSEA 通路分数  
> 数据分期：正式结论仅使用新 MPP2 七患者基线，即 6 名内部患者加 1 名 XZY 外部患者；旧三患者结果仅作历史背景  
> 证据策略：稳健双层口径——正式层只使用 `accepted` 证据，候选层列出需重新计算并接受后才能用于论文的指标  
> 本报告不批准新训练、不修改实验 Registry、不把探索性结果晋级为正式证据。

## 一、结论摘要

1. 空间转录组预测最常见的基础指标仍是 **PCC（Pearson Correlation Coefficient，皮尔逊相关系数）**和 **MSE（Mean Squared Error，均方误差）**。Beachum 进一步推荐 **CCC（Concordance Correlation Coefficient，一致性相关系数）**；Wang 的统一基准还使用 MI、JS-Div、NRMSE、SSIM 和 AUC。
2. PFMval 当前 accepted MPP2 基线的外部 XZY `pooled PCC=0.6549` 数值较亮眼，支持“模型捕获了整体相对趋势”；但该指标是把 `N×30` 展平后计算，不能和 Wang 的逐基因、逐图像再平均 PCC 直接比较。
3. 同一 accepted 基线的外部 `mean pathway raw R²=-0.0880`，说明绝对尺度重建仍不足。因此论文中不能只呈现 PCC，也不宜表述为“准确重建空间转录组”。更准确的表述是“预测了具有外部相关性的空间通路表型，但绝对幅度校准仍有限”。
4. 最值得补充、且公认度较高的指标组合是：**逐通路平均 PCC + 逐通路 CCC + patient-balanced z-RMSE/NRMSE + 逐通路 SSIM + 置信区间**。其中逐通路 PCC 和 CCC 最有希望形成对项目有利、又较难被审稿人质疑的补充证据。
5. 任何“小幅提升”都必须同时报告配对差值、改善通路比例、中位数、IQR（Interquartile Range，四分位距）和置信区间，不能只挑某个最有利的平均数。

## 二、LME1 文献指标提取（Literature Metric Extraction）

### 表 1：两篇论文中的常用评价指标

| 指标或评价维度 | 中文含义 | 主要回答的问题 | 论文中的地位 | 主要局限 |
|---|---|---|---|---|
| PCC / Pearson R | 皮尔逊相关系数 | 预测与真实值的线性趋势是否一致 | Beachum 称其为最常用指标之一；Wang 用作主要指标 | 不惩罚均值偏移和尺度偏差；低表达/低变异目标会使结果不稳定 |
| MSE / RMSE | 均方误差 / 均方根误差 | 绝对预测误差有多大 | Beachum：与 PCC 并列的常用指标 | 强依赖目标量纲，跨数据集不能直接比较 |
| NRMSE | 归一化均方根误差 | 不同量纲或数据集上的误差能否比较 | Wang Table 2 的统一基准指标 | 归一化分母必须固定；按极差归一化可能受异常值影响 |
| CCC | Lin 一致性相关系数 | 趋势、均值和尺度是否同时一致 | Beachum 明确建议作为比 PCC 更稳健的一致性指标 | 对异常值仍敏感；需要逐通路并报告分布 |
| MI | 互信息 | 是否存在不局限于线性的统计依赖 | Wang Table 2 | 估计依赖分箱或核参数，小样本时波动较大 |
| JS-Div | Jensen-Shannon 散度 | 预测和真实分布是否一致 | Wang Table 2 | 需要明确概率化和分箱方式；对连续通路分数不如 PCC/CCC 直观 |
| SSIM | 结构相似性指数 | 预测空间热图的强度、对比度和组织结构是否一致 | Wang Table 2；Beachum建议补充空间一致性 | 需要规则化网格、掩膜和统一缩放；处理不当会夸大相似性 |
| AUC | ROC 曲线下面积 | 能否区分零/非零或高/低表达 | Wang Table 2 | 对连续 ssGSEA 通路没有天然零点，阈值必须预注册 |
| well-predicted 数量 | 达到相关阈值且通过多重检验的基因/通路数量 | 有多少分子目标可稳定预测 | Beachum 提到常见做法如 `R>0.4` 加校正后 P 值 | 强烈受样本量、目标数量和模型架构影响，只宜作次要指标 |
| HVG/SVG 分层 | 高变异基因 / 空间变异基因子集 | 模型是否捕获真正有信息的信号而非被噪声稀释 | Wang 发现 HVG/SVG 上 PCC、SSIM通常更高 | 子集选择若使用外部测试集会产生选择偏差，必须标为描述性或预先锁定 |
| C-index / Log-rank P | 生存一致性指数 / 生存曲线检验 | 预测表达是否具有患者级临床价值 | Wang 的临床转化评价 | 需要独立临床终点和足够患者数；不适用于当前单一 XZY 外部患者 |
| 泛化与鲁棒性 | 跨队列、组织、分辨率和图像质量稳定性 | 换中心、换组织、换扫描质量后还能否工作 | Wang 的核心评价类别 | 不能由单个外部患者代表多中心泛化 |
| 可复现性与效率 | 代码可运行性、参数量、时间、峰值内存 | 方法能否实际复现和部署 | Wang 将可用性和计算效率纳入 28 项评价 | 必须计入基础模型特征提取成本，不能只报告轻量预测头 |

### 文献给出的关键纠偏

- Beachum 指出 PCC 和 MSE 虽常用，但单纯 PCC 会受到零表达、低表达和低变异目标影响；CCC 和空间一致性能够补足这一缺陷。
- Wang 在 11 个方法、5 类评价、28 项指标的统一基准中发现：不存在所有维度上的稳定赢家；复杂架构也不必然更好。
- Wang 的主要 ST 基准中，EGNv2 的平均结果为 `PCC=0.28、MI=0.06、SSIM=0.22、AUC=0.65`。这些数字只适用于其基因表达任务和聚合口径。
- Wang 报告多数方法在全基因上的平均相关性低于 `0.25`，并认为聚焦 HVG/SVG 往往更有生物意义。这支持本项目探索“高变异/空间变异通路”，但不允许直接把项目 pooled PCC 与这些结果作大小比较。

### 对项目结论是否有利的综合判断

项目现有指标支持的是一个“双重结论”，而不是单向的“效果很好”或“效果不好”：

> 模型在内部和单一外部患者上都捕获了较明显的总体相关结构；但逐通路绝对幅度恢复仍不足，跨患者、跨中心和空间结构的稳定性证据尚不完整。

因此：

- **有利之处**：accepted 外部 pooled PCC `0.6549`、内部 pooled PCC `0.7971`，以及 rejected 包中出现的逐通路 PCC/CCC线索，都说明预测并非随机，且存在可用于论文展示的通路排序或相对空间趋势。
- **不利之处**：external mean pathway raw R² 为负；LoRA、Huber和W007均未产生稳定、明确的总体提升。
- **最安全的论文策略**：把“相关结构恢复”和“绝对尺度恢复”拆成两个评价轴。前者可作为当前优势，后者应诚实列为局限和后续校准目标。

## 四、CFA3 可比性与有利性评估（Comparability and Favorability Assessment）

### 可以使用的表述

- “在冻结的 MPP2 七患者协议下，模型在独立 XZY 患者获得 `pooled PCC=0.6549`，表明预测通路表型与真实通路表型具有明显整体相关性。”
- “负的 mean pathway raw R² 表明相关趋势尚未转化为可靠的逐通路绝对幅度重建，因此本研究将相关性、一致性、误差和空间结构分开评价。”
- “在统一内部协议下，多种微调和损失改造仅产生小幅、方向混合的差异，冻结基础模型加轻量头仍是当前最稳健的基线。”

### 不能使用的表述

- “PFMval 的 `0.6549` 高于 Wang 的 `0.28`，所以优于 EGNv2。”
- “模型已经准确重建空间转录组。”
- “Huber 有 `17/30` 通路改善，因此总体优于 MSE。”
- “W007 某一外部指标略好，因此新结构已稳定提升。”

原因是任务目标不同（30 个 ssGSEA 通路 vs 数百个基因）、聚合口径不同、患者和数据划分不同，而且外部 XZY 仅一名患者。

## 五、MER4 指标扩展建议（Metric Extension Recommendation）

### 表 3：推荐新增指标、优先级和预期价值

| 优先级 | 推荐指标 | 公认度 | 对项目潜在价值 | 所需数据与正式计算要求 |
|---|---|---:|---|---|
| P0 | patient-balanced mean per-pathway PCC | 很高 | 避免 pooled PCC 受通路间尺度结构影响；更接近 Wang 的基因级聚合逻辑；现有线索约 `0.519` | 对每名患者、每条通路计算 PCC，再以 Fisher-z 或预注册等权方式汇总；内部按患者 bootstrap，XZY按空间块 bootstrap |
| P0 | mean per-pathway CCC | 高 | 同时奖励相关性、均值和尺度一致；Beachum明确推荐；现有线索约 `0.399` | 逐患者逐通路计算并报告均值、中位数、IQR、最差通路及置信区间 |
| P0 | patient-balanced z-RMSE / NRMSE | 很高 | 与 PCC/CCC形成“趋势+误差”组合；Wang使用NRMSE | 归一化参数只能来自训练集；预注册分母，避免用外部极差调尺度 |
| P0 | per-pathway SSIM | 高 | 如果模型空间形态比绝对值更可靠，SSIM可能比R²更能体现优势；与Wang直接接轨 | 由 `spot_id` 坐标重建带组织掩膜的固定网格；真实与预测必须共用训练期锁定的缩放规则 |
| P0 | 配对效应量与95%置信区间 | 很高 | 即使平均提升很小，也能展示改善是否稳定；防止单点 headline 误导 | 报告每通路 ΔPCC/ΔCCC/ΔSSIM 的中位数、IQR、改善比例和空间块 bootstrap CI |
| P1 | HVP/SVP 子集指标 | 高 | 对标 Wang 的 HVG/SVG 思路，减少低变异、低空间信号通路稀释；可能最有利于显示生物学信号 | HVP（Highly Variable Pathway，高变异通路）和 SVP（Spatially Variable Pathway，空间变异通路）必须仅用训练/内部真实值预定义并冻结；XZY后验选择只能标为描述性 |
| P1 | well-predicted pathway 数量与比例 | 中高 | 可直接回答“30条通路中有多少可可靠预测”，展示性强 | 预注册如 `PCC>0.4`，并使用 BH-FDR（Benjamini-Hochberg False Discovery Rate，多重检验校正）；只作次指标 |
| P1 | Spearman 相关 | 高 | 若模型保持通路活动排序但尺度不准，可能优于PCC/R² | 逐患者、逐通路计算；与PCC并列报告，不能替代绝对误差 |
| P1 | MI 与 JS-Div | 中高 | 补充非线性依赖和分布一致性；与Wang Table 2一致 | 固定分箱或核估计参数；在内部数据预注册后再看XZY |
| P1 | 参数量、训练时间、峰值显存 | 高 | 冻结 UNI2-h 加轻量头可能在可训练参数和训练成本上有优势 | 必须同时计入一次性特征提取时间、显存和缓存成本，报告硬件环境 |
| P2 | AUC | 中高 | 可展示高/低通路活动识别能力 | 连续 ssGSEA 没有天然零点；只能用训练集定义并冻结临床或分位数阈值 |
| P2 | Moran’s I 保持度 / 空间交叉相关 | 高（空间领域） | 直接评价空间自相关是否被保留，可补足PCC和SSIM | 预注册邻接图、距离阈值和掩膜；报告真实与预测 Moran’s I 差值 |
| P2 | 空间区域恢复（ARI/NMI） | 中高 | 衡量预测通路能否恢复真实组织分区 | 需要独立区域标签或仅从内部数据冻结的聚类协议 |
| P2 | C-index / Log-rank P | 高（临床领域） | 可证明预测通路的患者级转化价值 | 当前 XZY 单患者不可计算；应留给具有独立临床终点的 Phase 3 队列 |

## 六、建议用于论文的指标层级

### 主指标

1. patient-balanced mean per-pathway PCC；
2. patient-balanced mean per-pathway CCC；
3. patient-balanced z-RMSE/NRMSE；
4. per-pathway SSIM；
5. 所有主指标的患者级或空间块 bootstrap 95% CI。

### 支持性指标

1. legacy pooled PCC，用于与项目既有 accepted 结果兼容；
2. raw MAE、mean pathway raw R²；
3. HVP/SVP 子集的 PCC、CCC、SSIM；
4. well-predicted pathway 比例、Spearman、MI、JS-Div；
5. 训练效率与可复现性。

### 统计与防止选择性报告规则

- 主指标和方向在查看新实验外部结果前预注册。
- 所有 30 条通路均需提供结果分布；不能只展示改善通路。
- 多重通路检验使用 BH-FDR。
- 内部六患者优先做患者级 bootstrap 或 leave-one-patient-out；XZY 只有一名患者，只能做空间块 bootstrap，且该区间不能解释为跨患者置信区间。
- 同时报告 pooled、逐通路、逐患者口径，并在表头写清聚合顺序。
- 外部 XZY不得参与 z-score 拟合、阈值选择、指标选择或 checkpoint 选择。

## 七、最终审计判定

**总体判定：CONDITIONAL GO（有条件可用于论文指标框架）。**

满足以下边界时，可以使用当前 accepted 指标撰写论文结果：

1. 把 `pooled PCC=0.6549` 明确标为 `N×30` 展平后的项目兼容口径；
2. 同时披露 `mean pathway raw R²=-0.0880` 和误差指标；
3. 不与 Wang 的 `PCC=0.28` 进行数值优越性比较；
4. Ridge rejected 包中的逐通路 PCC、CCC只作为候选线索；
5. 新增 PCC/CCC/SSIM/NRMSE 等指标必须基于 accepted 预测文件按预注册方案重新计算、审核并接受后，才能成为正式论文成绩。

本报告不对新实验、重新计算、结果晋级或 Phase 3 决策作 GO/NO-GO 授权。
