## 1. 一句话决策摘要

建议把 accepted MPP2 冻结基线当作一把已经校准但仍存在系统误差的“旧尺子”，不重做整把尺子，而是在它旁边增加一个很小的残差修正器；再用严格匹配的三种训练方式判断：无对比残差新协议是否有效、普通硬配对对比是否提供增量，以及更符合连续 ssGSEA 生物学结构的“连续通路几何软对比”是否再提供增量。

首轮内部批次固定为四臂：

1. FBR：复放 accepted 冻结基线，不训练；
2. RCC：只训练残差修正器，作为同一新训练/选择协议下的无对比对照；
3. HCR：加入普通一对一硬配对对比损失；
4. CPGCR：在同一完整批内候选上加入连续通路几何软对比损失。

四臂必须使用相同数据合同、相同图像端推理结构、相同随机种子和训练预算。每臂仅用 internal validation 选择并冻结 checkpoint，随后快速执行一次 XZY 外部推理。四臂及其超参数必须在第一次 XZY 推理前全部预登记；任何逐臂 XZY 结果不得触发后续臂增删、改序、调参、重选 checkpoint 或重跑。四臂完成后统一进行内部—外部归因分析。

## 2. 当前事实、动机与证据边界

### 2.1 Accepted MPP2 基线

当前 accepted（已接纳）基线为 `mpp2_barcode_repair_v003_frozen_baseline_20260711`：

- 输入：冻结的 UNI2-h 病理图像特征；每个 spot 使用 1536 维 CLS 表征；
- 预测头：`1536 → 1024 → 30` 两层 MLP（Multi-Layer Perceptron，多层感知机）；
- 目标：30 维、由训练集参数标准化后的 ssGSEA 通路分数；
- 训练患者：HYZ15040、JFX、LMZ12939、TGC、XSL、ZHZ；
- 内部 checkpoint 选择：固定 manifest 的 internal validation，最小 val loss；
- 随机种子：42；最佳 epoch：15；
- internal-val PCC：0.7971；internal-val loss：0.374886；
- external XZY pooled PCC：0.6549；raw MAE：1176.2114；mean raw R²：-0.088。

这里的 PCC（Pearson Correlation Coefficient，皮尔逊相关系数）较好，说明预测能跟随总体升降趋势；但 raw R² 为负，说明绝对数值的均值、幅度或条件偏差仍然严重。通俗地说，模型“知道哪些 spot 大致更高”，但“高多少、低多少”仍不准。

### 2.2 已经被削弱或否定的简单路线

- MPP2 LoRA r=8 的外部 PCC 只有约 +0.0019 变化，30 条通路中仅 4 条改善，并且 6/6 内部患者的 MAE 均未改善；
- LoRA dropout=0.10 探索仍未形成稳定提升；
- Huber 损失相对同合同 MSE 对照的 external XZY PCC 下降约 0.0022；
- 逐通路 Ridge 仿射校准未改善 external raw R²/MAE，正式结果为失败。

这些结果不证明所有表示学习都无效，但说明只调 backbone（主干网络）、只换回归损失或只做全局线性校准，暂时没有解决当前核心问题。

### 2.3 Diagnostic-only 机制线索

已有空间诊断属于 `diagnostic_only`，不能升级为 accepted 结论，但可以用于提出假设：

- 7 名患者、11,589 个 spot、30 条通路中，内部 6 名患者的 30/30 通路均呈正空间自相关；
- XZY 上预测总体比真实值略欠平滑，21/30 条通路的预测 Moran's I 低于真值；同时误差仍呈显著空间聚集；

### 4.3 PEaRL

PEaRL 的原始设计是：ssGSEA 通路经过 Transformer 编码，图像经过 UNI 编码，使用 CLIP-style（类似 CLIP 的双向跨模态匹配）硬配对对比损失；随后冻结表示，训练 MLP 回归通路和基因。

本项目借鉴“图像—通路跨模态对齐”和 image-only 推理；但不照搬 Transformer、在线 UNI 微调和两阶段大模型训练。原因是本项目只有 30 条通路，且首要目标是最低改动地检验对比机制。PEaRL 的 pathway-only 消融也不能单独证明对比损失的因果收益，因此本方案专门增加 RCC 与 HCR/CPGCR 的同结构对照。

论文链接：[PEaRL](https://arxiv.org/html/2510.03455)

### 4.4 DeepPathway

DeepPathway 的原始思想是用图像和 UCell 通路分数进行双模态对齐，推理时直接回归通路。其官方仓库同时存在基于模态内相似度构造 soft target（软目标）的 `BLEEPOnly`，以及身份硬目标的 `BLEEPWithOptimus`；最终 `DeepPathway` 类使用后者。因此，软目标是值得测试的设计来源，但不能当作已经被最终模型完全证明的结论。

本项目把该思想改造成“真实 30 维 ssGSEA 的连续几何软标签”，并要求它与普通硬配对 HCR 直接比较。

论文链接：[DeepPathway 预印本](https://www.biorxiv.org/content/10.1101/2025.07.21.665956v1)；代码链接：[DeepPathway models.py](https://github.com/aahsan045/DeepPathway/blob/main/models.py)

### 4.5 Reg2ST

## 5. 核心模型设计

### 5.1 冻结基线加零起点残差

对 spot `i`，已有 UNI2-h 缓存特征记为 `f_i ∈ R^1536`，真实训练目标记为 `y_i ∈ R^30`。accepted 基线头为冻结函数 `B(·)`：

```text
b_i = B(f_i)                         # accepted MPP2 的30维基线预测
h_i = P_img(f_i)                     # 新的256维图像表示
δ_i = R(h_i)                         # 30维残差修正
ŷ_i = b_i + δ_i                      # 最终预测
```

`P_img` 是 image projector（图像投影器），建议结构固定为 `Linear(1536,256) → GELU`；`R` 为 `Linear(256,30)` 残差头，其权重和偏置零初始化。首轮不在新投影器内增加 Dropout，以减少与对比路径不同随机数消耗造成的匹配误差。零初始化使所有新模型在训练开始时严格退化为 accepted B0，避免初始随机残差破坏基线。

“冻结 B0”不仅指参数不更新，还必须固定其运行行为：全部 B0 参数设置 `requires_grad_(False)`，优化器不得包含 B0；复合模型即使处于训练模式，B0 仍强制保持 `eval()`，并在 `torch.no_grad()` 下前向。否则原 MLP 中的 `Dropout(0.3)` 会在训练态随机改变 B0 输出，破坏 accepted 锚点和零起点等价性。

不在图像投影器中加入 LayerNorm（层归一化），因为现有 MPP2 已明确避免其压缩回归动态范围；用于对比相似度的副本再单独做 L2 normalize（长度归一化），不影响残差分支保留幅值信息。

### 5.2 通路编码器只在训练期存在

```text
g_i = P_path(y_i)                    # 30 → 256 的通路表示
z_i = normalize(h_i)
u_i = normalize(g_i)
```

`P_path` 建议为 `Linear(30,256) → GELU → Linear(256,256)`。它只负责提供训练期的分子模态教师信号；模型导出和推理时删除，因此未来预测新患者时不需要真实 ssGSEA。

### 5.3 绝对预测损失

所有可训练实验臂都使用相同的 patient-balanced z-MSE（患者等权标准化均方误差）：

```text
L_abs = mean_over_patients(mean_over_spots_and_pathways((ŷ - y)^2))
```

它先对每名患者内部求平均，再对患者求平均，防止 spot 多的患者主导模型；训练目标使用现有 train-only z-score，既关注绝对偏差，又不让原始尺度特别大的通路压倒其他通路。

### 5.4 HCR 的硬配对对比损失

HCR（Hard-Pair Contrastive Residual，硬配对对比残差）把同一 spot 的 `(z_i,u_i)` 视为唯一正样本，把 batch 中其他有效 spot 视为负样本，采用双向 InfoNCE（Noise-Contrastive Estimation，噪声对比估计）交叉熵。HCR 与 CPGCR 使用相同的完整批内候选集合；仅 padding（填充项）或缺失项可以被屏蔽。

不屏蔽同患者非对角项是一个有意的反捷径设计：若屏蔽后同一患者在候选集中只剩自身正样本，模型可能只凭患者染色/批次身份就找到正样本。保留其他同患者候选，会迫使 HCR 做 spot 级区分，也让 CPGCR 能按真实通路距离为同患者与跨患者样本共同赋软权重。

```text
S_ij = cosine(z_i, u_j) / τ_z
L_hard = 0.5 × [CE(S, identity) + CE(S^T, identity)]
L_total = L_abs + λ × L_hard
```

首批固定 `τ_z=0.07`、`λ=0.10`，不做搜索。该臂代表 PEaRL/CLIP 式普通一对一设计。

### 5.5 CPGCR 的连续几何软对比损失

CPGCR（Continuous Pathway-Geometry Contrastive Residual，连续通路几何软对比残差）不把世界简单分成“同一个 spot”和“所有其他 spot”。它先用真实 30 维训练目标构造通路距离：

```text
D_ij = mean_k((y_ik - y_jk)^2)
Q^(I→P) = row_softmax(-D / τ_y)
Q^(P→I) = row_softmax(-D^T / τ_y)
```

`Q` 是目标相似度分布：通路状态越接近，目标概率越高；完全不同的 spot 才是强负样本。`τ_y` 固定取**当前训练折**中跨患者成对距离的中位数。为让大患者不支配该统计，先等概率抽取 6 名患者构成的 15 个无序患者对，再在每个患者对内部抽 spot 对；seed=42，总计至多 100,000 对且各患者对尽量等额。该统计只在训练折拟合，不能读取 internal-val 或 XZY。

软目标的 batch 矩阵同时包含同患者和跨患者样本；这不表示默认把同患者样本都当正样本，而是让它们依据 30 维真实通路距离获得连续权重。患者均衡采样、防捷径诊断和后续真正的跨患者验证承担泛化控制。

随后用 `Q` 监督图像—通路相似度分布：

```text
P^(I→P) = row_softmax(S)
P^(P→I) = row_softmax(S^T)
L_soft = 0.5 × [H(Q^(I→P),P^(I→P)) + H(Q^(P→I),P^(P→I))]
L_total = L_abs + λ × L_soft
```

这里必须分别对两个方向按行归一化；不能把已经按行归一化的 `Q^(I→P)` 直接转置后当成反向概率分布。`H` 表示交叉熵。

这里的创新候选不是单独的“soft label”，而是以下组合：

- 连续 30 维 ssGSEA 几何作为软关系；
- 同患者和跨患者均按连续通路距离参与监督，并显式监测患者身份捷径；
- accepted B0 冻结锚点与零起点残差；
- image-only 推理合同；
- 以绝对分数指标而非单独 PCC 选择 checkpoint。

该组合能否称为正式方法创新，需要在定稿论文前再做系统文献查新；本方案只称其为“创新候选机制”。

## 6. 四臂实验合同

| 缩写 | 英文与中文全称 | 训练内容 | 对比损失 | 推理结构 | 要回答的问题 |
|---|---|---|---|---|---|
| FBR | Frozen Baseline Replay，冻结基线复放 | 不训练；复放 accepted B0 | 无 | accepted B0 | 新批次是否忠实复现基线 |
| RCC | Residual Capacity Control，残差容量对照 | 图像投影器 + 零起点残差头 | 无 | B0 + 同一残差分支 | 无对比的残差协议整体是否有效 |
| HCR | Hard-Pair Contrastive Residual，硬配对对比残差 | 与 RCC 相同的图像端；增加训练期通路编码器 | 完整批内一对一硬目标 | 与 RCC 相同 | 普通对比学习是否带来额外收益 |
| CPGCR | Continuous Pathway-Geometry Contrastive Residual，连续通路几何软对比残差 | 与 HCR 相同 | 同一候选集合上的连续软目标 | 与 RCC/HCR 相同 | 连续生物几何是否优于硬负样本假设 |

公平性固定项：

- 三个可训练臂具有完全相同的图像端推理参数量；
- RCC、HCR、CPGCR 使用同一套预登记患者均衡 batch 计划；HCR 与 CPGCR 使用相同完整候选集合，避免归因混杂；
- 每个 seed 先保存一份共享图像分支初始状态供三臂加载，并保存一份共享 pathway encoder 初始状态供 HCR/CPGCR 加载；DataLoader 与参数初始化使用独立命名随机数流；
- 相同 manifest、train-only z-score、batch 计划、优化器、学习率、epoch、early stopping 和 seed；新残差分支首轮不使用 Dropout；
- FBR 只复放 accepted 模型，不重新训练一个“近似基线”；
- HCR/CPGCR 多出的 pathway encoder 只在训练期使用，不计入部署端参数；这是教师信号差异，不是推理容量差异；
- 首批固定 seed=42；每个 batch 固定包含 6 名训练患者、每名 5 个 spot，总 batch size=30；Adam `lr=1e-4`、最多 50 epoch、patience=10、min_delta=`1e-4`；
- checkpoint 一律最小化 internal-val patient-balanced z-MSE；PCC 不参与提前停止。

需要注意：accepted FBR 的历史 checkpoint 是按既有普通逐 spot `val_loss` 选出的，不能重选；RCC/HCR/CPGCR 则按新的 patient-balanced z-MSE 选 checkpoint。因此 `RCC−FBR` 表示“残差容量 + 新选择协议”的整体增量，不能严格只归因为容量。对比学习的主要归因比较是同协议下的 `HCR−RCC`，连续软目标的主要归因比较是 `CPGCR−HCR`。

同一个 `λ=0.10` 也不保证硬目标与软目标具有完全相同的有效梯度强度。首批结论只能解释为“固定 λ 下两种目标形式的整体差异”；必须同时记录 `L_con/L_abs` 和对共享图像投影器的两项梯度范数比，不能把差异全部归因于目标几何。

### 7.4 可选患者留一法

未来若要做有效 LOPO，必须另立方案和预算：每一折都重新训练一个排除留出患者的 fold-specific B0（分折专用基线），并让该折的 FBR、RCC 和候选共用它；所有 z-score、`τ_y` 和训练期参数也只能用其余 5 名患者拟合。派生折定义不得覆盖受保护标准 manifest。为保持当前探索工程最小，本方案只把这一点列为后续方法学需求，不预注册六折训练。

## 8. 指标、模型选择与诊断

### 8.1 唯一 checkpoint 选择指标

**internal-val patient-balanced z-MSE 越低越好。**

该指标直接惩罚绝对偏差、对患者等权，并与现有训练集标准化合同一致。只允许用它确定每个 job 的 best checkpoint，不能在运行结束后改用 PCC、XZY 或 Phase 3 指标重选 epoch。

### 8.2 必须报告的预测指标

整体、逐患者和逐通路均需报告：

- patient-balanced z-MSE；
- z-MAE；
- raw MAE；
- mean per-pathway raw R²；
- pooled PCC 与 mean per-pathway PCC，二者不得混写；
- CCC（Concordance Correlation Coefficient，一致性相关系数，兼顾相关性与均值/尺度偏差）；
- calibration slope/intercept（校准斜率/截距）；
- 预测均值、标准差与真实值的差异。

### 8.3 必须报告的表示机制诊断

- paired retrieval rank：图像表示能否在 batch 中找到配对通路表示；
- cross-patient neighborhood purity：图像近邻是否对应相似通路，而不是只对应同患者；
- effective rank（有效秩，反映表示是否退化到少数维度）；
- 各维标准差、平均非对角余弦相似度，排查 representation collapse（表示塌缩，即所有样本被压成几乎同一个向量）；
- HCR 的 hard-negative false-negative rate：被当作负样本、但真实通路距离很近的比例；
- CPGCR 软目标熵、有效跨患者配对数及每批患者数。
- patient-ID shortcut probe（患者身份捷径探针）：用训练 embedding 的六患者质心对 internal-val embedding 做最近质心分类，报告患者均衡准确率（随机参考为 `1/6`）及 k=5 同患者近邻率；只作诊断，不参与 checkpoint 选择。

### 8.4 条件式空间诊断

空间 Moran's I、残差变差函数和局部误差图只在已有坐标能够按现有合同读取时运行，不为此修改受保护数据。空间诊断不参与首批 checkpoint 选择，只用于回答“绝对误差是否仍呈空间结构”。

## 9. 性能 WARN 判据与用户决策矩阵

依据 `DIR-20260806-001`，以下全部是 **WARN（性能提醒）**，不是自动停止、淘汰或晋级硬门。任何是否继续、多 seed 或外部确认的决定都由用户在看到完整批次后明确作出；有效 LOPO 需另立方案。

建议把下列组合视为“较强正信号”：

- CPGCR 相对 RCC 的 patient-balanced z-MSE 至少下降 5%；
- mean per-pathway raw R² 至少提高 0.03；
- raw MAE 至少下降 3%；
- pooled PCC 下降不超过 0.01，并优先期待持平或改善；
- mean per-pathway PCC 相对 RCC 的下降不超过 0.005；
- 6 名患者中至少 4 名的 patient-level raw MAE 相对 RCC 不恶化超过 1%，30 条通路中至少 18 条的 pathway-level raw MAE 相对 RCC 不恶化超过 1%；
- 没有表示塌缩，跨患者 retrieval 和通路邻域一致性同时改善。

上述“患者/通路不恶化”只按 raw MAE 和预登记的 1% 相对容差判定，默认比较 `CPGCR vs RCC`；不能在结果出来后改用更有利的 PCC、R² 或其他容差重新计数。它仍是 WARN 参考，不是统计非劣性检验。

判读矩阵：

| 完整内部批次现象 | 机制解释 | 建议，但不自动执行 |
|---|---|---|
| RCC > FBR，HCR≈CPGCR≈RCC | 提升来自无对比残差协议；其中容量与 checkpoint 协议不能由该差值进一步拆开 | 保留残差路线，停止把收益归因于对比学习 |
| HCR > RCC | 普通跨模态对齐具有增益 | 进入多 seed；再判断 CPGCR 是否额外有用 |
| CPGCR > HCR > RCC | 固定 λ 下连续通路几何目标具有增量候选价值 | 优先进入多 seed，并准备后续 pathway-query 扩展；LOPO 另立方案 |
| retrieval 明显改善，但 raw 指标不改善 | 表示学到了关系，绝对解码仍是瓶颈 | 后续考虑 pathway-query residual，不直接上 GNN |
| raw 指标改善，但残差 Moran's I 仍高 | 数值校准改善，空间条件误差仍在 | 候选冻结后再设计轻量空间模块 |
| 所有训练臂均不稳定或恶化 | 当前对比表示不适配或样本量不足 | 用户决定停止、改损失或接受风险继续；不得自动追加 sweep |

6. 实现逐样本原始预测和结果包输出。

输出：新工作树内代码、配置和结构化输出合同。  
停止点：不得在实现过程中试跑真实训练数据并据结果改方案。

### Local Minimal Verification（本地最小验证，LMV-6）

只做三类最简测试：

1. 零初始化残差时，RCC/HCR/CPGCR 输出与 FBR 一致；复合模型处于训练模式时，B0 连续两次输出仍完全一致并等于 accepted checkpoint 的 eval 输出，B0 无梯度且不在优化器中；
2. 两个方向的软目标均逐行和为 1，HCR/CPGCR 使用同一完整候选集合，温度只从训练折患者对等权样本获得；
3. `internal_only` 模式无法读取 XZY；`external_benchmark` 不能写 checkpoint、训练参数或模型状态；两种模式的预测表均具备 patient、spot、truth、prediction 和 split 字段。

不增加与本方案无关的防御性测试。  
输出：最小测试记录。  
停止点：任一合同测试失败均为 HARD FAIL。

### Gitee Dry-run and Compatibility Audit（Gitee非证据性试运行与兼容审计，GDCA-7）

操作：

1. 冻结本地 source commit；
2. 仅经 Gitee 同步到登记的服务器持久工作树；
3. 执行预登记的 dry-run、资产预检和最小前向；
4. 如需服务器兼容修改，服务器只返回诊断/patch，本地单写修复后形成新冻结 commit；
5. dry-run 不产生可比较结果，也不消耗正式实验结论。

输出：诊断记录、兼容状态和最终冻结 source commit。  
停止点：路径、资产、依赖、输出合同或 Git 绑定失败均为 HARD FAIL。

### Internal Batch Execution（内部批次执行，IBE-8）

建议初始批次：

| 顺序 | 实验臂 | seed | 评估范围 | 预算性质 |
|---:|---|---:|---|---|
| 1 | FBR | 42 | internal-val → 冻结 → XZY | 无训练复放 |
| 2 | RCC | 42 | internal-val → 冻结 → XZY | 1 个正式训练 attempt |
| 3 | HCR | 42 | internal-val → 冻结 → XZY | 1 个正式训练 attempt |
| 4 | CPGCR | 42 | internal-val → 冻结 → XZY | 1 个正式训练 attempt |

操作：

1. 在一份批量批准文件中预登记全部 job_id、attempt、顺序、预算和 source_commit；
2. 按固定顺序运行完整批次；
3. 中途性能只记录，不暂停、不改序、不补跑；
4. 每个作业先返回逐样本 internal-val 预测、checkpoint 指标、训练历史和表示诊断；
5. 冻结该臂 checkpoint 后立即执行一次 XZY 推理并回传逐样本外部预测；XZY 结果不得改变后续臂。

输出：四臂内部结果包及四臂 XZY 外部基准矩阵。  
停止点：没有批量批准文件不得运行；运行失败不得擅自重试。

### Unified Internal Analysis（统一内部分析，UIA-9）

操作：

1. 四臂全部通过结果合同后统一比较；
2. 先确认 FBR 复放，再比较 RCC−FBR、HCR−RCC、CPGCR−HCR 三个增量；
3. 按整体、患者、通路和表示机制四层报告；
4. 所有性能阈值只标记 WARN；
5. 把可观察结果与机制解释分开，不能因 CPGCR 更好就直接证明某个生物学因果机制。

输出：统一内部分析报告和供用户选择的决策表。  
停止点：由用户明确决定停止、补证、进入多 seed 或接受风险继续；LOPO 若需要则另起部署方案。

### Conditional Multi-Seed Confirmation（条件式多随机种子确认，CMSC-10）

仅在用户看过 UIA-9 后另行批准。建议只比较 RCC 和用户选定的一个对比候选，固定 `seed={1,42,61}`；若 seed 42 已在首批完成，则只新增尚未运行的种子，不重复消耗同合同 attempt。

本步骤不捆绑 LOPO。输出包括均值、标准差、最差 seed、逐患者/通路方向一致性；如需有效 LOPO，须采用分折专用 B0 并另立方案。  
停止点：无新批次批准时不执行。

### Four-Arm External Benchmark Matrix（四臂外部基准矩阵，FABM-11）

仅按第一次 XZY 推理前已经冻结的四臂合同执行：

1. FBR、RCC、HCR、CPGCR 均在各自 internal checkpoint 冻结后评估同一 external XZY；
2. 四臂使用同一 XZY 数据、逆 z-score 参数、指标代码和预测表合同；
3. 禁止看到任一臂 XZY 后修改温度、损失权重、epoch、候选结构、后续臂配置或重跑已完成臂；
4. 报告 pooled/mean pathway PCC、raw R²、raw MAE、CCC、患者内排序和空间残差；
5. 统一报告 `RCC−FBR`、`HCR−RCC`、`CPGCR−HCR` 的内部—外部方向一致性；
6. 明确 XZY 已被历史实验多次查看且本轮比较四臂，因此是“共享外部基准集”，不是完全未触碰的最终独立测试集。

输出：四臂外部基准矩阵与内部—外部归因表。  
停止点：XZY 表现不足或内外排序冲突只记 WARN，后续是否继续由用户决定；不得自动调参或重试。

### Result Import and User Decision（结果导入与用户决策，RIUD-12）

操作：

1. 结果先进入 inbox 并通过现有 result import；
2. 区分 accepted、explore、diagnostic、failed 和 pending_review；
3. 用户明确决定是否接纳、继续空间模块、转向 pathway-query、停止路线或保留阴性结论；
4. 只有接纳后才能更新长期稳定结论和后续论文材料；
5. 工作树关闭、保留或物理移除遵循另行批准，不在本方案中自动处理。

输出：可审计的结果生命周期与用户决策记录。

## 14. 主要风险、解释边界与回退方案

| 风险 | 为什么会发生 | 影响 | 预防/回退 |
|---|---|---|---|
| 假负样本 | HCR 把生物状态接近的其他 spot 当负样本 | 表示被迫分开，可能损害回归 | 由 CPGCR 软目标直接对照；报告假负率 |
| 患者身份捷径 | 染色、扫描和组织背景可能比通路更容易辨认 | internal-val 好但跨患者不稳 | 六患者均衡 batch；报告 embedding 的患者可预测性、同患者近邻率；有效 LOPO 另立方案 |
| 对比损失改善 PCC、损害绝对尺度 | 归一化表示更关注方向 | raw R²/MAE仍差 | 残差读取未归一化表示；以 z-MSE 选 checkpoint |
| 残差覆盖基线 | 新分支学出过大修正 | 稳定基线被破坏 | 零初始化、固定 B0、报告残差幅值；必要时用户批准后再讨论门控 |
| 小批次导致对比不稳 | batch=30 的候选数量有限 | seed 方差大 | 首批只作机制筛选；有信号后条件式多 seed |
| 软目标温度敏感 | `τ_y` 决定相似度分布尖锐程度 | 过平或过尖均会弱化学习 | 固定训练折中位数规则，不对 internal-val/XZY 搜索；报告目标熵 |
| 患者均衡导致小患者重复采样 | 各患者样本数不同 | 训练分布与原始 spot 分布不同 | 固定无放回队列和循环规则；同时报告样本级与患者级指标 |
| internal-val 与训练来自相同患者 | 不能充分代表新患者 | 泛化证据偏乐观 | 不把当前结果称为跨患者 LOPO；四臂使用同一 XZY 基准核对；有效 LOPO 使用分折 B0 另立方案 |
| XZY 历史与四臂复用 | 多次查看会形成研究者适应 | 外部独立性下降 | 第一次 XZY 前冻结四臂合同，禁止据 XZY 调参；如未来有新队列再做真正独立验证 |
| 方法创新性被夸大 | 相似的 soft contrastive 可能已有文献 | 论文表述风险 | 当前称创新候选；投稿前系统查新并精确限定贡献 |
| 复杂度过早膨胀 | 同时引入 query/GNN/dynamic graph | 无法判断哪部分有效 | 首批只做四臂；每次后续只增加一种机制 |

失败回退原则：

- 若 RCC 有效而对比无效，保留残差，不把收益包装为对比学习；
- 若表示诊断有效但绝对预测无效，下一步只讨论 pathway-query decoder（通路查询解码器）；
- 若绝对预测改善但空间残差仍明显，下一步才讨论轻量空间图；
- 若四臂无稳定信号，完整保留阴性结果，由用户决定停止或提出新的、单因素方案；
- 不在同一批准内临时增加温度、损失权重、隐藏维度、batch size 或更多模型 sweep（网格/批量搜索）。
