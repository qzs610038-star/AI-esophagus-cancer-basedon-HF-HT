## 已核验事实

1. 现行划分是 **六名患者内空间 block 约 10% 作 internal-val**（`block_size=672`），不是患者留出。当前 manifest 对每名患者仅暴露一套坐标且没有 `slice_id` 字段；这支持“manifest 中未区分第二切片”，但不能单独证明物理采集层面一人一张切片。train 与 val 的患者集合相同；当前清单中同一 `patient+patch_stem` 不跨 split；XZY 不在 manifest，checkpoint 冻结后评估一次。
2. 选模 / 早停信号是与训练共享患者身份的 internal `val_loss`。内部 val 的标签 z 接近 (0,1)；230/230 个 val block 与同患者 train block 四邻接。因此 **internal PCC≈0.80 不是新患者难度的无偏代理**。
3. z-score **只在 train 拟合**（`fit_split=train`，排除 internal_val / external_test / embargo）。val 与 XZY 只 transform。没有发现用 val/XZY 拟合。不必回到 CA2 修代码。
4. 冻结基线（accepted）：内部 PCC≈0.797，外部 XZY PCC≈0.655，raw R²≈−0.088。PCC 对仿射不敏感，R² 敏感；XZY 在 train-z 尺度上有均值偏移与预测振幅压缩，故 **PCC 尚可与 raw R² 为负可以同时成立**。
5. Huber / W007 / Ridge 在同一划分与同一 z-score 下没有把外部 PCC 带离约 0.65。Ridge 保持 `rejected`。
6. 当前源码、accepted 结果和可用资产未显示 CA2 六类一般性硬 Bug。训练绑定 split 的逐行内容尚未在本机恢复，因此 CA2-1 / CA2-3 对实际历史运行是条件性通过。现阶段可以停止把 0.65 **首先**归因于一般性硬 Bug，但不能写成所有历史输入已经逐行完整复核。

## 六折患者级 LOPO 具体设计

### BF1：基线合同冻结（Baseline Freeze 1）

用户于 2026-08-21 明确：本轮只检验 accepted repaired MPP2 baseline，不比较其他候选模型。模型架构、MSE 损失、优化器、学习率、patience、最大 epoch、30 通路、seed 和其余基础超参数均与 repaired baseline 保持一致；唯一变化是训练/内部验证患者划分及随之产生的 fold-specific train-only z-score。

六折之间不得根据上一折的 internal-val 或 XZY 结果修改模型合同。Huber、Ridge、W007、LoRA、新头和新超参数均不进入本轮。

### LS2：六折划分（LOPO Split 2）

六名患者各完整作为一次 internal-val；其余五名患者作为该折 train。internal-val 患者的全部 patch 不得进入训练或 z-score 拟合，但允许用于该折调优、early stopping 和最佳 checkpoint 选择。

| fold | internal-val 患者 | train 患者 |
|---|---|---|
| F1 | HYZ15040 | JFX、LMZ12939、TGC、XSL、ZHZ |
| F2 | JFX | HYZ15040、LMZ12939、TGC、XSL、ZHZ |
| F3 | LMZ12939 | HYZ15040、JFX、TGC、XSL、ZHZ |
| F4 | TGC | HYZ15040、JFX、LMZ12939、XSL、ZHZ |
| F5 | XSL | HYZ15040、JFX、LMZ12939、TGC、ZHZ |
| F6 | ZHZ | HYZ15040、JFX、LMZ12939、TGC、XSL |

这是确定性的六折 LOPO，不再增加内层空间 block，也不做五患者全量二次重训。新 fold manifest 和每折 z-score 必须写入新版本资产目录，旧生产资产只读保留；不得使用当前 in-repo 冲突旧 train CSV。

### FE3：折内训练与早停（Fold Training and Early Stopping 3）

每折直接执行一次训练：

1. z-score 只在五名 train 患者的全部训练标签上拟合。
2. internal-val 患者与 XZY 都只使用该折 train-only 参数 transform。
3. 五名 train 患者参与梯度更新；完整 internal-val 患者参与每个 epoch 的验证。
4. 默认沿用现行 `val_loss` 最小作为 early-stopping 和 checkpoint 选择信号；若要改用 PCC 或组合指标，必须在任何训练前统一冻结，不能逐折改变。
5. 到达 early stop 后冻结该折最佳 checkpoint；不使用 XZY loss、标签或指标选择 checkpoint。

由于同一个 internal-val 患者既用于 early stopping 又用于报告该折成绩，该成绩是**模型选择后的内部验证成绩**，不是无偏测试成绩。用户已明确接受其角色是模型调优与跨患者验证，不要求另加内层验证。

### XE4：折后 XZY 外测（XZY Evaluation 4）

每折最佳 checkpoint 冻结后，立即加载 XZY 做一次外部测试。XZY 必须满足：

- 不进入 optimizer、梯度、训练 loss、early stopping、checkpoint 选择或该折超参数修改。
- 使用该折五名 train 患者拟合的 z-score transform；预测与真值按同一套参数反变换到 raw ssGSEA。
- 完整保存逐 patch 预测、PCC、R²、MAE、均值偏差和预测/真实振幅比。
- 该折 XZY 结果可以在训练结束后展示，但不得反向改变后续 fold 的 baseline 合同或训练设置。

因此本轮 repaired baseline 共执行 `6` 次训练、`6` 次 internal-val 和 `6` 次 XZY eval；不再要求先完成全部六折才解封 XZY，也不要求额外训练一个全六患者 final model。

用户确认的隔离标准是**正在训练的模型不知道 XZY**。历史实验已经评估过 XZY，不视为本轮训练泄漏。本轮按“模型盲法外部测试”记录。

### BA5：六折基线汇总（Baseline Aggregation 5）

六折 internal-val 用于估计 repaired baseline 在患者级 LOPO 下的跨患者泛化：

- 主要汇总指标：六名 internal-val 患者各自 pooled PCC 的等患者权重均值。
- 同时报告：六折中位数、标准差、最差患者值，以及每患者 raw R²、raw MAE、z MAE、均值偏差和振幅比。
- 通路层：30 条通路在六名 internal-val 患者上的 PCC、R²、MAE 按患者等权汇总。
- XZY 六次成绩独立列为 external 描述，不参与 fold、checkpoint 或超参数选择。

不从六个 fold checkpoint 中挑选一个作为“最佳基础模型”。六个 checkpoint 的训练患者不同；它们共同构成对同一 repaired baseline 合同的六折评估，而不是六个候选模型。

相对旧 spatial-val/XZY 指标的变化继续按 `DIR-20260806-001` 作为 WARN 报告，不自动停止、淘汰或晋级。

### RP6：结果报告（Result Presentation 6）

本轮至少形成两张主表：

1. 六名 internal-val 患者逐折成绩和等权汇总，用于描述 baseline 的跨患者泛化。
2. 同六个 checkpoint 在 XZY 上的六次外测成绩及均值/离散度，用于描述模型对训练患者组合变化的外部稳定性。

XZY 的六次结果不是六个独立外部患者，不能把 `n=6 checkpoint` 写成 `n=6 external cohort`。它们共享同一个 XZY，只反映六套五患者训练模型在同一外部患者上的变化。

## 已排除的其他选项（保留代价记录）

| 选项 | 可能换来什么 | 代价与边界 |
|---|---|---|
| 单次固定 5+1 患者留出 | 成本较低、可快速得到一个整患者验证结果 | 结论高度依赖被留出的单名患者；不采用 |
| 完整 nested patient CV | 超参数比较更严格 | 每个 outer fold 内再做五折患者留出，内层只剩四名患者且运行量显著增加；当前 frozen baseline 不采用 |
| 维持空间划分，只改报告口径 | 最低代价：停止把 0.80 写成可推广到新患者 | **不改变**选模乐观性；PCC 外部数字不会因此自己变好 |
| 新划分下按折重拟合 train-only z-score | 新 train 集合有自己的 (0,1) | 新资产；旧 manifest / params **只读保留**，不得覆盖 |
| 患者内相对标准化 / 排名 | 可能减弱跨患者位置项对 R² 的打击 | **改任务定义**（相对活性，不再是当前绝对 ssGSEA 尺度） |

历史 V3bis（MPP-3，5 训练 + ZHZ 整患者 val）仅为 `historical` 形态对照，不得锁定本讨论的协议。  
oracle「把预测均值对齐到 XZY 真值」使用了 XZY 标签，只说明位置偏差足以让 R² 变负；**禁止**当校准方法。
