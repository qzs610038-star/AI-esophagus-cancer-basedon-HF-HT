## 已核验事实

1. 现行划分是 **六名患者内空间 block 约 10% 作 internal-val**（`block_size=672`），不是患者留出。当前 manifest 对每名患者仅暴露一套坐标且没有 `slice_id` 字段；这支持“manifest 中未区分第二切片”，但不能单独证明物理采集层面一人一张切片。train 与 val 的患者集合相同；当前清单中同一 `patient+patch_stem` 不跨 split；XZY 不在 manifest，checkpoint 冻结后评估一次。
2. 选模 / 早停信号是与训练共享患者身份的 internal `val_loss`。内部 val 的标签 z 接近 (0,1)；230/230 个 val block 与同患者 train block 四邻接。因此 **internal PCC≈0.80 不是新患者难度的无偏代理**。
3. z-score **只在 train 拟合**（`fit_split=train`，排除 internal_val / external_test / embargo）。val 与 XZY 只 transform。没有发现用 val/XZY 拟合。不必回到 CA2 修代码。
4. 冻结基线（accepted）：内部 PCC≈0.797，外部 XZY PCC≈0.655，raw R²≈−0.088。PCC 对仿射不敏感，R² 敏感；XZY 在 train-z 尺度上有均值偏移与预测振幅压缩，故 **PCC 尚可与 raw R² 为负可以同时成立**。
5. Huber / W007 / Ridge 在同一划分与同一 z-score 下没有把外部 PCC 带离约 0.65。Ridge 保持 `rejected`。
6. 当前源码、accepted 结果和可用资产未显示 CA2 六类一般性硬 Bug。训练绑定 split 的逐行内容尚未在本机恢复，因此 CA2-1 / CA2-3 对实际历史运行是条件性通过。现阶段可以停止把 0.65 **首先**归因于一般性硬 Bug，但不能写成所有历史输入已经逐行完整复核。

## 六折患者级 LOPO 具体设计

### PF1：协议冻结（Protocol Freeze 1）

本轮只检验“患者级验证协议是否改变对泛化能力的判断”，因此模型侧保持 repaired MPP2 frozen baseline 的架构、MSE 目标、优化器和既有基础超参数，不同时引入 Huber、Ridge、W007、LoRA 或新头。训练 seed 固定为 `42`；六折开始后不得依据任一外层患者或 XZY 修改模型、损失、学习率、patience 或通路集合。

六折开始前必须冻结：患者清单、每折角色、内层空间划分生成规则、每折 z-score 规则、epoch 上限、early-stopping 规则、指标公式、失败处理、输出文件和 XZY 解封条件。

### OS2：外层划分（Outer Split 2）

六名训练患者各完整留出一次；外层留出患者的全部 patch 不得进入训练、内层验证、z-score 拟合或 checkpoint 选择。

| 外层 fold | outer-val 患者 | outer-train 患者 |
|---|---|---|
| F1 | HYZ15040 | JFX、LMZ12939、TGC、XSL、ZHZ |
| F2 | JFX | HYZ15040、LMZ12939、TGC、XSL、ZHZ |
| F3 | LMZ12939 | HYZ15040、JFX、TGC、XSL、ZHZ |
| F4 | TGC | HYZ15040、JFX、LMZ12939、XSL、ZHZ |
| F5 | XSL | HYZ15040、JFX、LMZ12939、TGC、ZHZ |
| F6 | ZHZ | HYZ15040、JFX、LMZ12939、TGC、XSL |

这是一轮确定性的六折 LOPO，不通过随机抽患者制造“重复折”。fold 顺序只用于编号，不表示优先级或筛选顺序。

### IS3：内层选模（Inner Selection 3）

outer-val 患者保持完全封存。仅在每折的五名 outer-train 患者内部，按冻结的空间 block 规则划出约 10% `inner_val`，用于 early stopping 和选择该折训练 epoch `E_f`。

每折内层 z-score 必须只在 `inner_train` patch 上拟合；`inner_val` 只 transform。不得先用五名患者全部标签拟合 z-score 后再评 inner-val。inner-val 的作用仅是训练控制，不作为新患者泛化结果。

本设计不默认采用完整 nested patient CV：完整嵌套将需要在每个 outer fold 内再做五次患者留出，成本显著增加，而且内层每次只剩四名患者。若用户以后要求无偏比较多个超参数合同，应另行升级为完整 nested CV；当前单一 frozen baseline 不需要用它扩大运行量。

### OR4：外层重训与验证（Outer Refit and Validation 4）

得到该折 `E_f` 后，从头初始化模型：

1. 使用该折五名 outer-train 患者的全部 patch 重新拟合一套 fold-specific train-only z-score。
2. 用全部 outer-train patch 固定训练 `E_f` 个 epoch；不再读取 inner-val，也不以 outer-val early stop。
3. checkpoint 固定后，仅评估一次该折完整 outer-val 患者。
4. 输出 outer-val 逐 patch 原始预测、z 空间预测、真值、患者/patch 身份、指标和该折 z-score provenance。

因此每折需要两次训练：一次内层选 epoch，一次五患者全量重训。六折内部阶段共 `6 × 2 = 12` 次训练。任何一折工程失败只记录并修复同一合同的工程问题；不得查看 XZY 决定是否重跑。

新 fold manifest、z-score 参数和标签必须写入新的版本化资产目录；旧生产 `split_manifest`、`zscore_params_from_train` 和标签 CSV 全部只读保留。正式生成这些受保护资产仍需另开获批任务，并核对 repaired 数据输入；不得使用当前 in-repo 冲突旧 train CSV。

### AF5：六折汇总与最终冻结（Aggregation and Freeze 5）

XZY 仍保持不可访问。六折全部返回并通过合同验证后，先汇总内部证据：

- 主要指标：六个 outer-val 患者各自 pooled PCC 的等患者权重均值；同时报告中位数、标准差和完整六患者值，不按 patch 数加权吞并患者差异。
- 次要指标：每患者 raw R²、raw MAE、z MAE、均值偏差和预测/真实振幅比。
- 通路指标：30 条通路分别在每个外层患者上的 PCC、R²、MAE，再按患者等权汇总；样本不足或常数导致的不可计算项必须显式列出。
- 对照边界：现行 spatial internal PCC≈0.797 只作“旧估计偏乐观程度”的背景，不与 LOPO 指标写成同一 estimator；历史 XZY≈0.655 不用于挑 fold、epoch 或规则。

提升性结果按 `DIR-20260806-001` 只记 WARN，不自动停止或晋级。六折分析交用户审核；只有用户决定进入外部确认后，才冻结最终合同。

最终模型使用全部六名患者：z-score 仅在六名患者的训练标签上拟合；最终训练 epoch 预先定义为六个 `E_f` 的中位数取最近整数（若恰为 `.5`，向上取整）。模型从头训练到该固定 epoch，不再使用 XZY 或额外验证集选 checkpoint。

### ET6：外部测试（External Test 6）

XZY 只在以下条件全部满足后解封：

1. 12 次内部训练和六折 outer-val 结果全部完成、回传并通过合同验证。
2. 六折汇总报告已交用户审核，用户明确决定继续外部确认。
3. 全六患者 z-score、最终 epoch、模型合同和最终 checkpoint 已冻结。
4. XZY 评估被登记为独立的 eval-only 步骤；不允许在其前后修改最终模型。

解封后只对**全六患者最终模型**评估一次 XZY，不把六个 fold 模型分别送入 XZY，也不使用 XZY 选择 ensemble、fold、epoch、截距或标准化。XZY 只使用全六患者 train-only z-score transform；预测与真值再按同一参数反变换到 raw ssGSEA，报告与 LOPO 相同的 PCC、R²、MAE、均值偏差和振幅指标。

若 XZY 结果不理想，只报告现象和风险，由用户决定是否结束路线；不得根据 XZY 回调超参数或重训同一协议。

必须如实限定：XZY 已在历史 MPP2、Huber、Ridge、W007 等实验中被多次评估，故它不再是全项目意义上的“从未见过外部测试集”。ET6 只能称为**本次冻结 LOPO 协议的一次性外部确认**。若论文需要强独立外部验证，仍需未来新增从未参与任何开发决策的患者队列。

### 运行量与停止点

| 阶段 | 训练/评估量 | 当前是否授权 |
|---|---:|---|
| 六折 inner selection | 6 次训练 | 否，仅讨论设计 |
| 六折 outer refit | 6 次训练 + 6 次 outer-val | 否，仅讨论设计 |
| 全六患者 final fit | 1 次训练 | 否，须先审核六折结果 |
| XZY external confirmation | 1 次 eval-only | 否，须另有用户明确决定 |

当前推荐总量是内部 `12` 次训练；通过内部审核后再做 `1` 次最终训练和 `1` 次 XZY eval-only。暂不增加多 seed；若要评估随机性，应另行预登记，不得看 XZY 后追加。

## 已排除的其他选项（保留代价记录）

| 选项 | 可能换来什么 | 代价与边界 |
|---|---|---|
| 单次固定 5+1 患者留出 | 成本较低、可快速得到一个整患者验证结果 | 结论高度依赖被留出的单名患者；不采用 |
| 完整 nested patient CV | 超参数比较更严格 | 每个 outer fold 内再做五折患者留出，内层只剩四名患者且运行量显著增加；当前 frozen baseline 不采用 |
| 维持空间划分，只改报告口径 | 最低代价：停止把 0.80 写成可推广到新患者 | **不改变**选模乐观性；PCC 外部数字不会因此自己变好 |
| 新划分下按折重拟合 train-only z-score | 新 train 集合有自己的 (0,1) | 新资产；旧 manifest / params **只读保留**，不得覆盖 |
| 患者内相对标准化 / 排名 | 可能减弱跨患者位置项对 R² 的打击 | **改任务定义**（相对活性，不再是当前绝对 ssGSEA 尺度） |

历史 V3bis（MPP-3，5 训练 + ZHZ 整患者 val）仅为 `historical` 形态对照，不得锁定本讨论的协议。  
oracle「把预测均值对齐到 XZY 真值」使用了 XZY 标签，只说明位置偏差足以让 R² 变负；**禁止**当校准方法。
