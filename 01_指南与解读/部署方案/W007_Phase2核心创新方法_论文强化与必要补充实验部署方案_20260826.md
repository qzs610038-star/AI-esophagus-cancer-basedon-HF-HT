## 0. 一句话决策摘要

W007 已经证明本项目真实实现并正式运行了“冻结基线零起点残差 + 跨模态对比监督 + 连续通路几何软目标”的四臂方案。本文不再要求 CPGCR 必须在 Phase 2 pooled PCC 上战胜极限性能方案，才允许作为核心创新方法；推荐把它定位为 **综合科研选择最优的 Phase 2 对比学习候选**：方法新颖性更强、与本领域前沿路线一致、当前性能未发生实质性下降，并能为 Phase 3 提供具有生物学结构的通路预测接口。

这里的“最优”不是“所有数值指标最高”，而是基于方法新颖性、生物学合理性、匹配消融完整性、性能可接受性和 Phase 3 接口价值作出的多维科研选择。论文必须使用 `selected contrastive candidate`（选定的对比学习候选）或 `methodologically preferred model`（方法学优选模型），不能写成 `best-performing model`（性能最佳模型）。

面向较高标准期刊，推荐采用严格的分级补证路线：

1. 先完成不新增训练的事实统一、完整指标复算、机制诊断和代码—公式映射；
2. 再用最小必要的 6 次新增训练完成 RCC/HCR/CPGCR 三随机种子验证；
3. 多随机种子不再以“PCC 必须提高”为成功条件，而以“性能不发生实质性退化 + 对比机制真实生效 + 结果可复现”为最低门；
4. 候选冻结后，优先通过严格配对的 Phase 3 下游实验检验其实际效用；
5. Phase 2 患者级 LOPO 与新鲜外部队列转为条件性增强证据，不在 Phase 3 之前默认消耗高预算；
6. 只有出现明显性能退化、机制未生效或 Phase 3 无效时，才重新评估核心方法定位。

## 1. 用户已经确认的目标与优先级

### 1.1 论文角色

W007 当前定位为 **Phase 2 核心创新方法**，不是普通补充消融，也不是只用于解释阴性结果的附录实验。Phase 2 的核心贡献主要承担“方法与通路表征创新”，Phase 3 承担主要下游预测效用验证。

### 1.2 资源原则

未来可以承担必要的新增训练，但按以下顺序控制预算：

- 先做能够复用现有 checkpoint、预测表和训练历史的无训练补证；
- 只执行决定论文主张是否成立的最低必要训练；
- 条件未满足时，损失 sweep（超参数扫描）、大型空间图模型、主干全面微调和大规模复现均延后；
- 不因为 XZY 的既有结果而选择新超参数、重选 checkpoint 或决定新增实验臂。

### 1.3 期刊标准

本文按较高标准期刊的最低审查问题设计证据链：

1. 方法是否与已有通路级或基因级对比学习清楚区分；
2. 提升是否来自连续通路几何，而不是新增容量、随机波动或损失尺度差异；
3. 结果是否在患者层面稳定，而不是由大量相关 spots 或单条通路放大；
4. 内部选择与外部验证是否严格隔离；
5. 方法是否具有可复现代码、预登记对照、完整负结果和机制证据。
6. Phase 2 候选是否在不依赖 Phase 3 反向选择的前提下冻结，并在 Phase 3 同一模型、同一切分、同一训练预算下接受配对检验。

### 2.4 Pending review（待审核）解释

以下目前只能作为机制假设，不能直接写成论文定论：

- RCC 的新增容量发生小样本过拟合；

## 3. 方法设计与论文创新边界

### 3.1 统一预测结构

对 spot `i`：

```text
f_i = frozen UNI2-h feature                         # 1536维冻结图像特征
b_i = B0(f_i)                                      # accepted 30维基线预测
h_i = P_img(f_i)                                   # 256维图像表示
delta_i = R(h_i)                                   # 30维残差
y_hat_i = b_i + delta_i                            # 最终预测
g_i = P_path(y_i)                                  # 训练期通路表示
```

预测端在 RCC、HCR、CPGCR 中完全一致；通路编码器只在 HCR/CPGCR 训练期使用，推理不需要真实 ssGSEA。

### 3.2 三层归因逻辑

| 比较 | 可以回答 | 不能单独回答 |
|---|---|---|
| RCC − FBR | 残差容量与新 checkpoint 协议的整体增量 | 不能称为纯容量效应 |
| HCR − RCC | 固定架构下普通硬配对对比监督的增量 | 不能证明连续几何有效 |
| CPGCR − HCR | 固定超参数下连续软目标相对硬目标的增量 | 损失梯度尺度不匹配时不能全部归因于几何形式 |

### 3.3 当前可主张的创新候选

候选创新不是“首次使用通路对比学习”，而是以下组合：

1. 用连续 30 维 ssGSEA 几何定义批内软关系，而不是把所有非配对 spots 一律视为强负样本；
2. 用 accepted B0 作为冻结锚点，以零起点残差限制新方法对已验证基线的扰动；
3. 将训练期跨模态对齐与部署期 image-only 直接回归结合；
4. 用 FBR/RCC/HCR/CPGCR 匹配消融，分离基线复放、残差容量、普通对比与连续几何；
5. 以患者均衡绝对误差为主选择指标，而不是仅优化或报告 pooled PCC。

### 3.4 “最优方案”的操作性定义

CPGCR 可以被选为最终 Phase 2 方法，但选择理由必须拆成五个维度：

| 维度 | 当前依据 | 允许结论 |
|---|---|---|
| 方法新颖性 | 连续通路几何软目标、零起点残差和 image-only 推理组合 | CPGCR 是最具方法创新性的候选 |
| 前沿一致性 | PEaRL、DeepPathway、BLEEP、mclSTExp 等均使用跨模态对比思想 | 选择对比学习具有明确领域背景 |
| 实验归因 | FBR/RCC/HCR/CPGCR 四臂匹配 | 能区分容量、普通对比和连续几何 |
| Phase 2 性能 | 各臂差异很小、指标方向混合，无明显全面退化 | 性能大体可比，不是性能赢家 |
| Phase 3 接口 | 输出仍为30维 image-only 通路预测 | 可冻结后进入下游效用评估 |

因此正文中推荐写“selected CPGCR as the final Phase 2 contrastive candidate”，并立即说明选择依据是方法与下游接口的综合权衡，而非单项 PCC 排名。

### 3.5 不能使用的论文表述

- “首次提出通路级对比学习”；
- “CPGCR 显著优于 FBR/RCC/HCR”；
- “连续软目标已经解决假负样本问题”；
- “冻结视觉表征的信息天花板已被证明”；
- “XZY 是完全独立、从未查看的外部测试集”；
- “1,078 个 internal spots 等价于 1,078 个独立统计样本”。
- “CPGCR 是四臂中所有性能指标最优的模型”；
- “因为对比学习是新方法，所以即使没有证据也必然优于传统方法”。

## 4. 总体执行路线与预算分级

```text
既有证据统一 + 代码/机制补证
  ↓
新增6次多随机种子训练
  ↓
性能是否处于预登记非劣范围，且对比机制真实生效？
  ├─ 否：只做有针对性的修订或重新评估方法定位
  └─ 是：冻结 CPGCR 为 Phase 2 最终候选
          ↓
        Phase 3 同期配对下游效用验证
          ├─ 有效：形成“方法创新 + 下游价值”主线
          └─ 无效：诚实报告 Phase 2 表征未转化为下游收益
                  ↓
        视期刊/数据条件决定是否补 Phase 2 LOPO 或新外部队列
```

| 优先级 | 内容 | 新训练 | 是否当前必要 | 启动条件 |
|---|---|---:|---|---|
| P0 | 证据统一、代码解析、完整复算、机制诊断 | 0 | **立即必要** | 本方案获批后先执行 |
| P1 | RCC/HCR/CPGCR 三随机种子 | 6 次 | **核心方法最低必要** | P0 未发现 HARD 问题 |
| P2 | Phase 3 冻结候选的同期配对下游验证 | 另立 Phase 3 预算 | **整篇论文主要效用证据** | P1 达到非劣与机制门 |
| P3 | 梯度平衡/损失尺度消融 | 条件式 | 条件必要 | P0/P1 证明尺度或梯度冲突影响归因 |
| P4 | fold-specific B0 的患者级验证 / 新鲜外部队列 | 较高 | 条件增强 | Phase 3 证据或审稿风险需要 |
| 延后 | GNN、完整主干微调、大规模超参扫描、Phase 3 反馈选择 | 高 | 当前不必要 | 另立研究问题与方案 |

### EBR-1 证据边界统一（Evidence Boundary Reconciliation）

#### 目标

#### 操作

1. 从 experiment Registry 提取四臂身份、source/return commit、样本数、指标和生命周期；
2. 从原始 prediction CSV 独立复算已登记指标；
3. 将每条陈述标为 `accepted`、`pending_review`、`diagnostic_only`、`historical` 或 `missing`；
4. 核对 W007 现场 branch、HEAD、dirty 状态与 workspace Registry；
5. 建立“可用于正文 / 仅补充材料 / 不能使用”的证据矩阵。

#### 输出

- W007 论文事实底表；
- W007 证据等级矩阵；
- 过期文档与状态漂移清单。

#### 停止点

发现 experiment/result/source identity 的 HARD 冲突时停止，不进入后续复算或训练。

### DCL-2 设计与代码逻辑重构（Design and Code Logic Reconstruction）

#### 目标

让方法设计、数学公式、真实代码和实验臂差异形成一一对应关系，为 Methods 写作和代码审查提供统一入口。

#### 操作

```text
protocol_v001.yaml

→ losses.py
```

每个模块记录：

- 四臂共享项与唯一变化项；

#### 输出

- 方法流程图；
- 公式—代码对应表；
- 四臂差异表；
- 论文级伪代码；
- 设计—实现缺口清单。

### NLR-3 新颖性版图复核（Novelty Landscape Review）

#### 目标

在论文定稿前重新确认 W007 相对通路级和跨模态对比方法的真实新颖性，避免使用“首次”或跨任务直接排名。

#### 最低文献集合

- PEaRL：pathway-enhanced ssGSEA 表示与跨模态对齐；
- DeepPathway：H&E 到 pathway expression 的对比学习直接预测；
- BLEEP：图像—表达双模态共享嵌入与参考库检索；
- mclSTExp：多层跨模态对比学习与表达预测；
- PathCLAST：通路图增强的多模态对比学习，但主要任务并非本项目的 30 维直接回归；
- 2026 年新增的病理—分子对齐、空间表达预测和 pathway prompting 工作。

#### 比较维度

- 任务：基因预测、通路预测、检索、聚类或下游结局；
- 推理：直接回归、参考库检索或分子提示；
- 标签：全基因、HVG、UCell、ssGSEA 或通路图；
- 训练：冻结特征、端到端微调、双编码器或残差对齐；
- 验证：spot 切分、patient-held-out、跨中心或跨癌种；
- 指标：pooled PCC、per-target PCC、CCC、MAE、R²和空间指标。

#### 输出

- 相关工作对照表；
- 可主张创新与不可主张创新清单；
- Introduction/Discussion 引用骨架。

### RER-4 既有结果再分析（Retrospective Evidence Reanalysis）

#### 目标

不新增训练，用现有原始预测补齐高标准期刊要求的性能、校准、异质性和不确定性表达。

#### 必算指标

- patient-balanced z-MSE；
- pooled z-MSE、z-MAE、raw MAE；
- pooled PCC 与 mean per-pathway PCC，严格分开；
- mean per-pathway raw R²；
- CCC（Concordance Correlation Coefficient，一致性相关系数）；
- calibration slope/intercept（校准斜率/截距）；
- 预测/真实均值差、标准差比和振幅压缩；
- 逐患者与逐通路配对差值；
- 每条通路对汇总增益的贡献度。

#### 不确定性原则

1. internal 的统计单位优先为患者，而不是 spot；
2. 只报告患者级配对效应、方向一致性和透明的描述性区间；
3. 若坐标完整且合同允许，可预登记空间 block bootstrap（空间块自助法）；否则不得用普通 spot bootstrap 制造过窄置信区间；
4. XZY 只有一名患者，只能给出该患者内部的描述，不形成“外部患者总体”的置信结论；
5. 不以多个指标中最好看的一个决定方法胜负。

#### 主比较顺序

1. `HCR − RCC`：普通对比监督增量；
2. `CPGCR − HCR`：连续软目标增量；
3. `CPGCR − RCC`：完整 CPGCR 对匹配容量对照的增量；
4. `RCC − FBR`：残差新协议相对 accepted 锚点的整体变化。

当前 seed 42 已经存在可用于“同期类似实验小幅比较”的透明事实：

| 同期比较 | 数值变化 | 可用于的论文含义 |
|---|---:|---|
| HCR vs RCC external pooled PCC | `+0.002224` | 普通对比监督在该外部患者上有很小 PCC 数值增益 |
| HCR vs RCC external raw MAE | `-2.509` | HCR 同时略微降低绝对误差 |
| CPGCR vs HCR internal patient-balanced z-MSE | `-0.000795`（约 `-0.21%`） | 连续软目标相对硬目标在内部主误差上略优 |
| CPGCR vs HCR external raw MAE | `-0.696`（约 `-0.06%`） | CPGCR 的外部绝对误差略优 |
| CPGCR vs HCR external mean pathway raw R² | `+0.002534` | CPGCR 的外部平均 R²略优，但不能忽略单通路主导问题 |
| CPGCR vs HCR external pooled PCC | `-0.001050` | 连续软目标并未同时提高 PCC，必须并列报告 |

这组比较允许写成“modest, metric-specific gains over matched contemporary controls”（相对匹配同期对照的小幅、指标特异性增益），不能写成总体显著优胜。

#### 输出

- 论文主结果表；
- 逐患者/逐通路补充表；
- 效应量森林图；
- 校准与振幅诊断图；
- 阴性结果与局部改善清单。

### MDP-5 机制诊断探针（Mechanism Diagnostic Probes）

#### 目标

利用既有 checkpoint 和冻结数据做前向/反向诊断，但不执行 optimizer step，不产生新的性能模型。

#### 必要探针

| 探针 | 回答的问题 | 论文用途 |
|---|---|---|
| paired retrieval top-k/MRR | 图像与对应通路是否真正对齐 | 区分表示改善与回归改善 |
| geometry Spearman | 图像距离是否反映真实通路距离 | 验证连续几何假设 |
| effective rank | 嵌入是否退化到少数方向 | 排查 representation collapse |
| mean off-diagonal cosine | 嵌入是否趋同 | 塌缩辅助证据 |
| patient-ID centroid/kNN | 模型是否优先编码患者身份 | 验证患者捷径假设 |
| HCR false-negative rate | 生物相近 spot 被当负样本的比例 | 支持硬目标局限 |
| CPGCR target entropy/effective neighbors | 软目标是否过尖或接近均匀 | 判断 `tau_y` 是否有效 |
| residual/base norm ratio | 残差是在微调还是重写基线 | 支持零起点残差解释 |
| gradient norm ratio | 对比/回归梯度相对强度 | 纠正“损失比例等于梯度比例” |
| gradient cosine | 两任务梯度是协同还是冲突 | 决定是否需要损失平衡 |

梯度诊断只在预先固定的训练 batch 上运行，不更新参数。建议同时检查初始化点和已保存 best checkpoint；结果生命周期为 `diagnostic_only`，在经过单独审核前不得自动晋级为 accepted 性能证据。

#### 输出

- 机制诊断表；
- 图像—通路几何图；
- 患者捷径图；
- 梯度范数与方向图；
- 现有归因报告的逐条保留/修正/撤回建议。

### MSV-6 多随机种子验证（Multi-Seed Validation）

#### 定位

这是把 W007 继续作为 Phase 2 核心方法的 **最低必要新增训练**。目标不是强迫 pooled PCC 高于极限性能方案，而是判断 CPGCR 是否能在不同随机初始化下保持可接受性能、稳定产生连续几何表征，并为 Phase 3 提供可复放的冻结输出。

#### 最小实验矩阵

| 臂 | seed 42 | seed 1 | seed 61 | 新增训练次数 |
|---|---:|---:|---:|---:|
| FBR | 既有确定性锚点 | 不重复 | 不重复 | 0 |
| RCC | 已完成 | 新增 | 新增 | 2 |
| HCR | 已完成 | 新增 | 新增 | 2 |
| CPGCR | 已完成 | 新增 | 新增 | 2 |
| 合计 | — | — | — | **6** |

#### 固定合同

- 每个 seed 内 RCC/HCR/CPGCR 共享图像端初始化；
- HCR/CPGCR 共享 pathway encoder 初始化；
- 三臂共享数据、batch plan、优化器、学习率、epoch、early stopping 和 checkpoint 指标；
- `tau_y` 只用训练折拟合；
- 主选择指标仍为 internal patient-balanced z-MSE；
- 不增加新的 λ、温度、投影维度或网络结构；
- 新 seed **不再评估 XZY**，避免继续把历史外部患者验证化；
- 完整回传训练历史、内部预测、checkpoint 和机制诊断字段。

#### 候选冻结门（Candidate Freeze Gate）

以下条件同时满足，即可把 CPGCR 冻结为 Phase 2 最终创新候选并进入 Phase 3；**不要求 pooled PCC 必须提高**：

1. 三 seed 训练均可复现，无崩溃、异常早停或合同偏离；
2. 相对 RCC，三 seed 平均 pooled PCC 的下降不超过 `0.01`；
3. 相对 RCC，三 seed 平均 patient-balanced z-MSE 与 raw MAE 的恶化均不超过 `1%`；
4. CPGCR 相对 HCR 至少在一个预登记的绝对误差指标或通路几何指标上，于 `2/3` seeds 方向一致；
5. 几何一致性、检索或有效邻居结构至少一项稳定改善，同时无明显表示塌缩或患者捷径增强；
6. 改善或非劣结论不由单一患者、单一 seed 或单一通路决定；
7. HCR 与 CPGCR 的梯度尺度差异已经量化并纳入解释。

其中 `PCC下降≤0.01` 和绝对误差恶化 `≤1%` 是论文叙事用的预登记容差，不是统计学非劣性检验。论文应写“performance remained comparable within the prespecified tolerance”，不得写“statistically non-inferior”，除非另有正式功效分析和非劣界值依据。

如果 CPGCR 同时取得小幅 PCC 或误差改善，可作为次要结果报告；如果 PCC 持平但通路几何改善并通过上述容差门，仍可作为方法学优选候选进入 Phase 3。

#### 停止规则

出现任一情况即停止自动进入 Phase 3：

- PCC、z-MSE 或 raw MAE 超过预登记可接受退化范围；
- 对比损失下降，但几何、检索和下游可用表征均未改善；
- 结果主要由单一通路、患者或 seed 决定；
- 患者捷径、塌缩或残差重写基线风险明显增加。

若 Phase 2 性能持平、机制改善，则不属于停止条件；这正是“方法创新优先、Phase 3 验证效用”的预期路径。只有性能明显退化且机制也不成立时，才必须重新讨论核心方法定位。

### GBA-7 梯度平衡消融（Gradient-Balanced Ablation）

#### 启动条件

本步骤不预先自动执行。仅在 MDP-5/MSV-6 发现以下任一现象时启动：

- 对比梯度范数相对回归梯度持续明显过大或过小；
- 两项梯度在共享图像投影器上持续负相关；
- CPGCR 软目标熵异常，导致有效监督接近 one-hot 或近似均匀；
- HCR/CPGCR 之间的差异主要可以由梯度尺度而不是目标几何解释。

#### 最小方案

只比较原始 `λ=0.1` 与一个在训练内预登记、根据初始化诊断确定的梯度匹配方案；不得做宽范围 sweep。候选方案优先采用：

```text
lambda_effective = lambda_base × stop_gradient(
    ||grad(L_abs)|| / (||grad(L_con)|| + epsilon)
)
```

具体是否采用固定一次性缩放或训练期动态缩放，必须在新的部署方案定版前决定；不得依据 XZY 结果选择。

#### 归因要求

- RCC 保持不变；
- HCR 与 CPGCR 使用同一平衡规则；
- 仍需保留硬目标与软目标的匹配比较；
- 如果平衡后 CPGCR 才改善，论文应表述为“连续几何需要梯度尺度校准”，不能把原 W007 直接写成成功结果。

### DUI-8 Phase 3 下游效用验证（Downstream Utility Integration）

#### 定位

这是修订后整篇论文的主要效用证据。Phase 2 负责提供具有通路几何结构的冻结预测，Phase 3 负责检验这种表征是否改善最终研究任务。Phase 3 不得用于反向选择 Phase 2 的 λ、温度、checkpoint 或实验臂。

#### 最小配对设计

在 Phase 3 中至少保留两个完全匹配的输入臂：

| Phase 3 输入臂 | 输入 | 目的 |
|---|---|---|
| P3-FBR | FBR 的30维通路预测 | 同期冻结基线接口 |
| P3-CPGCR | 冻结 CPGCR 的30维通路预测 | 核心创新候选接口 |

两臂必须使用相同 Phase 3 模型、患者切分、训练预算、随机种子、预处理、checkpoint 规则和评价指标。HCR 可作为补充臂；是否加入取决于预算和论文是否要继续区分硬/软对比的下游价值。

#### 冻结与防反馈规则

1. 在查看 Phase 3 结果前，根据 MSV-6 的候选冻结门确定 CPGCR；
2. Phase 3 结果只用于评价下游效用，不回写 Phase 2 配置；
3. Phase 3 患者切分必须按患者隔离，不能按 spot 随机拆分；
4. Phase 3 的主终点、次终点、统计单位和停止规则需另立部署方案；
5. 如果 P3-CPGCR 优于 P3-FBR，可形成“Phase 2 表征创新转化为下游收益”的主线；
6. 如果 Phase 3 未改善，则诚实报告对比表征未转化为最终任务收益，不回到 XZY 或 Phase 2 调参。

#### 论文表述目标

成功时推荐写：

> Although standalone Phase 2 pathway-prediction metrics remained comparable, the pathway-geometry-aware contrastive representation yielded improved downstream Phase 3 utility under a frozen, matched evaluation protocol.

这比强行要求 Phase 2 PCC 提升更符合本项目的实际研究主线，但前提是 Phase 3 确有经过独立配对验证的结果。

### CPV-9 跨患者验证（Cross-Patient Validation）

#### 定位

当前 internal-val 是六名患者内部的 spot 划分，不是患者留出验证。修订后，本步骤不在 Phase 3 之前默认执行；以下情况之一出现时再启动：期刊明确要求 Phase 2 独立患者泛化、Phase 3 本身没有严格患者隔离、或审稿前需要增强方法学证据。

#### 推荐设计

使用 6-fold LOPO（Leave-One-Patient-Out，患者留一法）：

1. 每折留出 1 名患者作为 outer test；
2. B0 必须在不含该患者的数据上重新训练，形成 fold-specific B0；
3. z-score、`tau_y`、batch plan 和所有训练统计只使用该折训练患者；
4. checkpoint 选择只使用剩余患者中的预登记 inner validation；
5. outer patient 不参与模型、超参数、checkpoint 或停止规则；
6. 每折运行 FBR、RCC、HCR、CPGCR，保持同一折内的初始化与容量公平性；
7. 汇总以患者为统计单位，报告六折完整结果和配对差值。

如果经过 MSV-6 后 HCR 已明确无额外信息，可由用户审核决定是否在 CPV 中保留 HCR；但若论文要主张“连续软目标优于硬目标”，HCR 必须保留。

#### 预算认识

完整单 seed 六折约包括：

- 6 个 fold-specific B0；
- 6 个 RCC；
- 6 个 HCR；
- 6 个 CPGCR；

合计约 24 个训练作业。该预算只有在 MSV-6 通过候选冻结门，且 Phase 3/期刊风险评估认为必要时才合理。三随机种子 LOPO 不作为第一轮默认要求。

#### 成功条件

- CPGCR 相对 RCC/HCR 的患者级效应方向在多数 outer patients 一致；
- 不是由单一患者决定总体均值；
- 关键误差、相关性和校准指标方向一致；
- 患者捷径诊断不恶化；
- 不依赖外部 XZY 选择任何配置。

### FEV-10 新鲜外部验证（Fresh External Validation）

#### 定位

XZY 已在历史实验中多次被查看，并在 W007 中比较四臂，只能作为共享外部 benchmark。新鲜 Phase 2 外部队列属于增强证据；如果整篇论文的主要泛化结论由严格隔离的 Phase 3 外部验证承担，本步骤可以延后，但不得声称 Phase 2 已完成多中心泛化。

#### 最低要求

- 优先多个患者，而不是单一新患者；
- 优先不同中心、批次或切片条件；
- 第一次解封前冻结候选模型、checkpoint、指标和统计计划；
- 只评估 MSV/CPV 已经选择并冻结的候选；
- 不根据新外部结果调参或重跑；
- 报告患者级分布、逐通路分布、校准和域偏移，而不是只报 pooled PCC。

如果短期内没有新外部队列，论文必须明确限制：现有外部证据来自一个历史复用患者，不能支持广义多中心结论。

### MNP-11 论文叙事包构建（Manuscript Narrative Package）

#### 启动条件

完成 P0 后可建立初稿结构；Methods/Results 的最终效果主张必须等待 MSV 和 Phase 3 配对证据冻结。CPV/FEV 是否进入正文取决于后续执行。正式论文排版和投稿文本仍等待作者提供目标期刊模板。

#### 推荐正文结构

1. **Introduction**：连续通路状态不适合简单 one-positive/all-negative 对比假设；现有方法与本任务边界；提出核心研究问题。
2. **Methods**：冻结 B0、零起点残差、患者均衡回归、HCR、CPGCR、四臂归因和无泄漏选择。
3. **Results 1**：FBR 复放和四臂公平性验证。
4. **Results 2**：多随机种子主结果与效应分布。
5. **Results 3**：表示几何、患者捷径、梯度冲突和残差机制。
6. **Results 4**：冻结 CPGCR 与 FBR 的 Phase 3 同期配对下游效用。
7. **Results 5（若执行）**：Phase 2 患者级或新外部泛化。
8. **Discussion**：连续几何的有效边界、阴性结果、域偏移、样本量与临床转化限制。

- Figure 2：公式—代码—数据流与无泄漏选择；
- Figure 3：三 seed 效应量、逐患者和逐通路分布；

#### 当前安全表述

> We developed a residual cross-modal alignment framework that uses continuous pathway geometry to replace the conventional one-positive/all-negative contrastive target while preserving an accepted frozen predictor as a zero-start anchor.

当前 Results 只能写：

> In the initial matched four-arm, single-seed experiment, no residual arm consistently outperformed the others across internal and external metrics; the observed differences were small and metric-dependent.

可以紧接着透明报告同期小幅比较：

> Relative to the matched RCC control, HCR showed a small numerical increase in external pooled PCC, whereas CPGCR modestly improved internal absolute error over HCR and achieved slightly lower external error; no arm dominated all metrics.

> We therefore selected CPGCR as the final Phase 2 candidate based on its pathway-aware contrastive design, matched ablation support, comparable predictive performance, and compatibility with the downstream Phase 3 interface, rather than on a single-metric performance ranking.

在补充证据通过前，不得把上述内容改写为“CPGCR was the best-performing model”或“CPGCR significantly improved PCC”。

## 10. 本方案的 GO / NO-GO 解释

### 当前部署判定

`CONDITIONAL GO`

允许：

- 继续审核并定版本方案；
- 定版后先开展 P0；
- P0 无 HARD 问题后，另行批准最小 P1 六次训练。
- P1 通过候选冻结门后，另立 Phase 3 配对效用部署方案。

暂不允许：

- 直接把 W007 写成已验证的性能创新；
- 用方法新颖性掩盖明显的预测性能退化或机制失效；
- 根据 XZY 追加超参数或模型；
- 用 Phase 3 结果反向调整 Phase 2；
- 自动启动任何训练或服务器操作。

### 核心方法保留条件

只要 MSV-6 通过候选冻结门，即“性能处于预登记可接受范围、机制诊断支持对比表征真实生效、无明显捷径或塌缩”，W007 就可以继续作为 Phase 2 核心创新候选，不要求 PCC 必须提高。

能否把它进一步写成整篇论文的有效创新，需要 DUI-8 的 Phase 3 配对结果决定：

- Phase 3 改善：形成“Phase 2 方法创新 + Phase 3 下游收益”的完整主线；
- Phase 3 持平：仍可写方法与机制创新，但效用表述必须保守；
- Phase 3 恶化：不能把 W007 写成有效的最终方案，只能保留为机制探索。

若 MSV-6 的 PCC 没有提高，但仍通过候选冻结门，不需要改变核心方法定位；推荐表述为：

> 一个在独立通路预测指标上保持可比性能、同时引入连续通路几何跨模态监督，并被预先冻结用于 Phase 3 下游效用检验的 Phase 2 创新方法。

只有 MSV-6 超出退化容差或机制证据失败时，才调整为：

> 一个具有明确生物学动机、实现完整、但在小样本与冻结特征条件下未显示稳定性能增益的严格四臂机制探索。

该调整不否定工程与实验价值，但会改变论文主创新承载方式。PCC 不提高本身不再构成调整定位的充分理由。
