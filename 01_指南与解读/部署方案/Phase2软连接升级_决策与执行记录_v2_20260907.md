## 二、已作出的设计决定及理由

| 决定 | 本轮内容 | 选择理由 | 主要风险/事后查什么 |
|---|---|---|---|
| 隐藏与关系维数 | h=256、z=256；输入1536，输出30 | 用户已选256；PEaRL/DeepPathway提供宽度起点 | 不保证最佳；回归欠拟合、h/z关系诊断可提示容量或目标问题 |
| 关系对齐位置 | L_rel经W_r回到W_h，h同时用于回归 | 让辅助监督有机会改善实际预测表征 | 关系头可能独自拟合；看回归增量与共享层梯度 |
| 通路表示 | 不新增可学习通路编码器 | 已有30维标签可直接构造教师关系 | 标签距离与生物学相似不完全等价；不等于双编码器不可用 |
| 主关系目标 | 保留截断软Q/P、三状态支持集 | 保留既有明确候选，先获得机制结果 | 有效中心不足、阈值偏差；稠密Q留为第一备选 |
| 双相似职责 | Q只看真实通路；空间边权看冻结x和坐标，消息用h | 不把形态相似自动当成通路一致 | 形态异质邻居可能被压低；看仅距离后续对照 |
| 空间参数化 | **从头训练直接B(256→30)，无W_v** | 减少65,536参数和一个独立映射，首轮规格更简单 | 与旧分解优化不同，不宣称训练等价或已优于v1.1 |
| 图结构 | 一跳局部有向图，固定边和权重 | 控制复杂度，明确推理可获得输入 | 无长程消息、验证图较稀疏；报告覆盖与修正量 |
| 验证路线 | 四臂配对、三个种子、内部先选 | 分离关系、空间及组合的实用增量 | 参数/正则化差异仍在，不能直接证明因果机制 |
| 扩展候选 | 稠密Q、RKD、RnC、双相似重权、旧空间分解均后置 | 每次针对一个有证据的问题 | 后续变更需新规格及单独配对比较，不自动扩大首轮 |

独立审阅记录：Luna子智能体建议首轮保留原空间分解，仅在导出时折叠，以减少相对旧规格的优化变化。主线采纳其“前向等价不等于训练等价”的限制，但选择直接B作为待审核的新首轮结构：v1.1尚无本轮结果，用户强调减少复杂度，故不为维持未运行的参数化而增加一层。该取舍是设计判断，非实证结论；它已进入关键审核二，旧分解保留后续独立对照。

另一次只读审阅帮助补齐了平分MSE聚合、无正式终点时不得回退、随机清单和源码快照。审阅建议不构成用户批准；batch、lambda、阈值等仍归“智能体定值”。

## 三、未经逐项人工复核的默认值已经固定

以下是实施清单，不要求用户再逐行审批；公式细节以v2.0部署方案为准。改变其中会影响学习问题或可比性的值，需要记录新版本并回到相应关键审核点。

| 项目 | 固定值/口径 | 出处与性质 |
|---|---|---|
| 共享/关系层 | GELU精确形式；W_h/W_o有偏置，W_r无偏置；z归一化eps=1e-12 | 沿用主架构并补齐数值实现 |
| 中心读出 | Dropout=0.3，仅中心读出使用；辅助分支读Dropout前h | 沿用v1.1；非最优值证明 |
| 空间读出 | B无偏置、全零初始，256→30 | v2新选择，关键审核二覆盖 |
| 距离 | 30个训练标准化分量的均方差；不再平方、不换余弦 | 沿用v1.1；各通路等权假设 |
| 阈值抽样 | 200,000非自身有序训练点对，有放回；PCG64 seed20260907；q10/q50线性分位数 | 工程初值；点对和阈值保存 |
| 支持集 | 批内近8、远32；其余及自身忽略；无近或无远跳过该中心关系项 | 截断候选；记录有效率 |
| 温度 | tau_y=1.0，tau_z=0.1 | 沿用v1.1，未经本项目调优 |
| 关系归约 | 对有效中心求软交叉熵均值；整批无有效中心时为0并记数 | 不能按全batch替换归约 |
| 空间范围 | 同slide/split，半径1.5s，最多8，身份并列排序，不对称化 | 工程初值，图像边界限制 |
| 图权重 | 距离因子exp(-rho²/2)，形态因子exp((cos−1)/0.2)，中心保留分母加1 | 固定先验；不是已学可靠性 |
| MSE | 全中心×30分量均值；不用患者平衡MSE | 保持新四臂共同目标 |
| 中心采样 | 每轮全部训练点打乱、无放回；batch256、保留末批 | batch影响关系覆盖，不自动缩小 |
| 随机配对 | 公共模块初值、中心顺序和Dropout掩码按种子复用；关系抽样独立随机流 | v2补齐执行细节，不增加模型 |
| 优化器 | AdamW，lr3e-4，wd1e-4，betas0.9/0.999，eps1e-8 | 沿用主值，补齐默认参数；有梯度参数含偏置同衰减 |
| 计算 | float32；无AMP/TF32、学习率调度或梯度裁剪；workers0、CPU线程8 | 实施初值；记录实际环境，不预测耗时 |
| 关系强度 | epoch1—5为0；6—15每轮增加0.005至0.05，此后固定 | 沿用v1.1；不自动按诊断改系数 |
| 上限与早停 | 60轮；16轮起参考+1e-4改善才重置计数，10轮不改善停止 | 沿用v1.1；实际预算按运行记录 |
| 选点主分数 | 患者内逐通路PCC均值，再六患者等权平均；第6轮开始 | 关键审核三覆盖，论文最终主指标未定 |
| 平分规则 | 1e-6内比较同有效集合的患者宏平均z-MSE，再取早轮 | v2消除聚合歧义；普通pooled z-MSE另存 |
| 无效PCC | 目标有效集合固定；预测恒定实测NA，选择项罚−1；非有限输出故障 | 工程选点规则，不伪造实测−1 |
| 候选推荐 | 三种子内部主分数均值→平分宏平均MSE→预测参数量→固定臂序 | v2消除“综合表现”歧义，不挑外部最优 |
| 外部对象 | 四臂×三种子的12个正式checkpoint，统一冻结后评价 | 不做每轮外部监测、不默认种子集成 |

最后两种MSE用途不同：训练及普通误差是全点均值；内部PCC平分的MSE按患者等权。输出中必须分别命名。当前默认值并非已优化配置，不能因为通过技术检查就标为最优方案。

每轮损失同时保留可复核的分子/分母：回归平方误差和及中心×30数量；关系交叉熵和及有效中心数量。lambda恒定于一轮，但批次有效率不同，epoch摘要不能无说明地对各batch均值再平均。训练总目标另记按实际更新步的均值，区别于样本加权诊断摘要。

诊断批索引在训练前固定并保存；两个关系臂同种子共用诊断支持，不改变训练采样器状态。诊断切到eval以关闭Dropout，独立反向只观测梯度，清理诊断梯度并恢复训练状态后继续；不执行优化器step，不自动校准lambda。若诊断关系无有效中心，明确记录无效，不临时换一个更好看的批次。

源码小快照和人工版本号用于找回实现，**不计算哈希，也不强制Git提交**。这些记录允许定位和重算，不承诺不同GPU或底层库位级复现。服务器不计算整套派生空间指标；本地`analysis/`保留分析代码版本、计算配置和结果，不改写raw。

## 七、后续问题怎样带回人工审核

常规修复：原规格要求不变的路径解析、类型/索引错配修复、输出缺字段补齐，可由智能体直接完成，记录问题、影响运行和新code_version。改变共同数据处理或数学的修复会使旧受影响结果失效，须保留并标记，补齐可比运行，不混合比较。

需要重新审核的变更：数据集合或标签定义、维数、batch、损失权重/支持集、图范围/边权/参数化、模型选择或预算。先完成定位，再向用户提供具体提案；不因已获“三项整体通过”就自行更换这些默认值。关键错误使数据或结果不可信时立即报告，不能等训练后再提。

每次给用户的反馈只优先展开2～3个问题，格式如下：

| 字段 | 填写要求 |
|---|---|
