# Phase 2 双关系通路回归：独立实验方案 v0.1

日期：2026-09-07  
状态：研究设计，未实施、未训练、未验证，不代表性能改善或论文新颖性已成立。  
用途：供用户阅读及本地智能体实施；不依赖 W007 原实现才能启动新代码包。

## 1. 核心决策

保留冻结 UNI2-h 的 1536 维图像特征，直接输出固定顺序的 30 维 ssGSEA。将两个作用不同的关系分开：

- 通路关系：训练期依据真实通路分数定义样本关系，约束图像共享表征；允许跨患者语义联系，不建立跨患者物理空间联系。
- 空间关系：训练与推理均只在同一切片的局部邻域使用图像特征。初版由冻结形态特征与物理距离确定权重，由通路监督过的隐藏特征提供消息。

第一轮采用一个四臂、二因素设计，不把复杂双编码器、全局动态图、通路协方差、超图、标签平滑同时加入。最终可以选择无图模型；完整模型不因复杂而自动优先。

## 3. 从解读中采纳什么、不采纳什么

### 采纳为待验证假说

- DeepPathway 导出中的“相对空间关系 + 跨区域通路语义关系”。
- 将选邻居用的特征与传递消息用的特征区分：冻结图像特征用于初版路由，任务表征用于消息。
- PEaRL 的训练期分子指导、部署时图像侧预测；独立读出阶段作为后续训练协议消融。
- Reg2ST 的分子潜在表征辅助关系建模；但不直接复制整条动态图链路。

### 不作为已证实结论

- GAT 或冻结基础特征不能保证自动识别组织边界、保证权重趋零。
- 不存在测序芯片网格，不等于 WSI 没有可用坐标。普通 WSI 可以保存 patch 像素坐标；物理尺度需元数据。
- 相对距离图对坐标平移、旋转不变，不等于整套模型对图像旋转不变。
- 图网络不是弥补硬配对假负例的唯一或必需方案；对比损失和推理期信息传递是两种操作。
- Reg2ST 的交叉注意力公开实现为跨点位交互，不是单个点的一对向量内部注意力。
- Reg2ST 的 wo_con 同时去掉对比损失和潜特征预测损失，不能归因到对比损失一个因素。去掉这些辅助项后，最终回归仍可能训练中间分支，不能断言中间层必然随机。
- DeepPathway 两种相似度的算术平均并不是逻辑“同时相似”，L1 嵌入惩罚也不是稀疏连边。
- PEaRL 的骨干差异值得控制，但 ResNet50 变体低于某基线不能证明“同骨干公平比较失败”；预训练、优化、输出头等条件也要一致。针对通路任务专门设计不是不当取巧。

## 4. 数据合同

每个样本必须有：

sample_id, patient_id, slide_id, patch_id/barcode, x_feature[1536], y_z[30], pathway_names[30], split。

空间臂还必须有：原始坐标与单位、切片 MPP/坐标换算信息、有效组织范围或连通区域信息（可用时）、原始 patch 覆盖尺度。

当前 MPP2 是方案/分组标识，不把名称直接解释为 2 微米/像素。仓库记录的不同患者原生步长不同，不能共用未经换算的像素半径。

监督标准化只从本次训练集拟合。关系距离、阈值、协方差、形态距离尺度均只由训练侧确定。测试样本的图像坐标及本身无标签局部图像用于构图，不等同于用测试标签拟合参数。

不能把遗留未修复标签与修复版本混用；不能改变通路顺序、匹配失败时按行号兜底。

## 5. 模型定义

### 5.1 点位共享表征

h_i = GELU(W_h x_i + b_h)，h 为 512 维。
点位预测 y_point = W_o Dropout(h_i) + b_o，输出 30 维。

回归分支不对 h 或最终输出做单位长度归一化。Dropout 初始候选 0.3，四臂一致。

训练期投影：z_i = normalize(P h_i)，P 为 512→128 线性映射。对比损失必须更新 W_h；不得意外 detach h。推理可删除 P。

### 5.2 同切片空间模块

对中心 i，候选 N_i 只来自相同 slide_id，在物理半径 R 内，最多 K_s 个邻居，不包含自身。即使两个切片属于同一患者，也不建立物理边。

先用冻结特征 f_i = normalize(x_i) 计算：

b_ij = exp[-d_phys(i,j)^2/(2 sigma_s^2)] * exp[-(1-cos(f_i,f_j))/sigma_x]。

b 是非负软权重。radius R 与尺度 sigma 只在训练侧确定；sigma_x 增加正下限，避免零距离除零。初版不加入从预测通路构造的全局动态边。

保留自保留权重：

a_ij = b_ij / (1 + sum_j b_ij)，a_i,self = 1 / (1 + sum_j b_ij)。

这样所有邻居都不匹配时，邻居总权重可趋近零；不强迫把全部概率分给不可靠邻居。

消息：v_i = GELU(W_v h_i + b_v)，v 为 128 维。

m_i = sum_j a_ij (v_j - v_i)。

最终：y_hat_i = y_point_i + W_delta m_i。

W_delta 为 128→30 的无偏置线性层，初始为零；W_v 正常初始化。无邻居时 m=0，输出严格回退为当前点位预测。不同时把整个消息分支全部零初始化，避免梯度被阻断。

这里的增量是“邻域相对中心的信息修正”，不是冻结 B0 上的泛用第二回归器。主共享层与回归头均参与训练。零初始化只保证初始无扰动，不保证训练后一定优于点位模型。

每个通路有独立 W_delta 行，允许使用不同邻域特征；不把权重解释为生物因果影响或天然的通路空间重要性。

### 5.3 参数量（上述精确结构）

- 1536→512→30 点位模型：802,334。
- 512→128 对比投影：65,664，仅训练需要。
- 512→128 消息映射：65,664。
- 128→30 无偏置空间读出：3,840。
- 完整可训练参数：937,502；推理可去掉对比投影。
- 历史 1536→1024→30 点位头：1,604,638。

这些是线性层结构计算，不是运行测量；更多邻居仍会增加训练和推理算量。

## 6. 连续通路关系目标

第一轮以现有 train-z 分数计算 D_ij = mean_p[(y_ip-y_jp)^2]。这是平方距离，不再次平方。

稠密软关系作为方法对照；重点候选使用三类候选：

P_i：预设近距离范围内的 Top-K 近邻。
N_i：预设远距离范围内的负样本。
U_i：中间、不确定，或虽接近但被 Top-K 数量截断的样本。

U_i 不自动成为负样本，从该 anchor 的对比分母排除。P_i 与 N_i 不重叠，均排除自身及重复 sample_id。

在 C_i = P_i ∪ N_i 上：

Q_ij = 1[j∈P_i] exp(-D_ij/tau_y) / sum_{k∈P_i} exp(-D_ik/tau_y)。

P_model,ij = exp(z_i dot z_j / tau_z) / sum_{k∈C_i} exp(z_i dot z_k / tau_z)。

L_rel,i = -sum_{j∈P_i} Q_ij log P_model,ij。

Q 完全由训练标签与固定规则产生，不反向传播。缺乏正样本或负样本的 anchor 跳过该项，但仍参加回归。损失以有效中心数平均，并记录每患者有效覆盖率。

“近/远”只表示预设度量，不声称有重复测量支持的生物学置信度。

### 6.1 初始候选，不是文献已证实的最佳参数

- 隐藏维度 512；投影维度 128。
- 中心批次 192（每名训练患者 32）；如资源不足，统一改为每人 16，四臂同步。
- 通路近邻列表最多 8；每中心随机取至多 2 个近邻作为额外辅助样本，避免大规模扩展批次。
- 负样本优先复用批次中心，最多 32/中心；患者组成尽可能均衡，不强制跨患者正样本。
- tau_z = 0.1；tau_y 用训练近邻正距离的中位数并设正下限。
- 关系损失权重候选 0.05；作为初始小规模探索值，不可据外部 XZY 修改。
- r_plus/r_minus：在患者均衡的训练点对距离分布上预定义较近/较远分位阈值；初始可比较 5%/50% 一组，不做多网格。覆盖率过低属于设计诊断，不偷偷修改外部测试后重跑。
- K_s = 8；radius_um 必须在核对组织覆盖尺度后填写，不能猜测。

采样到的辅助邻居与当前模型重新前向计算，不使用未声明的过时学习特征缓存。MSE 只计算中心点，不因某点被重复选作邻居就重复增加其标签权重。

### 6.2 两个特别诊断

1. 近邻是否几乎全来自同一患者？若是，先检查患者偏移、通路定义和打分尺度，不能强行增加跨患者正边作为“纠偏”。
2. 投影几何改善是否只发生在 z，而 h 的回归/探针没有改善？若是，投影头可能吸收了大部分辅助约束。

## 7. 四臂最小实验矩阵

B0：冻结历史 1024 头重放，仅历史参照。

A00：512 点位模型，MSE。
A10：同 A00，加连续通路关系损失。
A01：同 A00，加同切片空间模块，仅 MSE。
A11：通路关系 + 同切片空间模块。

四臂共用数据、中心采样、共享层初始化、训练预算、回归损失、内部选择规则。不同结构的同名共享模块需显式复用相同初始化；不能仅依赖同一个随机种子就假定权重和批次顺序相同。

推断：
- A10-A00：辅助关系监督。
- A01-A00：空间模块整体增量，但仍含新增参数影响。
- A11-A01：空间架构下关系监督的贡献。
- A11-A10：关系监督下空间模块的贡献。
- 四臂交互差：辅助描述是否超出简单加和，不用一个种子证明统计交互。

进一步对照只在相应分支出现希望后开展：
- 仅打乱辅助标签对应，MSE 真标签不变；可在患者内打乱以保留患者分布。
- 与空间分支参数相当、只用中心特征的 MLP 增量，排除纯容量收益。
- 固定邻居个数的同切片随机邻居或坐标打乱对照，记录距离分布变化。
- 固定形态路由 vs 同容量任务表征路由；不把两者区别混入第一次四臂。
- 稠密软目标 vs Top-K 后其余全负 vs 三状态目标。
- 最终仅在入选方案上比较 256/512/1024 宽度、独立回归读出阶段。

## 8. 训练、选择与外部边界

新方案不要求从历史 B0 恢复权重。512 四臂可以共用一个新的 MSE 预热模型副本，但预热只能使用训练侧，且四臂总更新预算一致。例：5 轮共同 MSE 预热，之后关系权重 5 轮逐渐增加；总预算候选 50 轮，内部早停 patience=10。具体初值由本地检查旧合同与资源后固定。

统一回归目标可采用患者均衡 MSE：先在每患者内平均点位×通路误差，再平均患者。该改变应同时用于四臂，不把历史 B0 的不同选择协议当成严格因果对照。

检查点选择预先统一为内部患者均衡 z-MSE；保留逐通路 PCC、展平 PCC、CCC、Spearman、raw R²、raw/z MAE、z-RMSE 与现有其他适用指标。最终发表指标由用户后续决定，不在看到 XZY 后更改筛选规则。

第一种子用于小规模机制筛选，入选方案及其匹配对照补至少两个种子。种子重复衡量优化波动，不代表增加患者数。

XZY 不参与监督预处理、阈值、结构、早停或超参选择。其历史结果已经被反复讨论，不能包装为从未查看过的新盲测。新独立患者/队列可用时承担更强外部证据。

## 9. 空间验证协议

当前六患者内空间块划分仍可用于第一轮探索，不能据此主张跨患者泛化。训练图与验证图应分开构造，不使用验证标签或跨 split 传播。保守初版各自使用本 split 的特征支持集；记录邻域缺失与训练/验证密度差。

若采用更大空间块、隔离带或完整图像上下文支持，需要新建明确协议，并让四臂在同一协议重跑；不能只给图模型改变划分。半径图扩张了实际输入视野，原来无 patch 重叠不自动代表扩大后的感受野无重叠。

指标补充：逐通路预测范围/方差比、均值偏差、残差空间自相关、局部预测差值与真值差值误差、固定组织边界分层。标签图空间自相关不是可预测残差空间自相关。没有可靠组织边界标注时，只能称“高形态差异邻接对”，不能称病理金标准边界。

## 10. Phase 3 交付

输出需要稳定 sample_id/patient_id/slide_id、坐标与单位、固定通路顺序、y_z 与一次逆标准化后的 y_raw、模型和预处理版本、邻域协议。可附原始 1536 特征及 h，但不直接替换 Phase 3 当前输入合同。

推理只用目标切片的图像特征和坐标，不需要真实通路、训练样本检索库或其他患者切片。单点模式仅图像；空间模式需要局部邻居，仍是“仅图像信息推理”，不是“仅单 patch 推理”。

将来的六折留一用于评价和选型，不挑最好一折交付。每折重新拟合监督预处理和回归层；不得从见过全部六人的 B0 开始冒充留出患者。最终方案锁定后，可在六名开发患者上重拟合一个交付模型；外部 XZY 不改作验证患者。

如果 Phase 3 患者与 Phase 2 开发患者重叠，应区分训练内预测与折外预测；独立患者结果不能和泄漏来源混合。不同折的 z 尺度不能直接当成同一绝对量；正确逆变换后仍需共同评分定义。

## 11. 本地智能体交付结构

建议在现项目 experiments/phase2_dual_relation_v001/ 中建立独立包，按当前 experiments/_template/ 组织；不默认创建工作树、推送或训练。

建议模块：

- contracts.py：身份、通路、尺度、split 与允许信息检查。
- data.py：中心样本、语义辅助样本、空间辅助样本的独立索引。
- models.py：PointRegressor、ContrastProjection、LocalContextResidual。
- relations.py：稠密与三状态关系目标、有效性掩码。
- spatial.py：同切片物理邻域、形态权重、自保留项。
- train.py / evaluate.py：统一训练及选择，完整原始预测导出。
- configs/：A00/A10/A01/A11，同一主配置的显式差异。
- tests/：单元、梯度、数据分割及推理独立性测试。

必须通过的检查：
1. 关闭关系损失，A10 与 A00 计算一致；空间无邻居时精确回退点位输出。
2. 对比项对共享 W_h 梯度非零，目标 Q 不求梯度。
3. 无有效正例、无负例、零距离和非有限值均有明确处理，不出现 0*(-inf)。
4. 所有物理边同 slide、符合半径、无跨 split；同患者不同 slide 也不能相连。
5. 改变验证真实标签不改变预测或图；只改变目标切片邻居图像时，空间分支才可相应变化。
6. 批次重新排列不影响 eval 预测；加入另一个患者切片不影响原切片预测。
7. 坐标平移/旋转在距离图层面结果一致；不扩张宣称为图像旋转不变。
8. 所有臂中心点数量、共享初始化、损失分母、标准化和选择规则可核对。
9. 模型输出与标签行、通路名一一对应，逆标准化仅一次。
