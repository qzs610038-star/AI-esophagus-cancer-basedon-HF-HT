## 一、先看新设计怎样工作

![新设计流程](../../experiments/phase2_spatial_warmstart_v1/docs/figures/新设计流程.png)

[查看矢量流程图](../../experiments/phase2_spatial_warmstart_v1/docs/figures/新设计流程.svg)

新设计的核心很简单：**先保留阶段一已经学会的单点预测，再让空间分支学习还能修正什么。**

阶段一已经得到一套模型：冻结的UNI2-h把病理图像转换成1536维特征；共享层H把这些特征整理成256维通路相关表征；回归头C将其转换为30条通路的预测值。这里H可以理解为“整理信息”，C则是“根据这些信息给出分数”。

此前阶段二只继承H，却把C重新初始化。这样一来，模型虽然保留了整理信息的方式，却需要重新学会怎样给出通路分数。与此同时，阶段二只有60次参数更新，全部30组模型的内部最佳结果都在最后一轮，尚没有清楚的收敛证据。

本次同时继承H和C。新空间矩阵B从零开始，因此在第0步、关闭训练随机丢弃时，空间修正量为零，模型应该与阶段一输出一致。之后再观察：保持单点模型不变、只学空间修正是否有用；允许单点预测与空间修正共同调整，能否进一步改善。

**暂时不使用LoRA（低秩适配）和对比学习。** 图像编码器保持冻结，本轮优先把阶段衔接、空间收益和训练充分性说清楚。

这不是第一次把空间结构接在新版特征后面。此前已经接过，区别在于**这次保留完整预测能力，并增加头部优化预算**。

“继承空间方案”也不等于复制旧B的权重。旧B适配旧H产生的表征，直接移植可能不匹配。因此，本轮继承结构和建图规则，B从零学习。

另外，冻结纯回归臂的图像编码器没有改变。阶段一较好的表现来自整套单点预测流程，不能说已证明图像特征本身变强，也不能预先断言新旧优势必然相加。

## 三、模型如何利用邻居：用一个公式讲清楚

对中心点i，先得到：

`h_i = H(x_i)`，`单点预测 = C(h_i)`

其中x是缓存的1536维图像特征，h是256维表征。对同一患者、同一数据划分内的邻居j，计算：

`u_i = Σ_j a_ij × (h_j − h_i)`

u表示“邻居与中心在表征上有什么不同”；a是由空间距离与冻结图像相似性确定的权重。最终预测为：

**`预测_i = C(h_i) + B × u_i`**

B把256维邻域差转换成30条通路的修正值。它可以学习正修正或负修正，并不要求把所有相邻点预测得更相似。

例如，原单点模型给某条通路预测0.40，空间分支给出−0.05，最终预测就是0.35。这只是帮助理解的数值例子，不是本轮实验结果。

图的连接关系固定，最多8个邻居，不跨患者，也不跨训练、内部验证或外部划分。邻居由坐标与冻结图像特征确定，通路标签不用于建图。若H继续训练，**图的连接与权重仍固定，但h和邻域差u必须随当前H重新计算**。若H冻结，h和u可预先计算一次，节省重复运算。无邻居点的空间修正必须为零。

Gemini提出的“中心冻结、热启动残差微调”对应第二组`spatial_residual_only`。**优先运行这一组，再完成单点续训和联合优化的匹配对照。** 它不是方案外的第四个训练臂，也不是要加载旧阶段二的B权重。

### 怎样比较才不会把收益算错

1. **纯空间补偿减第0步单点结果**：衡量在固定基座条件下学到的空间增量。
2. **空间联合优化减匹配种子的单点续训**：衡量在相同续训日程下加入空间分支的效果。这是本轮主要成对比较。
3. **单点续训减第0步单点结果**：判断仅延长训练是否已经带来变化。
4. 与旧空间模型的比较：回答最终模型是否超过历史参考，但不能用这种跨流程差值单独证明某个模块的因果贡献。

纯空间补偿与联合优化之间同时改变了H/C是否更新及训练时dropout（随机丢弃）状态，不能把两者差值只解释为某一个因素。

### 本轮具体训练设置

| 设置 | 预先采用的值或规则 |
| --- | --- |
| H结构 | 1536→256线性层，带偏置，GELU激活 |
| C结构 | dropout=0.3，再接256→30线性层，带偏置 |
| B结构 | 30×256矩阵，无偏置，全部置零 |
| 优化器 | AdamW，权重衰减1×10⁻⁴ |
| H/C学习率 | 续训两臂均为3×10⁻⁵ |
| B学习率 | 两个空间臂均为3×10⁻⁴ |
| 学习率日程 | 固定，不在本轮追加搜索或自适应改配方 |
| 损失 | 全部训练点×通路的z分数均方误差，各点等权 |
| 数据输入 | 全量9472个训练点，每步恰好一次优化器更新 |
| 图参数 | 半径1.5个原生步长、最多8邻居、距离sigma=1.0、图像温度0.2、自项原始权重1.0 |
| 训练精度 | 首版使用float32，先保证与来源模型一致 |

本轮沿用上一轮阶段二按点等权的损失，不同时引入患者均衡、子图采样或新空间结构。这样更容易解释三组之间的差别。阶段一曾用患者均衡采样，因此阶段一与本轮续训之间仍有目标权重差异；匹配的单点续训对照用于帮助辨认这一影响。

两个续训臂应使用相同的数据顺序及中心点dropout随机流，空间分支不额外消耗这个随机流。纯空间补偿必须让H/C保持评估模式，不能被外层`model.train()`重新开启C的dropout，否则“固定单点预测”就不成立。

## 五、怎样判断训练够不够，而不是又卡在轮数上限

**用参数更新步数描述训练。** 本轮全量训练每步看完9472点；500次小批量更新与500次全量更新不是相同的数据暴露量，不能混写。

预定训练规则如下：

1. 先记录第0步内部结果，并将来源模型纳入最佳候选。不能等第6轮之后才开始选模。
2. 每10次参数更新做一次内部验证，并记录两种PCC及用于打破同分的zMSE。
3. 首段预算1000步。若尚未触发早停，自动保持同一优化器、学习率和随机状态继续至最多2000步；这属于预先规定的延长规则，不是看XZY后追加训练。
4. 最少训练200步后才允许早停。以第0步PCC初始化早停参照；每次验证若平均PCC超过参照1×10⁻⁴，更新参照并清零无改善计数，否则计数加1。满20次无实质改善、且已达200步时停止。微小提升相对于上次参照累计，不是要求每10步都提升1×10⁻⁴。
5. 最佳权重选择使用所有已验证候选：先内部逐患者逐通路平均PCC最高，再zMSE最低，再更早步数。早停阈值不改变最佳权重的排序精度。
6. 到2000步仍未触发早停，记录`budget_exhausted`（达到预算上限），不要写“训练完成所以充分收敛”。触发早停则记录`early_stopped`，表示满足预定内部验证停止规则，不等于找到理论最优。

500、1000、2000步时记录实际耗时、最佳步数、最近验证趋势和停止原因；已经早停的组不为凑整轮而继续训练。所有组遵循相同预算规则，实际停止步数可以不同。

这次是**从阶段一完整权重出发的新实验**，不是旧阶段二第60步的严格断点续训。同时改变了C的继承方式和训练预算，因此不能单凭本实验把旧下降定量拆成“重置C贡献多少、步数贡献多少”。本轮优先解决可用模型；纯粹延长旧C重置流程的因果验证不列入本次必跑任务。

## 六、种子、内部选择与第一版模型交付

根据用户最新要求，**三组均只使用默认种子42，不安排43、44重复训练**。完整计划是3条训练轨迹；第0步基线不算额外训练。优先完成来源核验、充分训练和空间增益比较。

阶段一来源和本轮续训均为种子42，因此本轮属于单种子探索结果，**不能计算种子均值/标准差或宣称跨种子稳定**。如以后确有必要补种子，应另行安排；在固定阶段一起点下重复阶段二，也只能衡量阶段二的条件随机性。

纯空间补偿在固定H/C、固定图、零初始化B、全量确定性运算下没有有意引入随机因素。它只报告一次结果，种子SD标记为“不适用”；如果底层算子存在非确定性，应另行记录，不能把机械重复伪装成三个独立训练种子。

架构排序只用内部验证：比较三组各自内部最佳模型的逐患者逐通路平均PCC。同分依次比较内部zMSE，仍相同优先单点续训、纯空间补偿、联合优化这一复杂度顺序。两种PCC及成对差值都保留，不能隐藏不利口径。

第一版交付选择架构的**种子42内部最佳权重**，不自动生成集成模型。三组均完成预定训练、输出和核验后，可称本轮单种子实验完成；未安排多种子不是任务未完成，但须明确稳定性尚未经重复实验验证。

XZY仅在方法与checkpoint固定后评估。原有XZY属于历史已查看的一名患者外部参考，不能承担新的盲测结论；不以本轮XZY结果改来源、学习率、轮次或图参数。

若新方案未显示值得采用的内部增益，保留阶段一原模型及旧空间模型作为候选，不为等新方案反超而无限追加变体。旧空间模型是否作为正式第一版，还须结合现有待审状态作出最终确认；本部署方案不把历史结果自动升级为已确认。

沿用MPP2原划分：9472训练点、1078内部验证点，来自六名训练患者的空间块划分；XZY为1039点、一名患者；输出30条通路。内部验证不是六名全新患者外推。

## 八、训练代价与明天前的执行顺序

参数量按现有结构计算：H为393472，C为7710，B为7680。单点续训训练401182个参数，联合优化408862个，纯空间补偿仅7680个。图像大模型不参与本轮反向传播；已有缓存齐备时也不必重新提取图像特征。

固定H的纯空间补偿可以预存h、u和原单点预测，运算最少；联合优化需要每步重算H及邻域差。特征、邻域中间张量、梯度和验证输出仍占内存，不能只用参数量推断完整显存。

因此，**先保留全量训练，暂时不做子图采样**。当前规模已有全量运行记录，子图采样会增加邻域完整性、索引和公平比较的实现工作。只有实测内存或时间确实成为瓶颈，才单独讨论采样，不能在本轮静默替换训练方式。

## 十三、对Gemini融合建议的采纳与修正

### 1. 保留完整中心模型，只拟合空间残差：采纳，并优先运行

令固定单点输出为P，真实训练标签为Y，U为每个点的256维邻域表征差。纯空间补偿训练的目标可以直接写成：

`R = Y − P`，`L(B) = mean((U Bᵀ − R)²)`

这与原预测形式`mean((P + U Bᵀ − Y)²)`在H/C固定、关闭dropout时完全相同。因此可以先缓存P、U与R，再只优化7680参数的B，不必每步重复执行H/C。R只能由训练标签形成；验证标签只能计算指标。

“十几行代码”或许只描述了冻结参数与改前向的局部修改。完整部署仍需处理来源权重、身份映射、dropout模式、验证选择、缓存、恢复与输出，不能据此跳过交接清单。

### 2. “数学保证性能只增不减”：不能采纳这种总体表述

需要区分三个层面：

- **第0步预测一致**：B=0、H/C严格继承且处于评估模式时成立。它解决的是原阶段二一开始丢失C的问题。
- **内部主选择指标可回退**：第0步被保留在候选中，按同一内部平均PCC选择最大值，因此返回模型在这一个已观察的内部选择指标上不会低于第0步。数值容差和无效相关处理必须一致。
- **训练以后、其他指标以及外部泛化不下降**：没有这项保证。B可拟合训练集的特有误差；内部平均PCC提高时，整体展平PCC、某个患者/通路或XZY也可能下降。

不能用XZY决定“是否回退B=0”，否则外部测试就参与了模型选择。也不能把内部选择导致的表面不下降当作泛化证明。

### 3. 旧空间图实际是最多8邻居，不是固定6邻居

旧运行配置和新包目前都采用1.5倍原生步长半径、最多8个邻居，物理距离与冻结图像相似度联合加权，并为中心保留归一化权重。边界、稀疏点的实际度数可以少于8。

因此本次保留`max_neighbors=8`，不采用Gemini图示里的`k=6`。复用的是旧空间模型的结构与图规则；由于H变成新阶段一H，邻域表征差必须重新计算，不是直接搬用旧模型的隐层差或B。

来源：[旧运行配置快照](../../experiments/results/phase2_softlink_local_v2/20260908_005325_810_8d306c10/config_snapshot.json)、[新图实现](../../experiments/phase2_softlink_contrastive_v3/src/spatial.py)。

### 4. Ridge解析解：数学上可行，作为可选求解方式保留

固定H/C后，B的学习是线性多输出回归，可以使用Ridge（带L2惩罚的岭回归）。明确采用下面的“总平方误差”约定：

`min_W ||U W − R||²_F + λ ||W||²_F`，`W = Bᵀ`，`λ > 0`

对应线性方程为：

`(UᵀU + λI) W = UᵀR`

只需分解一个256×256矩阵，同时解30个通路，不必为每条通路重复建立求解流程。实现时用稳定的线性求解或SVD，不显式求逆；不增加截距，也不对U/R自动减均值，以保持无邻居时U=0、修正也为0。正则化尺度依赖损失采用总和还是均值，不能直接把AdamW的权重衰减当作同一个λ。[Ridge官方目标与求解说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)

在精确求得上述训练目标最小值时，B=0是可行候选，所以最优正则化训练目标不会比B=0差；由惩罚项非负还可推出训练平方误差不超过B=0。**这个推导只涉及训练平方误差，仍不保证验证PCC或XZY改善。**

Ridge需要预先确定λ及其选择规则，只能在训练/内部验证中处理。本次不扩大为新的必跑超参数搜索：保留`ridge_optional.enabled=false`，仍执行既定三组。后续若启用，须明确λ、数值精度及输出记录，作为纯空间补偿的另一求解器单独标记，不能冒充原AdamW轨迹或称为“没有拟合”。“一秒内”“100～200步必收敛”目前均没有实测依据。

### 5. 固定图平滑：加入廉价诊断，但不照抄α=0.15～0.20

旧批次确实完成过固定图平滑，不过已登记结果仅覆盖内部验证，使用的是含中心自权重的`β=1`，并没有证明新基座或XZY一定改善，更没有证明α=0.15～0.20是通用最优值。

本次增加**一个无需训练的诊断**：对来源第0步单点预测使用同一图，固定β=1，不搜索系数。正确写法为：

`p_smooth,i = p_i + β Σ_j a_ij (p_j − p_i)`

当β=1，等于`a_self,i p_i + Σ_j a_ij p_j`，其中`a_self,i + Σ_j a_ij = 1`。原图邻居权重之和通常小于1；若直接写`(1−α)p_i + αΣ_j a_ij p_j`却漏掉自权重，会改变总权重并额外缩小分数。只有重新定义为邻居归一化权重时，该混合写法才具有不同的合法含义，不能和原图静默混用。

在C评估模式下，固定平滑也可写为`B = β × C.linear.weight`的特殊空间残差模型，C偏置在邻居差中抵消。因此它可以帮助判断学习自由B是否比简单预测平滑更有价值；不是自动证明学到的B与平滑等价。

固定平滑放在本地派生分析中，报告内部两种PCC及与第0步差值。只要原始外部预测与图元数据齐备，也按同一固定规则报告XZY；没有就标明缺失，不拿内部结果代填。它**不参加本轮三臂的模型选择**，不因为诊断效果好就根据XZY改变最终架构。

旧固定平滑数据见[逐种子完整指标中的fixed_smoothing行](../../experiments/results/phase2_softlink_local_v2/20260908_005325_810_8d306c10/analysis/registration_metrics_by_seed.csv)，算法见[旧本地分析代码](../../experiments/phase2_softlink_local_v2/src/analyze_local.py)。本轮需保存图边表或可精确重建图的特征、坐标、患者/划分身份与参数，避免重演外部边表缺失的问题。这里平滑的是预测分数，并不是分类训练中的标签平滑。
