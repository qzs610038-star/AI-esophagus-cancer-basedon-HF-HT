# 7. 对参考对话中“指标和创新性”判断的项目化修正

## 7.1 当前 Phase 2 的性能评价

对当前仓库能给出的严谨结论是：

> PCC 是当前实现和实验登记中的主要通路回归指标，但必须与 raw-scale MAE、raw-scale R²、逐 pathway 结果和患者/空间级验证一起解释。

当前 MPP2 external PCC=0.6549 说明预测值与外部 XZY 的 30维通路标签存在整体线性相关；它不表示每个通路都同样可靠，也不表示可以直接用于治疗响应临床决策。

## 7.2 当前 Phase 3 的性能评价

仓库现有 yzq 已审核材料提供了团队探索 AUC，但缺少 accepted Phase 3 治疗响应实现与结果包，因此不能把这些探索数值写成正式性能，也不应使用生存任务的 C-index、KM、log-rank 或 time-dependent AUC 评价当前 pCR/MPR 分类任务。

在用户补齐真实 Phase 3 数据和代码后，至少需要分开报告：

1. **virtual ST 预测质量**：PCC、Spearman、MAE/RMSE、R²、逐通路和空间一致性；
2. **临床预后区分度**：二分类 AUC/PR-AUC/F1/MCC 或生存任务的 C-index 等；
3. **临床校准与增益**：calibration、Brier、decision curve，以及相对于 H&E-only/clinical-only baseline 的增益；
4. **泛化与泄漏**：患者级划分、外部验证、bootstrap CI 和多张 WSI 的患者级聚合。

## 7.3 当前最有证据的创新切入点

目前可以由仓库事实支持、且与用户目标相容的方向是：

- 以 30个 pathway score 而不是未经验证的全基因矩阵作为中间分子表型；
- 使用空间坐标/邻域图进行 pathway map 预测；
- 将 patch-level virtual ST 严格聚合到 patient-level，再与 H&E/clinical baseline 比较；
- 用 pathway-specific 贡献和空间热图增强解释性；
- 在 Phase 3 中做 modality ablation，证明 virtual ST 是否带来真正临床增益。

但 GNN、GAT、Mamba、cross-attention、multi-task learning 等目前只能作为候选架构，不能写成“项目已采用”。
