# Phase 2 模型、指标与补充实验整体分析报告

供组会讨论｜2026 年 9 月 5 日

## 1. 建议团队先确定什么

**当前建议以“冻结 UNI2-h 后直接回归 30 条通路”作为代码包的默认模型和 Phase 3 的交接入口；将“软关系对比纠错”保留为方法候选。** 这是一项基于现有证据的建议，最终选择仍由团队讨论确定。两者可以同时进入论文复现包：一个承担稳定参照，另一个承担方法检验，不必为了代码包只有一个入口而删掉比较对象。

当前最缺的并非另一个复杂网络，而是三个问题的可靠答案：第一，软关系学习是否真正改善新患者的通路预测；第二，直接预测通路与先预测基因再重建通路，哪条路线更适合本项目；第三，预测通路是否在控制普通图像压缩的影响后，仍能帮助 Phase 3 的疗效预测。


| 待决定事项      | 本报告建议                     | 依据与边界                              |
| ---------- | ------------------------- | ---------------------------------- |
| 默认模型       | 冻结 UNI2-h＋两层通路回归网络        | 已有已确认结果，结构清楚；软关系尚无稳定增益             |
| 论文主要指标     | 逐患者、逐通路 PCC＋训练尺度 z-RMSE   | 分别回答变化是否跟得上、数值误差有多大；沿用 9 月 5 日登记规范 |
| 软关系方案定位    | 保留为方法候选与消融，先诊断再修订         | 现有实验是联合纠错，尚未完整检验先对比、后回归            |
| 补充数据优先级    | 基因表达矩阵、基因集定义与评分过程、点位配准清单  | 决定能否开展团队已分配的基因重建和采样实验              |
| Phase 3 衔接 | 先固定完整 30 维预测包，再做患者独立的公平消融 | 当前 Phase 2 分数更高，不自动意味着疗效预测更好       |


这里的 Phase 2 指“从图像预测通路”，Phase 3 指“将图像及其预测通路用于患者疗效预测”。后文所谓“先对比、后回归”是 Phase 2 内部的两步训练，与整篇研究的 Phase 2／Phase 3 不是同一个划分。

## 2. 两个候选模型究竟怎样工作

### 2.1 共同的数据基础

两种方案都以同一个空间位置的病理小图及其真实通路分数配对训练。当前开发队列为 6 名患者：9,472 个点位用于更新模型参数，1,078 个点位用于内部验证；另外 1 名患者的 1,039 个点位用于独立留出评估。内部验证仍来自训练患者，不能称为新患者验证；独立留出一名患者也不能等同多中心外部队列。

UNI2-h 是预训练的病理图像特征提取模型。它把一张病理小图变成 1,536 个描述形态的数字。当前两方案都冻结这个模型，不更新它的参数。30 个最终输出各对应一条固定名称的通路；它们的监督标签来自空间转录组计算的 ssGSEA 分数，即“单样本基因集富集评分”。30 条通路的具体选择与评分过程仍须补齐可复现材料。

### 2.2 直接通路回归：看到形态，就预测分数

**输入是一块组织的1536维图像特征，经过小型回归网络，输出该位置30条具名通路的分数。** 用一个虚构的单通路例子说明：真实标准化分数为1.2，模型预测为1.0，训练就利用这0.2的误差调整网络。模型使用这块组织的图像，不读取同切片其他位置的图像特征。

```text
训练输入
病理小图 → 冻结的 UNI2-h → 1536 维图像特征
                                  ↓
                         1024 维中间特征
                                  ↓
                          30 项预测通路分数
                                  ↕ 比较预测误差
同一位置的真实表达 → 真实通路分数 → 用训练集参数标准化

使用新患者时
只输入病理小图 → 相同图像模型和回归网络 → 30 项预测通路分数
```

回归网络包含两个全连接层：1536→1024→30；中间使用 GELU 非线性函数及 dropout 0.3（训练时随机关闭部分单元，降低过拟合倾向）。1024 是可调整的隐藏层宽度，没有预设的生物学含义，更不代表 1024 条通路。当前没有充分的宽度比较证据证明 1024 最优。

这个回归网络有 **1,604,638 个可训练参数**。它直接学习每一条通路的数值，不需要独立通路编码器，也不在模型内部读取邻居坐标。坐标负责图像与标签配对、空间评估和画图，并不等于模型已经学习空间邻接关系。

### 2.3 软关系对比纠错：保留基线答案，再学习怎样修正

**输入仍是相同图像特征，但分成两路：一路保留基线预测，一路学习修正量；两者相加得到最终分数。** 沿用上面的虚构例子：基线预测1.0，新网络若给出+0.15，最终就是1.15。训练时，真实通路之间的相似关系还会指导新网络学习；使用时仍只输入图像，不需要检索训练样本或读取新患者真实通路。

```text
训练输入：相同的 1536 维图像特征
         ├→ 已训练并冻结的直接回归网络 → 原始30项预测 ─┐
         └→ 新的256维图像表示 → 30项修正量 ─────────┤ 相加
                                                       ↓
                                                最终30项预测
                                                       ↕ 数值回归误差
真实30项通路 → 通路编码网络 → 256维通路表示              真实30项通路
                    ↕ 与256维图像表示比较
真实通路之间的相似度 → 连续的配对权重 → 软目标对比损失

使用新患者时：图像特征 → 基线预测＋修正量 → 30项预测
真实通路和训练期的通路编码网络不参与新患者预测。
```

“软关系”规定：两块组织的真实通路状态越接近，它们之间的匹配权重可以越高；并非只有原始一一配对才算正确。**它依据通路分数相似度，不依据两块组织在切片上相距多远。** 因此不能把现有方案写成空间图网络，也不能把“软连接”与“对比学习”拆成两个已经独立完成的最终模型。

新增图像表示和修正网络为 1536→256→30，有 401,182 个可训练参数；训练期通路编码网络为30→256→256，再加上它，硬对比或软对比版本共新增 474,910 个可训练参数。这个数没有包括此前训练过、此时冻结的基线回归网络，因此不能说整个系统只有 47.5 万参数，也不能拿它与直接回归的全部训练成本作不对称比较。

现有训练同时优化“预测误差＋加权对比损失”，最终输出是基线加修正量。它检验的是**辅助关系监督能否帮助纠错**，并没有完整检验团队原建议中的**先学图像—通路表示，再固定表示、另训预测器**。

### 2.4 借鉴论文时，应该借哪一部分

PEaRL 用图像与通路对比对齐后，再训练预测头；它微调第一代 UNI 的末四层，不能因为两侧最终压到 256 维，就把它当作小参数方案。文中末四层若指四个完整 Transformer 模块，仅此部分约为五千万参数；这只是结构估算，不是作者公布的完整可训练参数统计。对本项目而言，优先检验冻结 UNI2-h 后的小网络训练顺序，更符合当前数据和过拟合记录。

PEaRL 的皮肤癌数据点位数与本项目接近；乳腺癌正文写 13,620，补充材料却写 135,620，相差十倍，当前无法确认哪个是实际分析数量。因此，之前“乳腺癌数据量也接近我们”的说法只能作为正文口径，不能继续作确定结论；也不能反向认定它一定用十倍数据训练。点位数帮助学习组织内变化，患者数帮助检验个体差异，两者都重要。图像中间维度与对齐维度是设计参数；预测输出 30 维由研究目标决定，不要求三者一致。[PEaRL 主文与补充材料入口](https://openaccess.thecvf.com/content/WACV2026/html/Majumder_PEaRL_Pathway-Enhanced_Representation_Learning_for_Gene_and_Pathway_Expression_Prediction_WACV_2026_paper.html)

PEaRL 还对表达做了 8 邻域平滑，并在通路侧引入坐标和注意力。标签平滑与空间编码是两项不同改动。DeepPathway 已有通路对齐和两步学习；Reg2ST 还要求图像恢复分子侧中间特征，再结合坐标及动态图预测。它们分别提供参考，但当前软关系纠错不是其中任何一个完整模型的复现。具体数值和证据链接见文献对照表。

## 3. 选不同模型，论文 Phase 2 会怎样写

### 3.1 如果选择直接通路回归

**适合写成以科学问题和临床衔接为核心的研究。** 单纯“UNI2-h＋常规小网络”的独立算法创新较弱。更有价值的是验证：在少患者条件下，直接重建通路是否优于基因重建；采样密度、病理基础模型和患者差异如何影响结果；这些通路表征在下游是否有用。

可用于论文方法与结果部分的文字如下：

> 本研究利用空间转录组监督，将常规病理图像映射为具有固定生物学定义的 30 维通路表征。病理小图经冻结的 UNI2-h 提取 1536 维特征，再通过包含一个 1024 维隐藏层的两层全连接网络预测通路分数。各通路的标准化参数仅由训练数据计算，并固定应用于内部验证与独立留出患者。评价先在每位患者内逐通路进行，再按预设规则汇总。当前独立留出患者的平均逐通路 PCC 为 0.5194，z-RMSE 为 0.7672，提示模型捕捉到了部分与通路变化相关的形态信息；但单患者评估及数值一致性不足限制了其泛化结论。模型输出随后作为图像衍生通路表征用于 Phase 3，并通过患者独立的消融实验检验其对疗效预测的增量价值。

最后一句是研究用途，**不能替代尚未完成的 Phase 3 有效性结果**。基因重建、采样和多模型比较完成前，也不能在结果中写“直接通路预测更优”“稠密性带来显著提升”。

### 3.2 如果选择软关系对比纠错

**适合围绕一个具体方法问题展开：数值回归是否遗漏了不同组织之间连续的通路关系，而这种关系能否帮助新患者预测。** 创新不能只写“采用了软对比学习”，因为已有论文包含相近思想；应指出本研究识别的问题、针对性改法，以及改法产生的可重复效果。

当前证据允许的写法如下：

> 在直接通路回归基线上，本研究进一步评估了一种利用连续通路相似关系的辅助学习方案。训练时固定既有回归模型，在图像特征后增加残差分支，将其输出作为 30 条通路的预测修正量；另将真实通路编码为与图像表示相同维度的特征，并根据真实通路状态的相似程度构建软配对目标。数值回归与对比目标联合训练，推理时仅需图像信息。通过基线复放、无对比纠错、一一配对对比和软关系对比进行比较，现有单随机种子结果未显示稳定的总体优势。软关系版本在独立留出患者上的逐通路 PCC 为 0.5190，z-RMSE 为 0.7657；因此当前将其定位为方法探索，进一步检验学习顺序和关系构造是否改善跨患者表现。

如果团队最终实施的是“先对比、后回归”的修订方案，上段的结构和训练描述必须随新实现重写，数值也必须换成该新方案的实际结果，不能继承现有纠错实验成绩。

### 3.3 创新点与 Phase 3 衔接的差异


| 比较维度             | 直接通路回归               | 软关系对比纠错                         |
| ---------------- | -------------------- | ------------------------------- |
| Phase 2 主要问题     | 形态是否能直接恢复有意义的通路数值    | 连续通路关系监督是否帮助预测                  |
| 方法新颖性            | 常规模型本身较弱             | 组合有研究价值，但软对比已有先例，尚不能称算法突破       |
| 最需要的证据           | 基因重建、公平基础模型比较、患者独立验证 | 同结构无对比对照，硬／软关系对照，稳定增益与机制诊断      |
| 交给 Phase 3 的默认内容 | 固定顺序的 30 项预测分数       | 仍是同样的 30 项预测分数，可直接保持接口一致        |
| 如改传中间特征          | 另设普通图像投影对照           | 256 维可能保留不同信息，但不能继续称其为 30 条具名通路 |
| 论文不能提前声称         | 比先预测基因更优；已提高疗效预测     | 纠错已稳定有效；软关系已解决患者漂移；已优于相关论文      |


## 4. 两个候选还需要哪些修正

### 4.1 先统一验证条件

**共同优先项是患者划分、标签定义和评价一致性。** 推荐在当前六名开发患者中讨论留一患者评估；若采用，每折不仅新分支要重训，项目内监督训练过的基线回归头、标准化参数、软关系参数也必须排除留出患者。冻结的通用 UNI2-h 特征可以复用。六折方案当前仍待团队决定，本报告没有启动训练。

### 4.2 直接回归：检查网络是否过宽

直接回归的近期修正可以聚焦容量：先比较线性输出、256 维隐藏层与当前 1024 维隐藏层，使用同一患者划分和选模型规则；有必要时再细化 128 维。256 维回归头约 40.1 万参数，当前 1024 维约 160.5 万。减少参数是否保留预测能力，要由同协议实验判断，不能由维度直接推出。  
用户评价：这个需要再看看有没有类似论文可以辅助得出比较适合的隐藏层维数

### 4.3 软关系：先查清辅助目标有没有帮对忙

软关系方案先补三类诊断：真实软权重是否过于分散、相似关系是否主要区分患者、对比目标与回归目标对共享网络的梯度是否冲突。软损失含有固定目标的熵，损失数值较大不自动意味着它主导训练；不应仅凭两项损失的数值比决定权重。现有“完整通路相似关系”与“预测剩余误差”的任务也可能不完全吻合，但这仍是机制假设。

如果诊断支持继续，先固定一个小网络宽度，比较同结构的纯回归、联合对比回归、先对比再回归。先用最小筛选，只有有希望的候选再补少量重复种子。硬配对与软配对的比较应在相同训练安排中进行；同时改宽度、残差结构和训练顺序，无法把结果单独归因于某一个因素。

“患者内相对通路”可作为有条件的关系修订：用训练患者自身训练区域的均值中心化后构造软关系，回归仍预测原通路尺度。它可能减少患者整体偏移，也可能删掉真实且与疗效相关的患者差异，因此只有诊断表明患者背景在主导配对时才值得试。不得用留出患者真实通路计算患者均值，推理也不能依赖真实通路。

### 4.4 空间信息：单独检验，不与其他改动混在一起

空间方案放在后续独立比较。先区分训练时额外提供空间监督、推理时读取邻居图像，以及直接平滑预测或标签。邻域范围必须使用真实物理坐标并限定于同一切片；考察肿瘤—间质边界和各通路差异，不能默认所有通路都适合平滑。改变标签平滑方式时，应在同一参考目标上报告结果并单独标注预处理差异。

## 5. Phase 2 指标的主线与副线

先抓住两句话：**PCC看“高低变化是否跟得上”，z-RMSE看“数值偏离了多少个训练标准差”。** 二者一起报告，才能避免相关性不错却数值偏差很大的情况被平均成绩掩盖。

截至 9 月 5 日，正式登记已采用下列分工。旧学习指南保留了历史文字及追加纠正，因此可以用来理解公式，但不能不加筛选地复制为论文方法。尤其不要沿用其中虚构的置信区间示例、固定通路筛选门槛或跨数据集优越性表述。


| 位置     | 指标及方向                    | 基础计算                                         | 反映什么、为何保留                               |
| ------ | ------------------------ | -------------------------------------------- | --------------------------------------- |
| 正文主线   | PCC，越高越好                 | 中心化后的真值与预测的协方差／两者标准差乘积                       | 看同一通路在不同位置的变化是否一致；与相关论文联系最直接，不能检验绝对值是否准 |
| 正文主线   | z-RMSE，越低越好              | √{平均[((预测−真值)／训练集通路标准差)²]}                   | 用训练集波动尺度报告误差，补足 PCC 对偏移和缩放不敏感的缺陷        |
| 补充副线   | CCC，一致性相关系数，越高越好         | 2Cov(y,ŷ)／[Var(y)+Var(ŷ)+(mean(y)−mean(ŷ))²] | 同时看相关性、均值和尺度；更全面，但不能据此断言达到生理测量精度        |
| 补充副线   | Spearman，排序相关系数，越高越好     | PCC(rank(y),rank(ŷ))；并列值取平均秩                 | 看高低次序是否一致；不等于误差小，也不保证下游疗效有用             |
| 空间补充   | 残差 Moran’s I             | 对残差计算空间加权自相关，详见下方                            | 判断误差是否成片聚集；它不是准确率，低值也可能只是随机误差           |
| 有空间主张时 | Masked SSIM，掩膜结构相似性，越高越好 | 对有效空间窗口内的均值、方差、协方差计算 SSIM，再汇总                | 检查局部空间图案；窗口、掩膜、尺度必须预先固定                 |
| 内部诊断   | R²，决定系数，越高越好             | 1−Σ(y−ŷ)²／Σ(y−mean(y))²                      | 与该评价集合的真值均值常数作参照；负值提示数值重建仍有问题           |
| 历史兼容   | 展平 PCC                   | 将点位×通路矩阵展开为一列后算 PCC                          | 保留历史追溯；混合不同通路，不能替代逐通路 PCC               |
| 条件指标   | 每位置前 k 条通路重合率            | 平均[预测与真实前k集合的交集大小／k]                         | 只有下游确实预设前k选择时使用；当前未采用，不应填数值             |
| 不确定性信息 | 95% CI，置信区间              | 依独立单位进行适当重抽样，优先模型配对差值                        | 说明估计不确定性，不是额外性能指标；均值±标准差不等于95% CI       |


公式中的 y 为真实值，ŷ 为预测值，rank 为排序，Cov 为协方差，Var 为方差。真实值和预测值使用同一套训练集均值 μ及标准差σ转换为 z=(y−μ)/σ；不分别标准化预测和真值，不重新拟合测试患者的标准化参数。

**汇总顺序决定了数值含义。** 先对患者 p 的通路 k，使用该患者所有有效点位计算 rₚₖ；同一通路跨患者用 Fisher-z 变换汇总：rₖ=tanh[meanₚ(atanh(rₚₖ))]；最后等权平均 30 条通路的 rₖ。不是先把整位患者的点位平均成一个数，再计算患者内相关性。除 PCC 外，当前规范跨患者用算术平均。常量目标等无法定义相关性的情形应保留缺失与有效数量。

z-RMSE 同样先逐患者逐通路计算再平均。**先计算各组 RMSE 再平均，不等于把所有误差平方混在一起平均后开根。** 这解释了为什么旧训练损失与新报告指标不能直接互换。PCC 的 Fisher-z 汇总也不同于对所有患者相关系数直接算术平均，文献没有明确协议时必须标记未知。

SSIM 的基础形式为：

```text
SSIM = [(2μyμŷ+C1)(2σyŷ+C2)] / [(μy²+μŷ²+C1)(σy²+σŷ²+C2)]
```

当前实现使用标准化分数、7×7等权窗口、窗口内所有位置均有效、固定动态范围6，因此 C1=0.0036、C2=0.0324；不使用高斯加权或插值。代码中“90%”控制网格名称，不能解释为允许每个窗口有10%缺值。坐标先按唯一值映射到数组，这是否保持真实固定物理间距还需核查；因此现有分数可作为已登记诊断值，正式空间主张仍需完善协议。内部验证无合格完整窗口，应显示“不可计算”，不能补零。

Moran’s I 的基础形式为 I=[N/Σwᵢⱼ]·[Σwᵢⱼ(eᵢ−ē)(eⱼ−ē)/Σ(eᵢ−ē)²]，e为残差，w为邻接权重。当前代码从全部横、纵坐标的正间隔中取最小值作为统一步长，再连接横、纵方向相隔该步长的点；尚未分别核验两个方向的物理间距。接近零只表示缺乏明显空间相关；在常见随机化零假设下期望约为−1/(N−1)，不能把零当作精确的统计阈值。必须结合误差大小、邻接定义和可用点位解释。[空间计算实现](D:/AI空间转录病理研究/PFMval_new/scripts/explorations/mpp2_metric_recalculation_v001/run_recalculation.py:100)

数学细节可回看[既有指标学习指南](D:/AI空间转录病理研究/PFMval_new/01_指南与解读/学习指南/Phase2_空间转录组核心评估指标体系与论文对比学习指南_20260904.md)；当前角色与实际数值以[指标补充登记审计报告](D:/AI空间转录病理研究/PFMval_new/03审计报告/MPP2基线与后续实验指标补充登记审计报告_20260905.md)及[实验登记](D:/AI空间转录病理研究/PFMval_new/experiments/experiment_registry.json:26)为准。

## 8. 现有数值能否证明我们的优势

**目前可以比较本项目两种候选的已观测差值，但还不能据此宣称某方案稳定占优，更不能据跨论文数值建立排行榜。** 内部验证与独立留出患者是不同任务，不能择其中较好的一项作为“整体性能”。


| 容易产生的结论                              | 为什么当前证据不够                                 | 应怎样写或怎样补                               |
| ------------------------------------ | ----------------------------------------- | -------------------------------------- |
| 我们 PCC 约0.52，高于 PEaRL 乳腺癌约0.51，因此更先进 | 癌种、通路集合、标签预处理、患者划分及汇总不同；我们30条，PEaRL数百至上千条 | 仅作相关任务的背景参照。要宣称优势，须同数据、同目标、同划分、同公式重训比较 |

| z-RMSE=0.767小于1，所以胜过常数预测             | 分母为训练标准差；外部患者的分布不一定均值0、方差1                | 显式计算仅用训练均值预测的基线。外部标准化真值的均方根不一定是1       |

| 一名患者有1039个点位，所以CI足够可靠                | 同患者点位有空间相关；通路之间也相关，不能替代独立患者               | 单切片空间块CI只能反映该切片内部波动。跨患者泛化CI需独立患者信息     |
| PCC高的通路一定最有助于疗效预测                    | 易预测不等于与临床结局相关；预测困难也不等于全无下游价值              | 在内部开发中预设选择规则，并比较全部30通路与筛选通路；外部结局不能挑通路  |
| 融合优于仅病理，证明新增了独立组学信息                  | 预测通路是图像的函数，使用时没有新测序；额外分支和压缩本身也可改变训练       | 定位为空间组学监督的知识迁移，增加相同维数普通图像投影对照          |


对单患者单通路，若测试通路标准差按总体公式计算（方差分母为有效点位数N），则有：

```text
R² = 1 − z-RMSE² × (训练通路标准差／测试通路标准差)²
```

因此，训练尺度误差小于1与测试尺度R²为负可以同时成立。这不是公式矛盾，也不能从两个跨通路平均数直接反推出统一的比例。若测试标准差改用分母N−1的样本公式，上式扣除项还须乘N/(N−1)。类似地，若文献 NRMSE 的分母为测试标准差，则其与本项目 z-RMSE 的换算需要知道每条通路、每个测试单位的训练和测试标准差；不能比较两个总平均后下结论。

**95% CI 不跨零不能单独证明生物学机制或临床价值。** 它依赖抽样单位、数据结构和统计假设，比较多条通路还存在多重比较问题。现有旧指南中的基线绝对CI及“高可靠通路数量”没有相应已确认依据，本报告不把它们写成结果。

独立留出患者已在多次分析中被查看。若后续据其成绩选择模型、关系权重、通路或阈值，就不能继续将它当作未经使用的最终盲测。建议把新选择限定在六名开发患者内；更多独立空间转录组患者，才可用于进一步检验最终方案。当前材料不足以证明历史训练已经使用外测调参，也不应反向作此指控。

## 9. 补充实验怎样与 Phase 3 衔接

### 9.1 最少需要交付给 Phase 3 什么

两个候选都应输出同一格式：**每个有效病理小图一行、固定顺序的30项连续预测分数，以及患者、切片、小图标识和坐标。** 同时提供通路名称、分数尺度、训练标准化参数、图像分辨率与物理大小、特征提取方式、模型版本和样例。原始分数和标准化分数必须明确区分。

Phase 3 原计划中的“仅基因”“病理＋基因”，如果实际输入是 Phase 2 的30维预测，应统一改称“仅预测通路”“病理＋预测通路”。不能让读者误以为下游患者做过实测基因表达。

Phase 2训练患者与Phase 3测试患者完全独立时，可冻结Phase 2直接生成预测；若患者重合，则须按下游划分隔离监督训练，必要时生成对应的折外预测。不能只让新对比分支避开下游测试患者，却复用已经见过该患者标签的基线头。另一方面，也不需要无条件把所有下游患者都重新套入一套Phase 2六折。

### 9.2 下游最值得保留的比较


| 比较组        | 实际输入           | 回答的问题                            |
| ---------- | -------------- | -------------------------------- |
| 仅病理        | 图像特征           | 当前形态信息自身能做多好                     |
| 仅预测通路      | 同一位置30项预测分数    | 通路表征单独是否具有疗效信息                   |
| 病理＋预测通路    | 正确配对的两类图像衍生表征  | 融合是否改善患者级预测                      |
| 病理与预测通路错配  | 训练中打乱预定层级的配对   | 正确对应关系是否重要；打乱患者、切片或点位会回答不同问题，须预设 |
| 病理＋普通30维投影 | 不使用通路监督的图像压缩表征 | 收益是否超出额外分支、容量和降维本身的影响            |


使用相同患者划分、相同主干聚合器及相近训练预算。普通30维投影的训练来源必须说明：若在Phase 3学习，则仅使用下游训练患者；如果用PCA（主成分降维），也只在训练数据拟合，而且不能声称与神经网络完全同容量。错配对照与普通投影对照各自排除不同解释，不能相互替代。

想比较两个Phase 2候选对下游的影响，就只替换预测通路来源，其余Phase 3设置保持一致。若改用256维中间表示，则另设相同维数的普通图像表示对照，并明确研究对象已由“具名通路分数”变为“通路监督下的潜在表征”。

### 9.3 解释性与病例处理

请病理医生在不先看预测优劣的条件下，标注少量肿瘤、间质、炎症及交界区域。既看整张切片，也看同一组织类型内部的通路预测，并记录样本量和真值波动范围。这样可以检查模型是否只认出了组织大类，但局部PCC下降也可能由真值变化过小造成，不能直接断言模型只有组织分类能力。

工作计划中的“删去一些差病例优化结果”应改为：按预先定义、与模型预测无关的图像质量和临床纳入标准复核病例；保留全纳入队列主分析，并另报客观排除后的敏感性分析。不能因被模型预测错而删病例。注意力热图表示模型权重，不直接证明细胞机制或因果通路，需要病理复核或遮挡分析支持。

## 11. 组会只需优先讨论三个实验设计问题

**第一，论文希望 Phase 2 承担哪种核心贡献？** 是以直接通路重建及临床迁移的可靠证据为主，还是要求一个独立方法创新？建议先固定直接回归为共同基线。若保留方法创新目标，就选择一个有诊断依据的软关系修订方向，并预先约定升级标准：患者留出结果方向稳定、PCC与误差收益清楚、不是少数通路或单个种子支撑，且复杂度与收益相称。具体最小有意义差值在内部开发前商定，不看外测后追认。

**第二，用什么评估设计支持“新患者可用”和“空间重建”？** 建议讨论六名开发患者的留一患者评估，主文沿用逐通路PCC＋z-RMSE；空间SSIM只在坐标、完整窗口和尺度协议统一后承担空间主张。若暂不补患者留出或无更多外部患者，就相应收缩论文结论，而不是用更多点位代替患者证据。

**第三，补充实验优先回答哪个问题，数据由谁提供？** 建议先由李博士提供能回算通路真值的表达与评分资料；随后开展直接通路／基因重建对照，以及稠密／规则稀疏／等量随机比较。多基础模型比较先定少量代表模型；Phase3先完成患者映射及独立验证条件。坐标、文件格式、具体采样间隔和训练轮次等实现细节可另约小范围确认。
