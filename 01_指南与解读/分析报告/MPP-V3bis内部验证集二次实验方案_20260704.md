# MPP-V3bis 内部验证集二次实验方案

日期：2026-07-04

用途：在 MPP-V3 已确认过拟合后，给下一轮 MPP-V3bis 提供可直接执行、可审计、严格防数据泄露的实验协议。

## 一、结论先行

MPP-V3bis 必须从 MPP-3 的 6 个非 XZY 患者中固定留出 1 个患者作为内部验证集，用 `val_loss` 选择 best checkpoint 和触发 early stopping；XZY 仍只作为最终外部测试集，不能参与训练控制。

推荐默认划分：

| 层级 | 数据 | 用途 | 是否参与参数拟合 |
|------|------|------|:---:|
| Train | MPP-3: `HYZ15040,JFX,LMZ12939,TGC,XSL` | 训练 MLP、拟合 z-score mean/std | 是 |
| Internal Val | MPP-3: `ZHZ` | 选择 epoch、early stopping、scheduler | 否 |
| External Test | MPP-2: `XZY` | 最终外部泛化报告 | 否 |

固定实验 ID：

```text
mpp_v3bis_valZHZ_xzy_external_uni2h_mlp_20260704
```

参数语义：`--train_patients` 只传真正参与训练和 z-score 拟合的 5 个患者；`--val_patient ZHZ` 单独传入。不要把 ZHZ 同时放进 `--train_patients`。

## 二、为什么必须改

MPP-V3 已完成：

| 指标 | Smoke 2 epoch | 正式 50 epoch | 变化 |
|------|:---:|:---:|:---:|
| XZY PCC | 0.6598 | 0.6020 | -0.058 / -9.6% |
| Train PCC | - | 0.9013 | 明显升高 |
| XZY R2 | - | -0.237 | 低于均值预测 |

这说明 frozen UNI2-h feature + MLP 在 42K patch 上会继续记忆训练集，而 `train_loss` 单调下降不能作为泛化停止信号。

严谨口径：2 epoch 的好结果来自 smoke 阶段的外部 XZY 评估，不能把 XZY 变成早停信号。MPP-V3bis 的目标是用独立内部验证患者的 `val_loss` 捕捉 2-5 epoch 的真实泛化窗口，然后只在选定 checkpoint 后评估一次 XZY。

## 三、参考项目原有划分方式

项目旧三患者跨患者实验的核心思想是患者级留一：

```text
Fold1: JFX0729 + LMZ12939 -> HYZ15040
Fold2: HYZ15040 + LMZ12939 -> JFX0729
Fold3: HYZ15040 + JFX0729 -> LMZ12939
```

代码事实：

- `config_utils.get_fold_config()` 定义患者级 train/test。
- `train_online_cls.py` / `train_online_tokens.py` 在 cross-patient 模式下，用 `get_fold_config()` 取训练患者和留出患者。
- 训练脚本以 `val_loss` 最小保存 best checkpoint，而不是按 `val_pcc` 最大选模型。
- 旧 `split.py` 曾做过单患者内部 train/val 空间距离划分，但 MPP-3 有 50% overlap patch，随机 patch split 会产生相似 patch 跨 train/val 的泄漏风险。

因此 MPP-V3bis 不采用随机 patch 内部切分，而采用更稳妥的患者级内部验证：

```text
5 个训练患者 -> 1 个内部验证患者 -> 1 个外部测试患者 XZY
```

这继承旧项目“跨患者留出”的科学边界，同时避开 MPP overlap patch 的去重难题。

## 四、数据泄露硬规则

以下任一条违反，本轮实验应判定无效：

1. XZY 不得参与 MLP 训练、z-score 参数拟合、epoch 选择、scheduler、early stopping、学习率/epoch/seed 选择。
2. 内部验证患者 `ZHZ` 不得参与 MLP 训练，也不得参与 z-score mean/std 拟合。
3. z-score 参数只用 5 个训练患者拟合；同一套参数应用到 train、internal val、external XZY。
4. MPP-3 内部验证不做随机 patch split；整例 `ZHZ` 全部进入 internal val。
5. `train_mpp_id=3` 与 `external_mpp_id=2` 的角色必须写入 summary：训练 MPP-3，外部测试固定 MPP-2/XZY，便于受控比较。
6. `best_checkpoint.pth` 只能由 internal `val_loss` 决定；不能根据 XZY PCC 回滚到某个 epoch。
7. 所有预测文件必须保留 `true_xxx` / `pred_xxx` 列名规范。

## 五、代码改造清单

### 1. `prepare_mpp_zscore.py`

新增参数：

```text
--val_patient ZHZ
--val_strategy internal
```

行为要求：

- `--train_patients` 只包含 5 个训练患者；拟合 z-score 参数时只使用这 5 个患者。
- `--val_patient` 单独加载并转换标签，但不参与 z-score mean/std 拟合。
- 输出训练 5 患者、内部验证 `ZHZ`、外部 `XZY` 的 z-scored CSV。
- `zscore_params_mpp3.json` 写明：
  - `fit_patients`
  - `val_patient`
  - `external_patient`
  - `ddof=1`
  - `clip_applied_after_transform=true`
- 继续保留坐标/ID 列，避免 dataset 回退到行序匹配。

### 2. `dataset_mpp.py`

维持坐标/ID 匹配优先级，但正式训练不允许无坐标/ID 时静默使用行序 fallback。

建议新增审计输出，作为首轮 V3bis 的可选复核文件，不阻塞 smoke test：

```text
split_manifest.csv
patient,split,mpp_id,patch_stem,x,y
```

若生成该文件，最小要求：ZHZ 的所有 patch 都标记为 `internal_val`，XZY 的所有 patch 都标记为 `external_test`。

### 3. `train_mpp_uni2h_mlp.py`

新增参数：

```text
--val_strategy internal
--val_patient ZHZ
```

训练逻辑：

1. 校验 `val_patient` 不在 `train_patients` 中；若重复传入，直接报错，避免参数语义混乱。
2. 构建 `train_loader`：5 个训练患者。
3. 构建 `val_loader`：MPP-3/ZHZ。
4. 每 epoch 记录 train loss/PCC + internal val loss/PCC/MAE/R2。
5. `best_checkpoint.pth` 只按 `val_loss` 最小保存。
6. `patience` 和 scheduler 只监控 `val_loss`。
7. 早停不要保留固定 `epoch >= 10` 守卫；使用 `epoch >= max(patience, 3)` 或完全交给 patience 控制，避免错过 2-5 epoch 的早期窗口。
8. 训练结束后加载 best checkpoint，先对 `val_loader` 评估并输出 `predictions_internal_val.csv`。
9. 随后评估 MPP-2/XZY 一次，输出 external predictions。

`training_history.csv` 必须包含：

```text
epoch,train_loss,train_pcc,val_loss,val_pcc,val_mae,val_r2,is_best
```

`training_summary.txt` 必须写明：

```text
Signal separation:
- train: MPP-3 / HYZ15040,JFX,LMZ12939,TGC,XSL
- internal_val: MPP-3 / ZHZ, used for val_loss early stopping only
- external_test: MPP-2 / XZY, evaluated once after checkpoint selection
```

### 4. `scripts/finalize_experiment.py`

确认或补齐：

- 对 `val_strategy=internal` 读取 `training_history.csv` 中的 `val_loss`。
- `best_epoch` 按 `val_loss` 最小，不按 `val_pcc` 最大。
- registry 写入 `val_patient=ZHZ`、`external_xzy_pcc`、`best_val_loss`、`best_val_pcc`。
- dashboard 中区分 internal val 指标与 external XZY 指标。
- V3bis 不使用 `--no-val`；启动训练前必须先在 `experiments/experiment_registry.json` 中注册 experiment entry，状态为 `planned`。

## 七、泄漏审计清单

训练前检查：

| 检查 | 通过条件 |
|------|------|
| 患者集合 | train=5，internal_val=ZHZ，external=XZY，三者无交集 |
| z-score fit | `zscore_params_mpp3.json.fit_patients` 不含 ZHZ/XZY |
| 标签匹配 | dataset 坐标/ID 匹配率接近 100%，正式训练无行序 fallback |
| XZY 使用 | 代码中 XZY loader 只在最终 external evaluate 调用 |
| best epoch | 由 internal `val_loss` 最小决定 |
| 输出列名 | predictions 文件只用 `true_` / `pred_` |

训练后检查：

| 文件 | 必须包含 |
|------|------|
| `training_history.csv` | train + internal val 全部指标，`is_best` 只有一行 true |
| `training_summary.txt` | 三层信号源说明、best epoch、external XZY 一次性评估说明 |
| `predictions_internal_val.csv` | ZHZ internal val 预测 |
| `predictions_external_xzy.csv` / `predictions.csv` | XZY external test 预测 |
| `per_pathway_pcc_external_xzy.csv` | XZY 逐通路 PCC |
| `split_manifest.csv` | 建议输出；每个 patch 的 train/internal_val/external_test 归属 |

`min_delta=1e-4` 暂作为初始值；smoke 后应观察 internal `val_loss` 的自然波动幅度，若曲线在 1e-4 到 1e-3 量级频繁抖动，再调大 `min_delta` 或考虑平滑策略。

## 八、结果解释规则

主报告只比较 external XZY：

```text
External XZY PCC / MAE / R2 / per-pathway PCC
```

内部验证只用于训练控制：

```text
Internal val_loss -> best epoch / early stopping
```

禁止写法：

```text
ZHZ internal val PCC 代表最终跨患者泛化性能
```

推荐写法：

```text
MPP-V3bis 使用 ZHZ internal val_loss 选择 epoch，并在 checkpoint 固定后一次性评估 MPP-2/XZY。
```

## 九、可选稳健性复核

若 V3bis 显著优于 V3，不要立刻用 XZY 结果反复调参。更稳妥的复核是固定同一超参数，再换一个内部验证患者做敏感性检查：

```text
mpp_v3bis_valTGC_xzy_external_uni2h_mlp_20260704
```

这只用于判断 `val_patient=ZHZ` 是否偶然，不用于根据 XZY 结果挑选更好验证患者。最终论文/组会汇报应保留第一次预注册的 `valZHZ` 为主结果。

## 十、成功标准

本轮不是追求训练 PCC，而是恢复可控泛化选择链条。

最低成功标准：

- 训练在 50 epoch 之前或之内由 `val_loss` 给出清晰 best epoch。
- best epoch 落在 2-10 epoch 的早期窗口，符合 V3 过拟合观察。
- External XZY PCC 高于 V3 正式 0.6020。
- External XZY R2 不再为明显负值，或至少较 -0.237 明显改善。

强成功标准：

- External XZY PCC 接近或超过 smoke 0.6598。
- Train PCC 与 XZY PCC gap 明显小于 V3 的 0.9013 vs 0.6020。
- 逐通路 bottom-3 不再集中崩坏，尤其 ifng / Interferon_Alpha / Reactive_Oxygen_Species 有改善。
