## 一、方案目标

在不阻塞 Phase 3 的 CLAM、DTFD-MIL、TransMIL 等治疗响应建模进度、不大幅修改现有融合接口的前提下，将 MPP2 后续实验拆分为两条相互独立、可并行推进的技术路线：

### 路线 A：绝对通路分数改进线

继续预测与当前合同一致的30维绝对或训练尺度通路分数，优先尝试低改动、可快速验证的空间增强、原型修正和轻量表示适配方法。

该路线的主要目的为：

1. 直接提高外部患者通路预测性能；
2. 保持 Phase 3 输入含义和数据格式不变；
3. 一旦获得稳定增益，可立即替换现有虚拟通路特征文件；
4. 为 Phase 3 的 pCR 二分类预测提供更高质量的30维虚拟通路输入。

### 路线 B：相对通路活性探索线

不再要求模型跨患者恢复可靠的绝对 ssGSEA 分数，而是预测同一患者内部、逐通路的空间相对活性关系。

该路线的主要目的为：

1. 降低跨患者测序尺度、分布偏移和标准化失配的影响；
2. 保留通路热点、低活性区域和空间异质性；
3. 以不修改 Phase 3 主体结构的方式，快速验证相对通路特征对 pCR AUC 是否具有增量价值；
4. 为后续空间序数建模、GraphSAGE、连续关系对齐和原型解释提供依据。

两条路线不得在第一阶段混合开发。任何复杂组合模型必须建立在单模块已经通过内部验证门槛的基础上。

# 二、当前固定基线与工程边界

## 2.1 固定输入

- 固定 UNI2-h 病理基础模型；
- 不重新提取或微调 UNI2-h；
- 仅使用已经缓存的1536维 CLS 特征；
- 30条通路定义、名称及顺序保持固定；
- 不新增不存在的单基因标签；
- 不将输出扩展为高维基因表达。

项目既有方案也已明确将 UNI2-h 固定为下游实验的特征提取基础，后续改造集中在空间邻域、通路表示和原型匹配。fileciteturn0file0L5-L7

## 2.2 当前模型合同

当前 accepted baseline 为：

```text
1536维 UNI2-h CLS
        ↓
Linear 1536→1024
        ↓
GELU
        ↓
Dropout=0.3
        ↓
Linear 1024→30
        ↓
30维通路预测
```

当前公开代码使用30维输出头和 MSELoss。 

Dataset 当前虽然能够从 manifest 获得患者、patch 和 `x/y` 信息，但训练时最终只返回：

```text
feature, target
```

即1536维特征和30维标签。 

因此，第一阶段优先选择仍然输出“每个 patch 对应30维数值”的方法，确保 Phase 3 只需替换输入文件或配置路径。

# 三、双线共同实验治理合同

## 3.1 数据划分

所有正式模型选择均采用6名 fit 患者的 patient-level LOPO：

- 每折留出1名完整患者验证；
- 其余5名患者训练；
- 同一患者的所有切片和所有 patch 必须位于同一侧；
- 不允许患者内 patch 随机拆分作为正式模型选择依据；
- 所有超参数和停止决策只依据6折 LOPO；
- XZY 不参与训练、损失权重选择、epoch 选择和超参数选择。

当前公开训练代码支持患者级内部验证，也存在 manifest patch-level 验证模式，但后者不能替代本方案要求的 patient-level LOPO。 

## 3.2 XZY 的定位

XZY 已经用于发现“pooled PCC 较高但 raw R² 为负”的跨患者尺度问题，因此不能再被视为完全未影响方法设计的纯净外部测试集。

本方案将其定义为：

> external challenge set，而不是超参数调优集。

每个候选方法仅允许在以下条件满足后对 XZY 评估一次：

1. 方法结构已经冻结；
2. 超参数已经由 LOPO 决定；
3. 训练 epoch 和 checkpoint 选择规则已经冻结；
4. 输出合同已经固定；
5. 不允许根据 XZY 结果继续调整该候选。

## 3.3 Phase 3 数据隔离

Phase 3 pCR 预测必须采用患者级划分：

- 同一患者的2～3张切片不得跨训练折和验证折；
- Phase 2 模型在生成 Phase 3 虚拟通路时必须保持完全冻结；
- Phase 3 内部的标准化、特征选择和融合参数只能在训练折拟合；
- 不能使用完整 Phase 3 队列统计量后再交叉验证。

## 3.4 统一输出接口

所有 Phase 2 候选必须输出统一格式：

```text
patient
slide
patch_stem
x
y
pathway_01
...
pathway_30
score_type
model_version
checkpoint_hash
```

其中 `score_type` 至少支持：

```text
absolute_baseline
absolute_spatial_refined
absolute_prototype_refined
absolute_adapter
ordinal_posthoc
ordinal_trained
```

强制要求：

- 30条通路名称和顺序完全一致；
- 使用 `patient + slide + patch_stem` 对齐，不依赖行号；
- 不得因某模型缺失 patch 而静默删除；
- 输出 NaN、Inf、重复 patch 或列顺序不一致时，禁止进入 Phase 3；
- 每个结果必须记录代码提交、标签版本、checkpoint 和参数配置。

# 四、两级实验门槛

所有实验分为两个阶段。

## 4.1 工程冒烟阶段

只验证：

- 代码可以运行；
- 标签和特征能够正确匹配；
- 输出维度仍为30；
- 无 NaN、Inf；
- 训练损失可以下降；
- 输出文件可以被 Phase 3 读取；
- patch 数量、顺序和通路列正确。

工程冒烟通过不代表模型有效。

## 4.2 科学验证阶段

必须完成6折 patient-level LOPO。

只有通过科学门槛的模型，才允许：

1. 对 XZY 进行一次冻结评估；
2. 向 Phase 3 团队交付；
3. 进入下一层复杂实验。

# 五、路线 A：绝对通路分数快速改进线

## 5.1 路线目标

在保持现有绝对30维输出含义、文件格式及 Phase 3 接口不变的情况下，寻找可以低成本提高外部通路预测性能的方法。

第一阶段只运行三个最小候选，分别对应空间、原型和表示适配三个方向。

---

## A0：Accepted Baseline 复现

### 模型

```text
1536→1024→30
GELU
Dropout=0.3
MSE
```

### 目的

- 建立新的6折 LOPO 对照；
- 确认 repaired baseline 可以稳定复现；
- 记录每一折、每一通路和每名患者的指标；
- 为后续所有候选提供配对比较基础。

### 必须保存

- 每折 checkpoint；
- 每折 OOF 预测；
- 逐通路 PCC；
- 患者级 pooled PCC；
- raw MAE；
- raw R²；
- 训练时间和参数量；
- 所有 patch 的预测文件。

若 baseline 无法在新 LOPO 协议下稳定复现，禁止开始后续模型比较。

---

## A1-S：预测后轻量空间邻域修正

### 基本方法

不重新训练模型，直接对 accepted baseline 的预测结果进行轻量邻域修正：

\[
\hat y_i^{new}
=
(1-\lambda)\hat y_i
+
\lambda\sum_{j\in N(i)}w_{ij}\hat y_j
\]

其中：

- \(i\) 为当前 patch；
- \(N(i)\) 为同一患者、同一切片内的空间近邻；
- \(w_{ij}\) 为归一化邻居权重；
- 不跨患者；
- 第一阶段不跨切片；
- 不使用真实标签进行推理时平滑。

### 推荐最小配置

只测试预先固定的少量组合：

- 邻居数：4、8；
- 平滑权重：0.10、0.20。

总计不超过4个配置。

### 选择原因

- 不改网络；
- 不改训练过程；
- 只需要 manifest 坐标；
- Phase 3 输出接口完全不变；
- 可以最低成本验证“当前预测是否仍存在可利用的空间连续性”。

### 通过门槛

相对于 A0：

1. 6折 patient-level pooled PCC 宏平均提升至少 +0.005；
2. 至少4/6名 held-out patient 获得正增益；
3. 30条通路 PCC 中位数不得下降超过0.003；
4. raw MAE 不得恶化超过1%；
5. raw R² 不得恶化超过0.02；
6. 增益不得由单一患者贡献超过总增益的50%。

若没有配置通过，停止该空间平滑分支，不进入 GraphSAGE。

### 主要风险

- 肿瘤—间质边界被错误平滑；
- 小区域热点被抹除；
- PCC 上升但空间异质性减少；
- 平滑只是在降低预测方差，而非增加真实生物信息。

---

## A1-P：固定患者平衡原型残差

### 基本方法

在每个 LOPO 训练折内：

1. 只使用5名训练患者；
2. 在 UNI2-h 特征空间中聚类；
3. 建立16或32个固定原型；
4. 每个原型使用真实训练 patch medoid，而不是自由可学习向量；
5. 记录该原型对应训练 patch 的30维平均通路谱；
6. 对新 patch 根据特征相似度获得原型建议；
7. 使用小权重残差修正原 MLP 预测：

\[
\hat y_i^{new}
=
\hat y_i^{MLP}
+
\alpha
\left(
\hat y_i^{proto}
-
\hat y_i^{MLP}
\right)
\]

### 推荐最小配置

- 原型数：16；
- \(\alpha\)：0.10；
- 原型构建要求患者平衡；
- 不使用动态更新；
- 不加入 Attention、CBAM、ECA 或图网络。

### 选择原因

- 输出仍为30维绝对通路分数；
- 不修改 Phase 3 接口；
- 可以同时探索性能和可解释性；
- 比完整 EGN/EGGN 改造成本低；
- 能够输出“当前 patch 最像哪个训练病理区域”。

### 通过门槛

除采用 A1-S 的通用性能门槛外，还要求：

1. 原型不能由单一患者占据；
2. 原型患者纯度不能普遍接近100%；
3. 真实原型通路谱必须明显优于随机置换原型通路谱；
4. 原型修正系数不得在多数折等效为0；
5. 原型结果在不同 LOPO 折中具有基本稳定性。

若固定原型不通过，不允许开发动态可学习原型。

### 主要风险

- 原型代表染色风格或患者身份；
- 原型数量不足导致稀有形态被平均；
- 原型平滑造成预测范围收缩；
- 生成的图像解释漂亮，但与预测增益无关。

---

## A1-A：轻量残差 Adapter 探针

### 基本方法

在固定1536维 UNI2-h 特征后加入一个零初始化残差 Adapter：

```text
1536
 ↓
64
 ↓
1536
 ↓
原有1024→30预测头
```

形式为：

\[
f'=f+A(f)
\]

其中 Adapter 最后一层零初始化，使模型训练初始状态接近原始特征。

第一阶段只使用原有 MSE，不加入：

- 对比学习；
- PCC loss；
- pathway graph；
- patient-aware hard negative；
- 多任务 loss。

### 选择原因

该实验用于回答：

> 在不修改 UNI2-h、不增加复杂损失的情况下，轻量特征适配是否已经能够提升跨患者泛化？

它是后续连续形态—通路对齐的结构前置实验，不代表完整 PEaRL 启发方法已经得到验证。

### 通过门槛

相对于等参数 MLP 对照：

1. patient-level pooled PCC 宏平均提升至少 +0.005；
2. 至少4/6患者正增益；
3. 等参数非 Adapter MLP 不能取得相同收益；
4. raw MAE 和 raw R²不得出现明显恶化；
5. 三个固定随机种子的方向必须基本一致。

若 Adapter+MSE 不能超过等参数 MLP，则停止连续关系对齐分支。

### 主要风险

- 增益只来自参数量增加；
- 6名患者不足以支持额外自由度；
- Adapter 学到患者或染色差异；
- 训练集改善但 held-out patient 下降。

# 六、路线 A 初始实验的晋级规则

A1-S、A1-P 和 A1-A 独立评估，不允许第一阶段组合。

每个候选被划分为以下三类：

## 6.1 通过

满足全部预注册门槛。

处理方式：

- 冻结配置；
- 在 XZY 上评估一次；
- 输出标准30维绝对通路文件；
- 交付 Phase 3 团队测试 pCR AUC；
- 可进入对应递进实验。

## 6.2 非劣但无明确提升

满足：

- PCC 未明显提升；
- 但下降不超过0.003；
- Phase 3 AUC可能具有解释性或增量价值。

处理方式：

- 可以作为探索性 Phase 3 输入；
- 不得宣称提高了 MPP2 通路预测；
- 只有当 Phase 3 AUC出现稳定增益时，才允许保留。

## 6.3 失败

任一情况成立：

- 少于4/6患者正增益；
- 增益由单一患者主导；
- raw误差明显恶化；
- 逐通路结果普遍下降；
- 随机种子不稳定；
- 等参数对照表现相当；
- Phase 3 AUC不升反降。

处理方式：

- 停止该分支；
- 不进入更复杂版本；
- 不通过更换 XZY 配置继续搜索。

# 七、路线 A 通过后的递进实验

## 7.1 空间分支递进

只有 A1-S 通过后，按以下顺序推进：

### A2-S1：一层零门控 GraphSAGE

- 单切片内建图；
- kNN 加最大距离限制；
- 一层 GraphSAGE；
- 邻域分支以零门控残差方式加入 baseline；
- 必须包含等参数 MLP 对照。

### A2-S2：局部 Transformer 或 edge-aware GAT

只有 GraphSAGE 稳定通过后才测试：

- 固定数量局部邻居；
- 相对位置编码；
- 不使用全图 Transformer；
- 不优先使用 ConvSSM。

### A2-S3：ConvSSM

仅在以下条件同时满足时考虑：

1. GraphSAGE 已证明空间结构有效；
2. 局部注意力仍存在明确性能上限；
3. 已解决非规则组织边界和扫描顺序问题；
4. 有充足工程预算进行方向、mask 和边界消融。

项目既有方案文档将 ConvSSM、MambaIR 和 AKConv列为可选模块，但这些是候选算子，不是本项目已验证结果。fileciteturn0file0L37-L58

---

## 7.2 原型分支递进

只有 A1-P 通过后：

### A2-P1：32个原型对照

比较16与32个固定 medoid 原型。

### A2-P2：锚定式动态原型

允许原型轻微更新，但必须通过约束使其不远离真实训练 medoid。

### A2-P3：原型空间解释

输出：

- 原型真实病理 patch；
- 原型30维通路谱；
- 新患者原型匹配权重；
- 原型空间热图；
- 跨患者原型稳定性；
- 原型置换对照。

不得在无医生复核时直接将原型命名为具体临床区域。

---

## 7.3 连续关系对齐分支递进

只有 A1-A 通过后：

### A2-A1：标准一对一对比学习

验证简单图像—通路配对对齐是否有效。

### A2-A2：连续关系对齐

使用 pathway profile 相似度作为软关系监督，避免把通路状态相近的其他 spot 全部作为负样本。

### A2-A3：低权重相关性损失

只有连续关系对齐已经有效时，才单独测试低权重相关性辅助损失。

第一轮不得同时加入：

- Adapter；
- 连续对比损失；
- PCC loss；
- pathway graph；
- 多种 negative sampling 策略。

# 八、路线 B：相对通路活性快速探索线

## 8.1 任务定义

路线 B 的主目标不是比较同一 spot 内30条通路谁高谁低，而是：

> 对每名患者、每条固定通路，预测该 patch 在该患者全部有效 patch 中处于相对低、中还是高活性区域。

设患者 \(p\)、patch \(i\)、通路 \(k\)，相对标签定义为：

\[
r_{pik}
=
\frac{\operatorname{rank}_{i\in p}(y_{pik})-0.5}{N_p}
\]

其中：

- 每条通路独立排序；
- 排名范围为0～1；
- 同一患者所有纳入切片原则上统一排序；
- 不在 mini-batch 内临时排名；
- 不进行同一 spot 内30条通路直接互相比较。

该任务生成的是患者内空间通路活性图，而不是跨患者绝对通路浓度。

---

## B0：Phase 3 接口审计

在进行相对实验前，必须确认 Phase 3 当前数据流。

### 必须确认

30维虚拟通路是：

1. 逐 patch 与 UNI2-h 特征拼接后输入 CLAM、DTFD-MIL、TransMIL 等多实例学习方法；

还是：

2. 先对患者全部 patch 求均值，再生成患者级30维特征。

### 裁决

若为逐 patch 融合：

- 可直接接入 ordinal 特征；
- 只需替换30维输入文件。

若为简单患者均值：

- 患者内百分位均值通常接近0.5；
- 相对信息会被平均操作消除；
- 不得直接开展 B1；
- 需要改用分位数、热点面积或空间统计量，这属于后续较大改动。

---

## B1：Accepted Baseline 预测后患者内排名

### 基本方法

不重新训练 Phase 2。

对 accepted baseline 已生成的绝对预测：

1. 按患者汇总全部有效 patch；
2. 对每条通路分别排序；
3. 将预测转换为0～1患者内百分位；
4. 输出与原文件同样的30维格式。

即：

```text
absolute_prediction
        ↓
patient-wise pathway-wise rank
        ↓
ordinal_posthoc
```

### 选择原因

- 不需要重新训练；
- 不修改 Phase 2 网络；
- 不修改 Phase 3 主体；
- 可以最快回答相对特征是否对 pCR AUC 有价值；
- 是整个相对路线的最低成本可行性筛查。

### Phase 2 描述性指标

B1不代表模型学习能力提高，因此只报告：

- XZY 每通路 Spearman；
- XZY 每通路 Kendall；
- top-20%真实热点与预测热点重合度；
- 各通路空间热图；
- 与随机排名、coordinate-only基线比较。

不得将“排名后数值更整齐”解释为 Phase 2 性能提升。

### Phase 3 通过门槛

使用完全相同的 Phase 3 多实例学习方法：

- 相同患者划分；
- 相同随机种子；
- 相同训练 epoch；
- 相同超参数；
- 只替换虚拟通路输入。

以下任一条件成立，可进入 B2：

#### 条件一：替代有效

```text
HE + ordinal_posthoc
```

相对于：

```text
HE + accepted_absolute
```

满足：

1. 重复 patient-level CV 平均 AUC 提升至少 +0.01；
2. 至少70%的配对运行方向为正；
3. 不存在由单一 fold 驱动的异常提升。

#### 条件二：互补有效

```text
HE + absolute + ordinal_posthoc
```

相对于：

```text
HE + absolute
```

平均 AUC 提升至少 +0.01，且增益在多数重复划分中存在。

若 B1 无任何 Phase 3 增量，停止相对路线的高成本模型开发，除非 XZY 排序指标显示 accepted baseline 的排序能力明显不足且存在充分理由训练专门 ordinal 模型。

---

## B2：同结构 Ordinal MLP

### 基本方法

保持模型结构完全不变：

```text
1536→1024→30
GELU
Dropout=0.3
MSE
```

只将标签替换为：

```text
患者内、逐通路空间百分位
```

### 实施原则

- 每名患者、每条通路单独生成相对标签；
- 训练患者排名只依赖其自身真实标签；
- held-out patient 标签只用于评估；
- 不使用 patch-level train/val 混合排名；
- 推理时对模型输出再次按患者、逐通路排名，获得稳定0～1特征；
- 不进行 raw-scale inverse transform。

### Phase 2 主指标

- 每患者、每通路 Spearman；
- 六名患者的宏平均 Spearman；
- Kendall’s \(\tau_b\)；
- spot pair concordance；
- top-20%热点 Jaccard；
- top-20%热点 AUROC；
- 30条逐通路结果；
- 空间块 bootstrap。

### 通过门槛

相对于 B1 的 post-hoc ordinal：

1. LOPO 宏平均 Spearman 提升至少 +0.01；
2. 至少4/6 held-out patient 正增益；
3. top-20%热点 Jaccard 平均提升至少 +0.02；
4. 不能只改善 pooled rank 指标而逐通路指标不变；
5. 三个随机种子结果方向基本一致。

通过后：

- 冻结 B2；
- 在 XZY 上评估一次；
- 生成 Phase 3 ordinal_trained 文件；
- 与 B1 使用相同 Phase 3 协议比较 AUC。

---

## B3：绝对与相对双文件联合

若 B1 或 B2 在 Phase 3 中通过，不立即开发 Phase 2 双头网络，而是直接输出两个文件：

```text
virtual_pathway_absolute.csv
virtual_pathway_ordinal.csv
```

Phase 3 比较：

```text
HE only
HE + absolute
HE + ordinal
HE + absolute + ordinal
```

若 Phase 3 只需把通路输入从30维扩展为60维，该改动优先于开发 Phase 2 双头模型。

### 选择原因

- 保留患者整体和绝对尺度信息；
- 同时保留患者内部空间关系；
- 消融最清楚；
- Phase 2 两个模型彼此独立；
- 避免绝对损失和 ordinal 损失相互干扰。

---

# 九、路线 B 通过后的递进实验

只有 B2 通过 Phase 2 排序门槛并在 Phase 3 中获得增量后，才依次考虑：

## B4-S：Ordinal + 空间邻域

顺序为：

1. ordinal预测后邻域平滑；
2. 一层零门控 GraphSAGE；
3. 局部 Transformer 或 edge-aware GAT。

不得直接从 ordinal MLP 跳到 ConvSSM。

## B4-A：Ordinal + 连续关系对齐

使用患者内 rank profile 计算通路相似关系，再进行形态—通路连续对齐。

必须依次比较：

```text
ordinal MLP
ordinal Adapter + MSE
ordinal Adapter + 标准对比
ordinal Adapter + continuous relational loss
```

## B4-P：Ordinal 原型解释

原型通路谱不再展示绝对分数，而展示：

- 原型对应哪些通路经常处于患者内高百分位；
- 原型在患者空间中的分布；
- 原型是否跨患者复现；
- 原型是否与 pCR 相关区域共现。

优先使用真实 medoid，不直接使用自由动态原型。

# 十、Phase 3 最低成本验证矩阵

Phase 3 第一轮不修改既定的 CLAM、DTFD-MIL、TransMIL 等主体，只替换或拼接输入。

最低实验矩阵为：

| 编号 | Phase 3 输入 | 目的 |
|---|---|---|
| P0 | HE only | 基础图像对照 |
| P1 | HE + accepted absolute | 当前正式方案 |
| P2 | HE + improved absolute | 绝对路线增益能否传递 |
| P3 | HE + ordinal post-hoc | 相对尺度假设快速筛查 |
| P4 | HE + trained ordinal | 专门训练相对模型是否更好 |
| P5 | HE + absolute + ordinal | 两类通路信息是否互补 |

所有实验必须使用相同：

- patient-level folds；
- 随机种子；
- CLAM、DTFD-MIL、TransMIL 等方法配置；
- 优化器；
- epoch；
- early stopping；
- patch过滤规则。

初始比较只允许改变 Phase 2 虚拟通路输入。

---

# 十一、Phase 3 必要对照

30维虚拟通路由 UNI2-h 特征预测而来，而 Phase 3 本身也输入 UNI2-h 特征，因此虚拟通路并非完全独立模态。

为证明 AUC 增益来自通路监督，而不仅是额外30维压缩特征，建议至少加入一个低成本对照：

```text
HE + 30维普通压缩特征
```

普通压缩特征可以是：

- 未使用通路监督的30维 MLP 压缩；
- 固定随机投影；
- 训练折内 PCA 30维。

若：

```text
HE + virtual pathway
```

未优于：

```text
HE + generic 30D compression
```

则不能把增益完全解释为通路生物学信息。

---

# 十二、总体停止规则

## 12.1 绝对线停止规则

任一情况成立，停止对应分支：

- 初始实验少于4/6患者正增益；
- LOPO 增益低于 +0.005；
- 增益由单一患者主导；
- 等参数 MLP取得相同结果；
- raw MAE或R²明显恶化；
- XZY出现灾难性下降；
- Phase 3 AUC无增量；
- 随机种子结果方向不稳定。

## 12.2 相对线停止规则

任一情况成立，停止或降级：

- B1 post-hoc ordinal 对 Phase 3 无任何增量；
- B2不能优于B1；
- 固定空间模板或 coordinate-only 与模型相当；
- 真实热点与预测热点重合度低；
- 逐通路 Spearman 未改善；
- ordinal输入被 Phase 3 简单求均值后失去信息；
- Phase 3 image-only模型已包含全部增益；
- absolute + ordinal 不优于 absolute；
- 结果依赖某个单一患者或单一切片。

## 12.3 组合模型停止规则

只有两个单模块均独立通过，才允许组合。

组合模型必须同时超过：

- 原 baseline；
- 单模块 A；
- 单模块 B；
- 等参数复杂度对照。

若组合仅超过 baseline，但不超过最佳单模块，应选择单模块。

# 十三、推荐执行顺序

## 第一阶段：共同准备

1. 建立6患者 LOPO baseline；
2. 固定 Phase 2 输出 schema；
3. 确认 Phase 3 当前是逐 patch 融合还是患者均值融合；
4. 固定 Phase 3 patient-level CV splits 和随机种子；
5. 建立 HE only、HE + accepted absolute 基线。

## 第二阶段：最低成本并行实验

### 绝对线

```text
A1-S：预测后邻域平滑
A1-P：固定原型残差
A1-A：零初始化 Adapter + MSE
```

### 相对线

```text
B1：accepted baseline预测后患者内排名
```

此阶段优先获得可以直接交给 Phase 3 的标准30维文件。

## 第三阶段：通过门槛后的有限升级

### 绝对线

- 空间平滑通过 → 一层 GraphSAGE；
- 固定原型通过 → 锚定动态原型；
- Adapter通过 → 连续关系对齐。

### 相对线

- B1 Phase 3 有增量 → B2 ordinal MLP；
- B2通过 → absolute + ordinal 双文件；
- 双文件有效 → ordinal空间建模或连续关系对齐。

## 第四阶段：最终组合

只测试已经独立成功的组合，例如：

```text
improved absolute + trained ordinal
ordinal + GraphSAGE
absolute GraphSAGE + ordinal
continuous alignment + fixed prototype
```

不得一次性加入多个未经单独验证的模块。

---

# 十四、最终决策原则

本双线方案不预设绝对路线或相对路线必然成功。

最终采用何种 Phase 2 输出，由两级证据共同决定：

## Phase 2 层面

证明模型确实能够：

- 更准确预测绝对通路；
- 或更稳定恢复患者内空间通路关系。

## Phase 3 层面

证明虚拟通路能够：

- 提高 pCR AUC；
- 在 patient-level CV 中稳定；
- 对 HE-only 模型提供增量；
- 优于普通30维特征压缩对照。

最终可能出现四种结论：

### 结论一：绝对有效，相对无效

继续使用 improved absolute。

### 结论二：相对有效，绝对无效

优先使用 ordinal，但保留 HE 主分支。

### 结论三：两者互补

使用 absolute + ordinal 双视图。

### 结论四：二者均不能提高 Phase 3 AUC

停止继续增加 Phase 2 模型复杂度，将 Phase 2 定位为生物学解释或辅助分析，而不作为 Phase 3 性能主线。

本方案的核心原则为：

> 先保持接口稳定，使用最低成本实验验证核心假设；单模块通过后再增加复杂度；Phase 2 指标改善必须进一步接受 Phase 3 pCR AUC 的下游检验。
