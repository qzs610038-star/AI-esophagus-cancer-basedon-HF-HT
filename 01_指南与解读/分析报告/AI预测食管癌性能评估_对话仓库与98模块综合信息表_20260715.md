## 0. 结论先行

1. 当前仓库可确认的正式主线是：`UNI2-h frozen CLS [1536] → Linear(1536,1024) → GELU → Dropout(0.3) → Linear(1024,30)`，预测 30 个空间通路/ssGSEA 分数，而不是全转录组重建，也不是已经完成的 pCR/MPR 治疗响应模型。
2. 当前应引用的 Phase 2 结果是 repaired MPP2 frozen baseline：外部 XZY `PCC=0.6549`、`raw MAE=1176.2114`、`raw R²=-0.088`。LoRA r=8 smoke 的候选有效性门失败，不能包装成增益。
3. 对话与 G09 补充的 Phase 3 主任务是 **pCR/MPR 治疗响应预测**：78 例独立患者、每例 2–3 张同一手术标本同一区域连续切片、有 patch 坐标，拟融合 H&E 与预测通路特征；本地已有 G09/PPT 候选材料，但仍没有 tracked patient manifest、完整标签表、模型代码、逐折患者级预测或 validated result bundle。
4. 对话把 Graph Transformer 排为第一优先，方向合理但优先级偏激进。结合 78 例样本、同源模态冗余和半年投稿约束，最先应做的是：**泄漏安全的 H&E-only / pathway-only / 简单融合基线，再尝试低参数 pathway-gated 或 low-rank fusion + coordinate-aware MIL**；图模型作为第二阶段增量。
5. `D:\98个即插即用的AI模块-阿飞` 虽以“98 个”命名，但原始 Markdown 实际解析出 **89 个模块**，README 也写“总计 89 个”。其中最适合当前任务的是 Low-rank Multimodal Fusion、Adaptive Fusion、CentralNet，以及在大量 token 时可考虑的 Agent Attention；GAT、Graph Transformer、MIL、pathway cross-attention 和连续切片一致性并不在该资料包中。
6. 当前最大阻塞不是选模块，而是 Phase3 标签闭环。患者标签中仅部分记录出现 `completely success`；该文本不是标准 pCR/MPR 术语，最多只能提出“可能表示 pCR 阳性”的假设。其余空白患者不得自动视为非 pCR/MPR，必须回查病理定义与逐患者标签。

# 3. 对话推荐方案的快速校验与优先级修正

## 3.1 推荐优先级总表

| 优先级 | 方案 | 快速结论 | 为什么 |
|---|---|---|---|
| **P0：先做** | 严格 patient-level 的 H&E-only、pathway-only、concat/gated-fusion 基线 | 必须 | 没有这些基线，无法证明 virtual pathway 带来临床增益；78 例不适合先堆复杂模块 |
| **P0：主模型首试** | **低参数 pathway-gated / Low-rank Fusion + coordinate-aware Attention MIL** | **最优先的创新模型** | 与冻结 UNI2-h、30 维 pathway、小患者队列最匹配；同时保留 patch 级解释和空间坐标，参数/过拟合风险低于重型 Graph Transformer |
| **P1** | 连续切片 patient-level 聚合 + slide-embedding consistency | 推荐 | 利用独特的 2–3 张连续切片；先在切片级 embedding 做一致性，不要求尚未证实的像素级配准 |
| **P1/P2** | 轻量坐标 GAT / spatial graph pooling | 条件推荐 | 仓库已有历史 GAT/graph 构图代码可参考，但它不属于当前 MPP2 正式证据；需先证明简单空间 MIL 有增益 |
| **P2** | Pathway-aware cross-attention | 可做消融或增强版 | 解释性好，但 pathway 是同一 H&E 特征的确定性派生，存在冗余；必须与等参数 concat/gating 对照 |
| **P2** | Agent Attention / BiFormer 处理大量 patch token | 条件推荐 | 只有当 token 数导致显存/复杂度瓶颈时才体现价值；不是生物学创新本身 |
| **P2/P3** | morphology–pathway contrastive alignment | 可探索 | 可强化同 spot 对齐，但 30 维连续通路向量并非天然独立模态，负样本设计容易引入患者/空间偏差 |
| **P1/P2** | 冻结 UNI2-h 后的低瓶颈 residual pathway adapter | 条件推荐 | 不改 backbone，只在 1536 维冻结特征后做小容量残差映射；比内部 LoRA 风险低，但必须与原 MLP 做参数匹配对照，不能因名称是“adapter”就默认有效 |
| **P1/P2** | 冻结 UNI2-h + coordinate/spatial adapter | 条件推荐 | 将后训练限制在空间上下文层而非改写 UNI2-h；与当前“单 patch 独立回归”的缺口最匹配，前提是先证明坐标/邻域在 internal validation 上有稳定增益 |
| **P3** | Phase 2–Phase 3 joint multi-task learning | 暂缓 | 两队列不配对，Phase 2 无 pCR/MPR 标签、Phase 3 无真实 pathway 标签；“78 例直接帮助 Phase 2”并不成立，需复杂的 unpaired/alternating training 才可能实现 |
| **P3/仅新批准后** | UNI2-h 最后 1–2 个 block 的选择性 LoRA | 不是当前推荐路线 | 全/广泛 LoRA r=8 已正式判定 `candidate_effectiveness_fail / no_go_formal`；只有出现新假设、显著降参和新的实验批准时，才可作为受限消融重开 |
| **P3** | Spatial Mamba / ConvSSM | 暂不优先 | 空间点集/图不是天然一维序列；扫描顺序敏感；小患者队列下复杂度和验证成本高 |
| **不建议当前稿件** | 全量 LoRA/full fine-tuning、spatial instruction tuning、diffusion virtual ST、因果 pathway discovery | 不推荐 | 6+1 ST 患者、连续 30 维标签和缺失临床协变量不足以支持稳定重写 backbone、视觉语言指令化、生成分布或因果主张 |

## 3.2 对话中若干关键说法的校验

| 对话说法 | 校验结果 | 修正后的表述 |
|---|---|---|
| “Phase 2 和 Phase 3 完全独立，所以不存在数据泄漏” | **不严谨** | 只能说明没有患者重叠；仍需防止 Phase 3 同患者多 WSI 跨折、全队列 pathway 筛选、全队列标准化、测试集阈值选择等泄漏 |
| “Graph Transformer 应第一优先” | **方向正确，优先级过高** | 先做低参数 spatial MIL / gated-LMF；若空间坐标消融有稳定增益，再升级到 GAT/Graph Transformer |
| “Phase 2 和 Phase 3 联合训练能让 78 例帮助 Phase 2” | **不能直接成立** | 两队列不配对且监督不同，只能设计共享 adapter 的交替多任务或弱监督方法，风险高，不适合首轮主模型 |
| “Cross-attention 比 concat 更创新，因此更好” | **创新不等于有效** | virtual pathway 由同一 H&E/UNI 特征生成，可能只是冗余变换；必须做 H&E-only、pathway-only、concat、gating、cross-attention 等参数匹配消融 |
| “连续切片可视为 pseudo-3D” | **需谨慎** | 未做跨切片配准前，只能称 serial-section aggregation；先做 slide-level consistency，不能声称 voxel/patch 一一对应的 3D 建模 |
| “加入空间平滑 loss” | **可能抹平真实边界** | 若使用，需 tissue/edge-aware 或 graph-attention 权重；必须与无平滑版本比较，并检查肿瘤–基质界面是否被抹平 |
| “筛掉 PCC 较低的通路” | **可以，但要预注册** | Phase 2 可靠性筛选应基于 fit/internal 稳定性和生物学先验并在进入 Phase 3 前锁定；Phase 3 治疗响应关联筛选必须嵌套在训练折内 |
| “C-index、KM、time-AUC 应作为当前主指标” | **当前不适用** | 没有 survival time + event 时主任务只能报告二分类指标；取得 time/event 后再建立独立生存方案 |
| “Phase 3 用 AUC 作为预测性能指标” | **合理，但单独 AUC 不足以支撑临床主张** | 应将 patient-level ROC-AUC 作为当前主指标候选，并补充 95% CI、PR-AUC、sensitivity/specificity、balanced accuracy、F1/MCC 和 calibration/Brier；若类别不平衡，PR-AUC 尤其重要 |
| “联合训练可写成 `L_pathway + λL_AUC`” | **通常不正确** | 常规 ROC-AUC 是排序评价量，不可直接按普通方式反向传播；Phase 3 默认应使用 BCE/加权 BCE/Focal 等可微损失并用 AUC 评价，除非明确实现并验证 differentiable AUC surrogate |
| “frozen UNI2-h + MLP 是 linear probing” | **术语不准确** | 当前头为非线性 MLP，更准确称为 frozen-feature supervised probing/head-only adaptation；只有单线性层才是严格意义的 linear probe |
| “随机 spot 都可作为对比学习负样本” | **风险高** | 邻近 spot 或通路谱相似 spot 可能是 false negative；需 pathway-similarity-aware、patient-aware 和 spatial-aware 采样，并防止模型只学患者/染色身份 |
| “可用全部 78 例做继续预训练，再交叉验证 Phase 3” | **可能泄漏** | 若自监督继续预训练使用了 held-out fold 的 WSI，就变成 transductive protocol；常规验证应在每个训练折内继续预训练，或使用完全独立的无标签语料 |
| “FPN/DCNv4/动态卷积适合当前主模型” | **匹配度低于最初判断** | 当前 UNI2-h 冻结且只用 CLS `[1536]`，这些模块主要作用于图像 feature map/backbone；除非重开多尺度在线编码器路线，否则难以真正插入 |

## 3.3 建议的最小实验阶梯

| 层级 | 输入/模型 | 目的 |
|---|---|---|
| B0 | H&E UNI2-h patch features → Attention MIL → patient | H&E-only 基线 |
| B1 | 30 维 virtual pathway → Attention MIL → patient | pathway-only 基线 |
| B2 | `[H&E, pathway]` concat → Attention MIL | 最简单融合基线 |
| B3 | B2 + coordinate encoding | 判断空间坐标是否有独立价值 |
| M1 | pathway-gated 或 Low-rank Fusion + coordinate-aware MIL | 推荐首个主模型 |
| M2 | M1 + 2–3 张 serial-section attention pooling | 利用连续切片 |
| M3 | M1 + slide-level consistency loss | 验证连续切片鲁棒性；与 M2 分开消融 |
| M4 | M1 + lightweight spatial GAT/graph pooling | 仅在 B3/M1 显示空间价值后追加 |
| M5 | M4 + pathway cross-attention | 冲高版本；必须做参数匹配和过拟合审计 |

所有 Phase 3 实验都必须按患者分折；同一患者的 2–3 张 WSI、所有 patch 和所有派生 pathway 预测必须始终位于同一折。78 例建议采用预先固定的 repeated stratified CV 或 nested CV，并报告 bootstrap/重复折的置信区间；最终阈值只在验证数据上选择。

## 3.4 从病理基础模型“后训练”角度整理的新方案

### 3.4.1 当前证据边界

这里的“后训练”不是把大语言模型流程机械套到病理图像，而是指：在已预训练的 UNI2-h 表征之上，使用本项目的空间通路监督或临床标签做任务适配。当前证据按强弱分为：

| 路线 | 当前状态 | 本表结论 |
|---|---|---|
| `UNI2-h frozen → MLP → 30 pathways` | **accepted formal baseline**；repaired MPP2 external XZY `PCC=0.6549` | 当前锚点；应先复现并版本化，再比较任何 adapter/空间模块 |
| `UNI2-h + LoRA r=8 → MLP` | 工程通过，但 external PCC 下降且 26/30 通路下降；`candidate_effectiveness_fail / no_go_formal` | 不再列为首选；保留为小样本微调失败的负结果/消融证据 |
| LoRA + dropout 0.1 | **accepted smoke**：`best_epoch=1`，internal-first gate 失败，external XZY PCC `0.643799`；`candidate_effectiveness_fail_close_dropout10_route` | 已是 [R-当前仓库] formal 负证据；路线关闭，不应继续扫 dropout/LoRA 参数 |
| full fine-tuning / instruction tuning / continued pretraining | 当前无正式实验 | 仅为设想，不得写成项目已验证能力 |

注意：Phase 2 的独立生物学样本数是 6 个 fit 患者，而不是 patch 总数。大量同患者 patch 不能消除患者、染色和批次相关性；这正是 LoRA 在 epoch 1 附近达到最佳、随后快速过拟合的合理风险解释之一，但最终归因仍需训练曲线、target module、参数量和患者/空间分层结果支持。

### 3.4.2 Phase 2 可尝试渠道（重新排序）

| 优先级 | 后训练方案 | 最小实现 | 价值 | 主要风险与公平对照 |
|---|---|---|---|---|
| **PT0：必须保留** | Frozen-feature head-only adaptation | 冻结 UNI2-h，仅训练现有 MLP | 已有正式 external 基线，是所有后训练方案的控制组 | 不得用旧 z-score、旧 checkpoint 或 XZY 选模型 |
| **PT1：首个低风险候选** | Compact residual pathway adapter | `1536 → 32/64 → 1536` 残差 adapter，再接相同 pathway head；可零初始化残差分支 | 只调整冻结特征到 pathway 空间，不扰动 UNI2-h 内部表征 | 现有 MLP 本身已有适配能力；必须匹配总参数量、训练轮数和正则化，证明增益不是“多了参数” |
| **PT2：更贴任务的候选** | Coordinate/spatial adapter | 冻结 UNI2-h；在 feature 后加入 Fourier/MLP 坐标编码、邻域聚合或轻量 GAT | 直接弥补当前单 patch 回归忽略坐标/邻域的缺口 | 先做 coordinate-only，再做 graph；防止空间平滑抹平组织边界 |
| **PT3：探索性辅助目标** | Morphology–pathway metric/contrastive alignment | 冻结图像 encoder；将 30 维 ssGSEA 经小型 pathway encoder 投影，与图像特征联合优化 regression + supervised metric/InfoNCE | 可学习形态–通路共同空间，BLEEP 提供直接方法参考 | 30 维连续谱不是类别；不能把随机 spot 全当负样本，需排除邻近/相似通路 false negatives，并做 patient-aware batching |
| **PT4：高风险增强** | Selective last-block LoRA | 仅最后 1–2 个 block、低 rank、小学习率、强早停；其余全部冻结 | 若 PT1–PT3 已证明需要改变高层视觉语义，可做受限消融 | 当前 LoRA 路线已 no-go；必须另立假设、显著降参并取得新训练批准，不能继续扫参 |
| **暂不做** | Full LoRA/full fine-tuning | 更新大部分或全部 UNI2-h | 理论容量大 | 6 个 fit 患者下灾难性遗忘和患者特异过拟合风险高，且已有 LoRA 负证据 |
| **暂不做** | Spatial instruction tuning | 将连续 pathway 分数离散成“high/low”文本指令 | 可形成视觉语言叙事 | 当前没有自然语言标注；人为离散会丢失信息，也不能据此称为病理 VLM |
| **条件很高** | MAE/对比式 domain-adaptive continued pretraining | 用大量食管癌 H&E 做自监督继续预训练，再做 Phase 2 | 可能降低染色/器官域偏移 | 需要远多于 7/78 例的独立无标签数据；若使用 Phase 3 WSI，必须 fold-local 或明确声明 transductive protocol |

### 3.4.3 整个项目的后训练框架：建议采用“分阶段适配”，不宣称配对联合训练

```text
Stage A  已接受的视觉锚点
UNI2-h frozen → versioned 1536-d patch features
             ↓
Stage B  空间分子适配（Phase 2，6 fit + XZY locked external）
head-only baseline → compact adapter → coordinate/spatial adapter
             ↓
Stage C  冻结并登记 virtual pathway generator
checkpoint + repair manifest + train-only z-score + pathway order + SHA256
             ↓
Stage D  pCR/MPR 治疗响应适配（Phase 3，78 independent patients）
H&E + virtual pathway + coordinates → low-parameter MIL/fusion
BCE/weighted BCE/Focal training → patient-level AUC evaluation
             ↓
Stage E  连续切片适配
slide→patient aggregation / consistency → pathway/region explanation
```

Phase 2 与 Phase 3 患者完全独立且标签不配对，因此不能直接声称“同一个样本同时接受分子与临床监督”。若未来探索共享 adapter 的 alternating multi-task training，应明确它是 **unpaired multi-domain optimization**，至少加入：任务专用 head、任务/队列均衡采样、梯度冲突检查、冻结/更新边界和 H&E-only/分阶段方案对照。该路线优先级低于先完成可靠的 Phase 3 基线与低参数融合。

### 3.4.4 建议的后训练消融阶梯与停止门

| 实验 | 变化 | 进入下一步的最低要求 |
|---|---|---|
| PT0 | accepted frozen UNI2-h + MLP | 复现 internal/external 指标、数据版本和 checkpoint provenance |
| PT1 | 小瓶颈 residual adapter | internal 多 seed/空间 block 稳定优于等参数 MLP；XZY 只在模型冻结后评一次 |
| PT2a | PT1 + coordinate encoding | 相对 PT1 稳定增益，并证明不是坐标泄漏或患者身份 shortcut |
| PT2b | PT2a + lightweight GAT/spatial pooling | 相对 coordinate-only 继续增益；空间边界和 Moran/局部结构指标不恶化 |
| PT3 | regression + contrastive/metric auxiliary loss | 同时报告 PCC/MAE/R²；不能只用检索或 embedding 可视化替代回归效果 |
| PT4 | 最后 1–2 block selective LoRA | **仅新批准后**；若仍在 1–2 epoch 达峰、external 不增或多数通路下降，立即停止 |

所有比较必须固定 repaired MPP2 split、train-only z-score、30 通路顺序和随机种子协议，并报告 trainable parameter count、峰值显存、训练时长、最佳 epoch、逐通路结果及患者/空间 block 分层结果。任何新训练仍需登记 experiment id、绑定 source commit 和显式批准；本文更新不构成训练授权。

| **Low-rank Multimodal Fusion (LMF)** | 用模态特定低阶因子降低张量融合复杂度 | **高** | 最适合把高维 H&E embedding 与 30 维 pathway 低参数融合；推荐作为主模型首试之一 |
| **Adaptive Fusion Techniques** | 让网络学习如何组合模态，不固定 concat | **中高** | 可改造成 pathway gate；**资料包误标“代码未公开”，原论文脚注给出了作者实验仓库 `demfier/philo`**；原任务仍非医学，需自己适配并与简单 gating 对照 |
| **CentralNet** | 在模态中间层建立联系并联合优化 | **中高** | 可用于 H&E/pathway 双分支轻量交互；但两模态同源，需防冗余和 shortcut；**资料包给出的 `mengmenm/SMIL` 实为另一篇 SMIL 论文代码，不是 CentralNet 官方实现** |
| **Agent Attention** | 用少量 agent tokens 聚合/广播信息，降低注意力复杂度 | **中** | 若每张 WSI patch 很多，可作为 token aggregator；它不是 pathway 融合机制本身 |
| **BiFormer** | query-aware 动态稀疏两级路由注意力 | **中** | 适合大量 patch 的稀疏交互；实现复杂度高于当前数据规模首选 |
| **GCNet / Non-local / A2-Nets** | 全局上下文或全局特征聚合 | **中低** | 可作为 spatial MIL 的对照；不自动利用真实坐标，也不提供跨模态解释 |
| **CoordGate** | 坐标编码控制空间变化卷积 | **中低** | 概念与坐标感知相符，但原资料标记“代码未公开”，且适用于 CNN feature map，不直接适配 CLS 向量 |
| **FPN / ASPP / ASFF** | 多尺度 feature map 融合 | **低（当前）** | 只有重开在线、多尺度 patch/feature-map 路线时才合理；不能直接加在冻结 CLS `[1536]` 后面冒充多尺度 |
| **Dynamic Conv / CondConv / ODConv / DCNv4** | 输入自适应卷积或动态稀疏视觉算子 | **低（当前）** | 需要修改图像 backbone/feature map；与“UNI2-h 固定”边界冲突，不适合半年内首试 |
| **ConvSSM** | 长程时空建模 | **低** | 资料包称其 Mamba 系列，但原应用偏视频/时空序列；空间 patch 图需先定义稳定扫描顺序 |
| **MambaTab** | 低参数表格分类 | **条件适用** | 只有未来获得 TNM/年龄/治疗等临床表格变量时才值得作为 clinical baseline |
| **nnMamba** | 3D 医学影像分割/分类 | **低** | 连续病理切片尚未配准成 3D 体数据，不能直接迁移其 3D 主张 |
| **GFNet / AFNO / AFFNet / SpectFormer** | 频域 token mixing | **低** | 仓库旧频域实验仅属历史/探索；当前状态禁止把它们当 formal 增益，除非重新登记并按 repaired MPP2 验证 |
| **TFN** | 显式张量多模态融合 | **低** | 78 例下参数/交互维度风险高；LMF 是更合理的低秩替代 |
| **ZigMa / diffusion 类** | 生成式图像/视频建模 | **不建议** | 与当前 30 维回归和小 ST 患者数不匹配 |
| **时间序列 16 个模块** | 预测/异常检测/时序建模 | **不匹配** | 连续切片是有序的空间切片，不等同于时间序列；不应因“2–3 张连续”直接套用 |

## 4.3 对话推荐但不在该资料包中的方法

| 方法 | 是否在“89 个”原始模块中 | 当前项目来源/定位 |
|---|---|---|
| GAT / Graph Transformer | 否 | 仓库有旧 GAT/图构建探索代码；不是当前 MPP2 formal 主线 |
| Attention MIL / CLAM / TransMIL | 否 | Phase 3 必需的患者级聚合候选；仓库未见 78 例实现 |
| Pathway-aware cross-attention | 否 | 对话提出的定制融合机制，需自行实现 |
| Serial-section consistency | 否 | 对话根据连续切片条件提出的定制训练约束 |

| Multi-task Phase 2/Phase 3 learning | 否 | 定制 unpaired 多任务方案，当前不优先 |

### 4.4.4 学习顺序建议

1. **先读 Attention MIL + CLAM**：先把 patient-level 聚合、无泄漏分折、attention heatmap 做对，这是所有复杂融合的实验地基。
2. **再读 LMF + Adaptive Fusion**：实现低参数 H&E–pathway 融合，与 concat/pathway-only/H&E-only 做公平对照。
3. **第三读 TransMIL + GAT**：先用真实坐标证明空间信息有用，再决定是否升级 GraphGPS/Graph Transformer。
4. **解释性补读 BLEEP + PathCLAST**：借鉴 morphology–molecular 对齐与 pathway attention，但不改变本项目的 30 通路回归和 pCR/MPR 治疗响应分类任务定义。
5. **Agent Attention/BiFormer/Mamba 类最后读**：只在明确遇到 token 数或计算瓶颈后引入，不要用它们代替临床终点定义、基线和外部验证。

# 7. 当前应采用的研究决策

1. **Phase 2 命名**：使用“空间通路/分子表型预测”，不要写成已经恢复了全空间转录组。
2. **Phase 2 事实基线**：只引用 accepted repaired MPP2 frozen baseline；旧三患者 GAT/频域/LoRA 只作实现参考。
3. **Phase 3 首轮**：先完成 pCR/MPR 标签闭环，再进行 patient-level、无泄漏的 B0–B3 基线；标签未闭环时不得训练或计算 AUC。
4. **主模型首试**：低参数 pathway-gated 或 LMF + coordinate-aware Attention MIL。
5. **连续切片**：先做 slide→patient attention pooling 与 slide-level consistency；只有完成配准后才能探索真正跨切片 patch graph。
6. **通路筛选**：Phase 2 可靠性规则在进入 Phase 3 前锁定；任何使用 outcome 的筛选都在 Phase 3 训练折内完成。
7. **评价**：队友当前已将 AUC 作为 Phase 3 性能指标；标签闭环后，暂按 patient-level ROC-AUC 作为主指标候选，并补充 PR-AUC、balanced accuracy、sensitivity、specificity、F1/MCC、calibration/Brier 和 95% 置信区间。pCR 与 MPR 应分别定义任务或明确层级关系，不得混成一个含糊的“success”标签。
8. **论文主张**：只有当 H&E + pathway 在预注册、患者级验证中稳定优于 H&E-only，并有空间/通路解释与医生复核，才能主张 virtual pathway 提供临床增益。
9. **后训练锚点**：当前继续以 frozen UNI2-h + MLP 为 accepted baseline；LoRA r=8 已 no-go formal，dropout 0.1 也已作为 accepted smoke 通过 Registry 固化为 candidate-effectiveness fail，相关路线关闭。
10. **后训练首选候选**：先比较 compact residual adapter 和 coordinate/spatial adapter；再考虑 pathway-aware contrastive auxiliary loss。所有方案都保持 UNI2-h 冻结，并做等参数、同 split、多 seed 对照。
11. **AUC 与 loss 分离**：Phase 3 默认用 BCE/weighted BCE/Focal 等可微损失训练、以 patient-level AUC 评价；除非队友明确提供可微 AUC surrogate 的代码与验证，不写 `L_AUC`。
12. **不配对队列边界**：Phase 2/3 只能先做分阶段适配；所谓 joint post-training 必须标成 unpaired/alternating high-risk exploration，不能声称 78 例为 Phase 2 提供 paired molecular supervision。
13. **训练权限**：本文仅整理方案，不授权重开 LoRA、continued pretraining、Graph/adapter 或 Phase 3 正式训练；新实验仍须登记、绑定 source commit 并取得显式批准。
14. **校准边界**：Ridge r003 的 external gate 已失败；`CalibratedMPP2` 不进入 Phase3。未校准 frozen baseline 仍是 Phase2 accepted 锚点，但其 Phase3 增量价值必须由同划分 H&E-only/pathway-only/fusion 消融证明。

## 7.1 pCR/MPR 标签判定依据

- [CAP 食管癌切除标本协议](https://documents.cap.org/protocols/Esophagus_4.2.0.0.REL_CAPCP.pdf)：治疗反应 score 0 为无活癌细胞，即完全反应。
- [食管/胃食管结合部肿瘤退缩分级国际 Delphi 共识](https://pubmed.ncbi.nlm.nih.gov/33221343/)：完全退缩为无残余肿瘤；近完全退缩为残余肿瘤低于 10%。
- [食管鳞癌残余肿瘤细胞量化研究](https://pubmed.ncbi.nlm.nih.gov/16607651/)：残余肿瘤细胞低于 10% 可作为主要组织学反应口径。

据此，`completely success` 只能视为待核验的自由文本候选，不能直接代替 pCR/MPR 的结构化病理标签。建议同时保留 `residual_viable_tumor_pct`、`pcr_status`、`mpr_status` 和 `label_review_status`，避免把空白值误编码为阴性。
