# 第一部分：CVNN 初学者学习指南

## 1.1 为什么需要复数神经网络？

### 核心直觉

传统深度学习使用**实数**（real-valued）表示权重和激活。但现实世界中的许多信号——电磁波、声波、量子态——天然是**复数**的（有振幅 + 相位两个自由度）。

**核心直觉**：复数 = 振幅（magnitude）× 相位（phase）

- 实值网络对输入做旋转（rotation）需要学习特定的权重组合
- 复值网络通过一次复数乘法就能同时完成**缩放（振幅）**和**旋转（相位）**两个操作

### 图像处理中的物理直觉

图像的傅里叶变换是复数谱：
- **相位信息**编码了图像的**结构/边缘/纹理位置**（"东西在哪里"）
- **振幅信息**编码了**强度/对比度**（"东西有多亮"）

一个经典实验（Oppenheim & Lim, 1981）：交换两张图的相位和振幅 → 人眼看到的是**保留相位那张图的内容**。相位编码了图像的结构信息。

### 与 PFMval 的潜在关联

H&E 病理图像的细胞排列方向、细胞核形态、纤维束走行——这些**组织形态学特征**在傅里叶域的相位信息中有独特表征，而实值 CNN 难以显式建模这种旋转/方向敏感性。

## 1.2 核心数学原理

### 1.2.1 复数基本运算（5分钟复习）

```
复数 z = a + bi = |z| · e^{iθ}
  a = Re(z): 实部
  b = Im(z): 虚部
  |z| = √(a² + b²): 模/振幅
  θ = arctan(b/a): 辐角/相位
```

关键运算：
- **共轭**：z̄ = a - bi（相位取反）
- **乘法**：(a+bi)(c+di) = (ac-bd) + (ad+bc)i
- **模的乘法**：|z₁z₂| = |z₁|·|z₂|（振幅相乘）
- **辐角的加法**：arg(z₁z₂) = arg(z₁) + arg(z₂)（相位相加）

**重要性质**：复数乘法天然包含旋转操作。乘以 e^{iθ} = 绕原点旋转 θ 弧度。

### 1.2.2 复数卷积（Complex Convolution）

类比实值卷积 `W * x`，复数卷积将权重和输入都表示为复数：

```
W = W_R + i·W_I     (权重: 实部 + 虚部)
x = x_R + i·x_I     (输入: 实部 + 虚部)

W * x = (W_R * x_R - W_I * x_I) + i·(W_R * x_I + W_I * x_R)
```

用实值操作等价实现（Trabelsi et al., 2018）：

```
[Re(out)]   [W_R  -W_I]   [x_R]
[Im(out)] = [W_I   W_R] × [x_I]
```

**关键洞察**：复数卷积 = 2×2 分块实值卷积，但权重是**耦合**的（用同一组 (W_R, W_I) 实现两个自由度）。这提供了两个优势：
1. **参数效率**：相比独立的双通道实值卷积，复数卷积参数减半（共享 W_R/W_I）
2. **等变性**：复数卷积对相位旋转天然等变（输入相位变化 → 输出相位相同变化）

### 1.2.3 复数激活函数

| 激活函数 | 定义 | 特点 | 提出者 |
|---------|------|------|--------|
| **modReLU** | ReLU(\|z\| + b) · z/\|z\| | 对模做阈值，保留相位信息 | Arjovsky et al., 2016 |
| **CReLU** | ReLU(Re(z)) + i·ReLU(Im(z)) | 实虚部分开激活（最简单） | Trabelsi et al., 2018 |
| **zReLU** | z if θ∈[0,π/2] else 0 | 仅保留第一象限（稀疏激活） | Guberman, 2016 |
| **Complex Cardioid** | (1+cos(θ))/2 · z | 平滑相位门控 | Virtue et al., 2017 |

**实践建议**：从 CReLU 开始（最稳定），modReLU 作为备选。

### 1.2.4 复数反向传播 — Wirtinger 微积分

关键问题：复数函数的梯度如何定义？

**错误理解**：
```
∂L/∂z = ∂L/∂(Re(z)) + i·∂L/∂(Im(z))    ← 这不是解析函数！
```

**正确形式**（Wirtinger 微积分）：

```
∇_z L = ½(∂L/∂x - i·∂L/∂y)     ← R-derivative（视共轭为常量）
∇_z̄ L = ½(∂L/∂x + i·∂L/∂y)     ← R̄-derivative（视 z 为常量）
```

**最速下降方向不是 -∂L/∂z，而是 -∂L/∂z̄**（共轭梯度）。

**实践要点**：PyTorch 的 autograd 通过分别处理实部和虚部，**自动实现了 Wirtinger 微积分** — 你只需要确保 `dtype=torch.complex64/complex128` 即可。不需要手动实现！

```python
import torch

# PyTorch 原生支持复数自动微分
w = torch.randn(64, 64, dtype=torch.complex64, requires_grad=True)
x = torch.randn(64, 64, dtype=torch.complex64)
y = w @ x  # 复数矩阵乘法
loss = y.abs().sum()  # 取模 → 实数损失
loss.backward()  # 自动计算 ∂loss/∂w_R 和 ∂loss/∂w_I
print(w.grad.shape)  # torch.Size([64, 64]) — 复数梯度
```

### 1.2.5 复数批归一化（Complex BatchNorm）

实值 BN 直接对均值和方差做仿射变换在复数域不适用 — 复数的协方差是一个 2×2 矩阵：

```
E[zz*] = [Cov(Re,Re)  Cov(Re,Im)]
         [Cov(Im,Re)  Cov(Im,Im)]
```

复数 BN（Trabelsi et al., 2018）需要：
1. 将数据白化到标准圆复高斯分布（均值为 0，协方差 = I）
2. 用可学习的 2×2 缩放矩阵 + 复数偏移恢复表达能力

**实现要点**：先计算复数的 2×2 协方差矩阵，用其逆平方根做白化，再应用可学习的缩放和偏移。

### 1.2.6 复数权重初始化

复数权重可以写成极坐标形式 W = |W|·e^{iθ}。Trabelsi 2018 的初始化方案：

1. **振幅 |W|** 从 Rayleigh 分布采样（参数由 He/Glorot 初始化推导）
2. **相位 θ** 从均匀分布 U(-π, π) 采样

PyTorch 实现：
```python
def complex_weight_init(w):
    # w 的形状: [out_ch, in_ch, ...]（复数dtype）
    fan_in = w[0].numel()  # 实部的元素数
    # Rayleigh 分布的 σ
    sigma = 2.0 / np.sqrt(fan_in)
    # 生成振幅和相位
    magnitude = torch.from_numpy(np.random.rayleigh(sigma, size=w.shape))
    phase = torch.from_numpy(np.random.uniform(-np.pi, np.pi, size=w.shape))
    w.data = magnitude * torch.exp(1j * phase)
```

## 1.4 CVNN 在医学图像中的已知优势

医学图像富含**相位信息**：

1. **MRI 的天然复数域**：k-space 数据是复数的，CVNN 可直接在原始 k-space 上训练，避免实值重建损失
2. **CT/超声的傅里叶表示**：重建图像的频域分析
3. **病理图像的纹理建模**：组织纹理的周期性和方向性在频域表现为相位谱的结构

**对 H&E 病理图像的核心假设**：细胞的排列方向、细胞核的形态、纤维束的走行——这些组织形态学特征在傅里叶域的相位信息中有独特表征，而实值 CNN 难以显式建模旋转敏感性。

# 第二部分：CVNN 在 PFMval 的可行性分析

## 2.1 项目现状回顾

| 参数 | 当前值 |
|------|--------|
| 数据量 | 3 患者（15K patches）→ 9 患者即将（~45K patches） |
| 输入 | H&E patch (224×224 RGB) → UNI2-h 特征 (1536d CLS / 265×1536 tokens) |
| 输出 | 30 条 ssGSEA 通路活性分数（连续回归） |
| 最佳跨患者 PCC | 0.4322（LoRA r=8, Fold1） |
| 核心瓶颈 | **跨患者泛化**（衰减 31%–77%） |
| 已有 backbone | UNI2-h（ViT-L/14, 1536d）、Virchow2（已关闭） |

## 2.2 两种集成方案

### 方案 A：CVNN 作为特征增强器（低风险，推荐验证用）

```
H&E Patch (224×224 RGB)
    ↓
UNI2-h (frozen, 实值)
    ↓
[CLS] 1536d 或 Tokens [265, 1536]
    ↓
实→复映射方案：
  A1. 奇偶拆分: 1536d → 768 个复数 (Re = 偶数位, Im = 奇数位)
  A2. 双线性映射: 1536d → 2×256d → [256 实部, 256 虚部]
  A3. 1D FFT: 对 token 序列每维做 FFT
    ↓
复值预测头 (2-3层复数全连接)
    ↓
取模 → 30 通路分数
```

**优势**：不改动 UNI2-h backbone，仅在预测头引入复数操作；训练参数量 < 0.5M；可 1 天内完成实验。

**劣势**：实→复"嫁接"缺少物理意义，可能只是另一种形式的非线性变换。

### 方案 B：端到端复值网络（高风险，不推荐）

```
H&E Patch (224×224)
    ↓
灰度化 → 2D FFT → 复数频谱 [224, 112]
    ↓
复值 CNN Encoder (CVNN blocks × N)
    ↓
复值全连接 Prediction Head
    ↓
取模 → 30 通路分数
```

**致命问题**：
- 需要从头训练，小数据集下极难收敛
- 丢失 UNI2-h 预训练优势（UNI2-h 在千万级病理图像上预训练）
- 与现有 H&E→ssGSEA pipeline 完全断裂

## 2.3 四维度可行性评分

### 维度 1：小数据集泛化能力 — ⚠️ 中风险

**理论优势**：复数参数共享（W_R 和 W_I 耦合）减少了有效自由度 → 理论上泛化更好。

**实践困境**：
- CVNN 的实证泛化优势主要在**大模型+大数据**场景下验证（MRI 重建，>50K 训练样本）
- 小数据集（<20K 样本）下复数的额外结构约束**可能**有益，但缺乏在 <20K 样本下的验证工作
- **PFMval 已有经验**：LoRA（低秩约束=正则化）在 3 患者下有效 (+5.1%)，说明参数约束确实帮助泛化
- 复数结构的隐式正则化与 LoRA 的低秩正则化在精神上一致，但实证基础弱得多

**评分：⭐⭐½**

### 维度 2：与预训练 Backbone 兼容性 — ❌ 严重冲突

- UNI2-h 和 Virchow2 输出的是**实值特征向量**（1536d CLS token）
- 若从频谱端到端训练呢？→ 则完全丢弃了 UNI2-h 的预训练优势
- **根本矛盾**：CVNN 的最大价值在端到端从频谱学习，但这与复用 UNI2-h 预训练优势的路径冲突

**评分：⭐⭐**

### 维度 3：组织形态学相位建模优势 — 🟡 有理论潜力

- H&E 图像经傅里叶变换后，相位谱编码了边缘位置、纹理方向、细胞排列周期性
- **但 H&E 是 RGB 三通道的强度图像**，不是相干成像（如 MRI 的 k-space）
- 相位信息是**计算出来的**而非物理测量，意义有本质差异
- MRI 中 CVNN 有效是因为 k-space 本身就是复数测量；H&E 的"复数"是人为变换

**评分：⭐⭐⭐**（理论）- **⭐⭐**（实践）

### 维度 4：训练复杂度与 GPU 显存 — ✅ 可以接受

- 复数乘法的 FLOPs ≈ 实值乘法的 4 倍（但参数减半，总体 FLOPs 相当）
- PyTorch CUDA 对 complex64 的支持已成熟（torch 1.6+）
- 方案 A（仅预测头复数化）显存增加 < 50MB，RTX 4060 8GB 完全可负担
- 方案 B（端到端 CVNN）需从头训练，但参数量可控（~1-2M）

**评分：⭐⭐⭐⭐**

## 2.4 CVNN 可行性总体评分

| 维度 | 评分 | 权重 | 加权分 |
|------|:---:|:---:|:---:|
| 小数据集泛化 | ⭐⭐½ | 35% | 0.88 |
| Backbone 兼容性 | ⭐⭐ | 30% | 0.60 |
| 生物学合理性 | ⭐⭐⭐（理论）| 20% | 0.60 |
| 工程可行性 | ⭐⭐⭐⭐ | 15% | 0.60 |
| **加权总分** | **2.68/5** | — | — |

**结论**：CVNN 目前不适合作为 PFMval 的主力方向。建议作为**P3 低优先级探索**，仅在核心方向（GNN/对比学习/元学习）取得进展后，以方案 A 形式做小规模验证（改动 <100 行代码，1 天内完成实验）。发论文时有"我们探索了 X 方向"的叙述价值。

# 第三部分：新型架构调研与优先级排序

## 3.1 图神经网络 (GNN) — 🟢 P0 最高优先级

### 3.1.1 2024–2025 顶会进展

项目已有 EGN-v2（GraphSAGE+Exemplar）基础，GAT 实验已完成但 PCC 提升不显著 (-0.27%)。但 2024–2025 年的图神经网络+空间转录组学领域出现了重大进展：

#### CVPR 2025 重点论文

**1. M2TGLGO — Multi-modal Topology-embedded Graph Learning** (Shi et al., CVPR 2025)
- 核心创新：引入 **Gene Ontology (GO) 知识**作为先验到 GNN 中实现多基因联合预测
  - 利用功能基因-基因关联约束预测，不再假设基因独立
- **空间定向邻域排序模块 (SONRM)**：保留拓扑结构，避免过平滑
- **多模态学习**：手工特征 + 深度学习特征的 intra/inter-modal 交互
- 在 3 个公开 ST 数据集上超越现有方法

🔗 [CVPR 2025 Poster](https://cvpr.thecvf.com/virtual/2025/poster/34913)

**2. MERGE — Multi-faceted Hierarchical Graph-based GNN** (Ganguly et al., CVPR 2025)
- 核心创新：**多面层次图构建** — 按空间和形态特征聚类组织 patch，构建簇内+簇间边
- 使得 **远处但有形态相似性的组织位置**也能在 GNN 消息传递中交互
- 引入基因感知的数据平滑技术缓解 ST 伪影
- 在 WSI 级基因表达预测上取得 SOTA

🔗 [CVPR 2025 Poster](https://cvpr.thecvf.com/virtual/2025/poster/32477)

#### 2024 重要论文

**3. asGNN — Adaptive Spatial GNN** (PMC, Bioinformatics 2024)
- 核心创新：**自适应图精炼** — 通过基于平滑的变分优化学习移除任务无关边
- 使用 Graph Transformer Networks (GTN) 作为 backbone
- 图精炼可将 spots 聚类为空间域（肿瘤微环境区域），具有**生物学可解释性**
- 在两个乳腺癌队列上超越 ST-Net、HisToGene 和 non-adaptive GNN baselines

## 3.3 注意力机制 / Transformer 正则化 — 🟡 P1 高优先级

### 3.3.1 项目已有经验

HisToGene-UNI Token 模式（265×1536 tokens → Transformer）是最优单患者模型（PCC=0.5217）。跨患者衰减问题需要更强的正则化。

### 3.3.2 推荐方案：Perceiver-IO 风格轻量 Transformer

```
UNI2-h Tokens [265, 1536]
    ↓
Cross-Attention: Latent Queries [32, 512] → KV from tokens
    ↓  (32 个可学习的 latent query 将 265 tokens 压缩为 32)
Self-Attention (×4 layers, latent space only)
    ↓
Cross-Attention: 30 pathway queries → KV from latent
    ↓
30 通路分数
```

**优势**：
- 参数量极小（~1M），符合小数据集约束
- Latent 瓶颈强迫模型学习紧凑表征 → 天然正则化
- 30 个 pathway-specific query 为每条通路学习不同的注意力模式

### 3.3.3 SAM (Sharpness-Aware Minimization) — 补充正则化

```python
# SAM 优化器 — 寻找平坦最小值
optimizer = SAM(model.parameters(), base_optimizer=torch.optim.AdamW, lr=1e-4)
for batch in dataloader:
    # 第一步: 梯度上升（寻找最差点）
    loss = criterion(model(batch), targets)
    loss.backward()
    optimizer.first_step(zero_grad=True)
    
    # 第二步: 梯度下降（从最差点更新）
    loss = criterion(model(batch), targets)
    loss.backward()
    optimizer.second_step(zero_grad=True)
```

SAM 在医学图像域泛化中已被验证有效（多篇 MICCAI 2023/2024 论文）。

| 实施难度 | ⭐⭐⭐⭐（Perceiver 架构简单，SAM 即插即用）|

## 3.4 元学习 / 少样本学习 — 🟡 P1 高优先级

### 3.4.1 为什么元学习适合 PFMval？

PFMval 的核心挑战是**跨患者泛化**：在 2 个患者上训练 → 在第 3 个患者上测试。这天然是元学习的**episodic training**范式：

```
元训练:  (JFX, LMZ) → 适应 HYZ  ← Fold 1
         (HYZ, LMZ) → 适应 JFX  ← Fold 2
         (HYZ, JFX) → 适应 LMZ  ← Fold 3
```

### 3.4.2 推荐方案：ANIL + LoRA

ANIL (Almost No Inner Loop, Raghu et al., 2020) 发现：MAML 的大部分收益来自**冻结 backbone + 仅元学习预测头**。

这与 PFMval 的 LoRA 经验完全一致：LoRA 本质上是"冻结 backbone + 学习轻量适配器"。

```
# ANIL 式 LoRA 元学习
for meta_iter in range(meta_iters):
    for (support_set, query_set) in task_batch:  # 每个 task = 一个患者
        # 内循环：在 support 上微调 LoRA 参数
        θ_lora' = θ_lora - α · ∇L_support(θ_lora)
        
        # 外循环：在 query 上评估 → 更新 LoRA 初始化
        L_query = evaluate(θ_lora', query_set)
    
    θ_lora ← θ_lora - β · ∇(Σ L_query)
```

### 3.4.3 适用条件

- 需要至少 5+ 患者（元学习的患者级 train/meta-test split）
- **9 患者数据到达后立即值得尝试** — 可以建立 ~7 患者元训练 / 2 患者元测试的数据划分

### 3.4.4 可行性评分

| 维度 | 评分 | 说明 |
|------|:---:|------|
| 跨患者泛化针对性 | ⭐⭐⭐⭐⭐ | 天然适配 episodic training |
| 与 LoRA 的协同 | ⭐⭐⭐⭐⭐ | ANIL 与 LoRA 思路一致 |
| 数据量要求 | ⭐⭐⭐ | 需要 5+ 患者（9 患者满足） |
| 实施复杂度 | ⭐⭐⭐ | 需要实现任务采样和双循环优化 |

## 3.6 多尺度/多分辨率融合 — 🟡 P2 中优先级

### 3.6.1 核心思路

组织学特征在不同尺度上表现不同：
- 224×224（~50μm）：细胞级形态
- 448×448（~100μm）：细胞群、腺体结构
- 更大的上下文窗口（~200μm）：组织架构、肿瘤-基质界面

### 3.6.2 具体方案

```
Patch Level 1 (224×224, 细胞级, 当前)
    ↓ UNI2-h → CLS 1536d
Patch Level 2 (448×448, 组织级, 新增)
    ↓ UNI2-h → CLS 1536d
    ↓
Cross-Scale Fusion (轻量交叉注意力)
    ↓
30 通路分数
```

**实施要点**：448×448 patch 需要 resize 到 224×224（UNI2-h 固定输入），不是用更大的模型。

## 3.8 物理信息神经网络 (PINN) — ❌ 不推荐

### 3.8.1 为什么不适用

PINN 将**已知的物理定律（PDE）**作为软约束加入损失函数。

- 将假设 PDE 作为软约束 → 退化为普通的正则化技巧
- 与 PINN 的"物理信息"本质不同 — 没有"物理"只有"信息"

### 3.8.2 搜索验证

| **论文撰写前** | — | P3 低优先级探索（可选，提升论文叙述丰富度） |

## 4.4 风险与收益矩阵

```
高收益 ↑
    │  元学习 (P1)        │  对比学习 (P0)
    │  (9患者后启动)      │  图神经网络 (P0)
    │                     │
    │  多尺度融合 (P2)    │  Perceiver-IO (P1)
    │                     │
    │  胶囊网络 (P2)      │
    │  CVNN方案A (P3)     │
    │                     │
    │  PINN (❌)          │  CVNN方案B (❌)
    │  CVNN方案B (❌)     │
    └────────────────────────────────────→ 高风险
```

## 4.5 最终建议

1. **立即着手 P0 双线并行**：图神经网络深化 + 对比学习任务适配
   - GNN 方向：基于 EGN-v2 改造成 Multi-faceted Graph（借鉴 MERGE 2025）
   - 对比学习方向：实现 SupCon 任务适配预训练 → LoRA 预测头

2. **9 患者到齐后全力投入 P1**：
   - 元学习是解决跨患者泛化的最直接方向，在 9 患者规模下统计可靠
   - SAM + LoRA 组合正则化是低成本的泛化增强

3. **CVNN 仅做"论文完整性探索"**：
   - 改动 < 100 行代码，1 天完成实验
   - 结果大概率不优于基线，但有"我们探索了 X 方向"的叙述价值

4. **PINN 和端到端 CVNN 不做**：与项目需求不匹配，不值得投入。
