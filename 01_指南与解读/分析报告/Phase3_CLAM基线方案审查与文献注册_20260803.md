# Phase 3 CLAM 基线方案审查与文献注册（2026-08-03）

## 1. 结论先行

队友提供的 `0801-CLAM` 已作为只读候选参考实现复制到 `reference_implementations/phase3_clam_escc_20260801/`，团队成员目录中的原件保持不变。该包能构成 Phase 3 的工程起点，但目前只能登记为 `reference_candidate`，不能登记为已验证基线或直接启动训练。

当前最重要的四个未闭环点是：

1. 当前状态要求 Phase 3 使用 accepted 修复版 MPP2 的 raw output，而队友说明指向 `ESCC_mpp2_z_scores_20260711`；代码只搬运输入分数，不负责证明其拟合范围或来源，两者存在协议冲突。
2. 78 名患者的 pCR/MPR 标签在表内一致，但没有原始病理字段、判定标准、复核状态和缺失值来源，不能替代既有标签完整性门禁。
3. CLAM 主程序以切片 bag 为样本并输出切片级 AUC；每名患者有 2-11 张切片（平均 4.22 张），若临床终点是患者级 pCR/MPR，切片级指标会对多切片患者加权，不能直接作为主要性能结论。
4. pCR 默认切分可找到，MPR 默认目录 `splits/ESCC_MPR_100` 未随包提供；已提供的 pCR/MPR 共用 5 折必须显式传入 `--split_dir ESCC_shared_pCR_MPR_100`，而当前说明没有写明该入口。

因此，本次完成的是“基线代码与协议事实输入 + 文献注册”，不是实验登记、训练批准或结果接纳。

## 3. 代码路径与模型族

### 3.1 数据与特征路径

1. `convert_patch_features_to_clam.py` 将逐 patch 的病理特征按文件名坐标转成 CLAM 的 `pt_files` 和 `h5_files`。
2. `convert_patch_scores_to_clam.py` 读取通路分数，并以病理 `h5_files/coords` 为参考顺序；这是避免病理和通路 patch 错位的正确方向。
3. `concat_clam_features.py` 要求两端 patch 数、坐标和特征文件同时匹配，再拼成 1566 维输入。
4. `main.py` 以单张切片的全部 patch 为一个 bag；`CLAM_SB` 是说明中的主模型，另有 `mean_pool`、`max_pool` 和传统分类器基线。

### 3.2 主比较

| 路线 | 当前实现 | 正确理解 |
|---|---|---|
| 直接拼接 | 1536 + 30 后进入 CLAM | 最低复杂度的多模态基线，应作为融合方法的必要对照 |
| 交叉注意力 | gene 作 query、pathology 作 key/value，可反向 | `nn.MultiheadAttention` 在整张切片的 patch 序列上计算；不是只在同一坐标 patch 内做一对一融合 |
| 自适应融合 | 每个 patch 生成两模态门控权重 | 属于本包自定义实现，不能仅凭命名宣称复现某篇特定论文 |
| 均值/最大池化 | 固定池化后分类 | 用于判断复杂注意力聚合是否真正带来增益 |
| 简单分类器 | LR/SVM/RF 等 | `simple_escc_baseline.py` 支持患者级聚合和训练集拟合的变换，可作为更低容量参照 |

源码还包含 dual branch、external attention、low-rank fusion、FiLM、modality attention、AEM 和 PseMix 等候选开关；它们没有出现在当前主操作卡中，也没有本项目结果，应登记为“代码内候选”，不能混入 Phase 3 已选主线。

## 4. 主要风险与修订要求

### P0：执行前必须闭环

- **MPP2 输入冲突**：当前项目指令是 accepted frozen MPP2 raw output，队友路径名称却是 `z_scores`。必须提供特征 manifest、生成 commit、输入/参数校验值，并说明 z-score 是否只在训练折拟合。未闭环前不得用它替代 accepted raw output。
- **标签定义**：必须把 pCR/MPR 的原始字段、病理定义、复核状态、未知/缺失处理和患者级唯一标签写入结构化标签审计；不能把未标注病例自动当阴性。
- **主要评估单位**：临床任务是患者级治疗响应。应预先规定多切片概率如何聚合，并同时保留切片级诊断结果；主要 AUC 的统计单位不能在结果出来后再选择。
- **切分入口**：若 pCR 与 MPR 要共享病例边界，训练命令必须显式绑定 `ESCC_shared_pCR_MPR_100`；补齐 MPR 默认路径或删除会误导的默认行为。

### P1：首轮核验必须完成

- 固化每个特征文件的 `case_id/slide_id/coords/feature_dim/source_commit/source_hash` manifest。
- 对 5 折逐折验证：患者无重叠、两类均存在、所有切片均能找到两种特征、坐标顺序完全一致。
- 明确直接拼接与融合模型的参数量、早停依据、调参预算和随机种子；不能让复杂模型获得额外调参预算。
- 交叉注意力当前允许跨 patch 混合信息；需要通过消融确认这是有意设计，并与“同坐标 patch 融合”区分。
- GPLv3 的 CLAM 代码和 UNI2-h 的非商业/不可再分发条款均需保留；不得把权重或预提取特征放入代码同步通道。

## 5. 文献关系分层

### 直接依据

- CLAM 原论文定义聚类约束的注意力 MIL，是当前主模型的直接依据：[Nature Biomedical Engineering](https://www.nature.com/articles/s41551-020-00682-w)。
- Attention-based MIL 提供可学习的置换不变 bag 聚合，是 CLAM 注意力分支的基础：[PMLR/ICML 2018](https://proceedings.mlr.press/v80/ilse18a.html)。
- UNI 论文和 UNI2-h 模型卡分别提供病理基础模型背景与当前 1536 维特征配置；UNI2-h 的实际架构/许可应以[官方模型卡](https://huggingface.co/MahmoodLab/UNI2-h)为准。
- PseMix 是代码内可选的 pseudo-bag mixup 来源，但当前主命令未启用：[官方代码与论文入口](https://github.com/liupei101/PseMix)。

### 方法扩展依据

- 多头注意力的基础来源：[NeurIPS 2017](https://proceedings.neurips.cc/paper_files/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html)。
- External Attention：[IEEE TPAMI, DOI 10.1109/TPAMI.2022.3211006](https://pubmed.ncbi.nlm.nih.gov/36197869/)。
- Low-rank Multimodal Fusion：[ACL 2018](https://aclanthology.org/P18-1209/)。
- FiLM：[AAAI 2018](https://ojs.aaai.org/index.php/AAAI/article/view/11671)。
- Pathomic Fusion 提供病理-组学融合背景，但当前实现不是该论文 Kronecker-product 模型的复现：[DOI 10.1109/TMI.2020.3021387](https://doi.org/10.1109/TMI.2020.3021387)。

### 邻近对照，不是当前实现依据

- TransMIL 建模 patch 间相关性与空间信息，可用于后续 MIL 聚合对照，但当前包没有实现 TransMIL：[NeurIPS 2021](https://proceedings.neurips.cc/paper/2021/hash/10c272d06794d3e5785d5e7c5356e9ff-Abstract.html)。
- Campanella 等的大规模弱监督 WSI 工作是 MIL 临床背景，不等同于当前 CLAM 实现：[Nature Medicine](https://doi.org/10.1038/s41591-019-0508-1)。
- PROGPATH 是病理-临床多模态预后模型，终点和输入均不同，只能作为邻近方法，不可用于证明 pCR/MPR 方案有效。

逐篇结构化登记见 `Ai病理项目文献汇总/PHASE3_CLAM_LITERATURE_REGISTRY_20260803.md` 和 `literature_manifest.json`。

## 6. 建议的后续最小闭环

1. 先完成标签与特征 provenance 审计，不训练。
2. 用户指定实验工作树并正式登记 Phase 3 baseline experiment。
3. 固定患者级共用 5 折、主要患者级 AUC、切片级辅助指标和单一调参预算。
4. 先跑患者级简单分类器、mean/max pool、CLAM 直接拼接三个最低复杂度基线。
5. 只有在上述基线可复现后，再比较交叉注意力与自适应融合；PseMix、FiLM、low-rank 等保持候选，不并行扩张搜索空间。
