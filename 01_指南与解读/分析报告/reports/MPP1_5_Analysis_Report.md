# MPP1-MPP5 方案重跑数据详细分析报告

## 1. 分析目标与背景
本次分析基于最新的 **MPP1-MPP5 统一标准化重跑实验 (unified-standard rerun)**，重点探讨各方案的预测性能、过拟合情况及生物学/病理学规格一致性。

> [!NOTE] 
> **关于数据规格与 Patch 数量说明：**
> 1. 本次评估覆盖了标准的 6 名患者 (HYZ, JFX, LMZ, TGC, XSL, ZHZ)，例如 MPP1 总 patch 数为 21,850，MPP2 为 10,550，以此类推。此前 PPT 汇报中所使用的数字（如 MPP1≈23k, MPP2≈10.3k）为基于旧版 5 患者的估算值，本报告已全盘采用最新、最准确的统一划分计数。
> 2. **UNI2-h 预训练规格核验**：根据 Mahmood Lab 官方文档与 HuggingFace UNI2-h features 数据卡，UNI2-h 公开预提取特征口径为 **20x magnification**；按本项目/PPT 的显微倍率换算约定，对应约 **0.50 MPP**。因此：
>    - **MPP4 (0.54 MPP)**：最贴近 UNI2-h 的官方**病理基础模型预训练规格**。
>    - **MPP2 (0.27 MPP)**：接近 40x，其核心意义在于贴合本次研究中**临床外部测试集 (如 XZY 队列) 的扫描与采样口径**，即**队列一致性优先**。

## 4. 详细维度分析与异象拆解

### A. 过拟合现象的直观呈现 (Train vs Val vs Test)
- **MPP1 的验证集“过度友好”异象**：MPP1 在最佳 Epoch 时，验证集的 Loss (0.59) 居然比训练集 Loss (0.73) 还要低。这表明 MPP1 可能在进行特征选择时，严重倾向于该批数据中的某些易被记忆的“特征 Shortcut”（在测试集上 Loss 暴增到了 1.22，但 PCC 反而奇高）。
- **MPP2 与 MPP4 的健康曲线**：MPP2 (Train 0.35, Val 0.39) 和 MPP4 (Train 0.33, Val 0.34) 的训练-验证拟合度极佳，展现出了极强的内部分布泛化能力。尤其 MPP4 在外部测试集的 Loss (0.47) 是最低的，代表着最稳定的绝对数值。

### B. 关于 R2 (决定系数) 出现负值的深度溯源
在外部测试时，我们观察到大部分方案的高 PCC 伴随了负的 R2，具体溯源如下：
- **数学本质**：R2 公式为 `1 - (SSE / SST)`。负 R2 并不代表 Z-score 逆变换出了 Bug（由于线性变换对 R2 评分免疫），而是表明**模型在 Z-score 空间下，对外部测试集 XZY 预测所产生的 SSE（残差平方和）已经大幅超过了外部测试集标签本身的方差 (SST)**。
- **物理意义**：虽然模型成功捕捉到了基因表达量“谁高谁低”的趋势（使得趋势评价指标 PCC 极高），但在应对不同队列间可能存在的域偏移（Domain Shift）时，预测出的绝对值存在严重的整体平移或发散。
- **Raw-scale R2**：这是上述情况在原尺度上的同比例放大呈现。MPP4 是唯一保住了正向 R2 的方案，说明在更接近 UNI2-h 20x/约 0.50 MPP 预训练口径的 0.54 MPP 下，模型学到的表征拥有更强的数值抗偏移能力。

## 5. 综合结论与多目标推荐

基于数据的全面核对与病理医学的客观背景，我们得出以下**多目标导向的推荐结论**：

1. **MPP1（排序性能上限候选）**
   - **特点**：拥有唯一的 0.70+ 外部 global PCC（0.7103）。
   - **定位**：如果我们的最终业务目标仅仅是基因表达量的趋势排序（即“只看高低，不看绝对值”），可将其作为强有力的性能基线。但需注意其 Test Loss/R2 风险极大，存在极强的不稳定性。
2. **MPP2（队列/外部测试集一致性优先候选 —— 重中之重）**
   - **特点**：0.27 MPP 精准契合临床与外部测试集（40x）的扫描/采样口径。在医生视角下具备**最强的病理/生物学一致性先验**。
   - **定位**：其内部 Val 拟合健康，外部 PCC 也能稳居第二（0.6489），是兼顾了预测性能与队列可解释性的核心候选。
3. **MPP4（病理基础模型一致性优先候选）**
   - **特点**：0.54 MPP 最接近 UNI2-h 公开预提取特征的 20x/约 0.50 MPP 口径。
   - **定位**：在所有方案中，MPP4 表现出了最逆天的数值稳定性（唯一的正数 R2，最低的 Test Loss 0.47）。如果我们重视“绝对值的校验与预测真实度”，MPP4 应作为重点保留与调优。

> [!IMPORTANT]
> **最终建议：** 停止“唯 MPP 单一指标论”。推荐将 **MPP2**（贴合临床采样口径）与 **MPP4**（贴合基础模型规范）作为项目的**双主线医学规格候选**齐头并进，而 **MPP1** 则作为纯数据科学角度的特征性能天花板对比使用。
