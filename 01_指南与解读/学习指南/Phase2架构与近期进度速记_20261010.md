# Phase2 架构与近期进度速记
截至2026年10月10日，当前交付模型是 **UNI2-h 全视野空间残差模型（seed45，正式检查点第28轮）**。Phase2负责从病理图像重建点位级通路特征，供Phase3用于患者级疗效预测；Phase3的实际临床预测获益尚未确认。

你已经记得两条分支的作用。接下来只需补准中间的数据流，以及“邻居怎样修正中心预测”。

## 架构怎么走
**完整H&E图像块 → 缩放224×224 → 冻结UNI2-h → 1536维图像特征 → 共享映射H → 256维表示。**

这里的224×224是缩放后的输入尺寸；全视野指保留完整图像块、不做中心裁剪。冻结表示训练Phase2时不更新UNI2-h，主要训练后面的H、C、B。

- **中心预测C**：把中心点的256维表示映射为30维基础预测。
- **空间修正B**：邻居也经过同一个H；将每个邻居与中心的表示差加权相加，再用B映射为30维修正量。
- **最终输出**：中心预测加空间修正。没有邻居时，修正为零。

用一个式子记住它：
`预测 = C(中心表示) + B[Σ 邻居权重 × (邻居表示 − 中心表示)]`

邻居来自同一切片，在2个原生网格步长半径内最多取12个。权重由坐标距离和冻结图像特征的相似度共同决定，并与自身项一起归一化。B是无偏置线性头，零初始化，所以起初不添加空间修正，随后从训练中学习怎样修正。

直接输出是 **30维通路z分数**，使用训练集的均值和标准差标准化，也能用同一参数逆变换。你记得的“通路分数”方向正确；主模型V003标签的原始评分来源仍待补证，不能直接与任务二用319基因重新计算的ssGSEA分数等同。模型以标准化通路的均方误差训练，检查点只根据内部验证选择。

给Phase3的是每点30维通路特征，也可与1536维图像特征拼为1566维。架构依据：[交付说明](../../团队项目进度与结论/qzs/Phase2最终模型_Phase3交接包_20260918/README.md)、[模型实现](../../experiments/phase2_fullfov_hpo_v1/src/model.py)。
