## 1. 背景：我们在做什么？

### 1.1 空间转录组学（Spatial Transcriptomics）简说

在传统的基因表达分析中，你把一块组织研磨成浆 → 测序 → 得到一份"基因表达清单"，但你**不知道**每个基因在组织中的哪个位置表达。

空间转录组学解决了这个问题：它在组织切片的**原位**测量基因表达。想象在一块食管癌组织切片上，以网格形式（spot 阵列）同时测量每个位置上千个基因的表达量。最终得到的数据结构是：

```
每个 spot（空间位置）→ 一个基因表达向量（~20,000 个基因）
```

而 H&E 染色的病理切片给出了同一块组织的**形态学图像**。我们的任务是：**从 H&E 图像预测每个位置的基因通路活性**。

### 1.2 ssGSEA 是什么？

ssGSEA（**single-sample Gene Set Enrichment Analysis**，单样本基因集富集分析）是一个降维工具。它把 ~20,000 个基因的表达值映射到几十个"通路"（pathway）的活性评分上。

打个比方：

> 你不能直接从 20,000 个基因的表达值看出"这个细胞的免疫反应有多活跃"。但如果把与免疫反应相关的 200 个基因的表达值综合成一个 **0 到 1 之间的分数**，问题就简化了。

这就是 ssGSEA 做的事。它不关心单个基因的表达高低，而是问：

> "这组功能相关的基因（比如所有与免疫反应相关的基因），**作为一个整体**，是被激活了还是被抑制了？"

在我们的项目中，30 条基因通路被选为预测目标：

| 通路 | 生物学含义 |
|------|-----------|
| `ECM_Organization` | 细胞外基质重塑（与肿瘤侵袭相关） |
| `MYC_Targets` | MYC 癌基因靶基因（与细胞增殖相关） |
| `Interferon_Alpha` | 干扰素α信号（与抗病毒免疫相关） |
| `Hypoxia` | 缺氧反应（与肿瘤微环境相关） |
| ... | ...（共 30 条） |

### 1.3 为什么需要预处理？

ssGSEA 出来的原始数值有一个问题：**不同通路的数值尺度、分布形状差异巨大**。

例如，在 JFX0729 患者数据中：

- `ECM_Organization` 的 ssGSEA 值范围可能在 0.2 到 0.8 之间（集中在高值区）
- `Interferon_Alpha` 的值可能集中在 -0.5 到 0.1 之间（高度偏态）
- `Toxic` 通路的值可能呈现严重的长尾分布（少数 spot 有极高值，大部分在低位）

如果你直接把这样的数据扔给神经网络，会出现三个问题：

1. **Loss 被大尺度通路主导**：梯度下降会优先拟合数值范围大的通路，忽略范围小的通路
2. **偏态分布导致梯度不稳定**：长尾方向上的极端值产生异常大的梯度
3. **不同数据集的标签不可比**：如果你训练时用患者 A 的标签分布，测试时用患者 B，即使同一条通路，绝对值的"高"和"低"在不同患者间含义不同

这就是标签预处理（label preprocessing）的动机。

## 2. 数据长什么样？— 用眼睛看分布

在动手做任何变换之前，你需要**先看数据**。这是医学数据预处理最容易被跳过但最重要的一步。

### 2.1 两个关键形状指标

**偏度（Skewness）**：分布的"不对称程度"。

```
正偏（右偏，skew > 0）:      负偏（左偏，skew < 0）:
        ██                        ██
       ████                      ████
      ██████                    ██████
     ████████                  ████████
    ██████████  █             █  ██████████
   ███████████████           ██████████████
   ↑ 尾巴在右边                ↑ 尾巴在左边
```

直观理解：如果 skew = 2.0，意味着大部分数据挤在左边，少数极端大值把平均值拉到了中位数的右边。就像一群人年收入大部分在 5-10 万，但有一个亿万富翁拉高了平均值。

**峰度（Kurtosis）**：分布的"尖峭程度"和"尾部厚度"。

```
高峰度（kurt > 3）:           低峰度（kurt < 3）:
       ██                      ████████████
      ████                    ██████████████
     ██████                  ██████████████████
    ████████                ██████████████████████
    ████████                ██████████████████████
     ██████                  ██████████████████████
      ████                    ██████████████████
       ██                      ████████████
   ↑ 尖峰 + 厚尾             ↑ 扁平 + 薄尾
```

> 正态分布的峰度 = 3。我们通常报告"超额峰度"（excess kurtosis = kurtosis - 3），所以正常数据在 0 附近。

### 2.2 JFX0729 数据的真实分布

以下是 JFX0729 修复数据（7788 个 patch，30 条通路）的分布诊断：

| 指标 | 数值 | 解读 |
|------|:---:|------|
| `abs(skew) > 1` 的通路数 | **10 条** | 1/3 的通路有明显偏态 |
| `abs(skew) > 2` 的通路数 | **2 条** | `toxic`(2.26) 和 `icp`(2.26) 严重右偏 |
| `abs(kurtosis) > 3` 的通路数 | **2 条** | `toxic`(7.53) 和 `icp`(7.25) 有非常厚的尾巴 |

**最需要关注的 5 条通路**：

| 通路 | Skew | Kurtosis | 问题 |
|------|:---:|:---:|------|
| `toxic` | 2.26 | 7.53 | 极端右偏+厚尾，少量 spot 毒性反应极强 |
| `icp` | 2.26 | 7.25 | 同上，免疫检查点通路高度集中在低位 |
| `mhc` | -1.95 | 1.85 | **左偏**，大部分 spot MHC 表达偏高，少量极低 |
| `G2M_Checkpoint` | 1.46 | 1.80 | 细胞周期通路右偏（多数细胞不在分裂期） |
| `tls` | 1.08 | 1.80 | 三级淋巴结构通路右偏 |

**关键认知**：这些偏态和长尾不是测量误差——它们反映了**真实的生物学现象**：
- 肿瘤组织中只有少数区域的细胞在快速分裂（G2M 右偏）
- 免疫浸润是不均匀的——只有少数 spot 有强免疫反应
- 毒性反应通常只在坏死/缺氧区域出现

所以预处理的目标不是"消灭这些特征"，而是让它们以 ML 模型能稳定处理的形式存在。

## 3. 标准化方法家族

### 3.1 Z-Score 标准化：最常用的选择

#### 数学定义

对每个通路 $j$，对全部 $N$ 个样本：

$$z_{ij} = \frac{x_{ij} - \mu_j}{\sigma_j}$$

其中：
- $\mu_j = \frac{1}{N}\sum_{i=1}^{N} x_{ij}$（均值）
- $\sigma_j = \sqrt{\frac{1}{N-1}\sum_{i=1}^{N} (x_{ij} - \mu_j)^2}$（样本标准差，ddof=1）

#### 直观理解

Z-Score 做的事很简单：**把每个通路的数值重新标定，让均值变成 0，标准差变成 1**。

```
变换前（单位不同）:              变换后（统一尺度）:
通路A: [0.2, 0.3, 0.5, 0.8]  →  [-1.2, -0.7, +0.2, +1.7]
通路B: [50, 100, 150, 200]   →  [-1.2, -0.4, +0.4, +1.2]
通路C: [-5, 0, 5, 10]        →  [-1.1, -0.2, +0.6, +1.5]
```

变换后，三条通路有了**可比性**：z = 1.5 在三条通路中都是"比均值高 1.5 个标准差"。

#### 为什么"除以标准差"而不是"除以范围"？

标准差体现了数据的"典型散布程度"。如果你除以范围（max-min），一个异常值就能把整个尺度拉偏。标准差虽然也受异常值影响，但比范围稳健得多。

#### Z-Score 的局限

**Z-Score 不能改变分布形状。** 它只做平移+缩放：

```
变换前:  ██             变换后:  ██
        ████  █                  ████  █
       ██████ ██                ██████ ██
       █████████                █████████
       ↑ 右偏                    ↑ 仍然右偏！
```

这就是 `toxic` 通路的问题：z-score 后它仍然是严重右偏的，只是现在极端值表现为 z > 5 的离群点。

---

### 3.2 Min-Max 缩放

#### 数学定义

$$x'_{ij} = \frac{x_{ij} - \min(x_j)}{\max(x_j) - \min(x_j)}$$

结果被压缩到 $[0, 1]$ 区间。

#### 直观理解

把数据均匀地"挤"进一个固定盒子。

```
原始: [3, 5, 7, 100]  →  Min-Max: [0, 0.02, 0.04, 1.0]
```

#### 为什么不选它

1. **极端值毁了整个尺度**：一个 outlier = 100 马上把所有正常值挤压到 0~0.04
2. **对新数据不友好**：测试集中可能出现训练集中没见过的更大/更小值，此时 min-max 会失效
3. **不改变分布形状**：和 z-score 一样，只平移+缩放

对于我们的项目，pass。

---

### 3.3 Robust Scaler（鲁棒缩放）

#### 数学定义

$$x'_{ij} = \frac{x_{ij} - \text{median}(x_j)}{\text{IQR}(x_j)}$$

其中 IQR（四分位距）= Q3 - Q1（第 75 百分位 - 第 25 百分位）。

#### 直观理解

鲁棒缩放的思想是：**用中位数代替均值，用四分位距代替标准差**。

中位数和 IQR 都是"不会被极端值影响的统计量"：

```
数据: [1, 2, 3, 4, 5, 100]
均值 = 19.2        ← 被 100 严重拉偏
中位数 = 3.5       ← 不受 100 影响！
标准差 = 38.9      ← 被 100 严重拉大
IQR = 4 - 2 = 2   ← 不受 100 影响！
```

所以 Robust Scaler 对异常值非常宽容——即使有 100 这个极端值，正常数据的缩放也不会被扭曲。

#### 为什么部署方案不把它作为 P0？

方案中的对比表已经给出了答案：

| Transform | max_abs | abs(skew)>1 | abs(kurt)>3 |
|-----------|:---:|:---:|:---:|
| Robust Scaler | **38.0** | 10 | 2 |
| Standard Z-Score | 8.1 | 10 | 2 |

Robust Scaler 虽然用中位数和 IQR 做了缩放，但它**把极端值放大了**（max_abs = 38.0 vs z-score 的 8.1）。

原因：中位数和 IQR 主要反映"正常数据"的范围，对极端值的约束力比均值和标准差更弱。在 IQR 很小（数据集中）但极端值很远的情况下，`x - median` 很大而 `IQR` 很小 → 变换后的值反而更极端。

**而且 Robust Scaler 同样不改变分布形状**——skew 和 kurtosis 在变换前后完全不变。它只是换了参照系（从"均值±标准差"换成"中位数±IQR"）。

### 3.4 Power Transform（幂变换）：让数据"变高斯"

这是真正能**改变分布形状**的方法。它的核心思想是：

> 对每个数据点 $x$，找一个非线性函数 $f(x)$，使得 $f(x)$ 的分布比 $x$ 更接近正态分布。

#### 直观类比：拉伸尺子

想象你有一把弹性尺子，刻度不均匀——左边 1cm 代表实际 1 单位，但右边 1cm 可能代表实际 10 单位。

幂变换就是**重新设计这把尺子的刻度**，让数据在新尺子上看起来是对称的钟形。

```
原始尺子（均匀刻度）:       变换后的尺子（非线性刻度）:
|----|----|----|----|       |--|---|---|------|
0    2    4    6    8       0   1   2   4     8
                             ↑ 左端拉伸，右端压缩
```

#### Box-Cox 变换

$$y_i^{(\lambda)} = \begin{cases} \frac{y_i^\lambda - 1}{\lambda} & \text{if } \lambda \neq 0 \\ \ln(y_i) & \text{if } \lambda = 0 \end{cases}$$

要求：**所有输入必须严格 > 0**（不能有零或负数）。

$\lambda$ 的直观作用：

| $\lambda$ | 效果 | 适合处理 |
|:---:|------|------|
| 1 | 不变换（等价于线性） | 已经接近正态 |
| 0.5 | 平方根变换 | 轻度右偏 |
| 0 | 对数变换 | 中度右偏 |
| -1 | 倒数变换 | 严重右偏 |

#### Yeo-Johnson 变换（本项目选择）

Yeo-Johnson 是 Box-Cox 的"升级版"——**它不要求数据全是正数**。

数学定义（简化版）：

$$y_i^{(\lambda)} = \begin{cases} \frac{(y_i + 1)^\lambda - 1}{\lambda} & \text{if } \lambda \neq 0, y_i \geq 0 \\ \ln(y_i + 1) & \text{if } \lambda = 0, y_i \geq 0 \\ \frac{(1 - y_i)^{2-\lambda} - 1}{\lambda - 2} & \text{if } \lambda \neq 2, y_i < 0 \\ -\ln(1 - y_i) & \text{if } \lambda = 2, y_i < 0 \end{cases}$$

别被公式吓到。核心思想很简单：

1. 对所有 $y \geq 0$：和 Box-Cox 几乎一样
2. 对所有 $y < 0$：用对称的方式处理负数

**$\lambda$ 是自动学习的**：`PowerTransformer` 通过最大似然估计找到最能让分布接近正态的 $\lambda$，你不需要手工调。

#### 为什么 Yeo-Johnson 之后还要 Z-Score？

Yeo-Johnson 把分布形状变正态了，但**不保证 mean=0, std=1**。所以管线是：

```
raw ssGSEA → Yeo-Johnson(shape→normal) → Z-Score(mean→0, std→1)
```

两步各司其职：前者修形状，后者修尺度。

### 3.5 Quantile Transform（分位数变换）：最激进的正态化

#### 核心思想

> 不管原始分布长什么样，**强制**让输出服从标准正态分布。

#### 如何做到？

分两步：

**Step 1 — 计算每个值的分位数（rank percentile）**

把 $N$ 个样本按值从小到大排序。第 $k$ 个样本的分位数 = $k/N$。

例如，7788 个 `toxic` 值中，排在第 7000 位的值对应的分位数 = 7000/7788 ≈ 0.899。

**Step 2 — 把分位数映射到正态分布**

对于分位数 $p$，找到标准正态分布 $N(0,1)$ 中对应概率 $p$ 的分位点：

$$x' = \Phi^{-1}(p)$$

其中 $\Phi^{-1}$ 是正态分布的逆累积分布函数（也叫 probit 函数）。

```
分位数 0.01 → 正态 N(0,1) 的第 1 百分位 ≈ -2.33
分位数 0.50 → 正态 N(0,1) 的中位数 = 0.00
分位数 0.99 → 正态 N(0,1) 的第 99 百分位 ≈ +2.33
```

#### 一个完整的例子

原始数据（10 个值，严重右偏）：
```
[1, 1, 2, 2, 3, 5, 8, 15, 50, 200]
```

分位数变换后的输出：
```
约 [-1.28, -1.28, -0.84, -0.84, -0.52, 0.00, +0.52, +1.28, +1.65, +1.96]
```

无论原始分布多扭曲，输出**严格服从** $N(0,1)$。

#### 优点和代价

| 优点 | 代价 |
|------|------|
| 输出完美正态，skew=0, kurt=0 | **丢失了原始分布的所有形状信息** |
| 极端值被自然压缩（尾部被正态分布截断） | 如果原始分布的双峰/多峰是真实生物信号，会被抹平 |
| 不需要调参数（除了 n_quantiles） | n_quantiles 太小会丢失细节（离散化） |

在 JFX0729 数据上的表现：

```
原始 → Quantile Normal:
  max_abs: 8.08 → 5.20
  abs(skew)>1: 10/30 → 0/30
  abs(kurt)>3: 2/30 → 0/30
```

它做到了 z-score 和 Yeo-Johnson 都做不到的事——把所有 30 条通路都变成完美正态。但代价是：如果 `toxic` 通路有 8% 的样本是"真正异常的高毒性反应"（存在生物学意义），Quantile Normal 会把这 8% 强行拉回正态分布的主体，**抹去**了可能具有医学意义的离群信号。

## 4. 本项目的方法选择与理由

### 4.1 主线：标准 Z-Score（ddof=1）

**选择理由**：

1. **历史兼容性**：3 个患者的现有标签均为 z-score 格式。保持主线不换，已有实验结果全部可比
2. **跨患者一致性**：如果只把 JFX 换成别的变换而 HYZ/LMZ 仍用 z-score，跨患者训练中标签空间不一致，结果不可解释
3. **实现最简单**：只需要均值+标准差，计算 O(N)，参数仅 2×30=60 个数
4. **ML 工程友好**：mean≈0, std≈1 是最适合神经网络初始化的标签分布，配合 HuberLoss 对异常值已有一定鲁棒性

**局限（诚实列出）**：

- 不改变分布形状：10 条通路仍存在 `|skew|>1`
- 极端 z-score 可能达到 ±8（如 `mhc` 通路的左尾）
- 这些通路在训练中可能产生不稳定的梯度

### 4.2 P0 对照：Yeo-Johnson + Z-Score

**选择理由**：

1. **唯一能同时处理正负值的幂变换**：ssGSEA 值有正有负，Box-Cox 不可用
2. **保留更多分布信息**：相比 Quantile Normal，Yeo-Johnson 只改变偏态和尾部形状，不强制抹平所有分布特征
3. **JFX 单患者对照即可**：不需要三患者全部换标签即可验证"修分布形状能不能提升单患者预测"

**在 JFX 上的预期效果**：

| 通路 | 原始 Skew | Yeo-Johnson 后 Skew | 改善 |
|------|:---:|:---:|:---:|
| `toxic` | 2.26 | < 1.0 | 右尾被压缩 |
| `icp` | 2.26 | < 1.0 | 同上 |
| `mhc` | -1.95 | > -1.0 | 左尾被拉伸 |

### 4.3 P1 消融：Quantile Normal

**选择理由**：

- 作为"最正态"的参照系，验证正态性本身是否是关键因素
- 如果 Yeo-Johnson 提升但 Quantile Normal 反而下降 → 说明保留部分分布特征比完全正态化更重要
- 如果 Quantile Normal 也提升 → 说明正态性本身对 HuberLoss 有普遍好处

### 4.4 为什么 RobustScaler 不是 P0？

参见 Section 3.3 — 它不改变形状，且放大了极端值的绝对尺度（max_abs = 38 vs z-score 的 8.1）。在 HuberLoss 下，极端值虽然被 delta 截断，但 38 的尺度意味着 delta 参数可能需要重新调校。

## 5. 实战：从原始 ssGSEA 到训练标签

### 5.1 数据拆分（Train/Val Split）

**原则**：在一切变换之前先 split。否则 val 的分布信息会"泄露"到训练标签中。

```
正确的顺序:
  1. 收集全部 7788 个 patch 的 ID
  2. 随机 split → 7010 train / 778 val
  3. 分别在 train 上 fit transform → 分别在 train/val 上 apply
  （但本项目当前使用全样本 fit，见 Section 6.1）

当前项目的实践顺序（历史基线）:
  1. 收集全部 7788 个 patch
  2. 随机 split → copy 到 train_patches/ val_patches/
  3. 在全部 7788 个样本上 fit z-score → apply 到全部
```

两种方式的差异在 math 上很小（因为 train 占 90%），但方法论上第二种有轻微数据泄露。详见 Section 6.1。

### 5.2 Z-Score 计算（Python 实操）

```python
import pandas as pd
import numpy as np

# 1. 加载原始 ssGSEA
df = pd.read_csv("JFX0729_ssGSEA.csv")
df.rename(columns={df.columns[0]: "patch_id"}, inplace=True)

# 2. 提取 30 条通路列
target_cols = list(df.columns[1:])  # 跳过 patch_id

# 3. 计算参数（ddof=1 表示样本标准差）
means = df[target_cols].mean()            # 每通路均值
stds = df[target_cols].std(ddof=1)        # 每通路标准差

# 4. Z-Score
df_z = df.copy()
for col in target_cols:
    df_z[col] = (df_z[col] - means[col]) / stds[col]

# 5. 验证
print(f"Post-zscore means: {df_z[target_cols].mean().abs().max():.2e}")  # 应 ≈ 0
print(f"Post-zscore stds:   {(df_z[target_cols].std(ddof=1) - 1).abs().max():.2e}")  # 应 ≈ 0

# 6. 保存参数（后续复现需要！）
params_df = pd.DataFrame({
    'pathway': target_cols,
    'mean': means.values,
    'std': stds.values,
})
params_df.to_csv("zscore_params.csv", index=False)
```

### 5.3 Yeo-Johnson + Z-Score（Python 实操）

```python
from sklearn.preprocessing import PowerTransformer, StandardScaler

# 1. Yeo-Johnson — 修形状
pt = PowerTransformer(method='yeo-johnson', standardize=False)
X_yj = pt.fit_transform(df[target_cols].values)

# 2. Z-Score — 修尺度
scaler = StandardScaler()  # 等价于 z-score (但 ddof=0)
X_yj_z = scaler.fit_transform(X_yj)

# 3. 组装回 DataFrame
df_yj_z = df.copy()
df_yj_z[target_cols] = X_yj_z

# 4. 保存变换参数
import json
params = {
    'lambdas_': pt.lambdas_.tolist(),  # 每条通路的 λ
    'scaler_mean_': scaler.mean_.tolist(),
    'scaler_scale_': scaler.scale_.tolist(),
}
with open('yeojohnson_params.json', 'w') as f:
    json.dump(params, f, indent=2)
```

### 5.4 质量验证清单

无论用哪种变换，输出前必须检查：

| 检查项 | 通过标准 | 命令 |
|--------|---------|------|
| 行数 | = 原始样本数 | `assert len(df_out) == N` |
| 列数 | = 通路数 + 1（patch_id） | `assert df_out.shape[1] == 31` |
| NaN | 0 | `assert df_out[target_cols].isna().sum().sum() == 0` |
| Inf | 0 | `assert np.isfinite(df_out[target_cols].values).all()` |
| Patch ID 完整 | 与 split manifest 交集 = 100% | `assert len(set(df_out.patch_id) & set(all_patches)) == N` |
| Z-Score 均值 | max(\|mean\|) < 0.01 | `assert df_out[target_cols].mean().abs().max() < 0.01` |
| Z-Score 标准差 | max(\|std-1\|) < 0.01 | `assert (df_out[target_cols].std(ddof=1) - 1).abs().max() < 0.01` |

## 6. 常见陷阱与最佳实践

### 6.1 数据泄露（Data Leakage）⚠️ 最重要

**问题**：如果你在 split 之前就做了 z-score，val 集的数据参与了 mean/std 的计算，这构成了一种**轻微但真实的信息泄露**。

**为什么影响不大（但方法论上仍应避免）**：
- 当 train 占 90%（7010/7788）时，全样本的 mean/std 主要由 train 决定
- 泄露的信息是"val 集的整体均值和散布"，不是"每个 val 样本的标签值"
- 相比之下，在特征提取阶段泄露 val 图像到训练过程要严重得多

**正确做法（P1 改进）**：
```python
# 只在 train 上 fit
train_indices = manifest[manifest['split'] == 'train'].index
means = df.loc[train_indices, target_cols].mean()
stds = df.loc[train_indices, target_cols].std(ddof=1)

# 在全部数据上 apply
df_z = df.copy()
for col in target_cols:
    df_z[col] = (df_z[col] - means[col]) / stds[col]
```

### 6.2 跨患者标签一致性

**问题场景**：患者 A 的数据用标准 z-score，患者 B 用 Yeo-Johnson+z-score，你还把它们混在一起做跨患者训练。

**后果**：同一条通路（如 `ECM_Organization`）在患者 A 的标签空间中"+1.5 标准差"和在患者 B 的标签空间中"+1.5 标准差"含义不同。模型无法学到一致的映射。

**原则**：
- 跨患者实验：所有患者必须用**同一种变换方法**
- 单患者实验：可以各用各的（但结果不能跨患者比较）
- 本项目当前策略：主线统一 z-score，Yeo-Johnson 先做 JFX 单患者对照

### 6.3 NaN/Inf 保护

z-score 最常见的失败模式：

```
某通路 std = 0 → 除以 0 → Inf
某通路所有值相同 → std = 0 → NaN
```

本项目 LMZ12939 患者的数据曾因此崩溃——极端 z-score 值触发了 numpy 的 reduce overflow。

**防护代码**（应嵌入每段预处理）：

```python
# 1. 零方差检查
zero_std_cols = stds[stds == 0].index.tolist()
if zero_std_cols:
    print(f"WARNING: {len(zero_std_cols)} columns have zero std")

# 2. 跳过零方差列
valid_cols = [c for c in target_cols if stds[c] != 0]

# 3. 结果 NaN/Inf 清理
df_z[target_cols] = df_z[target_cols].replace([np.inf, -np.inf], np.nan)
df_z[target_cols] = df_z[target_cols].fillna(0.0)

# 4. 极端值裁剪（防 LMZ12939 类溢出）
df_z[target_cols] = df_z[target_cols].clip(-100, 100)
```

### 6.4 参数必须保存

做完预处理不保存参数 = 无法复现实验 = 论文中的方法描述不完整。

**最少保存**：
```json
{
  "method": "z-score",
  "ddof": 1,
  "fit_on": "all_7788_samples",  // 或 "train_only_7010"
  "pathways": {
    "ECM_Organization": {"mean": 0.523, "std": 0.142},
    ...
  }
}
```

### 6.5 分布诊断应在变换前后各做一次

```
Raw 数据 → 诊断(skew, kurtosis, 异常值比例, 直方图)
         → 变换
         → 诊断(skew, kurtosis, 异常值比例, 直方图)
         → 验收通过 / 不通过 → 调整方法
```

不诊断就直接变换 = 闭着眼睛操作。你不知道变换到底改变了什么，也不知道是否有通路在变换后反而变得更差。

## 7. 总结：医学数据预处理的思维框架

### 你不需要记住所有方法，记住这个决策树：

```
数据来了 →
  1. 画分布图（直方图 + skew/kurtosis）
     │
     ├─ 所有通路已经接近正态 → 直接用 z-score
     │
     ├─ 少数通路偏态但异常值不多 → z-score（主线）
     │    └─ 对照：Yeo-Johnson + z-score（验证修形状能否提升）
     │
     ├─ 多数通路严重偏态 + 长尾 → Yeo-Johnson + z-score
     │    └─ 对照：Quantile Normal（验证正态性本身是否关键）
     │
     └─ 极端值极多（>15%）且怀疑是测量误差 → Robust Scaler
          └─ 但先排除数据质量问题再考虑
```

### 本项目当前的位置：

```
✅ 主线：标准 Z-Score（3 患者均用）
🔜 P0 对照：Yeo-Johnson + Z-Score（JFX 单患者）
🔜 P1 消融：Quantile Normal（JFX 单患者）
❌ 不选：Min-Max / RobustScaler / Box-Cox
```

### 最重要的三条原则：

1. **Split before fit**：先拆 train/val，再在 train 上 fit 变换参数
2. **保存参数**：mean/std/lambda 全部落盘，否则无法复现
3. **跨患者一致**：多患者训练时所有人用同一种变换
