## 总体是否存在“足以解释新方法几乎无增益”的超参问题

**审查意见（不是 GO 训练）：没有达到「不合理」三条件、且足以单独解释 Huber / Ridge / W007 几乎无增益的超参。**

可记录的**存疑、但不得升级为必须改**的点：

1. Huber δ=1 使损失在 z 空间接近 MSE，配对曲线同形、同停训点；这能减弱“Huber 作为一个不同优化目标”的可辨识性，但不能证明换 δ 会抬升外部 PCC。
2. Ridge 按合同选 λ=10，29/30 通路恒等回退；校准层接近空操作。该跑次已 `failed/rejected`，不得当校准器，也不得据此重开神经网络训练。
3. W007 用回归指标选模、对比项权重 0.1：HCR 出现“对比损失下降、回归不动、选中 epoch 1”；CPGCR 对比损失几乎不动。这更像协议（选回归不选对比）与模块未耦合，而不是某一登记值被日志证明为必须修改。

冻结基线的 lr / epoch / patience / min_delta / val_loss 选模 / batch / Adam **合理**，早停按设计工作，不能把 PCC≈0.65 归咎于过早停止。
