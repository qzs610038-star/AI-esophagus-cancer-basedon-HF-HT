# 常规维护日志

本目录保存自动化生成的简短维护摘要，供用户快速阅读；它不是项目事实源、实验结果或批准记录。

- `daily/`：每日治理健康检查，文件名 `YYYY-MM-DD.md`。
- `weekly/`：每周专项检查，文件名 `YYYY-Www_<任务缩写>.md`。
- 每份日志不超过 25 行，只记录结论、变化、证据路径和待处理项。
- 不粘贴原始长日志、密钥、Token、完整环境变量或大段命令输出。
- 自动化只能新增或更新本次同名日志，不得修改本目录外的文件。
- lifecycle 变更、清理、训练、结果导入或接纳仍需用户明确批准。

权威事实仍以 `project_state/current_state.json`、相关 Registry 和项目治理命令的现场输出为准。
