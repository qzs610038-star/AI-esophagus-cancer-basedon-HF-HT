# 团队项目进度与结论

本目录用于长期维护五位团队成员的项目进度、采用方案和已审核结论，并按研究板块形成团队汇总。全部内容使用中文；确需保留的英文专业术语统一在《英文专业术语速查表》中解释。

- `汇总/训练数据/`：汇总训练数据相关成果。

## 强制审核规则

1. 只有经过用户明确审核并批准的内容，才能写入成员目录并进入汇总目录。
2. “已完成”“实验通过”“方案有效”等结论必须附可核验的项目内证据路径；没有证据时只能标记为“待补充”或“未验证”。
3. 计划、探索结果、失败结果和正式验收结论必须分开表述，不得把计划或探索性结果写成已确认结论。
4. 每条记录应优先说明：采用了什么方案、得到了什么结论、证据在哪里、结论有哪些限制、是否需要后续动作。
5. 对已批准原始材料进行原样归档时，不擅自改写原文；任何新增摘要或二次解释仍需单独提交用户审核。
6. 汇总目录只汇集各成员目录中已经批准的条目，不直接接收未经审核的新结论。
