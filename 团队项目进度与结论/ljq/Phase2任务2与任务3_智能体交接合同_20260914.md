## 4. 结构合同

前向（必须保持）：

```text
冻结 UNI2-h 1536 维特征 + 同切片同划分坐标
→ 无标签图
→ H: Linear 1536→256 + GELU
→ C: Dropout 0.3（仅训练、仅中心）+ Linear 256→D → p
→ B: Linear 256→D，无偏置，零初始化 → 残差
→ y = p + B Σ_j a_ij (h_j − h_i)
```

任务3：`D=30`。任务2：`D=基因数`（当前材料常见 319，最终集合待对齐）。

必须与方案(a) `config.json` 一致的图/模型超参（任务2只改输出维，不改 H 与图超参）：

- `data.input_dim=1536`
- `model.hidden_dim=256`，`dropout=0.3`，`activation=gelu_exact`，`spatial_bias=false`，`spatial_initialization=zeros`
- `graph.hops=1`，`radius_in_native_steps=1.5`，`max_neighbors=8`，`distance_sigma=1`
- `graph.use_image_similarity=true`，`image_temperature=0.2`，`self_raw_weight=1`

身份键：`(patient_id, slide_id, spot_id)`，按键关联，不依赖文件行序。  
划分合同：`MPP2/group_2`；训练约 9472 点 / 内部验证 1078 点 / 外部 XZY 1039 点。先固定划分，再抽训练点。

初始化：H/C 配对随机种子；B 全零。禁止继承通路训练过的 `shared.*`。种子默认 42；禁止事后改用 43/44 追分。

## 7. 评价合同

- 并列报告两种PCC，二者不得互证优越。逐通路平均PCC：逐患者、逐通路先算点位相关，再对通路等权、对患者等权平均。展平PCC（项目`pooled_pcc`）：该划分全部点位×通路的z分数拉直后算一次相关；名称中的平均池化不是图像平均池化。
- rawMAE：先逆变换到同一原始通路尺度再比。
- 若比较展平 PCC 或 zMSE：须事先约定统一评价标度，且仅由允许的训练数据产生，不得回灌稀疏训练。禁止混比各臂自己的 z 分数。
- 相同 epoch ≠ 相同更新次数。预算匹配规则必须事先写明。禁止事后按 XZY 选配置。
- 空间规则优于随机 ≠ 生物学机制证明。
