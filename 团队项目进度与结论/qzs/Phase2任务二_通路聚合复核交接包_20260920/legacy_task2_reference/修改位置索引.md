# 旧任务二建议修改位置

## 必须先审查

| 文件/函数 | 当前行为 | 建议 |
|---|---|---|
| `src/pathway_reconstruction.py::_gene_sets` | 从 mapping 取成员，只保留 319 背景内基因 | 将 mapping 来源、版本、ID/别名/重复/缺失和过滤前后成员数写入合同与产物 |
| `src/pathway_reconstruction.py::_score_matrix` | 调用 GSEApy ssGSEA，rank、`min_size=1`，读取 ES | 显式冻结软件版本和所有会影响结果的参数；不要依赖库默认值 |
| `fit_pathway_standardizer_from_train` | 训练真值 ES 另拟合一套候选 z-score | 从核实后的**共同重构真值训练集**只拟合一次通路尺度，冻结后两臂复用，不能从预测/验证/XZY 重拟合 |
| `prepare_reconstructed_pathway_labels` | 为直接臂预生成一套候选真值 | 可参考其预生成思路，但必须核实输入/算法，改为**只生成一次**有版本的共同真值，供两臂共读 |
| `reconstruct_prediction_table` | 对 true 与 pred 319 基因都再次运行 ssGSEA | 只对预测基因聚合；`true_30` 按身份读取预生成的共同真值 |
| `src/main.py` 任务二分支 | 直接臂和基因臂走不同真值路径 | 两臂接收同一重构真值路径；启动前检查路径、身份和30维顺序一致 |
| `src/targets/gene_expression.py` | 读取 `*_genes_pre_ssgsea.csv` | 明确这些数值是 counts、归一化还是 log1p，并核对 319 是否是完整排序宇宙 |
| `src/targets/gene_standardization.py` | 对基因做训练集标准化与逆变换 | 记录拟合点位、ddof、逆变换精度；避免因不同数据块分别逆变换造成真值漂移 |

## 不应修改

- MPP2/group_2 患者和点位划分。
- 全视野 224×224 和 UNI2-h CLS 1536 维输入。
- 最新 Phase 2 模型主体、空间图、优化器、学习率、batch、早停和内部验证选模口径。
- 当前主线 30 通路名称、顺序和标签文件。
- XZY 的外部测试角色。

直接臂输出30、基因臂按核实后的有序基因名单输出（历史为319）是任务定义所需差异；除输出维度和基因臂预测后聚合外，不应同时改模型或训练口径。确认输入/算法并冻结两臂共同真值后即可进行任务二；V003 逐值一致不是统一开跑条件。
