# 同步说明：本开箱包 vs 实验室服务器原方案包

面向：Phase 3 同学  
配套用法见 [`README.md`](./README.md)

---

## 一句话

**日常跑 Phase 3 特征，只用本开箱包即可，不依赖服务器上的原方案代码目录。**  
服务器上的 `phase2_softlink_local_v2` 是训出方案 A 的**原实验包**；本目录是从那次已接纳结果裁出来的、面向 Phase 3 的**推理交付包**。

---

## 两边分别是什么


| | 本开箱包（你手里这份） | 实验室服务器原方案包 |
| --- | --- | --- |
| 是什么 | Phase 3 用的特征生成桥接包 | Phase 2 完整实验包（训练 / 四臂 / 多种子） |
| 默认入口 | `run.ps1` → `src/phase3_package.py` | 原包训练与预测脚本（见服务器代码目录） |
| 包内是否含正式权重 | 有：`weights/formal_best_seed42.pt` | 权重在**运行目录**，不在代码目录 |
| 是否训练 | 否，只推理导出 | 是，曾训练方案 A 等臂 |
| 输入侧重 | CLAM H5 / 逐 patch / 自定义适配器 | Visium / Phase 2 训练数据管线 |
| 输出侧重 | `features_z`、`fused_z`、逐点 CSV | 训练日志、checkpoint、预测 npz 等 |
| 源码对照 | 随包 `reference_phase2_source/`（只读快照） | 服务器当前代码树（可能与快照略有差异，以已接纳批次为准） |

---

## 联系（同源合同）

两者描述的是**同一份已接纳方案 A**：

- 实验：`phase2_softlink_local_v2`
- 批次：`20260908_005325_810_8d306c10`
- 臂 / 种子 / 权重：`spatial` / seed **42** / `formal_best`（选出轮次 30）
- 模型合同：UNI2-h 1536 → 空间图 → 30 维训练 z-score 通路输出

本包权重是上述服务器 checkpoint 的本地交付副本；通路顺序与训练集 z-score 参数也按同一合同打包。  
包内测试要求：同一输入下，本包适配实现与 `reference_phase2_source` **逐位一致**。

---

## 区别（为什么要单独给你一份）


| 点 | 说明 |
| --- | --- |
| 目的不同 | 原包要训练与消融；本包只服务「生成 Phase 3 通路输入」 |
| 依赖不同 | 本包自带权重、资产与推理入口，**不必**先挂上服务器 `code\phase2_softlink_local_v2` 才能跑 |
| 接口不同 | 本包按 Phase 3 / CLAM 常见格式读写；原包按 Phase 2 实验 IO |
| 可改范围不同 | 本包鼓励改输入适配与输出路径；**不要**为了 Phase 3 去改原包训练代码或覆盖原批次 `runs` |
| 内容裁剪 | 本包不含四臂训练、多种子调度、任务 2/3 消融脚手架；那些仍在原实验材料里 |
