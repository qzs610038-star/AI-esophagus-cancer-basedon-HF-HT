## 3. 输入 / 输出合同

输入（三选一，与 2026-09-12 包相同的目录形状）：

- `clam_slide`：每切片 H5，`features=[N,1536]`，`coords=[N,2]`。
- `per_patch`：点表 + 特征文件。
- `custom`：适配器按切片返回 features / coords / ids。

强制字段：`input.feature_protocol = "full_fov_224_bicubic_v1"`。此字段是声明，代码不能从无元数据数组反推是否裁剪。使用历史 `legacy_crop_0875_v1` 缓存属于合同失败，应停止并报告，不得继续当成功运行。

坐标：切片原始坐标系；禁止跨 `slide_id` 构图。原生步长已知时提供 `graph.slide_geometry`（至少 `slide_id,s`）。缺失或无效时，推断或回退 `native_step_fallback=224`，必须警告、登记来源并继续；严格模式也不得因该项中止。训练切片步长为 336 / 448 / 224，不是统一 224。推断间距不等于已核实原生步长；对待核实切片报告 `geometry_status` 和 `geometry_unverified_slides`，以后取得可靠值时另建运行再生成相应特征。

切片编号须全局唯一。同一切片编号对应多个患者时不得选首个/末个患者凑合：H5 映射清单冲突在处理前失败；逐 patch 冲突整片排除，继续其余切片并返回 `partial`。适配器重复产出相同切片编号不得覆盖文件。坏行剔除后保留特征、坐标、身份一一对应。

输出：

- `features_z`：`[N,30]`，推荐给通路分支。
- `fused_z`：默认 `pathology_gene`，`[N,1566]`。改 `fusion_order` 必须写入实验记录。
- `predictions/*.csv`：含 `pred_z_*` 与一次训练集逆变换的 `pred_raw_*`。
- `run_manifest.json`：`contract_variant=true` 时禁止称为本交付模型。
- `contract_variant=false` 仅说明固定图超参数未变，不证明步长或特征协议已核实；后者仍为操作者来源声明。
- `status=completed_with_warnings` 且 `input_complete=true` 可以继续；步长未知属于此类。`partial` 表示缺片/跳片/剔除点，退出码 1，不能称完整队列。致命输入身份或模型错误退出码 2。完整处理退出码 0。

加载权重失败条件（应全局停止）：种子/臂/kind 不符，epoch 不是 28，编码器或协议不是 uni2h / full_fov，图参数与上表不符，维度不是 1536/256/30。

## 5. Phase 3 使用规则

允许：

- 复制本包到工作目录；只改配置里的路径、列映射、输出根、设备。
- 用 `run.ps1 -Mode preflight` 再 `-Mode all`。
- 将 `features_z` / `fused_z` 接入现有 CLAM 多模态或机器学习通路分支（`gene_dim=30`）。
- 按原 Phase 3 划分重训疗效模型；做仅病理 / 仅通路 / 错配 / 融合消融。

禁止：

- 改 `ACCEPTED_GRAPH` 对应字段后仍写本模型名称。
- 加载本 `formal_best.pt` 作为疗效网络初始化。
- 用厦门外部或任何测试集选择 Phase 2 检查点、图参数或编码器。
- 静默改用 UNI / Virchow2 权重。Virchow2 CLS 为 1280 维，本检查点无法 strict 加载。
- 覆盖 `D:\AIPatho\qzs\code\phase2_fullfov_hpo_v1` 或上述已接纳 runs/weights。
- 把 Phase 2 的 PCC 表当作 Phase 3 疗效结果。

缺少以下实验决定时须明确报告，不得自行选定后开训：

1. Phase 3 特征是否已按 `full_fov_224_bicubic_v1` 重新提取。
2. 下游是否掌握切片原生步长来源；未知允许警告后继续生成特征，不作为暂停项。
3. 下游读 `features_z` 还是 `fused_z`，融合顺序是否仍为病理在前。
4. 疗效模型划分、标签和原 checkpoint 是否作废重训。
