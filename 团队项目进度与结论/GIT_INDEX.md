## 当前目录边界

本机目录保留 `yzq/`、`wzk/`、`ljq/`、`qzs/`、`lzd/` 和 `汇总/` 六个板块。成员原始材料、团队汇总、组会汇报、图片、附件、结果文件和术语表均仅保留在本机，不纳入 Git。

## 维护规则

团队资料继续遵循既有规则：用户明确审核后才可写入；既有内容只追加、不删除、不改写、不重排；成员原始材料保持原目录和原内容。该规则约束本机资料维护，不使团队资料自动成为工作树输入。

## 与公共仓库的边界

跨工作树可复用的公共代码、配置、治理规则或已批准技术结论，必须经独立审核后进入公共代码、`project_state/` 或 active 治理文档。它们不得只存在于团队资料、组会材料或聊天记录中。

## 写入边界

- 禁止提交成员进展、实验结果、组会材料、图表、附件、个人资料或术语表。
- 新增团队材料默认保留在本机相应成员目录；本索引只在目录边界或维护规则变化时更新。
- 工作树若需要某项团队输入，须在实验方案中明确列出经批准的最小文件集；不得整目录复制。
