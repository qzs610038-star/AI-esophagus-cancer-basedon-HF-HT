# 评审任务与待完善事项

请围绕三个问题反馈：研究过程是否讲清；现有比较与结论是否充分；论文 Phase 2 部分怎样写更准确。每条意见附具体材料位置和修改建议。

## 评审顺序

1. 读[实验总表](../02_实验档案/实验总表.md)，确认研究过程和路线选择。
2. 看[全视野结果](../02_实验档案/已接纳全视野三模型结果.md)与[任务 3 结果](../02_实验档案/已接纳任务3密度消融结果.md)，核对比较对象、数据与指标。
3. 从实验卡进入[原始记录](../07_原始训练记录/README.md)，按疑问检查配置、训练历史、选模和预测；[复算工具](../08_智能体阅读/阅读说明.md)可生成逐运行及逐通路结果。
4. 查看[论文逐段填写材料](../04_论文填写/对照现有大纲逐段填写.md)，提出段落、图表与补充材料的安排建议。

## 需要判断的事项

| 方面 | 请检查什么 | 建议的反馈形式 |
|---|---|---|
| 研究覆盖 | 各实验的目的、观察结果和后续选择是否连贯 | 指明需要增加哪段过渡或哪份证据 |
| 数据一致性 | 预测、真值、患者、点位、通路和标准化是否对应 | 给出实验、运行、字段及发现 |
| 比较充分性 | 空间与去 B、视野、配方、密度的比较是否对齐 | 指明应并列的表格行和建议措辞 |
| 结果完整性 | 两种 PCC、误差、内外部结果及种子波动是否清楚 | 指明需要补充的指标、图或表注 |
| 可追溯性 | 结论能否找到原始记录和独立计算入口 | 给出缺失链接、字段或说明 |
| 论文适配 | 方法、结果与讨论能否准确对应实验 | 提供替换句及主文或补充材料建议 |

## 已知事实与待完善资料

| 事项 | 已有事实或当前处理 | 请队友重点判断 |
|---|---|---|
| 评估对象 | 内部为六名开发患者的留出点；外部为历史已使用的 XZY | 论文是否准确表达这两个评估层级 |

| 密度消融 | 三臂的训练点数、空间覆盖及邻接关系随采样方案变化 | 观察结果和机制解释是否分开表达 |

| 原始数据覆盖 | 近期主要结果有逐点预测；部分早期数据缺身份；对比学习第二阶段内部保存汇总历史 | 根据现有数据，哪些分析最值得补充 |
| 事实时点 | 任务 3 已于 9 月 20 日接纳；旧快照保留各自日期 | 卡片与来源是否便于识别现行状态 |
| 后续接口 | 任务 2 聚合诊断保留在独立交接包；完成聚合修正与本地自检后可直接启动新实验。第二批新模型结果待补 | 后续比较需要统一哪些输入和输出 |
| 论文资料 | 原大纲含旧数据与网络描述，通路评分来源和部分临床资料待补 | 指明应由哪位作者补充什么 |

当前研究资料包与实际模型运行包通过[来源索引](../06_证据摘录/方案代码原始结果路径表.md)关联。Phase 3 的真实队列分析由相应运行与结果记录提供依据。

## 返还方式

使用[反馈表](评审反馈表.md)记录“问题—证据—影响—建议”。优先级分为：高（影响主要比较或结论）、中（影响解释或复现）、低（组织与展示改进）。需要新增分析或实验的建议同时写明目标与所需输入，供用户安排。
