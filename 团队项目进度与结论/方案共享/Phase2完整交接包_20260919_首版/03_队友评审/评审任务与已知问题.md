# 评审任务与已知问题

请判断当前材料能否支撑 Phase 2 的论文叙事，以及哪些地方还需要修改。优先阅读现有证据，围绕具体疑问核对；这不是要求重新审计全仓库或重训全部实验。

## 评审顺序

1. 看[实验总表](../02_实验档案/实验总表.md)，确认研究过程、未改善和失败路线没有遗漏。
2. 看当前全视野与第一轮四臂卡片，核对数据、对照、指标和结论是否匹配。
3. 看[最新三模型结果](../02_实验档案/已接纳全视野三模型结果.md)，重点区分空间对去 B、空间对单点。
4. 根据疑问看[已有复核记录](../06_证据摘录/接纳记录与结果/全视野复核接纳记录.md)、[冻结配方](../06_证据摘录/关键配置与通路/冻结配方.json)和源码。
5. 看[论文逐段映射](../04_论文填写/对照现有大纲逐段填写.md)，判断哪些内容应改写、补充或暂留空位。

## 需要你作出的判断

| 方面 | 请检查什么 | 如何给出可执行意见 |
|---|---|---|
| 研究覆盖 | 每条关键路线为什么做、为什么停止是否清楚 | 指明缺失的实验、证据或过渡解释 |
| 数据一致性 | 点位、患者、通路、标签、标准化是否对应；验证层级是否说清 | 引用具体合同或字段，不把缺证据写成已证实错误 |
| 比较充分性 | 同一次比较改了什么；是否有对应控制；不同视野/配方是否混排 | 指明应比较哪些行，结论应如何限定 |
| 结果完整性 | 双 PCC、内外部、种子、已有误差是否保留；是否只呈现有利结果 | 指明应补的来源指标或表注 |
| 方法可理解与追溯 | 当前输入、H/C/B、构图、选模与停止规则是否能找到 | 指明缺少哪个事实，不笼统要求“增加细节” |
| 论文适配 | 段落使用的是不是当前协议，是否夸大普适、因果或显著性 | 提供具体替换句或放入补充材料的建议 |

## 两类交付状态分别看

原全视野结果接纳记录说明 export-phase3 合同未随该批回传；现有独立 Phase 3 包的 README 记录了权重落地与本地检查。前者是原批次输出范围，后者是另一份工程材料的状态。本包不据此声称真实 Phase 3 队列已经完成推理或疗效验证。

当前包内保存的源码来自现有交付包的训练参考目录，用于阅读。实际运行仍回原工程，不从档案包直接启动。

## 意见优先级

高：已有依据表明可能改变主要比较或结论。中：影响解释与复现的具体信息缺项。低：组织、用词和展示改进。优先级不等同于重训指令。
