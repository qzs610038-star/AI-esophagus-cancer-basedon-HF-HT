# 指标定义与复算方式

主表并列两种 PCC（Pearson 相关系数），分别描述患者内各通路的预测相关性，以及全部标准化数值合并后的相关性。

| 输出字段 | 计算方式 |
|---|---|
| patient_macro_pathway_pcc | 每名患者、每条通路分别计算点位 PCC；先在患者内平均，再对患者等权平均 |
| pooled_pcc | 把全部点位 × 通路的 z 分数展平，计算一次 PCC |
| pooled_pathway_pcc | 合并所有点位后逐通路计算 PCC，再平均；作为单独辅助指标 |
| pooled_z_mse | 全部点位 × 通路的 z 分数均方误差 |
| patient_macro_z_mse | 每名患者的 z 分数均方误差，再对患者等权平均 |
| raw_mae | 原始通路评分单位下，全部点位 × 通路的平均绝对误差 |
| fisher_patient_pathway_pcc | 同一通路的各患者 PCC 先做 Fisher z 变换，平均并逆变换，再对通路平均；用于复核历史登记 |

原始评分预测和真值已保存时直接使用；只有 z 分数时，复算程序使用文件内的均值、标准差，或索引指定的训练集标准化记录反变换。独立标准化记录按通路名对齐，派生来源保存在结果中。

患者或通路内方差为零、点位数少于 2 时，相关系数按缺项记录，同时输出具体原因和数量。训练选模使用的常量预测惩罚属于选模规则；此处报告实测相关性。缺少患者身份时输出可计算的整体及逐通路指标。缺少逐点身份时，数值复算与身份验证的覆盖分别说明。

## 历史基线的三个数值

修复后 MPP2 历史基线内部算术等权 PCC 为 0.648464，整体展平 PCC 为 0.797126，历史 Fisher 聚合为 0.667369。XZY 的等权与 Fisher 值均约 0.519386，因为它只含一名患者。对应字段及来源见[修复基线卡](../02_实验档案/实验卡片/02_标签修复_复核与缓存一致性.md)。

该基线早期记录 `test_loss=0.6621`，后续登记保存了历史整体 zMSE 的完整值约 0.662076825。引用时保留字段来源和精度。

## 种子与比较

各模型、视野协议、配方、对照臂、阶段、预测端点、数据划分和选择规则分别成组。一个组中的独立种子输出均值及样本标准差（分母 n−1）；单种子输出原值，标准差留空。重复种子或缺少分组身份时保持逐记录展示。

任务 3 的 `equal_updates` 表示等更新次数下选择，`equal_50_epochs` 表示前 50 轮的敏感性选择。冻结参考单列，供核对已交付模型。内部与外部预测分别计算；全部模型选择依据内部验证。

登记基准见[指标基准](指标基准.json)。现代 PCC 与 zMSE 通常按绝对差 0.000005 比较；历史显示值按来源保留的小数位设置容差。raw MAE 的比较容差记录在相应基准条目中。数值差异会保留在复算输出，供核对来源和精度。
