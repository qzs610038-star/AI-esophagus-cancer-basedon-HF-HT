## 独立复算

运行环境：Python 3.10 或更新版本、NumPy。所有输入均通过包内相对路径读取；将整个文件夹复制到其他位置后可沿用同一命令。

在本包根目录打开终端：

```powershell
python "08_智能体阅读/复算指标.py" --list
python "08_智能体阅读/复算指标.py" --experiment 12 --output "../全视野复算结果"
python "08_智能体阅读/复算指标.py" --experiment 13 --output "../任务3复算结果"
python "08_智能体阅读/复算指标.py" --output "../全部预测复算结果"
```

`--experiment` 接受卡片编号或实验编号；`--run` 接受精确运行编号或预测记录编号。输出目录应为新目录，以便保留历次分析。

输出包括逐运行指标、种子汇总、逐患者逐通路明细、登记比较表和完整 JSON（结构化数据）结果。登记比较中的 `PASS` 表示该项数值在记录容差内一致，`DIFFERENCE` 表示存在数值差异，`not_available` 表示本次选择的数据或指标不足以比较。输入读取或身份连接错误会逐项写入结果，并以非零退出码返回。

## 阅读结构化索引

实验索引保存卡片、现行登记、原始记录入口和结论来源。预测索引逐项记录数据路径、运行、模型、对照臂、种子、阶段、选择规则和字段映射。相同文件可提供训练与验证两组数组，它们有各自的数据记录编号。

历史 MPP、修复基线和 Huber 的部分 CSV 保存预测与真值，逐点身份信息较少；其可计算指标在数据说明中列明。对比学习第二阶段内部保留 60 轮的汇总指标历史，外部保存逐点预测。智能体应根据实际可用字段选择分析层级。

任务 3 的两种选模结果分别汇总；冻结参考单列。旧报告及原始 JSON 中的历史状态保留原文，当前状态从[现行实验事实](../06_证据摘录/现行实验事实_20260920.json)读取。
