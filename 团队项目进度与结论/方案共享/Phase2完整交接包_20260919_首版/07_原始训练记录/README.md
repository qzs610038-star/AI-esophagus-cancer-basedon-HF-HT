## 怎样分析

1. 从实验卡或上表进入该实验的数据说明，确认所需运行、种子与评估端点。
2. 在[预测索引](预测索引.json)查找文件及原字段映射。CSV 是表格文本，NPZ 是 NumPy 数组容器。
3. 按[复算说明](../08_智能体阅读/阅读说明.md)运行工具。输出含逐运行、逐患者逐通路、种子汇总及登记比较。
4. 把需要修改的结论、发现的差异和建议写入[评审反馈表](../03_队友评审/评审反馈表.md)，附文件路径和运行编号。

## 来源与缺项

[文件清单](文件清单.json)记录原项目路径、包内路径、大小和副本验证方式。普通记录按字节原样复制。8 份重复 CSV 已复用同内容文件，原来源记录在 duplicate_source_aliases 中。对比学习第一阶段的 20 个混合文件保留预测、真值、已有身份等数组，剥离中间特征；保留数组已逐项核对类型、形状和数值。该实验第二阶段的完整逐轮汇总历史同时保留。

早期部分 CSV 只有真值与预测列，可计算整体或逐通路指标；患者等权计算需要患者身份。对比学习第二阶段内部的逐点预测在现有记录中未保存，可核对逐轮汇总、选点及外部预测。其他缺项逐项列在预测索引的 missing_records 中。

共享 XZY 真值有正式来源。第一轮空间模型按患者与点位连接；历史 UNI/Virchow2 记录按患者、来源组与点位连接；复用的 UNI2-h 参考按其原合同连接。复算时检查身份集合、重复项和通路顺序。

图像、模型权重和特征缓存保留在原位置，所需定位信息随已有路径登记交付。历史文件中的绝对路径用于回溯来源；包内复算统一使用相对路径。
