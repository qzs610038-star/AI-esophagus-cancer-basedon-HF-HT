# 本地分析与回传操作卡

服务器训练结束后，只复制整个批次结果目录；不复制 `weights` 和 `feature_caches` 中的大文件。批次内必须保留：

- `batch_manifest.json`、`config_snapshot.json`、`model_weights.json`、`feature_caches.json`；
- `reference_<seed>_uni2h/raw/` 的历史参照预测与登记；
- `train_<seed>_<model>/raw/` 的内部预测、历史和点位顺序；
- `external_<seed>_<model>/raw/external_predictions.npz`；
- `provenance/package_snapshot/` 与故障日志。

在本地代码包目录运行：

```powershell
.\analyze_local.ps1 `
  -BatchDir D:\...\<batch_id> `
  -OutputDir D:\...\<batch_id>\analysis `
  -PythonInterpreter D:\miniconda\envs\pfmval_py310\python.exe
```

分析目录必须尚不存在；工具不会覆盖 `raw/`。首批只含 seed 42 时，报告明确写“单种子”，不生成样本标准差。

建议把服务器批次复制到：

```text
D:\AI空间转录病理研究\PFMval_new\experiments\results\phase2_backbone_point_ablation_20260914\<batch_id>
```

并将 `-OutputDir` 指向该批次下尚不存在的 `analysis`。分析成功后主要产物为：

- `metrics_by_model_seed.json`：双 PCC、误差、资源字段及分集合种子汇总；
- `model_seed_metrics.csv`：模型—种子核心表；
- `metric_details.json`：逐患者、逐通路和患者—通路选择明细；
- `per_patient_metrics.csv`、`per_pathway_metrics.csv`：图表和复核用源数据；
- `首批种子42审核报告.md` 或 `三种子统一分析报告.md`。

空间指标、Top-k overlap 尚未冻结定义时会显式写为 `not_computed_not_predefined`；不会临时补定义或填 0。三种子统计只在同一模型恰有 42、43、44 后产生样本标准差，并分别汇总内部验证与 XZY。

种子 42 与后续 43/44 位于不同服务器批次时，一次传入两个目录：

```powershell
.\analyze_local.ps1 `
  -BatchDir @(<seed42批次目录>, <remaining批次目录>) `
  -OutputDir <新分析目录> `
  -ExternalTargets <可选XZY真值.npz> `
  -PythonInterpreter <本地python.exe>
```

工具按模型—seed—集合合并，不平均预测；协议版本不一致或同一结果在多个批次重复出现时停止。只有 UNI2-h、UNI、Virchow2 三者都齐备 42、43、44，报告才命名为“三种子统一分析报告”；其他多 seed 状态明确标为部分结果。

## 可选 XZY 真值文件

服务器预测始终无标签。若需在本地计算 XZY 指标，提供一个可信、按共同身份整理的 NPZ：

```text
target_z        float array [1039,30]
patients        Unicode string array [1039]
source_groups   Unicode string array [1039]
spots           Unicode string array [1039]
pathways        Unicode string array [30]
target_raw      可选 float array [1039,30]，身份对齐的原始未裁剪真值
```

可兼容字段名 `patient_id`、`slide_id`、`spot_id`、`pathway_names`。工具按三元身份键重排真值，不按文件行序直接拼接；缺行、重复或通路顺序不同都会停止。

```powershell
.\analyze_local.ps1 `
  -BatchDir <批次目录> `
  -OutputDir <新分析目录> `
  -ExternalTargets <XZY真值.npz> `
  -PythonInterpreter <本地python.exe>
```

如果没有 `target_raw`，raw 指标只使用 `target_z × train_sd + train_mean` 的一次逆变换结果，并标注为“裁剪 z 真值的逆变换”，不冒充原始未裁剪 ssGSEA。若提供 `target_raw`，报告会保留它与上述逆变换真值的平均和最大绝对差异，便于发现修复标签与原始真值的不一致。
