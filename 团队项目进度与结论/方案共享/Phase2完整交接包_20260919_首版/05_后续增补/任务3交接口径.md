| 测试集合 | 内部验证 1,078 点、外部 XZY 1,039 点保持稠密且各臂一致；训练采样不能改变评价集合 |
| 初始化 | 三臂均从零训练，同一种子核对相同初始化；已接纳 seed 45 检查点只作冻结参考，不用于初始化、继续训练或调参 |
| 邻域 | 训练图只含该臂保留点；抽稀后不扩大半径。沿用半径 2 原生步长、最多 12 邻居的冻结图约定，禁止使用留出真值 |
| 标度与选择 | 每臂标准器只拟合本臂训练 raw 真值，评价统一回稠密训练集 z 尺度；固定 14,800 次更新、关闭早停。主选择每 296 次更新验证，另保留前 50 个完整 epoch 的敏感性选择；外部仅在两者冻结后评价 |
| 统计口径 | 同一通路、评价标度和两种 PCC；主选择与敏感性选择分别报告，不混成同一结果；保留训练点数及空间覆盖 |
| 回传 | 保留/排除点位、初始化来源、各集合邻域规则、稠密预测与真值、配置和运行记录 |
| 论文占位 | “训练密度与稠密测试比较”；结果和方向均待补 |
