# 当前模型源码阅读说明

这份源码快照取自既有 Phase 3 交付包的 training_reference（训练参考）目录，用于查看当前输入、构图、模型、训练和选择行为。其路径迁移修复见[原训练参考说明](原训练参考说明.md)。这里没有复制数据、缓存和权重，不能把档案目录当成独立训练包直接运行。

| 阅读问题 | 源码入口 |
|---|---|
| 完整图像块怎样缩放和归一化 | [transforms.py](src/transforms.py)、[feature_extract.py](src/feature_extract.py) |
| 身份、标签与特征如何连接 | [input_data.py](src/input_data.py)、[data.py](src/data.py)、[feature_cache.py](src/feature_cache.py) |
| 空间邻居怎样构建 | [graph.py](src/graph.py) |
| H、C、B 如何产生输出 | [model.py](src/model.py) |
| 损失、优化与训练轮次 | [train.py](src/train.py)、[stage_runtime.py](src/stage_runtime.py) |
| 内部验证与配方冻结 | [selection.py](src/selection.py)、[search.py](src/search.py) |
| 外部预测与任务调度 | [predict.py](src/predict.py)、[runner.py](runner.py) |

参数来源另见[冻结配方](../关键配置与通路/冻结配方.json)、[种子 45 生效配置](../关键配置与通路/生效配置.json)。本轮只复制和整理代码供阅读，没有修改训练实现，也没有在本档案中重跑训练或缓存。
