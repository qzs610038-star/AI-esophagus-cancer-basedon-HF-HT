# 全视野空间模型：训练复现与 Phase 3 交接

本包交付一款已经选定的图像到通路模型。它把每个病理 patch 的图像特征、同切片坐标和邻居特征转换为 **30 维通路 z 分数**，供下游预测模型使用。模型是 UNI2-h 全视野空间残差模型，训练种子为 45，正式检查点选自第 28 轮。交接适配版本为 **1.1.0**；正式权重和训练配方未变。

**正式权重已放入并通过本地检查**，文件为 `weights/formal_best.pt`。服务器原件与代码位置见 [`server_locations.json`](../关键配置与通路/现有交付包服务器路径.json)。推理入口会核对检查点种子、正式轮次、输入协议、模型维度和空间参数；不会静默加载旧权重。向团队交付时复制整个目录。

## 图像如何变成模型输入

1. 读取完整的**正方形** patch，转为 RGB，不做中心裁剪。
2. 用双三次插值与抗锯齿缩放到 224×224；转为 0–1 浮点张量，并按 ImageNet 均值和标准差归一化。没有随机图像增强。
3. 用固定版本 UNI2-h 编码器提取第 0 个 CLS token（整块图像的汇总向量），得到每个 patch 的 **1536 维**浮点特征。编码器规范与版本记录在 `training_reference/inputs/model_manifest.json`。
4. 将特征与 `patient_id`、`slide_id`、`spot_id`、坐标逐行绑定。坐标属于切片原始坐标系；不能把不同切片拼成同一张邻域图。

Phase 3 输入若已经是 H5 或逐 patch 特征文件，必须确认特征是按上述**完整视野**协议提取的 UNI2-h CLS。配置中的 `input.feature_protocol` 是操作者对来源的声明；程序无法从一个无元数据的 H5 数组反推当初是否裁剪过图像。

## 空间预测到底做什么

对同一切片上的每个中心点，只在半径 **2 个原生网格步长**内找邻居，最多取距离最近的 **12 个**；边是有向的，彼此不强制对称。邻居原始权重同时考虑距离和 CLS 余弦相似度：距离 σ=**0.5**，图像温度=**0.7716396069760084**，自身原始权重=**0.5**。权重与自身项共同归一化。

共享层 H 将 1536 维特征映射到 256 维。点位读出层 C 给出 30 维基础预测；空间头 B 接收“加权邻居 H 减去中心 H”，给出 30 维修正量。输出是 **C + B**。孤立点没有空间修正，仅用基础预测。推理时模型处于评估模式，不使用训练时的 Dropout。

图半径是相对每张切片的**原生坐标步长**，不是固定的物理微米。已知时请提供 `graph.slide_geometry` CSV，至少有 `slide_id,s`。缺失、无效或冲突时，程序**警告并继续**：优先从保留点坐标推断，无法稳定推断时使用 `native_step_fallback`（默认 224）。`-Strict` 也不会因此暂停。推断间距可能因稀疏采样而大于真实步长；来源与实际值写入 `slide_summary.csv`，待核实切片写入 `run_manifest.json` 的 `geometry_unverified_slides`。未知步长可以先生成特征，但不能将其记录为几何已核实；以后补得可靠步长时须新建运行重新生成受影响切片。

## 权重和预检

这份交接包已包含权重。先把样例配置中的输入路径改成实际数据路径，再在包根目录执行：

```powershell
.\run.ps1 -Config .\configs\clam_slide.example.json -Mode preflight
```

`preflight` 会加载权重、检查资产并验证切片与构图，但**不输出预测特征**。预检后根据运行报告执行 `-Mode all`；步长缺失警告不阻止继续。启动脚本不会安装或升级 Python 依赖；所需包见 `requirements.txt`。交付前已用真实权重和合成 H5 / 逐 patch 输入完成本地检查。目标环境仍须对真实输入运行预检。

切片编号必须在本次输入中全局唯一。同一编号对应不同患者时，H5 患者映射清单会在开始处理前报错；逐 patch 模式会跳过有冲突的整张切片并继续其他切片。适配器重复返回同一切片编号时拒绝覆盖。坏坐标、非法特征行号或坏特征只剔除对应行，记录保留在 `dropped_patches.csv`，不会使其余行错位。

## Phase 3 如何导入

沿用上次分享包的三种输入方式和输出目录结构：

1. **每切片 H5**：`input.mode="clam_slide"`。每个文件默认含 `features=[N,1536]`、`coords=[N,2]`；可用切片清单绑定患者和切片身份。
2. **逐 patch 清单**：`input.mode="per_patch"`。CSV 给出切片、坐标、特征文件路径，列名不同可在 `column_map` 里映射。
3. **自定义适配器**：`input.mode="custom"`。适配器按切片返回特征、坐标和身份；样例在 `examples/`。

在包根目录复制相应的 `configs/*.example.json`，修改输入路径、输出根目录和切片步长，再运行：

```powershell
.\run.ps1 -Config .\configs\clam_slide.example.json -Mode preflight
.\run.ps1 -Config .\configs\clam_slide.example.json -Mode all
```

每次运行新建输出目录，不覆盖以前的运行。`features_z/{pt_files,h5_files}` 是推荐给下游通路分支的 **[N,30]** 特征；`fused_z/{pt_files,h5_files}` 默认按“1536 维病理特征在前、30 维通路特征在后”拼接成 **[N,1566]**。`predictions/` 为逐点 CSV，含 z 分数与一次逆变换后的原始量纲值。`run_manifest.json` 记录模型、图参数、通路顺序、完成状态及警告；坏切片写入 `warnings.jsonl` 和 `skipped_slides.csv`。

完成状态分别解释：`completed` 为全部输入完成；`completed_with_warnings` 为全部输入完成但有警告（包括步长推断/回退）；二者退出码均为 0。`partial` 为存在缺片、跳片或剔除点，保留有效输出但退出码为 1，不能当作完整队列；`failed` 或不可加载模型/配置等致命错误返回退出码 2。请同时检查 `input_complete`、缺项清单和 `geometry_status`。`contract_variant=false` 只表示图超参数未改动，不证明输入特征来源或原生步长已经核实。

下游使用 `features_z` 或 `fused_z` 后，需要按原下游划分重新训练并评价下游模型；通路列顺序固定，不能重新排列或用下游队列重估标准化参数。若修改图参数，运行记录会标记 `contract_variant=true`，该输出属于不同的推理配置。

## 如何复现训练

`training_reference/src/` 含编码器加载、全视野变换、特征缓存、按身份连接标签、空间构图、H/C/B 训练、内部验证选模与外部预测的源码。`effective_config.json` 是种子 45 实际生效的参数：Adam 学习率 1e-4、批 32、隐藏层 256、Dropout 0.3、最多 120 轮、正式检查点从第 1 轮开始选，早停从第 41 轮开始计数且耐心值 20。实际训练到第 60 轮停止，正式检查点来自第 28 轮。

复现时须取得服务器上与训练记录一致的图像、标签及完整视野 CLS 特征缓存；本包不包含这些大文件，也不包含外部测试标签。训练集为 9472 点、内部验证集为 1078 点。标准化参数只用训练集拟合；外部测试数据不得用于训练、超参数选择或检查点选择。

在具备原始数据和缓存的服务器上，可运行以下单模型复现入口。两个输出路径必须预先**不存在**；这是一次新训练，不覆盖已接受的原运行：

```powershell
python .\training_reference\reproduce_seed45.py `
  --run-dir 'D:\新实验\run_seed45' `
  --weights-dir 'D:\新实验\weights_seed45' `
  --device cuda
```

如数据或缓存已迁移，可附加 `--feature-caches-root`、`--labels-root`。缓存根参数指向 `feature_caches` 这一层，其下须保留 `phase2_fullfov_hpo_v1/common_identity_v1/` 和对应模型/协议/集合目录。入口只允许将原身份清单位置映射到当前位置，仍逐项核对身份顺序、维度、模型版本与预处理；不改写原缓存元数据。位置映射保存为新运行的 `reproduction_inputs.json`。入口再从头训练种子 45，`raw/train_result.json` 记录新训练的正式检查点和早停结果。不同设备与底层库可能产生数值差异。原批次完整的多阶段调度代码也保留在 `training_reference/runner.py` 和 `training_reference/run.ps1`，用于追溯搜索与冻结过程；本次便携读取修复列表见 `training_reference/README.md`。

## 已接受结果与交付边界

这份权重对应的单种子结果：内部验证集逐患者逐通路等权平均 PCC **0.677195**、整体展平 PCC **0.810774**、z-MSE **0.352305**；外部单患者测试集对应为 **0.568833 / 0.685507 / 0.638409**。两种 PCC 的聚合方式不同。外部结果仅覆盖一名患者，不能推断跨队列稳定性。

同一 UNI2-h 空间配方的种子 45/46/47 汇总如下（均值 ± 样本标准差，ddof=1）；交付种子 45 在评估前指定，未按外部高分择种子。

| 数据集合 | 患者—通路等权 PCC | 整体展平 PCC |
|---|---:|---:|
| 内部验证 | 0.676986 ± 0.000402 | 0.810549 ± 0.000228 |
| 外部 XZY | 0.571073 ± 0.003306 | 0.683748 ± 0.001527 |

内部训练和验证来自相同六名患者的空间分块，点位身份无重叠，但不属于独立患者验证。XZY 是既有外部患者参考，不是新盲测。

完整的 30 通路次序和训练集均值/标准差随包提供。原始图像及物理 patch 覆盖范围没有随包交付；原训练记录中的切片步长已核对为观测网格，物理覆盖范围仍需由数据持有者核实。
