# 任务 3 已接纳全视野密度消融结果

当前状态见[现行实验事实](../06_证据摘录/现行实验事实_20260920.json)；首版登记与历史指标见[首版实验登记摘录](../06_证据摘录/实验登记摘录.json)。

**先看观察。** 主选择器下，稠密训练在内部验证的患者—通路等权 PCC 为 0.676986 ± 0.000402，规则 2×2 隔点为 0.639430 ± 0.000480，随机等量为 0.638148 ± 0.003037；外部 XZY 对应为 0.571073 ± 0.003306、0.555398 ± 0.004882 和 0.541204 ± 0.004402。pooled PCC、zMSE 和 raw MAE也沿同一方向支持稠密臂的整体优势；规则 2×2 的外部主指标高于随机等量。

**结论。** 在固定 full-FOV 输入、图半径和图权重的合同下，训练点数保留至约四分之一后，内部和外部整体预测表现下降。抽稀同时改变训练点数、空间覆盖和训练图连接，因此本页报告固定部署协议下的系统级密度效应。

## 比较合同

PCC（Pearson correlation coefficient，皮尔逊相关系数）分为患者—通路等权 PCC 与 pooled PCC（整体展平 PCC）；SD（sample standard deviation，样本标准差）用于三种子汇总。

- 稠密训练：9,472 个训练点。
- 固定相位规则 2×2 隔点：2,383 个训练点，保留 25.16%。
- 逐患者随机等量：2,383 个训练点，保留 25.16%。
- 内部验证：1,078 点、六名开发患者；外部 XZY：1,039 点、一名既有患者；两者在三臂中保持稠密且完全一致。
- 三臂均从零训练，种子 45/46/47，每次固定 14,800 次更新并关闭早停。
- 主选择器 `equal_updates` 每 296 次更新验证一次，共 50 次机会；患者—通路等权 PCC（主指标）选模，zMSE 打破并列。
- 敏感性选择器 `equal_50_epochs` 沿同一轨迹按前 50 个完整 epoch 选择。
- 外部 XZY 在 checkpoint 冻结后评价；冻结 seed45 参考 checkpoint 用于评估，任务 3 三臂均从零训练，种子 45/46/47 作为正式种子。

## 配对变化与解释

相对稠密臂，规则 2×2 的患者—通路等权 PCC 在内部下降 0.037557、外部下降 0.015675；随机等量内部下降 0.038839、外部下降 0.029869。四组比较的三个种子方向一致。外部规则 2×2 相对随机等量高 0.014194 ± 0.000938。

稠密、规则 2×2、随机等量的训练图平均度分别为 9.712、3.039、2.481，孤立点率分别为 0.085%、1.007%、8.057%。这些图统计与性能结果共同描述固定 full-FOV、图半径和图权重合同下的训练密度效应；样本数、空间覆盖和图连接在本设计中同步变化。
