# 英文专业术语速查表

本表只解释项目材料中常见术语，不替代具体实验的审核结论。

| 英文术语 | 中文对照 | 简明解释 |
|---|---|---|
| Phase 2 | 第二阶段 | 当前项目中主要指空间转录组通路分数预测与模型改进阶段。具体范围以已批准方案为准。 |
| Phase 3 | 第三阶段 | 当前项目中主要指治疗反应预测阶段。具体标签、输入和输出必须以已批准协议为准。 |
| Baseline | 基线 | 用作后续方案比较参照的固定模型、数据和评估结果。 |
| LoRA | 低秩适配 | 冻结大部分模型参数，只训练少量低秩参数的轻量微调方法。 |
| Huber Loss | Huber 损失 | 兼顾平方误差与绝对误差特点、对极端误差相对不敏感的训练损失。 |
| MSE | 均方误差 | 预测值与真实值之差的平方平均值，越低通常表示平均误差越小。 |
| MAE | 平均绝对误差 | 预测值与真实值之差的绝对值平均，越低通常越好。 |
| PCC | Pearson 相关系数 | 衡量预测值与真实值线性变化趋势的一致程度，越接近 1 表示正相关越强。 |
| R² | 决定系数 | 衡量模型相对均值预测基线的解释能力；负值表示还不如直接预测均值。 |
| LOPO | 患者留一验证 | 每次留出一名患者验证，其余患者用于拟合，用于观察跨患者泛化。 |
| Smoke Test | 冒烟测试 | 用较小运行规模验证流程、资源和基本效果门槛，不等同于正式有效性实验。 |
| Internal Validation | 内部验证 | 使用训练体系内部预留数据进行模型选择和门控。 |
| External Test | 外部测试 | 使用未参与模型选择的独立数据评估外部泛化能力。 |
| Checkpoint | 模型检查点 | 训练过程中保存的模型参数状态。 |
| Bootstrap | 自助重采样 | 通过重复重采样估计指标波动范围或置信区间的方法。 |
| Dropout | 随机失活 | 训练时随机屏蔽部分神经元或适配器输出，用于减少模型过度拟合训练数据的风险。 |
| Ridge Regression | 岭回归 | 在拟合误差之外加入参数大小限制的回归方法，用于降低参数过度波动。 |
| Affine Calibration | 仿射校准 | 使用“原预测值乘斜率再加截距”的方式调整预测值尺度。 |
| Lambda | 正则化强度 | Ridge 中控制参数限制强弱的数值；数值越大通常限制越强。 |
| Pooled PCC | 合并计算的 Pearson 相关系数 | 将所有样本和通路值合并后计算一个总体相关系数，不能替代逐患者或逐通路分析。 |
| Early Stopping | 提前停止 | 当内部验证结果连续若干轮没有改善时停止训练，减少过拟合和无效计算。 |
| AUC | ROC 曲线下面积 | 衡量二分类模型区分阳性与阴性的排序能力；约 0.5 接近随机，越接近 1 通常越好，但不能单独说明校准或临床阈值表现。 |
| AUPRC | 精确率-召回率曲线下面积 | 在阳性比例不均衡时补充观察模型对阳性样本的识别质量，必须结合阳性率解释。 |
| CLAM | 聚类约束注意力多实例学习 | 将一张切片视为许多图像小块组成的集合，通过注意力汇总后预测切片标签。 |
| OOF Prediction | 折外预测 | 样本只由训练时未见过该样本所属患者的模型预测，用于汇总交叉验证结果和进行配对统计。 |
| Direct Concatenation | 特征直接拼接 | 不引入复杂交互模块，直接把病理与通路特征连接，作为判断复杂融合是否真正有额外价值的简单对照。 |
| Paired Delta AUC | 配对 AUC 差值 | 在相同 seed 和 fold 中计算两个模型 AUC 的差，减少不同数据划分造成的干扰。 |
