### 权重怎么读

```python
import torch
from pathlib import Path

path = Path(checkpoint)  # 必须是 train_42_spatial/checkpoints/formal_best.pt
payload = torch.load(path, map_location="cpu", weights_only=False)
if payload.get("arm") != "spatial" or payload.get("kind") != "formal":
    raise RuntimeError(f"拒绝非方案(a)正式权重: arm={payload.get('arm')} kind={payload.get('kind')}")
if int(payload.get("seed", -1)) != 42:
    raise RuntimeError("消融只允许种子 42")
if int((payload.get("selection") or {}).get("epoch", -1)) != 30:
    raise RuntimeError("种子 42 正式轮次应为 30")
state = payload["model_state_dict"]
```

model.load_state_dict(state, strict=True)

shared_only = {k: v for k, v in state.items() if k.startswith("shared.")}

### 空间前向合同

`SoftlinkModel.forward` 在 `use_spatial=True` 时需要：

- `center_features`: `[B, 1536]`
- `neighbor_features`: `[B, K, 1536]`
- `neighbor_weights`: `[B, K]`（图里的 a_{ij}，不含自环项进 u）
- `neighbor_mask`: `[B, K]`
- 训练时中心 Dropout 只作用在进 C 的 h_i，**不**作用在邻居编码或 u

邻居必须来自 **当前 split 当前用于该 split 的点表** 上已经建好的图，禁止每个 batch 现场用标签或全库点现拼。身份键与本包一致时用 `(patient_id, slide_id, spot_id)`；图只连同 slide、同 split。

任务 3 顺序必须是：

1. 读完整 `split_manifest`
2. 仅 `split=="train"` 做 `spatial_stride`
3. 用过滤后的 train 点建 `train` 图
4. `internal_val` / `external` 用未过滤点建图

默认 stride 2×2 约留 1/4 训练点。缺匹配随机对照时不要写成「已经证明稠密有用」。
