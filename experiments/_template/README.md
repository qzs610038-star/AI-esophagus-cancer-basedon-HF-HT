# 独立实验包模板

这是零训练演示模板，不是已实现的科研实验。只需 Python 3.10+ 和 Windows PowerShell 5.1+，不需要 Git、仓库根目录或网络。

## 新建实验

1. 在本地将本目录复制为 `experiments/<实验名>/`，不创建工作树。
2. 修改 `package.json`：`experiment_id` 是稳定实验标识（字母、数字、中文、下划线或短横线），`code_version` 是人工递增的代码版本，`entrypoint` 是包内入口，`args` 是额外参数数组。修复后递增版本。
3. 在 `src/` 编写本轮全部实验代码；入口接收 `--config`（实际配置副本）和 `--run-dir`（本次输出目录）。入口按自身位置解析包内代码或小型输入，不能依赖仓库根目录。运行工作目录是本次输出目录。
4. 将必要公共代码、小型配置和划分文件复制到包内，保留来源与许可；在 `code_sources` 中记录原路径、来源说明和复制日期。禁止通过上级目录导入仓库公共代码。
5. 在 `config.json` 中填写外部输入绝对路径、运行参数；在 `requirements.txt` 列出必要依赖及版本。大数据、特征缓存、预训练权重使用服务器已有位置。
6. 实现具体训练后，将 `demo_only` 改为 `false`，更换入口并补充本包的数据合同和最简测试。不能只改标志就声称完成训练。

## Windows 服务器运行

仅使用 PFMval 服务器：代码包放 `D:\AIPatho\qzs\code\<实验名>`，运行产物放 `D:\AIPatho\qzs\runs\<实验名>\<运行编号>`。

`config.json` 默认解释器来自本项目配置：`C:\Users\AIPatho1\pfmval_env\Scripts\python.exe`。路径是配置记录，未经过本次服务器实测；若有变化，由用户修改配置。依赖在训练前按具体实验安装，启动器不自动联网安装。

在上传后的包目录运行：

```powershell
.\run.ps1
```

如系统不允许执行脚本，可仅对本次进程运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

配置可通过 `-Config` 指定；显式传入的 `-PythonInterpreter` 和 `-RunsRoot` 覆盖配置同名值。例如本地零训练验收必须指定本地解释器及项目内输出目录，不使用服务器路径。

## 日志与输出合同

- 每次运行新建目录，目录编号是时间加随机标识，不是哈希。默认从头运行，不自动读取旧 checkpoint。
- `run.json`：实验、版本、起止时间、状态和退出码；`config.json`、`package.json`：实际配置与版本快照。修复时回传这些文件即可定位本地代码。
- `logs/startup.log`：启动位置；`logs/stdout.log`：标准输出；`logs/errors.log`：错误输出和异常；`logs/console.log`：合并日志（标注输出来源，跨流顺序不保证严格时间一致）。
- `raw/`：具体实验的原始训练历史、预测、标签、样本标识和指标重算所需元数据；`checkpoints/`：约定的权重；`metrics.json`：训练、早停和模型选择所需指标。
- 最佳方法、最佳轮次、选择指标名称和值、选用数据划分和 checkpoint 相对路径由训练入口记录；只能使用训练或内部验证数据选择模型。
- 启动器不制造训练结果，也不替训练入口决定科学输出。演示只有 `raw/demo.json` 和空指标，始终明确标注 `demo_only`。
- 报错返回非零退出码。输出目录建立后可记录解释器无法启动等错误；若配置无法解析、输出磁盘不可写，则只能回传终端信息。断电、强杀后可能停留在 `running`，不能据此认定训练仍在运行或成功。

## 修改与回传

失败时回传 `logs/`、`run.json`、配置和版本快照；Agent 在本地同名实验包修复并递增代码版本。训练停止后，由用户替换服务器对应 `code/<实验名>`，保留 `runs/`，再次启动产生新运行目录。

完成后直接复制所需运行文件夹，放回本地 `experiments/<实验名>/runs/<运行编号>/`。原始输出保持不变，派生指标和图表写入本地 `analysis/<运行编号>/`；全部既定指标仍保留，只把可重算部分移到本地。

交付和回传均直接提供文件夹路径，不自动创建压缩包；需要时由用户自行压缩。

本地登记按原始证据建立待登记记录。旧导入器要求 W###、提交编号或哈希时，不伪造这些字段，不为兼容旧格式自动启用哈希；可按项目授权范围直接维护相关实验登记。导入与确认是不同操作，未经明确确认不改为 `accepted`（已确认）。
