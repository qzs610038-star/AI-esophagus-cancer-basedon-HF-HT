## 五、执行smoke小跑

smoke只验证实际服务器读取、构图、反向更新和写出流程。每臂只更新2次，只跑seed45，共3次小运行；结果不是正式科研证据。

先生成唯一批次号和输出路径：

```powershell
$SmokeBatch = 'smoke_' + (Get-Date -Format 'yyyyMMdd_HHmmss')
$SmokeRun = "D:\AIPatho\qzs\runs\$Experiment\$SmokeBatch"
$SmokeWeights = "D:\AIPatho\qzs\weights\$Experiment\$SmokeBatch"
```

启动：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 `
  -Action smoke `
  -Python $Python `
  -OutputDir $SmokeRun `
  -WeightsDir $SmokeWeights `
  -Device cuda
```

smoke成功后检查：

```powershell
$SmokeManifest = Get-Content -LiteralPath (Join-Path $SmokeRun 'batch_manifest.json') -Raw | ConvertFrom-Json
$SmokeManifest | Format-List mode,status,task2_training_called,formal_training_count
Get-ChildItem -LiteralPath (Join-Path $SmokeRun 'runs') -Directory | Select-Object Name
```

预期：

- `mode = smoke`；
- `status = smoke_complete_non_evidence`；
- `task2_training_called = False`；
- `formal_training_count = 0`；
- `runs` 下有 `dense__seed45`、`stride_2x2__seed45`、`random_equal__seed45` 三个目录；
- 每个 `run_summary.json` 的 `fixed_updates = 2`。

smoke失败时不要直接开始formal。保留该smoke运行目录和权重目录，不要清理；根据本卡“失败处理”回传信息。

## 六、执行正式训练

确认smoke通过后，新建正式批次号。不要复用smoke目录，也不要同时启动两个formal。

```powershell
$FormalBatch = 'formal_' + (Get-Date -Format 'yyyyMMdd_HHmmss')
$FormalRun = "D:\AIPatho\qzs\runs\$Experiment\$FormalBatch"
$FormalWeights = "D:\AIPatho\qzs\weights\$Experiment\$FormalBatch"
Write-Host "正式结果目录: $FormalRun"
Write-Host "正式权重目录: $FormalWeights"
```

启动正式训练：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 `
  -Action formal `
  -Python $Python `
  -OutputDir $FormalRun `
  -WeightsDir $FormalWeights `
  -Device cuda
```

运行期间另开一个PowerShell窗口可查看GPU：

```powershell
nvidia-smi
```

正式流程会顺序执行：

1. 冻结seed45基线评估；
2. seed45的稠密、规则2×2、随机等量三臂；
3. seed46的三臂；
4. seed47的三臂；
5. 汇总三种子均值/标准差及相对稠密组配对差值。

每个正式训练固定14,800次更新，不使用早停。不要因为稀疏臂epoch数较多就中止；三臂比较采用相同更新预算。

## 七、判断正式运行是否完整

命令正常返回后，执行：

```powershell
$Batch = Get-Content -LiteralPath (Join-Path $FormalRun 'batch_manifest.json') -Raw | ConvertFrom-Json
$Summary = Get-Content -LiteralPath (Join-Path $FormalRun 'analysis\batch_summary.json') -Raw | ConvertFrom-Json
$Weights = Get-Content -LiteralPath (Join-Path $FormalRun 'model_weights.json') -Raw | ConvertFrom-Json
$Cache = Get-Content -LiteralPath (Join-Path $FormalRun 'feature_caches.json') -Raw | ConvertFrom-Json

$Batch | Format-List mode,status,task2_training_called,frozen_reference_used_for_initialization,external_used_for_selection,formal_training_count
$Summary | Format-List n_training_runs,expected_training_runs,external_used_for_selection
"weight_records=$($Weights.runs.Count)"
$Cache | Format-List status,source_experiment_id,new_feature_cache_created,cache_dir
```

完整运行应满足：

| 检查项 | 预期值 |
|---|---|
| `batch_manifest.mode` | `formal` |
| `batch_manifest.status` | `formal_complete_unregistered` |
| `task2_training_called` | `False` |
| `frozen_reference_used_for_initialization` | `False` |
| `external_used_for_selection` | `False` |
| `formal_training_count` | `9` |
| `analysis/batch_summary.n_training_runs` | `9` |
| `analysis/batch_summary.expected_training_runs` | `9` |
| `model_weights.json`中的运行数 | `9` |
| `feature_caches.status` | `reused_read_only` |
| `new_feature_cache_created` | `False` |

再检查9个运行摘要：

```powershell
$RunSummaries = Get-ChildItem -LiteralPath (Join-Path $FormalRun 'runs') -Filter run_summary.json -File -Recurse
"run_summary_count=$($RunSummaries.Count)"
$RunSummaries | ForEach-Object {
  $Item = Get-Content -LiteralPath $_.FullName -Raw | ConvertFrom-Json
  [pscustomobject]@{
    run = $_.Directory.Name
    status = $Item.status
    updates = $Item.fixed_updates
    equal_updates = $Item.selection_opportunities.equal_updates
    equal_50_epochs = $Item.selection_opportunities.equal_50_epochs
    selectors = $Item.evaluations.PSObject.Properties.Count
  }
} | Format-Table -AutoSize
```

9行都应为：`status=complete`、`updates=14800`、`equal_updates=50`、`equal_50_epochs=50`、`selectors=2`。

重要：`formal_complete_unregistered` 只表示服务器批次完整写出，不表示结果已经人工审查、登记或接受。

## 九、失败处理

### 输入检查失败

- `accepted_common_manifest`或`accepted_feature_cache`失败：核对已验收 `phase2_fullfov_hpo_v1` 缓存位置；禁止换成旧裁剪缓存。
- `frozen_seed45_checkpoint`失败：核对本卡列出的精确checkpoint；它只用于参考评估，但formal要求该参考存在。
- `labels_root`失败：核对活动修复版 `barcode-repair-20260711-d626ad8-v003`；禁止回退旧标签。
- Python或CUDA失败：保存终端完整报错和版本输出，不自行改训练超参数。

### smoke或formal中断

1. 不删除已产生的运行目录和权重目录。
2. 不在同一个 `OutputDir` 或 `WeightsDir` 上重跑；入口会拒绝覆盖。
3. 本包不支持断点续训。修复后使用新的批次号从头运行。
4. 回传或记录以下内容：
   - 终端完整报错；
   - 使用的 `$SmokeRun/$SmokeWeights` 或 `$FormalRun/$FormalWeights`；
   - 已产生的 `batch_manifest.json`、`run_summary.json`、`selection_history.json`；
   - Python、PyTorch、CUDA和GPU版本输出。
5. 不因为部分臂成功就把批次称为完整正式比较。
