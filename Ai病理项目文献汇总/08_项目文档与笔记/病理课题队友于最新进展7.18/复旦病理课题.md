## 2 评估指标

- 均方误差（MSE, Mean Squared Error）：衡量预测值与真实值之间误差的平方平均，能够对较大的预测误差进行更强惩罚，因此对异常值较为敏感。

![图片\.png](图片和附件/图片%2015.png)

- 平均绝对误差（MAE, Mean Absolute Error）：衡量预测值与真实值之间误差的绝对值平均，对异常值更具鲁棒性，能够提供稳定的平均误差估计。

![图片\.png](图片和附件/图片%2011.png)

- 决定系数（R², Coefficient of Determination）：衡量模型对目标变量方差的解释能力，解释了多少相对于“预测均值”基线的方差。

![图片\.png](图片和附件/图片%2013.png)

- Pearson 相关系数（PCC, Pearson Correlation Coefficient）：衡量预测值与真实值之间的线性相关性强度与方向，反映模型是否能够正确捕捉整体变化趋势。

![图片\.png](图片和附件/图片.png)

---

- 均方根误差（RMSE，Root Mean Squared Error）：MSE 开根号，把误差重新带回到和目标变量相同的尺度上。

- 平均绝对百分比误差（MAPE）：平均来看，预测误差占真实值的比例有多大。因为已经进行过zscore，有不少接近0的分数，在MAPE的计算过程中会不合理的放大最终结果，不具备很高参考价值。

![图片\.png](图片和附件/图片%2021.png)

- 对称平均绝对百分比误差（sMAPE）：表示预测值和真实值之间的相对误差百分比，减轻普通 MAPE 对高估/低估不对称的问题，对接近 0 的值仍然可能不稳定，0\~200%。

![图片\.png](图片和附件/图片%2014.png)

mclSTExp 是一个多模态对比学习框架，它用 DenseNet\-121 编码病理图像 patch，用 Transformer 编码 spot 的基因表达\+空间坐标位置，把两种模态对齐到同一个共享嵌入空间。训练时通过对比损失学习配对关系，推理时则让测试 patch 在这个共享空间里检索最相似的训练 spots，并用它们的真实表达加权聚合来预测基因表达。

#### 3\.4\.4 HistoGene

```Python
img_size       = 224          # 输入图像尺寸，与 ImageNet 标准一致
patch_size     = 16           # ViT patch 分割粒度，14×14=196 个 token
model_dim      = 1024         # 嵌入维度，ViT-Large 标准配置
depth          = 8            # Transformer 层数，略低于标准 12 层以控制参数量
heads          = 16           # 多头注意力，每头 64 维子空间
mlp_dim        = 2048         # FFN 隐藏层，嵌入维度的 2 倍
n_pos          = 128          # 坐标嵌入表大小
n_targets      = 30           # 预测通路数
dropout        = 0.3          # Dropout 比率，高于标准 0.1 以适应小数据
epochs         = 150          # 最大训练轮数（配合早停）
batch_size     = 64           # 批大小，兼顾显存和梯度稳定性
learning_rate  = 1e-4         # AdamW 初始学习率
optimizer      = AdamW        # weight_decay=1e-4，解耦正则化
loss           = HuberLoss    # δ=1.0，对异常值鲁棒
```
