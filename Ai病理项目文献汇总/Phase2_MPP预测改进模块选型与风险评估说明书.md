## 一、Phase 2 MPP 预测当前基线与前提约定

### 1. 教师基模固定约定 (Teacher Backbone Policy)
在本项目多轮实验中已验证：**UNI2-h (Nature Medicine 2024)** 作为病理基础模型提取的 $D=1536$ 维表型特征具有最强的表征力。
因此，我们做出如下明确约定：
- **冻结并固定 UNI2-h 为预提取 Teacher Backbone**；
- 避免在更换 Vision Backbone 上浪费计算资源与实验次数预算；
- 后续所有模型设计与网络重构，均输入自 UNI2-h 预提取好的 Tile 特征向量，专注于下述三大核心模块的架构创新。

### 2. 当前遇到的四大核心痛点
1. **独立 Tile 预测造成邻域断裂**：目前简单 MLP 独立拟合单个 Tile，忽略了切片物理空间中 100μm 邻域 Spot 之间的生物学连续性与细胞间通信。
2. **高维表达预测噪声大、raw $R^2$ 偏低或为负**：直接拟合上千维单基因表达，受高维噪声与测序 Drop-out 影响严重，欠缺物理先验约束，导致跨样本泛化差。
3. **PCC 指标遭遇瓶颈**：在交叉切片验证中，PCC 维持在 0.60 ~ 0.65 之间难以向上突破。
4. **纯黑盒模型缺乏临床可解释性**：医生无法直观理解模型预测高表达的病理形态依据。

## 二、模块一：结合 ConvSSM/MambaIR 增强的“空间邻域坐标 Transformer/SSM 聚合模块”

### 1. 建议原因
文献 *Hist2ST* (*Nature Machine Intelligence 2023*) 验证了引入 2D 物理相对位置编码和 Transformer 邻域自注意力机制，能够显式捕捉切片上 100μm 邻域 Spot 之间的空间依赖。结合 `"98个即插即用模块-阿飞"` 中的 **ConvSSM (卷积状态空间模型)** 与 **MambaIR**，可以进一步利用 SSM 模型的线性计算复杂度 $O(N)$ 代替传统 Self-Attention 的 $O(N^2)$，兼具全局感受野与计算高效性。

### 2. 建议具体内容
- **输入特征**: UNI2-h 预提取的单 Tile 特征 $\mathbf{f}_i \in \mathbb{R}^{1536}$，结合其 2D 相对物理坐标 $(x_i, y_i)$。
- **即插即用算子融合**:
  - **2D 相对位置编码 (Relative Position Embedding)**。
  - **ConvSSM / MambaIR 状态空间块 (RSSB)**: 利用局部卷积增强邻域像素/Spot 建模，同时借助 SSM 的参数化策略建模长距离空间时空依赖。
  - **AKConv (任意形状采样卷积)**: 针对 Visium/Visium HD 边缘非规则排列的 Spot 区域，采用可变形状卷积核提取边界 Spot 空间特征。
- **Loss 函数**: 主预测 Loss (MSE/PCC) + 空间邻域拉普拉斯光滑正则项 $\mathcal{L}_{smooth}$。

### 3. 解决什么当前痛点
- 彻底解决孤立 Tile MLP 预测值在空间上跳变剧烈、离散噪声大的痛点。
- 打破 PCC 维持在 0.60~0.65 的瓶颈，预期可提升 PCC **0.03 ~ 0.06**。

### 4. 对论文/课题创新性的贡献
- 在论文中可作为 **"SSM-Enhanced Spatial Context Neighborhood Aggregator (SSM 增强的空间上下文邻域聚合器)"**。不仅打破了传统独立 Tile 回归的范式，更是将 2024-2026 前沿的 **Mamba/SSM** 架构引入空间转录组病理映射，创新性极强。

### 5. 潜在风险点与应对预案
- **潜在风险点**: Mamba/SSM 算子需依靠 2D 扫描顺序，切片边界悬空 Spot 可能引入填充伪影。
- **应对预案**: 采用 **AKConv 不规则采样** 补齐边界，或退化为 **3×3 局部滑动窗口 Transformer** 作为备用 Fallback 方案。

## 三、模块二：结合 MambaTab 增强的“通路物理约束 Multi-Task 损失模块”

### 1. 建议原因
文献 *PEaRL* (*WACV 2026*) 提出了通过引入 MSigDB/KEGG 先验知识矩阵，将高维基因表达映射到低维通路活性（Pathway），并增加辅助 Multi-task Loss。结合 `"98个即插即用模块-阿飞"` 中的 **MambaTab (针对表格/高维特征的 SSM 架构)**，能够以极少的参数量实现增量特征学习与长依赖关系建模，极其适合处理基因/通路这类高维表格型连续变量。

### 2. 建议具体内容
- **生物学先验准备**: 提取食管癌相关的 50 个核心 MSigDB Hallmarks / KEGG 通路先验矩阵 $W_{pathway} \in \mathbb{R}^{G \times K}$ ($G$ 基因数，$K$ 通路数)。
- **双头即插即用算子网络**:
  - **主分支 (Gene Head)**: 预测高维单基因表达 $\mathbf{\hat{y}}_{gene}$。
  - **辅助分支 (MambaTab Pathway Head)**: 利用 **MambaTab** 模块建模 50 条低维通路活性得分与上千维基因表达之间的深层非线性对应关系 $\mathbf{\hat{y}}_{pathway}$。
- **联合 Loss 设计**:
  $$\mathcal{L}_{total} = \mathcal{L}_{MSE}(\mathbf{\hat{y}}_{gene}, \mathbf{y}_{gene}) + \lambda \cdot \mathcal{L}_{MSE}(\mathbf{\hat{y}}_{pathway}, \mathbf{y}_{pathway})$$

### 3. 解决什么当前痛点
- 解决单基因预测维数高、噪声大、跨样本泛化差、raw $R^2$ 偏低或为负的严重痛点。
- 引导 UNI2-h 特征向食管癌核心通路（p53 突变、EMT 转换、Wnt 信号通路、免疫微环境浸润）收敛。

### 4. 对论文/课题创新性的贡献
- 在论文中可作为 **"Prior Biological Pathway-Guided Multi-Task Constraint Network with MambaTab"**。在方法论上实现了“病理基础模型表型 + Mamba表格模型 + 分子生物学先验”的三者深度融合。

### 5. 潜在风险点与应对预案
- **潜在风险点**: 若定义的通用 MSigDB 通路包含过多非特异性基因，可能会引入无关噪声先验。
- **应对预案**: 仅保留与食管癌 (ESCC/EAC) 密切相关的 30~50 条核心通路，并采用**动态 Loss 权重 $\lambda$ 随 Epoch 逐渐衰减**策略，避免强监管压制主 task。

## 四、模块三：结合精细 Attention 增强的“EGN-v2 原型匹配与临床可解释引导模块”

### 1. 建议原因
文献与源码校验表明：*EGN-v2* (*PR 2026 / WACV 2023*, 本地包含 `09_EGN-v2补充材料/EGN-v2/` 源码) 建立了全局 Exemplar 库，利用交叉注意力计算当前图像与原型的相似度权重。结合 `"98个即插即用模块-阿飞"` 中的 **精细通道/空间注意力块 (如 CBAM/ECA)**，能提高 UNI2-h 特征在识别细微病理形态（如细胞核异型性、间质胶原纤维）上的匹配灵敏度。

### 2. 建议具体内容
- **原型库构建**: 从训练集中提取 16~32 个涵盖食管癌主要病理形态（如癌巢中心、间质高浸润区、正常黏膜等）的 Exemplar 特征对 $(e_{img}^k, e_{exp}^k)$。
- **注意力增效匹配层**:
  - 对 UNI2-h 输入特征施加 **ECA/CBAM 注意力** 进行微观通道筛选。
  - 计算 Query Tile 特征与 Exemplar 库的余弦相似度权重向量，Softmax 后对 Exemplar 表达特征加权融合，指导最终预测。
- **临床可解释性输出**: 输出具象化的原型匹配分值（如“本区域与标准食管癌免疫高表达范例相似度为 88%”）。

### 3. 解决什么当前痛点
- 解决少量切片训练场景下的模型过拟合风险。
- 彻底解决病理 AI“黑盒不可解释”的痛点，给医生提供直观的相似度比对视图。

### 4. 对论文/课题创新性的贡献
- 在论文中可作为 **"Interpretable Exemplar-Guided Attention Module (可解释原型引导注意力模块)"**。本地已有现成代码，移植与对比成本最低。

### 5. 潜在风险点与应对预案
- **潜在风险点**: 如果初始 Exemplar 原型库挑选不均匀，可能拉低罕见表型切片的预测上限。
- **应对预案**: 采用无监督 K-Means 算法在表型空间中均匀抽样 Exemplar，并允许 Exemplar Dictionary 在训练阶段通过梯度反向传播实现**动态可学习更新**。

| 评估维度 | 模块一：ConvSSM/MambaIR 邻域空间聚合 | 模块二：MambaTab 通路 Multi-Task 约束 | 模块三：EGN-v2 精细 Attention 原型引导 |
|---|---|---|---|
| **推荐优先级** | **P0 (建议首选尝试)** | **P0 (建议首选尝试)** | **P1 (第二阶段尝试)** |
| **前提约定** | 保持 UNI2-h 教师特征提取固定 | 保持 UNI2-h 教师特征提取固定 | 保持 UNI2-h 教师特征提取固定 |
| **主要目标** | 提高 PCC，平滑邻域预测跳变 | 提高 raw $R^2$，引入生物学物理约束 | 提高少样本泛化，增强临床可解释性 |
| **引入即插即用算子** | **ConvSSM / MambaIR / AKConv** | **MambaTab / 表格注意力** | **CBAM / ECA 通道-空间注意力** |

### 2. 建议落地实施路线图
1. **第一阶段 (P0)**：在固定 UNI2-h 特征提取的前提下，优先引入 **模块一 (ConvSSM/Hist2ST 局部邻域空间聚合)** 与 **模块二 (PEaRL/MambaTab 通路 Multi-Task 约束)**。双管齐下攻克 PCC 瓶颈与 $R^2$ 负值痛点。
2. **第二阶段 (P1)**：基线性能突破后，引入 **模块三 (EGN-v2 原型引导)**，生成可视化结果图表，为后续论文撰写提供高质量的临床可解释性视图。
