## 0. 讨论问题与结论演进

原讨论分为两个连续问题：

1. 为什么当前 Phase 3 的 H&E 与 MPP2 通路特征直接拼接或复杂融合难以稳定提升？《SpaMIL_vs_Phase3》指南的判断是否准确，相关论文能否借鉴？
2. 如果直接照搬 SpaMIL、BLEEP 或 SurvPath 创新性不足，项目真正独有的数据优势是什么，如何把这些优势组合成更原创的方法？

讨论最终形成三层结论：

- **第一层：当前问题不是“融合无法实现”，而是虚拟通路不是独立第二模态。** MPP2 通路由同一套 H&E 特征推导，信息高度冗余且误差相关。
- **第二层：项目真正优势不是基础模型或切片数量，而是双队列互补、局部空间通路、多切片患者结构和 pCR/MPR 嵌套终点。**
- **第三层：创新不应来自堆叠现成模块，而应来自完整的问题设定。** 即从 Phase 2 的真实空间转录组学习通路形态知识，再以不确定性控制、可关闭的残差形式迁移到没有真实组学但有治疗响应终点的 Phase 3。

## 1. 当前 Phase 3 到底在融合什么

### 1.1 两个输入的真实关系

当前 Phase 3 输入可写为：

\[
X_{H\&E}+\hat Z_{MPP2},\qquad \hat Z_{MPP2}=f_{MPP2}(X_{H\&E})
\]

- `X_H&E`：UNI2-h 提取的 1536 维 patch 病理特征；
- `Z_MPP2`：MPP2 根据同一病理特征预测的 30 维通路分数；
- `f_MPP2`：冻结的 MPP2 映射，结构上是 `1536 → 1024 → 30`。

传统病理—组学融合通常是：

\[
X_{H\&E}+Z_{真实RNA}
\]

两者由染色形态与测序分别产生，可能包含互补信息。本项目目前则更接近：

> 高维病理表示 + 对同一病理表示的一次带噪、带生物学先验的低维重编码。

在理想确定性条件下：

\[
I(Y;\hat Z_{MPP2}\mid X_{H\&E})=0
\]

这表示当通路完全由病理特征决定时，把通路再拼回病理不会凭空增加关于标签 `Y` 的新信息。但有限数据、有限模型容量下，30 维通路仍可能作为：

- 生物学先验；
- 低维正则化；
- 更容易学习的中间表征；
- 辅助任务；
- 来自真实空间转录组的训练期特权知识。

因此准确结论不是“融合必然无效”，而是：

> 虚拟通路很难成为独立第二模态，但可能成为有用的正则化表示或知识载体；必须证明它带来的增量超过普通降维、额外参数和调参预算。

### 1.2 “raw MPP2”不能理解成真实 RNA raw count

项目里的 MPP2 输出是模型生成的 30 维通路预测。即使文件名或讨论中使用 `raw`，也只能表示“未经过后续 Ridge 校准或其他后处理的模型直接输出”，不能理解为测序原始表达。

历史目录、z-score 表述和转换流程必须由输入 manifest、checkpoint、通路顺序和哈希证明。未闭环前不得把 legacy z-score 兼容输入写成真实 raw MPP2 生物量纲。

## 2. 为什么直接拼接容易出现不提升或负提升

### 2.1 信息冗余与共线性

由于 `Z_MPP2` 是 `X_H&E` 的函数，拼接后模型同时看到原始形态信息及其低维投影。低维投影可能强调有用模式，也可能只是重复已有信息，造成共线性和不稳定权重。

### 2.2 MPP2 误差是与图像相关的误差

MPP2 输出可写为：

\[
\hat Z=Z+\epsilon(X)
\]

其中误差 `epsilon(X)` 本身依赖图像。某种染色、组织结构或患者风格可能：

```text
同一图像偏差
   ├─ 直接进入病理分支
   └─ 经 MPP2 转换后再次以错误通路值进入通路分支
```

因此这不是可由第二模态抵消的独立噪声，而可能是相关误差的重复输入。

### 2.3 问题不能简化成“30 维被 1536 维淹没”

维度比例低不代表通路必然不起作用。线性层完全可以给少数通路更高权重。更合理的风险是：

1. 两模态尺度和方差不匹配；
2. 30 维与 1536 维高度共线；
3. 独立患者数少，监督信号不足以稳定识别有用通路；
4. 通路误差没有 patch/通路级置信度；
5. 病理主干已能学习相似形态，缺乏使用通路分支的必要性；
6. 缺少随机 30D、PCA 30D 和等参数对照，无法证明通路语义重要。

### 2.4 当前直接拼接缺少的保护机制

普通 `concat` 通常没有同时提供：

- 每模态的训练折内标准化；
- pathway/modality dropout；
- 通路可靠性权重；
- 零初始化残差；
- 去相关或冗余控制；
- 通路打乱、随机 30D、PCA 30D 等反事实对照。

所以直接拼接必须保留为基线，但不适合作为主要创新方向。

## 3. 为什么当前复杂融合也存在结构风险

### 3.1 Cross-Attention 的真正问题不是 30 与 1536 维不能点积

历史指南曾把问题归因于“30 维 pathway query 与 1536 维 pathology key/value 维度不匹配”。现有参考实现会先把两边投影到共同隐藏维度，因此这不是准确的代码事实。

真正风险包括：

- 30 维被投影到更高维并不会创造新的分子信息；
- 若在整张切片跨所有 patch 做注意力，会破坏已知的同坐标一一对应；
- 没有空间位置编码时，模型不知道 patch 间真实距离；
- 全局 patch-to-patch 交互成本约为 `O(N²)`，容易过拟合患者/切片风格；
- 当前患者数不足以稳健支撑大容量跨模态注意力。

更合理的交互范围应是：

- 同一 patch 的图像 token 与其 30 个 pathway token；或
- 全切片聚合后的 pathology token 与 30 个切片级 pathway token。

### 3.2 Adaptive Fusion 的模态塌缩

普通 adaptive gate 可写为：

\[
h=w_{path}h_{path}+w_{gene}h_{gene}
\]

如果没有 gate entropy、modality dropout、分支辅助监督或最低利用率约束，模型可能：

1. 长期关闭噪声较高的 pathway branch，退化为 H&E；
2. 在某些折偶然过度依赖少数通路，跨折性能波动；
3. 强制两分支竞争，而不是允许通路只提供安全的增量。

### 3.3 有效样本量更接近患者数

Phase 3 有多张切片，但同一患者切片共享标签、染色和组织来源。独立统计单位主要仍是患者。复杂融合模型可能记住：

- 患者特异染色；
- 扫描或制片批次；
- 连续切片共同纹理；
- 患者特异的 MPP2 偏差；
- 每名患者的切片数量。

因此不能把数百张切片等价为数百名独立患者。

## 4. 对原《SpaMIL_vs_Phase3》指南结论的逐项判断

| 原指南结论 | 讨论判断 | 修正后的使用方式 |
|---|---|---|
| 虚拟通路来自同一 H&E，独立增量有限 | 基本正确，是最重要的核心判断 | 把通路解释成正则化/先验，而非真实第二模态 |
| MPP2 误差会传播到 Phase 3 | 正确，但应强调误差相关且可能异方差 | 使用 patch/通路级不确定性控制 |
| 30 维占比低，所以必然被淹没 | 过度简化 | 检查尺度、梯度、门控和等参数对照 |
| Cross-Attention 存在 30/1536 维点积不匹配 | 与代码实现不符 | 重点审查全局跨 patch 混合和容量 |
| 分子信息更适合作为 teacher/loss | 是合理方向，但不是普遍定理 | teacher 必须来源于真实 SpT，而非仅蒸馏虚拟 MPP2 |
| 当前融合已证明没有提升 | 证据不足 | 需要同 seed/fold 的单模态、concat 和融合配对结果 |
| 直接拼接应停止 | 不应作为主创新，但必须保留为基线 | 作为 `ΔAUC_fusion-vs-concat` 参照 |
| 用 PCC 阈值筛通路 | 阈值武断，可能泄漏 | 改成训练折/Phase 2 LOPO 的不确定性估计 |
| SpaMIL 的高 C-index 来自 H&E-only student | 原指南表述曾混淆 teacher 与 student | 只借鉴真实 SpT 表征迁移思想 |
| THuNDER 可直接作为实施依据 | 原讨论中无法可靠核验 | 没有 DOI/官方代码前不纳入正式路线 |

总体评价：

- 问题意识：可靠；
- 对现有代码的解释：不完全准确；
- 对论文性能和设定的部分描述：需要纠偏；
- 对真实 SpT 知识迁移的方向启发：有价值；
- 不能直接作为模型改造设计书。

## 5. 相关论文可以借鉴什么、不能照搬什么

### 5.1 SpaMIL

可借鉴：

- 真实空间转录组分支作为知识来源；
- 病理学生分支学习分子表征；
- 推理阶段只使用 H&E。

不能照搬：

- SpaMIL 的分子、图像和结局来自匹配队列；本项目 Phase 2 没有大规模 pCR/MPR，Phase 3 没有真实 SpT；
- 本项目只能借鉴“真实 SpT 表征迁移”，不能声称复现“结局监督的 SpT teacher”。

### 5.2 BLEEP

可借鉴：

- 在 Phase 2 真实配对的 H&E patch 与真实空间表达/通路上进行 patient-safe 对比学习；
- 学习联合形态—通路空间或形态原型。

不能照搬：

- 不能把 `X` 和由同一 `X` 生成的 `f(X)` 当作两个真实模态；
- 同一患者空间相邻 spot 不应全部作为负样本；
- 测试患者不能进入 gallery。

### 5.3 SurvPath

可借鉴：

- pathway identity embedding；
- 每条通路独立 token 化；
- 通路级解释，而非把 30 个标量视作匿名整体向量。

不能照搬：

- SurvPath 推理时使用真实 transcriptomics；Phase 3 没有真实 RNA；
- 不宜在小样本上使用大型密集跨模态 Transformer；
- 当前更适合共享低容量 pathway encoder 或局部交互。

### 5.4 PathGen、STORM 与不确定性工作

这些工作已经覆盖了合成转录组、共注意力、对比学习、不确定性或大规模 histology-ST 预训练中的若干单项。因此以下模块单独出现已难构成强创新：

- 普通图像—通路对比学习；
- pathway token；
- H&E-only 推理；
- 普通 uncertainty weighting；
- 普通知识蒸馏；
- 合成组学后直接分类。

本项目必须把创新建立在自身数据结构及完整证据链上，而不是某一个通用模块上。

## 6. 项目优势逐项核验

| 被提出的优势 | 是否成立 | 准确边界 |
|---|---|---|
| 329 张切片、78 名患者 | 部分成立 | 切片丰富利于异质性建模，但独立统计单位主要仍是患者 |
| pCR/MPR 是硬终点 | 基本成立 | 必须先确认输入均为治疗前材料、治疗方案及病理标准一致 |
| UNI2-h 1536 维先进 | 工程优势 | 降低特征提取风险，但不能作为核心创新 |
| 30 条医生筛选通路有解释性 | 有条件成立 | 通路需在 Phase 3 标签分析前锁定，并超过 generic 30D 对照 |
| MPP1–5 均可作为优势 | 不成立 | 当前 Phase 3 主线只能使用被允许的 repaired frozen MPP2 路径 |
| 虚拟通路可作为跨中心稳定锚点 | 尚未证明 | 跨患者绝对尺度和逐通路可靠性仍需验证 |
| 每名患者多张切片 | 真实且被低估 | 应拆解患者共同响应与切片异质性，而非扩大样本数 |
| 同时有 pCR 和 MPR | 真实且重要 | 两者嵌套，可设计单调联合响应模型 |
| Phase 2 有真实空间转录组 | 核心优势 | 可为 Phase 3 提供真实分子知识，但必须跨患者、跨队列验证 |

### 6.1 最关键临床前提

“治疗响应预测”成立至少需要：

- 输入切片来自治疗前；
- pCR/MPR 来自治疗后手术病理；
- 治疗方案相对一致或已结构化记录；
- 病理终点按统一标准审核。

若不能证明输入均为治疗前标本，论文不得写成“治疗前临床响应预测已验证”；任务可能更接近治疗后病理反应评估。

## 7. 四个可以组合成原创方法的数据优势

### 7.1 分子真值队列与治疗响应队列彼此分离

```text
Phase 2：H&E + 真实 SpT + 坐标，但没有大规模 pCR/MPR
Phase 3：H&E + pCR/MPR，但没有真实 SpT
```

这形成了一个区别于普通匹配多模态学习的问题：

> Cross-cohort privileged spatial biology transfer，跨队列特权空间生物学迁移。

### 7.2 30 条通路是局部空间功能概念

这些通路随 patch/spot 空间位置变化，不是一个患者级 bulk RNA 向量。可以研究：

- 哪些区域呈现免疫、缺氧、代谢等通路状态；
- 不同状态如何组成空间生态位；
- 哪些生态位与 pCR/MPR 相关；
- 同一患者多张切片中是否稳定出现。

### 7.3 多切片可以分解患者共同信号与异质性

对患者 `j` 的第 `m` 张切片：

\[
h_{j,m}=c_j+d_{j,m}
\]

- `c_j`：患者共同响应表示；
- `d_jm`：切片特异的采样和组织异质性残差。

这比把所有切片当独立样本更符合数据生成过程。

### 7.4 pCR 与 MPR 构成临床层级

独立训练两个二分类器可能产生 `P(pCR) > P(MPR)` 的逻辑矛盾。可以改为：

\[
P(MPR)=\sigma(a)
\]

\[
P(pCR)=P(MPR)\cdot\sigma(b)
\]

从结构上保证：

\[
P(pCR)\le P(MPR)
\]

## 8. 推荐原创主方案：CUSP-MIL

暂定名：

> **CUSP-MIL：Cross-cohort Uncertainty-aware Spatial Pathway Multiple Instance Learning**  
> 跨队列、不确定性感知、空间通路引导的层级多实例学习。

名称不是核心，核心是以下环节构成完整闭环。

### 8.1 阶段一：从 Phase 2 学习真实 SpT 支持的通路形态原型

对每条通路 `k`：

1. 在每位 Phase 2 患者内部，选出真实通路分数较高和较低的 patch；
2. 每位患者先分别计算高/低代表向量，避免 patch 数多的患者支配；
3. 再跨患者平衡聚合，得到：

\[
p_k^+,\quad p_k^-
\]

对任意 patch 特征 `h_i` 计算：

\[
s_{ik}=\cos(h_i,p_k^+)-\cos(h_i,p_k^-)
\]

`s_ik` 表示该 patch 在形态上更接近真实 SpT 验证过的通路高活性还是低活性区域。

它与 MPP2 回归值的差异是：

- MPP2 输出 `mu_ik` 是回归网络产生的连续预测；
- prototype activation `s_ik` 是由真实 SpT 高/低区域定义的形态证据；
- 两者不一致时可形成自然的不确定性信号。

### 8.2 阶段二：构建四视图通路证据

每个 patch、每条通路形成：

\[
c_{ik}=[\mu_{ik},r_{ik},s_{ik},u_{ik}]
\]

- `mu_ik`：MPP2 absolute 预测；
- `r_ik`：切片内或患者内 percentile/rank；
- `s_ik`：真实 SpT 原型相似度；
- `u_ik`：不确定性。

absolute 与 ordinal 的职责不同：

```text
absolute：保留跨患者和跨切片绝对水平
ordinal：保留切片/患者内部热点与冷点，减弱尺度漂移
```

只用 absolute 容易受尺度偏移影响；只用 ordinal 又可能丢失真实的患者间差异，因此建议保留双视图。

不确定性不应由固定 PCC 阈值替代，可组合：

- Phase 2 leave-one-patient-out（LOPO，留一患者）预测误差；
- 小型模型集成方差；
- MPP2 absolute 与原型证据的分歧；
- 每条通路的训练患者稳定性。

### 8.3 阶段三：零初始化、置信度控制的通路残差注入

令原始病理表示为 `h_i`，通路残差为：

\[
r_i=\sum_{k=1}^{30}g_{ik}Wt_{ik}
\]

- `t_ik`：包含通路数值、身份、原型和不确定性的轻量 token；
- `g_ik`：该 patch、该通路的置信度 gate；
- `W`：共享低容量映射。

gate 可写为：

\[
g_{ik}=\sigma(q(h_i,t_{ik})-\lambda u_{ik})
\]

最终表示：

\[
h'_i=h_i+\epsilon r_i,\qquad \epsilon(0)=0
\]

其中 `epsilon` 或残差最后一层初始化为 0，使模型初始严格等价于 H&E：

\[
h'_i=h_i
\]

只有训练证据支持时，通路分支才逐步开启。这比强制两模态竞争的 adaptive fusion 更保守。

30 条通路不需要各自配置大型 MLP。可使用：

```text
数值/原型/不确定性 + pathway identity embedding
                    ↓
              共享小型编码器
```

若后续有可靠通路基因集，可按基因集合重叠构建固定图：

\[
A_{kl}=\frac{|G_k\cap G_l|}{|G_k\cup G_l|}
\]

但 pathway graph 应放在 Lite 版之后，不能替代基础对照。

### 8.4 阶段四：patch—slide—patient 三级层级 MIL

第一层，保持同一 MIL/CLAM 主干：

\[
\{h'_i\}_{i\in slide}\rightarrow z_{slide}
\]

第二层，同一患者多张切片经轻量 set-attention 聚合：

\[
\{z_{j,1},z_{j,2},...,z_{j,m}\}\rightarrow z_j^{patient}
\]

切片级损失按患者切片数倒数加权：

\[
w_{j,m}=\frac{1}{n_j}
\]

避免有 11 张切片的患者比有 2 张切片的患者对训练贡献高数倍。

第三层，用单调联合头同时建模 MPR 与 pCR。切片级仍保留为当前主评估口径，患者级为敏感性分析，除非用户另行修改协议。

## 9. 与现有论文和 W004 的实质差异

### 9.1 与相关工作的差异

| 方法 | 主要设定 | CUSP-MIL 的差异 |
|---|---|---|
| SpaMIL | 匹配患者内的 SpT、H&E 与结局，蒸馏患者级表示 | Phase 2/3 为不同队列；迁移的是真实 SpT 支持的局部通路概念 |

## 10. 必须设置的生物学反事实与公平对照

审稿人最关键的问题会是：

> 这 30 维通路是否只是对 1536 维病理特征做了一次普通降维？

建议完整对照如下：

| 对照 | 目的 |
|---|---|
| H&E-only | 病理基础性能 |
| pathway-only | 通路单模态可预测性 |
| H&E + MPP2 direct-concat | 最低复杂度融合基线 |
| H&E + standardized concat | 排除量纲问题 |
| H&E + PCA 30D | 检验任意线性低维压缩 |
| H&E + trainable generic 30D | 检验非生物学低维适配器 |
| H&E + covariance-matched random 30D | 检验额外参数和分布效应 |
| pathway identity permutation | 检验通路身份/名称是否重要 |
| patch–pathway pairing shuffle | 检验同坐标配对是否重要 |
| CUSP 去掉 uncertainty | 不确定性消融 |
| CUSP 去掉 prototype | 真实 SpT 原型消融 |
| CUSP 去掉 ordinal | 相对活性视图消融 |
| CUSP 去掉 patient hierarchy | 多切片患者层级消融 |
| 等参数零初始化无语义 Adapter | 区分机制与容量增益 |

三个核心差值：

\[
\Delta AUC_{synergy}=AUC_{fusion}-\max(AUC_{H\&E},AUC_{pathway})
\]

\[
\Delta AUC_{fusion-vs-concat}=AUC_{fusion}-AUC_{direct\ concat}
\]

\[
\Delta AUC_{bio}=AUC_{CUSP}-AUC_{generic\ 30D}
\]

只有 `Delta AUC_bio` 在相同 seed/fold 和患者聚类统计下保持正向，才可主张增益来自空间通路生物学，而不仅是低维正则化或额外参数。

## 11. 最小可行版与完整创新版

### 11.1 CUSP-Lite

尽量复用现有缓存，不重新训练大型基础模型：

1. 从 Phase 2 构建患者平衡的 30 条通路 high/low prototype；
2. 计算 Phase 3 patch 的 prototype activation；
3. 组合 absolute、slice ordinal、prototype 和轻量 uncertainty；
4. 用零初始化残差接入现有 MIL 主干；
5. 使用 pCR/MPR 单调联合输出；
6. 使用患者平衡的切片损失；
7. 完成 generic 30D、identity 和空间配对反事实。

这一版本不需要在线微调 UNI2-h，模型参数较少，已经比普通拼接形成更清楚的科学问题。

### 11.2 完整 CUSP-MIL

只有 Lite 版出现稳定证据后再增加：

- Phase 2 LOPO 模型集成不确定性；
- pathway graph；
- patch—slide—patient 三级模型；
- 患者共同成分与切片异质性残差分解；
- 空间邻域 prototype；
- pathway intervention heatmap；
- conformal risk–coverage；
- 外部 ESCC 队列验证。

不建议第一轮就加入 GraphSAGE/GAT、OT、全局 Cross-Attention、大型 Transformer 或 end-to-end UNI2-h 微调。

## 12. 从完整方案中筛出的两个低成本优先点

### 12.1 P1：absolute + ordinal 双视图零初始化残差

\[
h'_i=h^{H\&E}_i+\epsilon g([z_i^{abs},z_i^{ord}]),\qquad \epsilon(0)=0
\]

- `epsilon`：可学习残差强度，初始化为 0；
- `g`：低容量通路编码器；
- 初始模型等价于病理主干，通路只提供可关闭增量。

推荐理由：

- W004 A002 已出现 pCR `+0.0232` 正向信号；
- 保留 ordinal 的抗尺度漂移能力，同时避免完全丢弃 absolute；
- W004 已有相关变换和零初始化残差接口；
- 比全局 cross-attention 风险低、归因清楚。

最小比较：H&E-only、A001、A002、direct-concat、双视图残差、等参数无语义残差。

论文定位：相对活性补偿绝对尺度漂移的保守双视图融合。

### 12.2 P2：pCR/MPR 单调联合头 + 多切片敏感性分析

\[
P(MPR)=\sigma(a),\qquad P(pCR)=P(MPR)\sigma(b)
\]

- 不需要重新提取特征；
- 利用 pCR 嵌套于 MPR 的临床结构；
- 避免两个独立模型产生逻辑冲突；
- 可与患者多切片轻量聚合共同评估。

最小比较：两个独立二分类头 vs 单调联合头。切片级仍是主口径，患者级仅作敏感性分析。

论文定位：把病理—通路融合与临床终点结构约束组合起来，提高方法完整性。

### 12.3 为什么不把真实 SpT 原型列为最低成本第一批

真实 SpT 原型的创新性更高，但还需要：

- Phase 2 患者平衡与 LOPO 稳定性；
- 原始通路顺序、坐标和形态特征闭环；
- identity、generic 30D 和空间配对反事实；
- 跨队列尺度与批次检查。

因此建议 P1/P2 作为近期低成本组会候选，真实 SpT 原型作为下一阶段重点创新线。

## 14. 论文主张建议

不建议的主张：

> 我们提出了一个新的多模态融合网络。

更有竞争力的主张：

> 我们提出一种跨队列空间生物学知识迁移框架：从独立空间转录组队列学习真实通路形态概念，在没有真实组学的 ESCC 治疗响应队列中，将其作为带不确定性的可解释残差注入病理 MIL，并结合多切片患者层级和 pCR/MPR 单调联合学习预测治疗响应。

潜在三项核心贡献：

1. **跨队列特权空间生物学迁移**：解决 ST 队列与治疗响应队列不重合的问题；
2. **真实 SpT 支持的不确定性通路原型**：区分虚拟回归值与真实空间生物学概念；
3. **多切片层级治疗响应学习**：同时利用切片异质性、患者共同信号和 pCR/MPR 嵌套关系。

若 CUSP 只优于 concat、不优于 generic 30D，只能写成“低维正则化或优化形式可能有效”，不能主张已证明空间生物学增量。

## 15. 可行性、主要风险与止损点

### 15.1 可行性较高

- 现有 UNI2-h 缓存可复用；
- Phase 2 有真实通路标签和空间坐标；
- Phase 3 有 patch、slide、patient 映射；
- pCR/MPR 嵌套关系明确；
- 原型库与残差 gate 都是低参数模块；
- 不需要第一轮重训大型基础模型。

### 15.2 最大风险

1. **Phase 2 独立患者少**：大量 patch 不能替代患者数，原型必须患者平衡并做 LOPO。
2. **Phase 3 外部验证缺失**：内部交叉验证不能支持临床泛化主张。
3. **治疗前后时间点未闭环**：可能改变研究任务定义，是发表前最大事实门。
4. **当前 repeated holdout 有患者重叠**：W004 AUC 不能称为患者独立泛化。
5. **MPP2 输入仍为 legacy compatibility 路径**：不得声称 raw MPP2 已验证。
6. **复杂模型归因混杂**：若同时更换特征、融合、MIL 和终点头，将无法判断增益来源。

### 15.3 暂不优先

- 大型全局 cross-attention；
- GraphSAGE/GAT、TopoSSM、二维频域或复杂 OT；
- 只蒸馏虚拟 MPP2 的 self-consistency teacher；
- end-to-end UNI2-h 微调；
- 没有 generic 30D 和等参数对照的复杂融合。

## 16. 统一评价与证据要求

所有获批实验应满足：

- fold 按患者分组；
- 主报告切片级 AUC，并给患者级敏感性分析；
- bootstrap 以患者为聚类/重采样单位；
- 四 seeds × 五 folds 不作为 20 个完全独立样本做普通 t 检验；
- 保存逐切片 OOF、`case_id`、`slide_id`、seed、fold、标签和预测；
- 复杂模型与基线使用相同 early stopping、调参次数和随机种子；
- 报告参数量、训练资源、gate 分布和模态消融；
- 不按测试 AUC 排除患者或 fold；
- 结果经验证、import 后才可能晋级；代码存在或测试通过不是科学证据。

建议同时报告：

- AUC、AUPRC、灵敏度、特异度；
- 校准曲线/Brier score；
- 配对 fold 差值；
- 患者聚类 bootstrap 区间；
- gate、梯度和预测相关性；
- 单患者删除敏感性；
- identity/空间打乱和 generic 30D 反事实。

## 17. 最终推荐

当前不推荐简单组合：

```text
SpaMIL + BLEEP + SurvPath + uncertainty
```

更适合项目的数据驱动路线是：

```text
Phase 2 真实空间转录组
        ↓
患者平衡的通路高/低形态原型
        ↓
absolute + ordinal + prototype + uncertainty
        ↓
零初始化、可关闭的 pathway residual
        ↓
patch → slide → patient 层级 MIL
        ↓
满足 pCR ⊆ MPR 的单调联合响应模型
```

近期建议：

1. 先患者独立复核 W004 ordinal 信号并补齐最小融合对照；
2. 优先试 P1 双视图零初始化残差；
3. 可同批加入 P2 单调联合头；
4. 若低成本路线出现稳定信号，再进入真实 SpT 原型和完整 CUSP-Lite；
5. 复杂空间模型必须由残差空间证据驱动，而不能仅因结构更新而优先。

以上所有推荐仍为 `review_draft / NOT RUN / pending_review`，是否登记并实施由后续组会和用户显式裁决。
