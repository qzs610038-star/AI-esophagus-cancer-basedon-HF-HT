# PFMval 独立实验包与手动回传

依据：DIR-20260905-002，用户批准实施。适用范围仅为 PFMval_new。

## 当前决定

工作树要求彻底退役，只有用户明确指令才创建；旧工作树、代码和结果保留追溯。实验直接在 `experiments/<实验名>/` 独立文件夹内进行，使用 [通用模板](../../experiments/_template/README.md)。旧 W### 编号、Git 提交、同步和预检不再作为实验前置条件。

当前传输为用户直接复制文件夹，不自动生成压缩包；需要时由用户自行压缩。Gitee 暂停、SSH 暂不使用。GitHub 仅用于备份和网页端 GPT/Gemini 等工具查阅；提交推送由用户触发。本次不创建定时智能体，日常实验不主动检查 Git 干净状态；大规模改动前安排用户触发的备份提交。

## 新建和上传

在本地复制模板、设置实验标识和递增代码版本，编写本轮全部实验代码。必要的公共实现和小型划分随包携带并记录来源；大数据、缓存、预训练权重引用服务器现有位置。入口不依赖主仓库、其他实验或 Git。

本项目 [服务器配置](../../configs/server_paths.yaml) 记录的服务器是 **Windows**，不是本机，也不是其他项目服务器：

```text
D:\AIPatho\qzs\
  code\<实验名>\                 用户上传代码包
  runs\<实验名>\<运行编号>\      日志与结果
  weights\<实验名>\<批次>\<运行>\ 服务器保留的模型权重
```

自 DIR-20260908-002 起，新训练不再将 checkpoint 写入常规结果目录。权重按实验、批次和运行分层保存于 `D:\AIPatho\qzs\weights`；运行结果中保留 `model_weights.json`，记录每项任务的权重目录及 warmup、formal、last checkpoint 服务器绝对路径和产出状态。常规回传只复制 `runs`，不复制 `weights`；后续只在用户选定最终权重或明确要求共享时单独取回。

解释器配置为 `C:\Users\AIPatho1\pfmval_env\Scripts\python.exe`，允许通过包配置显式更改。本次只登记新目录，不连接服务器，路径可用性未现场验证。保留旧服务器路径键和值作为历史，新增 `server_manual_code` 和 `server_manual_runs`；不把旧脚本重定向到新目录。

用户在对应代码包目录运行：

```powershell
.\run.ps1
```

配置及启动参数见包内 README。模板本身只提供零训练演示；具体实验需实现训练入口和必要依赖。

## 报错、修复和重跑

启动器每次建立新运行目录，保存实际配置、代码版本、时间、状态、退出码；标准输出和错误分别落盘，另留合并日志。日志持续写入，不等进程结束才保存。

报错时将 `logs/`、`run.json`、`config.json` 和 `package.json` 发回本地。Agent 只在对应实验文件夹内修复并递增版本。训练进程停止后，用户仅替换服务器 `code/<实验名>`，保留 `runs/`，重新启动生成新运行目录；默认不自动续训。

无法解析配置或无法创建输出目录时，必要终端信息仍需人工回传；断电或强杀不保证完整错误记录。`running` 是最后写入状态，不能替代实时存活判断。

## 原始结果和本地登记

服务器保留原始训练历史、预测与真实标签、样本/患者/切片与数据划分对应关系、必要坐标、通路顺序、标准化参数及权重。具体实验明确其指标重算所需输出，既不遗漏必要数据，也不复制整个输入数据集。

模型权重作为服务器单独保留产物，不属于常规本地回传内容。路径登记用于追溯、最终权重回传及 Phase3 共享；登记不代表权重已复制到本地，也不代表结果已被接受。不默认计算权重哈帏。

服务器只计算训练、早停和模型选择必需指标。最佳方法、最佳轮次、选择指标及数值、内部验证划分、checkpoint 相对位置由实际实验写入 `metrics.json`；不能用外部测试集挑选或调参。

自 DIR-20260908-001 起，本地回传运行结果与可继续调整的代码包分离。用户将新运行文件夹直接复制至 `experiments/results/<实验名>/<运行编号>/`，Agent 在对应运行目录的 `analysis/` 内补算指标、图表和统计，保留原始输出。既有实验结果不做特别迁移，其实际原存储地址继续有效并由相关记录保留。“全部既定指标保留”继续有效，仅改变计算位置；本次不变更科研主线或已确认结果。

本地按证据维护相关实验登记。既有结果信封仅用于已有兼容元数据的结果；新的手动回传不要求工作树编号、提交编号或哈希，不伪造旧格式字段。若导入器不适配，可在用户授权范围内直接维护相关实验登记，并注明原始产物路径及计算口径。登记不自动等于 `accepted`（已确认）；本次不重构旧导入器、不导入或确认新结果。
