### 3.3 跨患者 3 折交叉验证（最终评估）

这是最常用的训练模式。训练集 = 2 个患者，测试集 = 1 个患者。

```powershell
cd D:\AIPatho\qzs\pfmval_deploy_git

# ═══ Fold 1: JFX0729 + LMZ12939 训练 → HYZ15040 测试 ═══
cmd.exe /c "set PYTHONIOENCODING=utf-8 && set OMP_NUM_THREADS=8 && set MKL_NUM_THREADS=8 && C:\Users\AIPatho1\pfmval_env\Scripts\python.exe -u train_online_cls.py --mode lora --lora_rank 8 --cross_patient --fold 1 --num_epochs 15 --batch_size 1 --early_stop_patience 5 --num_threads 8"

# ═══ Fold 2: HYZ15040 + LMZ12939 训练 → JFX0729 测试 ═══
cmd.exe /c "set PYTHONIOENCODING=utf-8 && set OMP_NUM_THREADS=8 && set MKL_NUM_THREADS=8 && C:\Users\AIPatho1\pfmval_env\Scripts\python.exe -u train_online_cls.py --mode lora --lora_rank 8 --cross_patient --fold 2 --num_epochs 15 --batch_size 1 --early_stop_patience 5 --num_threads 8"

# ═══ Fold 3: HYZ15040 + JFX0729 训练 → LMZ12939 测试 ═══
```

> ⚠️ 跨患者训练约 1-2 小时/epoch，训练中终端可能长时间无输出，这是正常的（通过 `nvidia-smi -l 2` 确认 GPU 在工作即可）。

### 3.4 关键参数速查表

| 参数 | 可选值 | 说明 |
|------|--------|------|
| `--mode` | `frozen` / `lora` / `stage2` / `stage3` | **frozen**=冻结 backbone；**lora**=低秩适配（推荐）；**stage2/3**=解冻 backbone（已证实损害泛化） |
| `--lora_rank` | `2` / `4` / `8` | LoRA 的秩。r=8 效果最好 |
| `--lora_dropout` | `0.0` / `0.1` / `0.2` | LoRA dropout（正则化实验用） |
| `--cross_patient` | flag | 开启跨患者 3 折交叉验证 |
| `--fold` | `1` / `2` / `3` | 指定当前 fold（需同时传 `--cross_patient`） |
| `--patient` | `HYZ15040` / `JFX0729` / `LMZ12939` | 单患者模式（与 `--cross_patient` 互斥） |
| `--num_epochs` | 整数 | 最大训练 epoch 数，推荐 15-30 |
| `--batch_size` | `1` | RTX 4080 上推荐 bs=1 |
| `--early_stop_patience` | `3` ~ `10` | 早停 patience，推荐 5 |
| `--num_threads` | `4` ~ `16` | CPU 线程数，推荐 8 |
| `--dataset_name` | 自定义字符串 | 输出目录标识（**变体实验必须传！**） |
| `--resume` | checkpoint 路径 | 断点续训 |

### 3.5 ⚠️ 变体实验防覆盖

改变 `--lora_dropout` 或 `--lora_rank` 时，必须同时传 `--dataset_name` 区分输出目录，否则会覆盖之前的结果！

```powershell
# ❌ 错误 — 不传 dataset_name，会覆盖 r=8 的结果
--mode lora --lora_rank 4 --cross_patient --fold 1

# ✅ 正确 — 显式区分
--mode lora --lora_rank 4 --cross_patient --fold 1 --dataset_name online_cls_cross_fold1_r4
```

输出目录命名规则：`{mode}_r{lora_rank}_{dataset_name}`
例如：`lora_r8_online_cls_cross_fold1` / `lora_r4_online_cls_cross_fold1_r4`

## 五、常见问题与故障排查

### 5.1 启动/环境类

| 问题 | 原因 | 解决 |
|------|------|------|
| `The system cannot find the path specified` | 当前目录不在项目根 | `cd D:\AIPatho\qzs\pfmval_deploy_git` |
| `ModuleNotFoundError: No module named 'xxx'` | venv 未激活或缺少依赖 | 确认使用完整 Python 路径 `C:\Users\AIPatho1\pfmval_env\Scripts\python.exe` |
| `CUDA out of memory` | GPU 显存被占用 | `nvidia-smi` 检查，`taskkill /F /IM python.exe` 清理 |
| `UnicodeEncodeError` | PowerShell 编码问题 | 命令中已含 `PYTHONIOENCODING=utf-8`，无需额外操作 |

### 5.2 CUDA / GPU 类

| 问题 | 原因 | 解决 |
|------|------|------|
| `CUDA out of memory` 启动即报 | 残留进程占用 GPU | `taskkill /F /IM python.exe` → 等 10 秒 → `nvidia-smi` 确认空闲 |
| `torch.cuda.is_available() → False` | PyTorch CPU 版本或驱动问题 | 确认 `C:\Users\AIPatho1\pfmval_env\Scripts\python.exe -c "import torch; print(torch.__version__)"` 输出含 `cu124` |
| 训练中途 OOM | batch_size 过大（一般不会，bs=1） | 检查是否有其他进程同时占用 GPU |

### 5.3 训练过程类

| 现象 | 原因 | 处理 |
|------|------|------|
| **Loss 变成 NaN** | LMZ12939 标签含极端 z-score 值 → 数值溢出 | 当前脚本已内置 `nan_to_num + clip ±100` 保护；如仍出现，降低学习率 |
| **终端长时间无输出** | 跨患者训练约 1-2h/epoch，内部无逐 batch 进度条 | **正常现象**。用 `nvidia-smi -l 2` 确认 GPU 在工作即可 |
| **Val PCC 很低 (<0.1)** | fold 对应的 train/test split 可能有问题 | 检查是否正确传入 `--fold` 参数 |
| **训练启动后立即退出** | 命令行参数错误或数据路径不对 | 查看终端最后几行报错信息 |
| **checkpoint 多了一倍** | 可能是不小心同时跑了两个相同实验 | `nvidia-smi` 查看 Python 进程数量 |

### 5.4 数据/缓存类

| 问题 | 原因 | 解决 |
|------|------|------|
| `FileNotFoundError: uni2h_cache/xxx.pt` | UNI 特征缓存未提取 | 运行 `extract_uni_tokens.py --patient {患者}` 先提取缓存 |
| `No PNG patches matched labels` | patches 文件名与标签 CSV 不匹配 | 检查数据路径配置，运行 `python config_utils.py` 验证 |
| HF 模型下载失败 | 直连 HuggingFace 被墙 | 已配置 `HF_ENDPOINT=https://hf-mirror.com`，如果仍失败检查代理 |

### 5.5 Git 同步类

| 问题 | 原因 | 解决 |
|------|------|------|
| `git push` 卡住 | Clash 代理断开 | 检查 Clash Verge 是否运行，`git config --global http.proxy` 确认代理配置 |
| `non-fast-forward` rejected | 本地和远程历史分叉 | `git fetch origin main --force && git reset --hard origin/main` |
| `git push` 报 SSL 错误 | 代理干扰 | 检查 `git config --global http.proxy` 是否设为 `http://127.0.0.1:7897` |

### 5.6 Checkpoint 目录覆盖

**现象**：跑了一个变体实验，发现之前的结果不见了。

**原因**：`--dataset_name` 没传，新旧实验输出到同一目录，被覆盖。

**解决**：变体实验必须传 `--dataset_name` 区分，例如：
```powershell
# dropout 变体
--dataset_name online_cls_cross_fold1_d01    # dropout=0.1
--dataset_name online_cls_cross_fold1_d02    # dropout=0.2

# rank 变体
--dataset_name online_cls_cross_fold1_r4     # rank=4
```

### 5.8 PowerShell 脚本乱码

如果自己编写 .ps1 脚本在服务器上运行时报语法错误、乱码：

**原因**：Windows 中文版 PowerShell 5.1 默认编码为 GBK，UTF-8 without BOM 文件中的中文/非 ASCII 字符会被错解码。

**解决**：服务器 PowerShell 脚本必须**全英文**编写，不要包含中文或 emoji。
