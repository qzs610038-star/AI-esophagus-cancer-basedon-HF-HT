## 执行原则

1. **先修接口，再做新模型**：当前 `model_online_tokens.py` 不能运行，必须先修复自检。
2. **先 65-token，再 265-token**：默认训练脚本是 `num_tokens=65`，所有 P0 实验先在 65-token 下对比。
3. **所有实验必须显式传 `--dataset_name`**：否则 Transformer baseline 与 GFNet 会写入同一目录，结果互相覆盖。
4. **每一步都做短验证**：新增模型先跑自检；训练脚本先跑 1 epoch smoke test，再跑正式训练。
5. **Mamba/VSS 暂不部署**：本方案只把 GFNet 跑通并给出 AFNO 后续入口；Mamba 依赖和收益都不适合放入首轮执行。

## Step 0：修复 `model_online_tokens.py` ✅ 已完成

### 0.1 当前问题

`OnlineTokenModel` 当前有两个接口错误：

- 构造 `LightweightTokenEncoder` 时传入了不存在的 `token_drop_rate` 和 `use_attn_pool`。
- `forward()` 中写成 `encoded, _attn = self.token_encoder(tokens)`，但 `LightweightTokenEncoder.forward()` 只返回单个 tensor。

### 0.2 修改方法

在 `OnlineTokenModel.__init__` 增加参数：

```python
encoder_type: str = "transformer",
```

并在 `super().__init__()` 后保存：

```python
self.encoder_type = encoder_type
```

将 token encoder 创建逻辑替换为：

```python
if encoder_type == "gfnet":
    from model_gfnet import GFNetTokenEncoder
    self.token_encoder = GFNetTokenEncoder(
        embed_dim=feature_dim,
        hidden_dim=encoder_hidden_dim,
        seq_len=num_tokens,
        n_layers=n_encoder_layers,
        dropout=dropout,
    )
elif encoder_type == "transformer":
    self.token_encoder = LightweightTokenEncoder(
        embed_dim=feature_dim,
        hidden_dim=encoder_hidden_dim,
        n_heads=n_encoder_heads,
        n_layers=n_encoder_layers,
        dropout=dropout,
    )
else:
    raise ValueError(f"Unsupported encoder_type: {encoder_type}")
```

将 `forward()` 中的编码调用改为：

```python
encoded = self.token_encoder(tokens)
```

保留 `token_drop_rate` 参数可以暂时不删，但要在 docstring 中标注“当前未使用”，避免破坏训练脚本参数兼容。


## Step 1：新建 `model_gfnet.py` ✅ 已完成

创建项目根目录下的 `model_gfnet.py`。

```python
"""
model_gfnet.py - GFNet Token Encoder for PFMval.

Uses a learnable FFT filter to replace Transformer token mixing.
No external dependencies beyond PyTorch.
"""

from __future__ import annotations

import torch
import torch.nn as nn


class GlobalFilter(nn.Module):
    """Learnable residual FFT filter over the token dimension."""

    def __init__(self, seq_len: int, dim: int, init_scale: float = 0.02):
        super().__init__()
        self.seq_len = seq_len
        self.dim = dim
        self.complex_weight = nn.Parameter(
            torch.randn(seq_len // 2 + 1, dim, 2, dtype=torch.float32) * init_scale
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x: [B, N, D]
        b, n, d = x.shape
        if n != self.seq_len:
            raise ValueError(f"GlobalFilter expected seq_len={self.seq_len}, got {n}")
        if d != self.dim:
            raise ValueError(f"GlobalFilter expected dim={self.dim}, got {d}")

        x_freq = torch.fft.rfft(x.float(), dim=1, norm="ortho")
        weight = torch.view_as_complex(self.complex_weight)
        x_freq = x_freq * weight.unsqueeze(0)
        out = torch.fft.irfft(x_freq, n=n, dim=1, norm="ortho")
        return out.to(dtype=x.dtype)


class GFNetBlock(nn.Module):
    """GFNet block with residual FFT filter and residual FFN."""

    def __init__(self, seq_len: int, dim: int, mlp_ratio: float = 2.0, dropout: float = 0.3):
        super().__init__()
        hidden = int(dim * mlp_ratio)
        self.norm1 = nn.LayerNorm(dim)
        self.filter = GlobalFilter(seq_len, dim)
        self.norm2 = nn.LayerNorm(dim)
        self.ffn = nn.Sequential(
            nn.Linear(dim, hidden),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(hidden, dim),
            nn.Dropout(dropout),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = x + self.filter(self.norm1(x))
        x = x + self.ffn(self.norm2(x))
        return x


class GFNetTokenEncoder(nn.Module):
    """Drop-in replacement for LightweightTokenEncoder."""

    def __init__(
        self,
        embed_dim: int = 1536,
        hidden_dim: int = 512,
        seq_len: int = 65,
        n_layers: int = 1,
        dropout: float = 0.3,
    ):
        super().__init__()
        self.input_proj = nn.Linear(embed_dim, hidden_dim)
        self.blocks = nn.ModuleList(
            [GFNetBlock(seq_len, hidden_dim, dropout=dropout) for _ in range(n_layers)]
        )
        self.output_proj = nn.Linear(hidden_dim, embed_dim)
        self.norm = nn.LayerNorm(embed_dim)

    def forward(self, tokens: torch.Tensor) -> torch.Tensor:
        x = self.input_proj(tokens)
        for block in self.blocks:
            x = block(x)
        x = x.mean(dim=1)
        x = self.output_proj(x)
        return self.norm(x)


if __name__ == "__main__":
    print("=" * 60)
    print("GFNetTokenEncoder self-test")
    print("=" * 60)
    for seq_len in (65, 265):
        encoder = GFNetTokenEncoder(seq_len=seq_len)
        params = sum(p.numel() for p in encoder.parameters())
        filter_params = sum(p.numel() for p in encoder.blocks[0].filter.parameters())
        x = torch.randn(4, seq_len, 1536)
        with torch.no_grad():
            y = encoder(x)
        assert y.shape == (4, 1536), y.shape
        print(f"seq_len={seq_len}: params={params:,}, filter={filter_params:,}, output={tuple(y.shape)}")
    print("GFNetTokenEncoder self-test passed")
```

## Step 6：结果对比 ⏸️ 脚本就绪 (compare_token_encoder_runs.py)，待 GFNet 正式训练完成后执行

新增临时脚本 `compare_token_encoder_runs.py`，或直接用 PowerShell 读取 CSV。推荐脚本：

```python
from pathlib import Path
import pandas as pd

runs = {
    "transformer_65t": Path("checkpoints/online_tokens/frozen_r8_online_tokens_cross_fold1_65t_transformer"),
    "gfnet_65t": Path("checkpoints/online_tokens/frozen_r8_online_tokens_cross_fold1_65t_gfnet"),
}

for name, run_dir in runs.items():
    hist_path = run_dir / "training_history.csv"
    if not hist_path.exists():
        print(f"{name}: missing {hist_path}")
        continue
    hist = pd.read_csv(hist_path)
    best = hist.loc[hist["val_loss"].idxmin()]
    gap = float(best["train_pcc"] - best["val_pcc"])
    print(
        f"{name}: best_epoch={int(best['epoch'])}, "
        f"val_loss={best['val_loss']:.4f}, "
        f"val_pcc={best['val_pcc']:.4f}, "
        f"train_pcc={best['train_pcc']:.4f}, "
        f"train_val_pcc_gap={gap:.4f}"
    )
```

运行：

```powershell
python compare_token_encoder_runs.py
```

判定：

| 结果 | 动作 |
|---|---|
| `GFNet val_pcc >= Transformer val_pcc` | 频域方向通过 65-token 初筛，进入 265-token 扩展 |
| `GFNet val_pcc` 低于 baseline 但差距 `< 0.01` | 可做一次 265-token GFNet 复核 |
| `GFNet val_pcc` 低于 baseline 且差距 `>= 0.01` | 停止频域 token mixing，优先考虑 pooling/正则化/CLS 旁路 |

同时参考 CLS 历史基线：

- CLS frozen Fold1：`0.4113`
- CLS LoRA Fold1：`0.4322`

如果 Token Transformer baseline 本身明显低于 CLS frozen `>0.05`，说明 token 路线需要重新评估，不要只看 GFNet 是否超过 token baseline。

## 常见问题与回退

| 问题 | 症状 | 处理 |
|---|---|---|
| `model_online_tokens.py` 自检失败 | `token_drop_rate` 或 tuple unpack 报错 | 回到 Step 0，确认未再传不支持参数 |
| 训练目录覆盖 | baseline 和 GFNet 写到同一目录 | 检查 `--dataset_name` 是否分别包含 `transformer` 与 `gfnet` |
| GFNet loss 为 NaN | 第 1 个 epoch 出现 NaN | 降低 `lr` 到 `5e-5`；确认 FFT 输出没有 dtype/device 错误 |
| GFNet 完全不学习 | val_pcc 接近 0 且 loss 不动 | 检查 `GlobalFilter` 是否参与优化；打印 `TokenEncoder` 参数量 |
| 265-token OOM | CUDA out of memory | `batch_size=1 --grad_accum_steps 8 --grad_checkpointing` |
| `HF_HUB_OFFLINE=1` 下加载失败 | 找不到本地模型缓存 | 取消该环境变量，或先确认 `hf_cache`/UNI2-H 缓存可用 |
