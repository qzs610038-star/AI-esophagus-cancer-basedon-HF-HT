# W004 A001 与队友 Phase3 参考实验设置完整对比

> 日期：2026-08-08  
> 用途：供组会讨论和后续实验协议采纳。  
> 比较对象：本方 W004 Stage 2 的 A001（S2-ABS-001）、队友旧版 4 seeds × 5 folds 汇总、队友 0804 结果工作簿。  
> 证据边界：本表是设置与结果的审计对照，不把跨协议 AUC 差值解释为模型净提升。

## 一句话结论

W004 A001 的高 AUC 不能简单解释为“我们的模型比队友好很多”。两边虽然都使用 1536 维 H&E 特征、30 维 pathway 特征和 MIL（多实例学习），但在**划分单位、患者是否跨集合、模型结构、损失权重、学习率、训练轮数和证据完整度**上均有实质差异。当前最可能显著影响数值的是：W004 使用切片级重复 holdout，允许同一患者的不同切片跨 train/validation/test；队友现存 split 文件则是患者互斥划分。

### 对“为什么 A001 高很多”的直接解释

W004 的患者重叠是目前最需要优先排查的因素。同一患者不同切片往往共享组织学、取材和技术特征；如果它们分散在训练集和测试集，模型可能部分识别“患者特征”，从而提高测试 AUC。这个解释目前是**合理怀疑**，不是已经量化的结论；要量化必须在同一模型、同一 307 张队列上改为患者互斥 split 后重跑。

## 5. 模型与融合结构

| 设置 | 设置含义 | W004 A001 | 队友 CLAM-SB / adaptive fusion | 同异与影响 |
|---|---|---|---|---|
| 总体骨架 | 从 patch 特征得到 slide 预测的网络体系 | 自研 `stage2_mil_adaptive_gated_attention` | CLAM-SB | **不同模型家族**，A001 不是队友基线的原样复现 |
| 图像投影 | 将 1536 维 H&E 压到共同空间 | Linear 1536→128 + GELU | adaptive fusion 中通常投影到 512 维 | 表征容量不同 |
| pathway 投影 | 将 30 维通路特征压到共同空间 | Linear 30→128 + GELU | 通常 30→512；配置中另有 gene/path projection 维度参数 | 实际通道宽度不同 |
| 融合门控粒度 | 模型以多细的尺度决定偏向哪个模态 | 拼接两模态后产生 **128 维 feature-wise sigmoid gate**；每个隐特征可有不同权重 | adaptive fusion 产生 **2 个 patch-wise softmax 权重**；整条图像/通路向量各用一个标量权重 | 都叫 adaptive fusion，但数学实现明显不同；这是本方真正的结构改动之一 |
| 融合公式 | 两模态如何合并 | `gate × image + (1-gate) × pathway` | `w_img × img_proj + w_path × path_proj`，且两权重和为 1 | 思路相似、参数化不同 |
| MIL pooling | 如何把一个 slide 内多个 patch 汇成 slide 表征 | attention pooling | CLAM attention pooling | 核心思想相同 |
| 隐层宽度 | 模型内部特征容量 | 128 | adaptive fusion output 通常 512，hidden 256 | W004 更窄；参数量和过拟合行为不同 |
| 低秩维度 | 用较小中间空间限制交互复杂度 | 配置为 16 | 无直接同名设置 | W004 的结构约束之一，不能与 CLAM 参数一一对应 |
| dropout | 随机丢弃部分神经元，抑制过拟合 | `MILBagClassifier` 中无显式 dropout | README 命令为 0.25 | 正则化强度不同 |
| instance 分支 | 除 slide 标签外，是否对关键 patch 做辅助监督 | 无 instance loss | CLAM 可有 instance-level loss；README 示例传 `--inst_loss ce`，0804 又有“无 instance loss”变体 | 训练目标明显不同 |
| 输出头 | 最终预测类别的形式 | 单 logit，sigmoid 后为阳性概率 | 两类 logits，softmax/CE | 二分类表达等价性较强，但损失实现不同 |

## 9. 哪些改动可以明确说，哪些结论不能说

### 可以明确说

1. 我们把参考的双模态 MIL 思路改成了自研的 128 维 feature-wise 门控融合，而不是队友的两个模态标量权重。
2. 我们为 W004 建立了 4 seeds × 5 folds × 2 tasks 的可追溯运行、逐样本预测和不可变结果包。
3. 我们明确剔除了 22 张切片，并将 Stage 2 的 identity、ordinal、spatial-identity、spatial-shuffle 做成同一 W004 协议下的配对探针。
4. 在 W004 自身协议内，A002 相对 A001：pCR +0.0232，MPR +0.0040；A003 与 A004 的差异很小。这些是当前更可信的“同协议内部差值”。

### 不能说

1. 不能说 W004 相对队友 feature fusion 获得了 +0.2087 的真实模型增益。
2. 不能把 A001 称为“H&E baseline”；它已经使用 H&E + pathway。
3. 不能说队友一定使用 329 张旧切片。现存 pCR split 明确为 307 张；旧图和 0804 工作簿的实际队列仍需原始 manifest 才能确认。
4. 不能把当前 A001 数值写成独立患者泛化性能，因为 W004 split 允许患者跨集合。
5. 不能把 legacy z-score compatibility 结果称作 raw MPP2 结果。

## 10. 建议组会采用的表述

> W004 Stage 2 已完成无空间变换锚点和三类空间对照。内部配对结果显示，ordinal 空间平滑对 pCR 有约 0.023 的平均 AUC 增量，对 MPR 增量较小；spatial-identity 与 spatial-shuffle 的差异接近零，尚不足以证明真实坐标拓扑带来稳定收益。W004 A001 的绝对 AUC 高于队友阶段性参考，但两者的患者划分、模型、训练预算和证据包不同，尤其 W004 当前允许同一患者的切片跨 train/test，因此该跨团队差值只能作为现象参考，不能归因于模型改进。

## 11. 如果要把“参考对比”升级为公平验证，最少要固定什么

这不是要求现在补跑 Stage 1，而是给后续是否采纳的最小协议清单：

1. 固定同一 307 张切片、同一 78 名患者及同一剔除清单。
2. 使用患者互斥的 4 seeds × 5 folds，双方读取同一份 split manifest。
3. 固定完全相同的 UNI2-h 与 30D pathway 输入哈希。
4. 在相同 seed/fold 上分别运行队友 CLAM/AF 和 W004 门控模型。
5. 统一 AUC 汇总规则，并保留逐样本预测。
6. 如要回答“融合是否有效”，至少补 H&E-only、pathway-only、direct concat 与 fusion 的同折配对；如只回答“空间平滑是否有效”，则优先比较 A001/A002/A003/A004，无需把两个问题混在一批实验里。
