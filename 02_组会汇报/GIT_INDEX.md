# 组会汇报目录索引

> 管理模式：仅本索引纳入 Git。  
> 复核日期：2026-08-09。  
> 同步范围：`main` 与所有新建工作树仅获得本文件；组会材料不参与服务器同步。

## 当前定位

本目录用于本机保存组会演示、会议记录、汇报附件和相关导出材料。其内容服务于人工沟通与回顾，不是实验执行依据、服务器输入或结果证据。

## 与公共仓库的边界

组会中形成的可复用代码、已批准的治理规则或可验证实验结论，必须经过独立审核后进入公共代码、`project_state/` 或 active 治理文档；不得仅保留在组会材料中。

## 写入边界

- 禁止提交 PPT、PDF、视频、录音、截图、会议纪要正文、附件或导出文件。
- 新增组会材料默认仅保存在本目录；本索引只在目录边界或管理规则变化时更新。
- 工作树若需要引用组会结论，须在受管方案中写明对应的已批准事实源，不得直接依赖本目录材料。
