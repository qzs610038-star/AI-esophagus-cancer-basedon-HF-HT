## 关键术语速查

| 术语 | 一句话解释 |
|------|------|
| **PCC** | 皮尔逊相关系数，衡量预测值与真实值的吻合程度，1.0=完美预测，0=无关 |
| **GFNet** | Global Filter Network，用傅里叶变换（FFT）在频域中混合 token 信息，替代 Transformer 自注意力 |
| **modReLU** | 复数 ReLU 变体，对频域分量做幅度阈值截断——弱频率直接清零，实现频域稀疏化 |
| **LoRA** | Low-Rank Adaptation，不修改原始权重，训练低秩增量矩阵（rank=8, ~2.4M 参数） |
| **Frozen** | 冻结 UNI2-H backbone 所有参数，仅训练下游预测头 |
| **cls_patch64** | Token 选取模式：CLS token + 64 patch tokens（排除 register tokens），比旧版 legacy_firstN 更干净 |
| **Train-Val Gap** | 训练集与验证集 PCC 之差——衡量过拟合程度的核心指标 |
| **Cross-Fold** | 跨患者交叉验证：2 患者训练 → 1 患者测试（Fold1 = JFX+LMZ→HYZ） |
| **最佳 epoch** | 以 **val_loss 最小** 为准（非 val_pcc 最大），本项目统一标准 |

## 一、研究背景（1 页内）

> **结论前置**：GFNet 频域模块的第一阶段烟雾测试（+5.6% vs Transformer）触发了第二阶段的机制性对照实验。经过 5 个实验、三条独立证据线的系统性验证，频域增强方向被全面否决。

**问题起源**：GFNet 用傅里叶变换（FFT）取代 Transformer 的自注意力机制，将 token 信息在频域中全局混合。第一阶段的烟雾测试（1 epoch）显示 GFNet（0.3933）优于 Transformer（0.3724, +5.6%），但正式训练后差距缩小至 +2.4%（0.3914 vs 0.3821）。这个增益是来自"傅里叶变换本身"还是"全局感受野 + 参数减少的正则化效应"？第二阶段需要精确拆解。

### 1.1 技术路线选择：为什么优先探索频域（GFNet）而非状态空间（Mamba）？

> **听众提示**：此节面向希望理解"为何不做 Mamba"的技术听众。**面向医学背景听众时可跳过**，直接看三路线实验设计表。

在 Transformer TokenEncoder 基线确立后（PCC=0.3821），我们面临两条正交的技术改进方向：**频域方法**（GFNet/AFNO）和**状态空间方法**（Mamba/MambaIR）。两者的核心差异：

| 维度 | 频域路线（GFNet → AFNO） | 状态空间路线（Mamba → MambaIR） |
|------|------|------|
| **核心机制** | FFT → 频域可学习滤波 → IFFT | 选择性状态空间 — 用隐藏状态记忆序列历史 |
| **复杂度** | O(N log N)，FFT 高度优化 | O(N)，但需要定制 CUDA 核 |
| **实现难度** | 纯 PyTorch ~100 行（`torch.fft.rfft` + 复数乘法 + `torch.fft.irfft`） | 需 `mamba-ssm` 包（C++/CUDA 编译）或手动实现选择性扫描 |
| **正则化倾向** | **强正则化**：固定滤波器，输入无关 | **弱正则化**：输入依赖的选择性记忆，更接近 Transformer |
| **可消融性** | 高（modReLU 开/关、频域 vs 均值池化） | 低（选择性机制难以干净地 on/off 对照） |
| **上下游依赖** | GFNet 结果 → 决定 AFNO 是否需要入场 | Mamba 独立 — 不依赖频域结果 |

**选择 GFNet 优先的五个理由**：

1. **实现成本最低、验证速度最快**：GFNet 的 GlobalFilter 核心就三步——`rfft → 复数权重乘法 → irfft`。全部用 PyTorch 原生 API 实现，[model_gfnet.py](model_gfnet.py) 仅 ~200 行（含 modReLU 和 GFNetBlock）。Mamba 的 selective scan 需要高效的 CUDA 实现，引入第三方依赖后调试和部署成本显著增加。

2. **风险梯度：先试最简、再试最繁**：频域方法形成一条复杂度递进链——`GFNet (最简单) → modReLU (加幅度门控) → AFNO (加块对角 + 软阈值)`。如果 GFNet 不 work，后续方法大概率也不 work。这种"先探最低成本、用阴性结果关闭整条线"的策略，3 天内 7 个实验就完成了频域方向收敛。

3. **正则化倾向匹配核心问题**：PFMval 的核心瓶颈是**过拟合**（15K 样本、跨患者泛化）。GFNet 的固定滤波器是天然正则化——对不同输入使用相同的频率权重，强制模型学通用的频率模式。Mamba 的输入依赖选择性机制会让模型"因样本而异"地混合 token，在小样本下更可能过拟合。

4. **可消融性决定结论的干净程度**：频域方法的对照设计非常干净——A1 vs A0b（仅 modReLU 开关）、B1a vs B1b（仅频域 vs 均值池化）。Mamba 的选择性机制与输入依赖模式深度耦合，难以设计"仅开关选择性"的干净对照。

5. **两者互不依赖、可分阶段探索**：GFNet 的阴性结果直接关闭了 AFNO/AFNO-v2 等频域增强方向，但 Mamba 与频域**完全正交**——频域的失败不意味着 SSM 不可行。Mamba 被设为 P2 暂停（非关闭），等待 Token+LoRA 完成跨 fold 验证后在更大数据量下重新评估。

**实际验证结果**：这个优先级决策被实验验证——频域方向 3 天内完成收敛，避免了在 AFNO、MambaIR 上投入实现和调试时间。节省的资源转向了 C1（Token+LoRA），后者产出了 Token 模式历史最佳结果（PCC=0.4169）。



**实验设计（三路线对照）**：

| 路线 | 实验 | 核心问题 | 决策条件 |
|------|:---:|------|:---:|
| **A 线**：频域稀疏化 | A0b 基线 → A1 modReLU | 对频域做幅度阈值截断能提升信号纯度吗？ | A1 优于 A0b → 继续 |
| **B 线**：CLS频域旁路 | B1a GFNet vs B1b mean | 频域处理在 CLS 模式下有机制增量吗？ | B1a 显著优于 B1b → 继续 |
| **C 线**：Token+LoRA | C1 GFNet LoRA r=8 | LoRA 在 GFNet Token 模式是否复现 CLS 上的增益？ | C1 ≥ 0.41 → 通过 |

## 二、方法概述

> **结论前置**：GFNet 的核心操作是将 token 序列通过 FFT 变换到频域 → 用可学习的全局滤波器逐频率加权 → IFFT 回到时域。modReLU 在这个流程中增加了一步"幅度阈值截断"试图稀疏化频域表示，但实验证明这一步反而过滤掉了有用的病理纹理信息。

### 2.1 GFNet TokenEncoder 流程

```
输入: CLS token + 64 patch tokens [65, 1536]
  ↓
FFT 变换到频域 (逐 token 维度)
  ↓
┌─ 路线 A (频域稀疏化) ─────────────────────┐
│  modReLU: 复数幅度 < threshold → 置零       │
│  类比: 对CT图像做"去噪"，低于阈值的信号丢弃  │
└───────────────────────────────────────────┘
  ↓
全局可学习滤波器 (逐频率加权)
  ↓
IFFT 回到时域
  ↓
MLP + 残差连接 (GFNetBlock)
  ↓
输出: [65, 1536] → 预测头 → 30 通路活性
```

### 2.2 CLS 频域旁路（B 线）

```
CLS token → CLS 路径 → CLS 特征 [1, 1536]
Patch tokens → [GFNet FFT 或 Mean Pool] → 旁路特征 [1, 1536]
                                                   ↓
                                    拼接 [1, 3072] → 预测头 → 30 通路活性
```

<details>
<summary><b>📖 折叠概念："拼接"（Concat）是什么？为什么这里用了反而变差？（点击展开）</b></summary>

**Concat（向量拼接）** 就是把两个信息源的输出向量**首尾相接**钉在一起，交给下游网络自行决定如何利用。

```
CLS 分支输出:   [0.5, 0.3, -0.2]     ← 3 个数，"这张 tile 整体是什么"
Patch 分支输出:  [0.8, -0.1, 0.4, 0.9] ← 4 个数，"tile 内部各子区域有什么"
                         │
                    Concat（拼接）
                         ▼
合并后: [0.5, 0.3, -0.2, 0.8, -0.1, 0.4, 0.9] ← 7 个数，信息完整保留
```

对比常见的**加法融合（Add）**：Concat 不要求两个分支维度相同，也不把信息"搅拌"在一起——每个分支的信息被完整保留，MLP 自己学习该信哪个。

**为什么这个实验里 Concat 反而降低了性能？**

| 原因 | 通俗解释 |
|------|---------|
| **CLS 已经知道了** | UNI2-H 的 CLS token 经过 24 层 Transformer 处理，通过注意力机制已经聚合了所有 patch token 的信息。再 concat patch 特征是"把同一份信息说了两遍"。 |
| **参数变多 → 更容易过拟合** | CLS-only 的预测头约 2.1M 参数。Concat 后输入维度从 1536 膨胀到 3072，预测头约 5.4M 参数——参数翻倍，但训练样本只有 15K。额外参数去拟合了训练数据的噪声。 |
| **破坏了 CLS 的"出厂设置"** | CLS token 在 UNI2-H 预训练时被训练为"自包含的图像摘要"。强行拼接额外向量等于告诉下游网络"别全信 CLS"，但下游网络没有在预训练阶段学过如何处理这种拼接。 |

> **一句话**：Concat 本身是中性工具（信息不丢失），但在此实验中，CLS token 已经足够好，多给信息只是增加了过拟合燃料。

</details>

### 3.2 频域方向否决——三条独立证据线

#### 证据线 1：频域稀疏化损害性能（A1 vs A0b）

| 指标 | A0b (baseline) | A1 (modReLU) | 变化 |
|------|:---:|:---:|:---:|
| Val PCC | 0.3967 | 0.3724 | **-6.1%** ❌ |
| Val Loss | 0.3320 | 0.3394 | **+2.2%** ❌ |
| Train-Val Gap | 0.1600 | 0.2412 | **+50.8%** ❌ |
| 最佳 Epoch | 2 | 4 | 收敛延迟 |

> **解读**：modReLU 的幅度阈值截断了微弱频率分量。在自然图像/病理图像中，精细的纹理细节（如细胞核形态、染色质分布）往往对应低幅度频域分量——阈值截断直接丢弃了这些信息。Train-Val Gap 从 0.16 扩到 0.24 也提示截断后的稀疏表示更容易过拟合。

#### 证据线 2：CLS 频域旁路无机制优势（B1a ≈ B1b）

| 旁路方式 | Val PCC | Val Loss | 差异 |
|---------|:---:|:---:|:---:|
| GFNet 频域旁路 (B1a) | 0.3881 | 0.3297 | — |
| Mean Pooling (B1b) | 0.3955 | 0.3313 | +0.0074 |

> **解读**：用 GFNet FFT 做旁路 vs 直接取均值——频域旁路没有胜出。按本项目统一的 best-loss 口径，B1a 低于 B1b（0.3881 vs 0.3955）；按训练过程 peak PCC，两者几乎相同（0.3956 vs 0.3955）。这说明无论采用哪种口径，都看不到 GFNet 频域旁路相对 mean pooling 的机制性增量。

#### 证据线 3：两者均低于 Frozen 基线

| 实验系列 | 最佳 PCC | vs CLS Frozen 0.4113 |
|---------|:---:|:---:|
| A 线（Token 频域） | 0.3967 (A0b) | -0.0146 |
| B 线（CLS 频域旁路） | 0.3955 (B1b) | -0.0158 |
| **C 线（Token+LoRA）** | **0.4169** | **+0.0056** |

> **关键**：A/B 两条频域路线（包括不含频域的 B1b）均未超过 CLS Frozen 0.4113。Token 模式如果不加 LoRA，本质上是更弱的架构；只有加上 LoRA 才首次超越 CLS Frozen。

### 3.3 Token+LoRA 确立——C1 详细分析

#### C1 vs A0b（LoRA 增益分析）

| 指标 | A0b (Frozen) | C1 (LoRA r=8) | Δ LoRA |
|------|:---:|:---:|:---:|
| Val PCC | 0.3967 | **0.4169** | **+5.1%** |
| Val Loss | 0.3320 | 0.3321 | ≈持平 |
| Best Epoch | 2 | 3 | 窗口延长 |
| Train-Val Gap | 0.1600 | 0.1937 | +21% |

> **解读**：LoRA 在 GFNet Token 模式上的增益（+5.1%）与在 CLS 模式上（0.4113 → 0.4322, +5.1%）**完全一致**。这说明 LoRA 改善 UNI2-H backbone 特征的质量是一个跨架构通用的效应——无论下游用 CLS 还是 Token 编码器、用 Transformer 还是 GFNet 混合 token，LoRA 的低秩适配都能稳定提升泛化性能。

#### C1 vs CLS LoRA（当前差距）

| 维度 | CLS LoRA r=8 | Token+LoRA (C1) | 差距 |
|------|:---:|:---:|:---:|
| Val PCC | **0.4322** | 0.4169 | -0.0153 |
| 架构复杂度 | 简单 (CLS→MLP) | 中等 (Token FFT→MLP) | — |
| 计算开销 | 低 | 中（FFT/IFFT） | — |

> Token+LoRA 虽然 Token 模式历史最佳，但仍不如最简单的 CLS LoRA。增加的计算开销（FFT + 全局滤波器 + GFNetBlock）并未带来对应的性能提升——这是进一步质疑 Token 模式整体性价比的信号。

## 五、讨论与结论

> **结论前置**：GFNet 频域模块两阶段实验达到清晰收敛——三条独立证据线一致否定了频域增强在此任务上的有效性。Token+LoRA 成立但尚不足以挑战 CLS LoRA 主力地位。

### 5.1 频域为何在此任务上失效？

三个可能原因：

1. **H&E 病理图像信息不在频域稀疏**：自然图像可以通过丢弃高频分量压缩（JPEG 原理），但病理图像的精细纹理（细胞核染色质、胞浆颗粒、间质纤维）分散在多个频率分量中，不存在"少数强分量 + 大量可忽略弱分量"的稀疏模式。

2. **UNI2-H 特征已是"频域处理过的"**：Transformer 的自注意力本身就有 token 混合能力，UNI2-H 的 ViT 经过 24 层处理后，每个 token 已经是全局上下文的聚合表示。再在频域做一次 FF 变换——信息增益有限。

3. **15K 样本不足以训练频域滤波器**：GFNet 的全局滤波器（65 个频率 × 1536 维 = ~100K 复数参数）在小样本下容易学到训练集特异性模式，难以泛化到新患者。

### 5.2 从频域实验中暴露的四个结构性缺陷

频域方向虽然关闭，但实验过程中暴露了当前架构的四个更深层问题。这些问题**不依赖于频域方向成立与否**，而是影响所有后续改进方向的通用瓶颈。

#### 缺陷 1：参数量是第一约束 — 任何增加参数的操作都加速过拟合

> 通俗类比：当前 15K 样本就像只有 3 道真题的考试——模型容量已经足够"记住"所有训练样本。再多给参数等于多给"空白草稿纸"，只会让学生把题目噪声也抄上去。

| 实验 | Δ参数量 | ΔPCC | Epoch2 Train-Val Gap |
|:---|:---:|:---:|:---:|
| CLS Frozen → CLS LoRA r=8 | +极少 (LoRA 低秩) | **+5.1%** | 0.201→0.172 (收窄) |
| CLS Frozen → CLS Stage2 | +2 层 ViT Block 解冻 | ±0% | 0.201→**0.281** (+40%) |
| CLS Frozen → CLS Stage3 | +4 层 ViT Block 解冻 | **-1.4%** | 0.201→**0.336** (+67%) |
| GFNet Frozen → GFNet modReLU | +bias 参数 | **-6.1%** | 0.160→**0.241** (+50%) |

**规律：单调且一致**。只有 LoRA 的低秩约束（=强正则化）能稳定增益。任何放松参数约束的操作都导致过拟合加速。

#### 缺陷 2：所有改进集中在 224×224 patch 内部 — 完全忽略全切片 patch 间空间关系

每个 patch 的预测通过 `x_embed(pos_x) + y_embed(pos_y)` 仅加了一个可学习坐标偏置——这只是一个"这个位置的 patch 平均表达偏高"的先验，无法建模邻域平滑（相邻组织基因表达应高度相关）、空间梯度（肿瘤-基质交界）或全局上下文（肿瘤中心 vs 边缘）。

之前 GAT（0.4068，低于 Frozen 0.4113）和 EGN-v2+UNI 三折（0.3537/0.3909/0.3967）的失败表明：**参数化的空间图模型在小样本下会把空间噪声学进去，而非提取真实的邻域依赖。**

#### 缺陷 3：cls_patch64 仅取前 64 个 token — 丢弃每个 patch 底部 75% 的空间信息

```
UNI2-H 16×16 token grid:           cls_patch64 实际获取:
┌──────────────────┐              ┌──────────────────┐
│ ██ rows 0-3 (64) │ ← 保留       │ ██ rows 0-3 (64) │
├──────────────────┤              └──────────────────┘
│ .. rows 4-15     │ ← 丢弃           底部 75% 丢失
│   (192 tokens)   │
└──────────────────┘
```

这个截断是为控制过拟合而做的妥协（减少 token 数 → 减少 GFNet FFT 参数量），但病理关键结构（腺体、免疫浸润、坏死）可能出现在 patch 任何位置。

#### 缺陷 4：patch 边界 token 的空间连续性被切分破坏

相邻 patch 在原始组织中物理连续——P0 底部边缘 token 与 P3 顶部边缘 token 代表同一块组织的相邻区域。但 patch 切分后，这种空间连续性完全丢失：

```
┌────────┬────────┐
│  P0    │  P1    │     P0 底部行 15 ↔ P3 顶部行 0 = 同一块组织的相邻区域
├────────┼────────┤     但模型把它们当作完全独立的两个 patch
│  P3    │  P4    │
└────────┴────────┘
```

### 5.3 🆕 新方向：空间信息修复 — 三步路线图

> **核心思想转变**：后续不再问"能不能加一个更强模块"，而问"能不能在不增加自由度的前提下，把已经存在但被切块和采样破坏的空间信息恢复出来"。

#### 路线图总览

```
Step 1 (立即执行)          Step 2 (Step1 完成后)        Step 3 (Step2 正信号后)
┌────────────────┐       ┌──────────────────┐        ┌─────────────────────┐
│ cls_pool8x8    │  →    │ 零参数空间后处理   │   →   │ 训练内空间正则       │
│ token 采样修复  │       │ 现有预测上扫 alpha │       │ CLS LoRA + TV/Laplacian│
│ 零参数，全空间  │       │ 验证邻域平滑信号   │       │ 通路选择性加权        │
└────────────────┘       └──────────────────┘        └─────────────────────┘
    2 个实验                  先改预测导出坐标             2-3 个实验 (条件性)
    ~3h GPU×2                 再 ~30 min 分析              ~3h GPU×2
                              (无需 GPU)
```

#### Step 1: cls_pool8x8 — Token 采样修复 [P0，立即执行]

**原理**：将 cls_patch64（仅取前 4 行）替换为 2×2 平均池化——16×16 grid → pool → 8×8 = 64 tokens + CLS = 65 tokens。

| 属性 | cls_patch64 | cls_pool8x8 |
|:---|:---:|:---:|
| 参数量 | 0 | **0**（无参数 pooling） |
| 序列长度 | 65 | **65**（GFNet FFT 维度不变） |
| 空间覆盖 | 25% (仅 rows 0-3) | **100%**（全 16×16 grid） |
| 噪声抑制 | 无 | 2×2 pooling 自带均值降噪 |

**实验**：

| ID | 模型 | Mode | 对照基线 | 目的 |
|:---|:---|:---|:---|:---|
| S1a | GFNet frozen + cls_pool8x8 | frozen | A0b (0.3967) | 全空间覆盖能否提升 frozen？ |
| S1b | GFNet LoRA r=8 + cls_pool8x8 | lora | C1 (0.4169) | Token+LoRA 是否从全空间受益？ |

**决策门**：S1a ≥ 0.4067 → cls_pool8x8 替代 cls_patch64；S1b ≥ 0.4269 → 空间覆盖是 Token 路线关键瓶颈。

#### Step 2: 零参数空间后处理 [P1]

在现有模型预测上直接做空间平滑（无需重训），扫 α ∈ {0.05, 0.1, 0.15, 0.2, 0.3}：
```
pred_i' = (1-α) × pred_i + α × mean(pred_j for j in 6 nearest spatial neighbors)
```
升级版：用相邻 patch 边界 token 的余弦相似度作为平滑权重——直接回应缺陷 4。

**决策门**：最佳 α 带来 PCC +0.005 以上 → 空间平滑信号成立，触发 Step 3。

#### Step 3: 训练内空间正则化 [P1，条件性]

将 TV/Laplacian 正则直接集成到 CLS LoRA 训练 loss 中。历史 TV sweep（旧离线系统）已有正信号：l2 w=0.01→0.4170, laplacian w=0.1→0.4169。

**创新点**：通路选择性正则——ECM/Fibrosis/Wound/Angiogenesis/tls 等形态空间相关通路强平滑；Interferon/ifng/tgfb 等弱 H&E 可见通路不平滑，避免扩散噪声。

### 5.4 关键方法论教训

| 教训 | 说明 |
|------|------|
| **Smoke test 的信号会放大** | GFNet smoke 0.3933 vs Transformer 0.3724 看起来是 +5.6%，但正式训练仅 +2.4%，且修正 token 选取后基线提升到 0.3967——初始"微弱信号"其实是被低基线放大了。 |
| **机制对照是关键** | 没有 A0b/A1/B1a/B1b 的四点对照，无法区分"GFNet 结构改善"vs"频域处理改善"vs"任何旁路都有益"。这组对照给了关闭频域方向的信心。 |

### 附录 C：预判 Q&A（ML 专业听众）

#### Q1：GFNet 只在 65 token 上试验，如果 token 数量增大（如 265），频域利用效率会不会提升？

**A**：可能性存在但不高。265 token 的 FFT 等价于在更长的序列上做逐频率加权——如果 65 token 下频域稀疏化已经 -6.1%，增加到 265 token 只是放大了同一机制的弱信号。在 CLS Frozen 基线已明确高于所有频域实验的前提下，继续探索频域方向的机会成本（GPU 时间 + 注意力分散）不值得。

#### Q2：modReLU 的阈值是可学习的，是否存在"没调好参数"而非"方向错误"的可能？

**A**：modReLU 的 bias 是可学习参数，训练过程中梯度可更新。Epoch 4 的 val_loss 和 val_pcc 均劣于 A0b——模型已经有机会自行调整幅度门控。更重要的是，Train-Val Gap 从 0.160 扩大到 0.241（+50%），提示稀疏化系统性地加剧了过拟合——这是机制层面的问题，不是简单调一个固定阈值就能解决的。

#### Q3：B1a 和 B1b 都低于 CLS Frozen 0.4113，这个退化是因为加了旁路造成的吗？还是 token_select_mode 的变化？

**A**：这个问题问得很好——B1a/B1b 的 `token_select_mode` 同时从 `legacy_firstN` 切换到了 `cls_patch64`，存在混杂变量。CLS `cls_patch64` 本身可能就比 CLS `legacy_firstN` 差（这一点尚未做 CLS side 的 `legacy_firstN` vs `cls_patch64` 对照）。不过这不影响 B1a ≈ B1b 的核心结论——两个实验的 `token_select_mode` 相同，差异仅来自旁路方式（频域 vs 均值），频域无增量是干净的对照结论。至于 B1a/B1b 低于 Frozen 是 cls_patch64 的问题还是旁路架构的问题——这确实是未解决的问题，但这不影响"频域方向关闭"的判断。

#### Q4：Token+LoRA 0.4169 vs CLS LoRA 0.4322，你们认为 Token 模式还有可能追上来吗？

**A**：在 3 患者下大概率追不上——CLS LoRA 0.4322 有 0.0153 的稳定领先。Token 模式增加了序列建模复杂度但引入了更多参数（65×1536 的输入空间），在小样本下额外参数是负担而非资产。9 患者下 Token+LoRA 可能缩小差距但大概率仍落后 CLS LoRA——更强的 backbone 特征 + 更简单的预测头是在小样本病理任务上的一致最优组合。Token 模式的 ROI（投入产出比）低于 CLS 模式，但作为备选技术路线值得保留 Fold2/3 结果。

#### Q5：为什么对"阴性结果"花了这么多篇幅？

**A**：频域实验两阶段共 5 个实验（占最近 GPU 使用的主要份额），结论是清晰的方向关闭——这本身就是有价值的科学产出。写清楚"频域为什么不行"能避免自己或后来者在同一方向上重复踩坑。三个独立证据线（A1 退化 / B1a≈B1b / 均低于基线）提供了足够的论证强度来关闭这个方向。

#### Q6 🆕：为什么转向"空间信息修复"而不是继续试新模块？

**A**：8 个实验中 6 个失败（modReLU/B1a/B1b/Stage2/Stage3/EGNv2）的共同根因都是参数增加→过拟合加速。CLS LoRA 的成功（+5.1%）恰好反证了"低秩=强正则化"是关键。空间修复的三个步骤都遵循零参数或低参数原则：cls_pool8x8 是零参数的 avg pool；空间后处理完全不需要训练；TV/Laplacian 只加一个标量权重。这是从"表达能力不足"到"信息组织被破坏"的根本性诊断转变。

#### Q7 🆕：cls_pool8x8 的 2×2 pooling 会不会丢失细粒度信息？

**A**：有可能——如果某些通路依赖 1-2 个 token 级别的精细特征（如单个免疫细胞），pooling 后可能被平均掉。但当前 cls_patch64 直接丢弃了底部 75% 区域，信息损失是**确定性的 100% 丢失**，而 2×2 pooling 则是**所有区域都参与但分辨率降低**。两种信息损失的性质不同，pooling 的损失更可控。如果 S1a vs A0b 的逐通路对比显示某些通路显著下降，备选方案 cls_uniform8x8（stride=2 均匀采样 64 token）可以保留细粒度。

#### Q8 🆕：TV/Laplacian 在旧系统上只涨了 +0.003，为什么还值得在 CLS LoRA 上重试？

**A**：旧系统基线 ~0.4142，CLS LoRA 基线 0.4322——基线的"天花板"不同。旧系统可能已经接近其架构上限，+0.003 是微调；CLS LoRA 学习到的特征质量更好，预测的"空间噪声"成分可能不同，空间正则的边际收益也相应不同。关键是我们设计了 Step 2（零参数后处理）作为低成本验证——先用 30 分钟的 alpha sweep 判断空间平滑信号在 CLS LoRA 预测上的符号和幅度，再决定是否投入 GPU 做 Step 3。这避免了"训一个 epoch 发现没用"的浪费。
