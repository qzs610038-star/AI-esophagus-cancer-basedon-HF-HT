# 目录与汇总路由规则

## 固定成员目录

正式维护根目录为 `团队项目进度与结论/`，必须保留：

- `yzq/`
- `wzk/`
- `ljq/`
- `qzs/`
- `lzd/`
- `汇总/`

## 固定汇总板块

`汇总/` 下按用途维护：

- `Phase2与Phase3/`：模型、实验、阶段输入和阻塞结论。
- `论文写作/`：可进入论文的方法、结果、图表和限制。
- `训练数据/`：数据版本、修复、拆分、标签、质量和来源结论。

同一成果可以进入多个索引，但每个索引只写板块相关摘要并链接成员原文，不复制整份文档。

## 成员材料边界

- 原始成员资料保持原目录结构和内容。
- 新写的解释文档与原始材料分开保存，并标注来源。
- 不因格式统一而修改已纳入的原始文档、图片、表格或代码。
- 成员成果归属不清时停止正式写入，先请求用户确认。
