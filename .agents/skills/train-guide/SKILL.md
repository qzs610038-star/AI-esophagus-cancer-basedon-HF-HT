# Train Guide Compatibility Router

Read `../_shared/legacy-compatibility-policy.md` completely.

Lifecycle: `reference-router`.

Create a guide from the active experiment plan, manifest, registered paths,
critical contract, numbered workspace protocol, run-count decision, evidence
requirements, stop conditions, and return/import flow. Clearly label
code-pending automation and unresolved approvals. A guide is not a job approval
and must not contain an alternate ungoverned launch path.
