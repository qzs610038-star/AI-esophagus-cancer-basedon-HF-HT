# Visualization Guide Compatibility Router

Read `../_shared/legacy-compatibility-policy.md` completely.

Lifecycle: `reference-router`.

Use accepted or explicitly labeled pending source data, state the cohort,
protocol, metric definition, exclusions, and evidence scope, and preserve source
identifiers in the figure metadata. A plot is supporting material unless it is
explicitly registered as conclusion-bearing evidence; never infer acceptance
from visual appearance alone.
