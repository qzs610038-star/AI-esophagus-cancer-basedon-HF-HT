# 日常最小审查

## 入口与选择

方案定稿：只核对下面四项的约定，不为尚未编写的代码制造测试。代码包交付：沿真实入口查看对应实现，复用相关测试；新增或改变的行为才补诊断。仅修正文案／路径说明不启动本流程；实际输入来源变化属于数据行为变化。

四项分别记录“已查、复用证据、不适用、未核实”，不是四套必须运行的测试。默认同一智能体完成；不自动启动另一层审计。先执行本节基础检查；补充模块按下表选择，只读取命中的段落：

| 改变 | 阅读补充段落 |
|---|---|
| 编码器、图像变换、缓存读取 | 输入与缓存 |
| 空间图、关系损失 | 空间与关系，仅涉及的分支 |
| 热启动、恢复训练、历史结果复用 | 历史与恢复 |
| 不涉及以上内容 | 不加载补充检查 |

## 四个基础模块

### 实验约定与超参数

- **输入**：方案比较组、主要配置及实际执行入口。
- **动作**：列清本次改变和固定因素；核对重要默认值、命令行覆盖、恢复状态覆盖、分支激活条件和实际调用。代码阶段从优化器参数组等运行对象获取实际值；仅静态追踪时注明“代码可达，实际运行待验”。
- **预期**：设定与实现一致；批大小、梯度累积（如有）、更新次数、损失归约、预热／渐增、学习率和早停配合。日志中有值不等于该分支激活。
- **边界**：不将某个数值固化成项目最佳值；固定配方比较与各模型等预算调优比较分开解释。参数未搜索不判错。

只列与本实验有关的行：`参数 | 设定值 | 生效值或待验证 | 作用位置 | 设置依据`。覆盖本次涉及的优化参数、容量／正则、损失／温度、空间参数和选择参数；不抄录无关字段。设置依据可以是“控制变量”，不必虚构最优性证据。

### 数据与输入边界

- **输入**：划分、身份／通路清单、预处理来源、少量可追踪样本。
- **动作**：核对图像—特征—标签—坐标的连接键、重复／缺项／过滤及顺序，输出形状和有限值；检查训练拟合标准化的来源、患者／切片分组和外部数据不进入拟合／选模。元数据交集可便宜地全量检查，不因此扫描全部图像或大缓存。
- **预期**：按身份连接而非碰巧同序；标签、预测和通路一一对应；拟合及模型选择只用允许的数据。
- **边界**：身份和形状通过不证明标签物理区域正确；声明来源组不自动等于真实切片。无现场资产只标未核实，继续能完成的工作。

### 学习行为

- **输入**：预期可训练参数、实际模型／优化器／损失和已有小测试。
- **动作**：对新改动做小型前向，涉及训练逻辑时做必要的单步反向／更新；核对损失归约、掩码和广播、输出约束、冻结范围、模型训练／推理模式。将优化器实际参数与预期集合比较。
- **预期**：应训练的参数在相应激活阶段进入优化器并有符合设计的梯度／更新；冻结参数保持不变；数值有限。
- **边界**：零初始化、预热或冻结阶段可以合法没有某些梯度，不要求每个参数每步变化。不加载真实大编码器也可以核对头部；这种诊断不能证明服务器完整模型已验证。

### 选模与结果交付

- **输入**：主指标定义、选择／早停窗口、计划中的模型—种子—数据集合、预测来源。
- **动作**：新改选择逻辑时用短合成历史检查起点、同分与停止；从真实分析入口模拟完整和部分失败批次，查看最终报告是否传递缺项及批次失败。核对正式检查点与预测元数据绑定。
- **预期**：已完成部分可以分析，但不能悄悄遗漏失败模型并称完整。完整单种子无需三种子标准差；预期覆盖由方案决定，不固定三模型三种子。
- **指标约定**：分别标示患者—通路等权平均 PCC 与全部点位×通路 z 分数整体展平 PCC；另算 pooled_pathway_pcc 时独立命名。内部／外部及可用种子统计分开，不改变既定选模指标。不把同名不同聚合的 R² 等指标直接对比。
- **边界**：覆盖不足是部分结果，不自动说明已算出的指标错误；不能据此删除成功任务或要求重训。没有真实结果时，只声明分析逻辑的合成验证。

## 补充：输入与缓存

- **输入**：模型规范或版本化库说明、实际变换对象、缓存读取与元数据。
- **动作**：展开 RGB、缩放、插值、裁剪、归一化及默认值，检查可见视野、物理尺度声明和 CLS／平均 patch 等汇总取法；必要时让实验自身变换处理带边缘标记的合成图片。核对缓存来源、身份、版本和复用条件。
- **辅助文件场景**：方案声明可选时，用“主数据完整、仅辅助文件缺失”调用真实读取函数，主任务应可用；声明必需时则应给出明确缺失提示。不预先要求所有辅助文件都可选。
- **边界**：中心裁剪本身不是错误。实际裁剪与约定不符是实现偏差；与标签支持区域适配性未知是条件风险。官方示例与当前配方不同不自动否定有意控制变量的实验。

## 补充：空间与关系

- **空间输入／动作**：坐标单位、分组／划分边界、邻域和边权定义；用小图核对边界、孤立点、自环和权重归一化，调用实际构图／前向代码。
- **关系输入／动作**：近远例约定、距离、温度、掩码与归约；用合成输入核对有效中心、无候选边界、目标权重及分支激活。已有便宜诊断可查看候选数、目标熵或梯度量级，不规定通用“合格熵”。
- **预期**：实现符合约定，无不允许的跨界信息或广播；温度解释结合距离尺度，图半径解释结合坐标单位。
- **边界**：图密度不同、教师接近均匀、梯度较小等不直接判性能失败；有信号才建议独立敏感性实验，不自动扩大邻域或改温度。

## 补充：历史与恢复

- **输入**：指定来源检查点、当次配置／输出、继承范围、恢复记录。
- **动作**：区分继承模型权重与完整恢复优化器／调度器／随机状态；仅在声称完整续训时核对这些状态。核对正式检查点与预测来源，结合最终续跑状态解释初次失败；继承一致性容差应与精度约定相符。
- **预期**：实际恢复范围与声明一致，不用当前源码倒推当时执行；同名配置或文件存在不等于来源已核实。
- **边界**：历史源码缺失保留未知，不补造或自动判废；不支持恢复的实验没有义务新增续训功能。

## 辅助工具接口

单文件 [minimal_checks.py](../assets/minimal_checks.py) 可复制为包内 `tests/minimal_checks.py`，由包内测试调用，Python 3.10+，仅标准库。没有 CLI、自动扫描、训练导入或写文件副作用。输入由调用者从真实对象提取并转换为普通 Python 值；工具不证明提取路径正确。

- `check_identity_order(expected, actual, label="identity")`：输入可哈希身份键序列，可直接用患者／点位元组；也可另调用一次检查通路。返回缺项、多项、两侧重复与顺序错位样例。两边均空为未核实，不能算覆盖成功。
- `compare_contract(expected, observed, tolerances=None)`：输入按名称索引的约定／生效值字典；缺少 observed 键表示未核实，合法 `None` 值仍可比较。只检查声明的字段，不因运行对象有额外字段报错。默认精确比较；需要浮点容差时显式提供 `{字段: (相对容差, 绝对容差)}`，不内置科学参数标准。
- `check_result_coverage(expected, actual, batch_status=None)`：expected 为非空 `(model, seed, split)` 序列；actual 为含 `model/seed/split/status` 的记录序列。调用者将真实成功状态映射为 `succeeded`，其余状态原样保留。失败、未运行、缺项、多项、重复、未知状态均使 `complete=False`；批次状态若提供且不为 succeeded 也不能称完整。未提供批次状态只检验指定覆盖，不声称整个批次成功。expected 无声明时返回未核实。

返回值都是普通字典。身份／约定的已观察不一致返回 `FAIL`，只有缺证据为 `UNVERIFIED`；覆盖不完整返回 `WARN`，由真实报告是否误称完整决定是否存在实现错误。工具不抛科研“门禁”异常，不自动阻断任务；输入结构错误会抛 Python 参数异常，属于调用需要修正。

维护辅助文件时，在仓库根目录执行 `python -B -m unittest discover -s .agents/skills/pfmval-audit/tests -v`。测试包含复制到隔离临时目录、禁用站点依赖的独立运行。实验包使用者运行本包的实际调用测试，不需要每次重跑技能维护测试。

```python
from minimal_checks import compare_contract, check_result_coverage

# 期望取自冻结方案；实际取自已构造的优化器，不从配置复制。
check = compare_contract({"lr": planned_lr}, {"lr": optimizer.param_groups[0]["lr"]})
# 多参数组必须分别命名检查，不能用第一组代表全部。
coverage = check_result_coverage(
    [("uni", 42, "internal_val"), ("virchow2", 42, "internal_val")],
    actual_records, batch_status=actual_batch_status,
)
# 将 coverage 的缺项和失败清单传到用户可见报告；只调用工具不算完成集成验证。
```

## 记录和结束

用 [简短记录模板](../assets/minimal-review-record.md)，只列适用项与关键证据。未触发模块可合并一行写不适用；不为排版扩成长报告。已有检查充分时结束，不为“提高覆盖率”再跑全套。模块外检查仅按 [技能入口的范围扩展条件](../SKILL.md) 执行；“存在疑点”本身不等于可以扩大范围。发现具体科学错误不作正式可用声明；缺服务器资产、参数未搜索等记录后继续编写。新规则只面向后续相关工作，不追溯迁移旧结果。
