# 双语伪代码与图表规则

## 双语伪代码

- 中文块解释研究逻辑、条件和后续行为。
- 英文块保持真实代码中的变量名、函数名、参数名和主要调用次序。
- 每个英文伪代码块附近必须有真实代码链接，优先定位到行号。
- 不得虚构实现中不存在的变量或函数。
- 真实代码若使用内部变量名，可在英文伪代码保留；面向队友的中文正文必须展开其具体条件。

## 图表归档

- 正文引用的图表必须位于 qzs 的 `可视化图表/` 内。
- 已有权威图直接复制，保留源链接并逐文件比较 SHA-256。
- 缺失图根据可核验数据绘制，同时保存 PNG 与 SVG。
- 绘图数据可复制为 CSV，或链接不可变结果文件。
- 不从不完整结果推断缺失指标；明确写“待补图”和建议参考文件。
- 禁止使用截断柱状图或不说明局部尺度的坐标轴夸大微小差异。
- 图题、坐标、图例和限制说明优先使用中文。

## 主代理复核

即使图表由子代理绘制，主代理仍需逐图确认：数据值、方向、对照关系、坐标尺度、证据范围、中文可读性和输出路径。
