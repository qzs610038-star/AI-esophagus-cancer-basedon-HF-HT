# 实验章节固定结构

实验标题下先写完成日期及证据链接，然后依次写四个可折叠部分：

1. `采用的方案`
2. `比较条件、实际结果与下一步`
3. `实现代码与中英文对照伪代码`
4. `图表与数据来源`

四个 `<details>` 必须完整闭合，编号不得缺失、重复或交换。

第二部分不得只写内部简称，应采用以下句式：

> 事先要求……。实际结果为……，已满足/未满足……条件。因此下一步……。

结论必须同时写限制，例如外部 Raw R² 仍为负值、空间元数据不足、只有单随机种子或实验不是完整并行对照。

修正既有内容时不改变原四段，只在需要修正的位置追加带日期的独立补充说明。
